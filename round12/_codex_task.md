# Codex 작업 지시 (round12 — blind 아님, 검증 전용)

[CROSSCHECK_WORKER] 이 폴더(`round12/`) 안의 파일들과 `../PROBLEM.md`만 근거로 검토를 수행한다.
새로운 웹 조사나 창작은 하지 말 것 — 이미 작성된 번역을 원문과 대조하는 작업이다.

## 이 폴더의 파일
- `원문1_추출텍스트.txt` — 선행연구 1(Kwon 2021, 3페이지) PDF에서 추출한 원문 텍스트(pdfplumber
  추출이라 일부 줄바꿈·OCR 순서가 깨져 있을 수 있음. 특히 수식 부분은 글자가 뒤섞여 있으니 문맥과
  물리적 타당성으로 해석할 것).
- `원문3_추출텍스트.txt` — 선행연구 3(Kwon et al. 2024, 19페이지) PDF에서 추출한 원문 텍스트
  (마찬가지로 일부 깨짐 있음, 특히 페이지 6, 14 부근의 수식 (8)(9)).
- `선행연구1_Kwon2021_번역.html` — Claude가 작성한 한국어 완역본.
- `선행연구3_Kwon2024_번역.html` — Claude가 작성한 한국어 완역본.

## 할 일
`../PROBLEM.md`에 적힌 5가지 관점(완결성, 기술적 정확성, 수식 정확성, 참고문헌 정확성, 저작권
판단 검증)에서 두 HTML 번역본을 각각의 원문 추출 텍스트와 대조 검토한다.

특히:
- 저작권 판단(선행연구 1 = 미국 정부 저작물, 선행연구 3 = CC BY 4.0)의 근거 문구를
  `원문1_추출텍스트.txt`, `원문3_추출텍스트.txt`에서 직접 찾아 그대로 인용해서 확인할 것.
- 선행연구 3의 식 (8), (9)(HTML의 6.2절)는 Claude가 "원문 폰트 인코딩이 깨져서 미시역학적으로
  타당한 형태로 재구성했다"고 명시해 두었다. `원문3_추출텍스트.txt`에서 해당 수식 부분의 깨진
  텍스트를 보고, Claude의 재구성이 합리적인지, 혹은 명백히 다른 구조라면 어떤 구조가 맞는지
  판단할 것.
- 각 절(섹션) 제목과 문단 수를 원문과 번역본에서 대략 세어, 누락된 절이나 문단이 없는지 확인.
