# Codex 독립 검증 결과

## 결론

최종 대조 PDF는 원본 126쪽과 한국어 번역 126쪽을 1:1로 대응시킨 126쪽 A3 가로 문서다. 왼쪽에는 원문 페이지 전체 이미지를 배치하고 오른쪽에는 동일 페이지의 한국어 번역을 배치했다. 이 구조로 원본 수식, 그림, 표와 레이아웃을 그대로 보존하면서 페이지별 번역 누락을 확인할 수 있게 했다.

## 객관 검증

- 원본 `pdfinfo`: 126쪽, Letter, 암호화 없음.
- 원본 페이지 이미지: 126개 생성. 텍스트 추출이 빈 17쪽과 103쪽은 실제 이미지도 빈 페이지임을 직접 확인했다.
- 번역 파일: `page_001.txt`부터 `page_126.txt`까지 126개, 모두 비어 있지 않음.
- 최종 PDF: 126쪽, A3 landscape, 한국어 페이지 표제 126개, 추출 가능한 한글 71,945자.
- 수치 보존 자동 대조: 임계치 미달 플래그는 없었다. 일부 쪽은 각주 결합, 범위 하이픈, 지수표기 분리 때문에 토큰 단위 보존률이 100% 미만으로 계산되었으며, Claude 최종 검토가 대표 7쪽을 원문과 대조해 실제 수치 누락이 아니라 추출·토큰화 차이임을 확인했다.
- 자동 QA가 43, 92, 116쪽을 `possible_summary`로 표시했으나, 이는 원문의 문구 `In summary`가 한국어 `요약하면`으로 정확히 번역된 데 따른 오탐이다. 세 쪽을 원문과 직접 대조해 본문, 수치, 식 번호, 변수 정의가 모두 포함됨을 확인했다.
- DOM 기반 오버플로 검사: 번역 패널 126개, `overflow=true` 0개.
- 최종 PDF 전 126쪽을 8개의 연락판으로 렌더링해 잘림, 겹침, 검은 사각형, 한글 글꼴 깨짐이 없음을 확인했다.
- 1, 18, 43, 78, 92, 116, 126쪽을 150 dpi로 별도 렌더링해 표지, 본문, 수식, 표, V&V 절, 참고문헌의 가독성을 확대 점검했다.
- 용어 정규화: `coalescence`의 번역을 27개 페이지에서 `병합`에서 `합체`로 통일했다.

## 한계와 판단

텍스트 추출로 재조판한 오른쪽 번역면의 일부 수식은 분수선, 위첨자와 아래첨자의 시각적 형태가 단순화된다. 그러나 동일 쪽 왼쪽에 원본 페이지 전체가 원형 그대로 포함되어 모든 수식과 기호를 정확히 확인할 수 있으므로, 사용자의 수식·그림 보존 요구는 충족한다. 표도 오른쪽에는 행 텍스트가 번역되어 있고 왼쪽 원본 표의 격자와 배치가 그대로 보존된다.

참고문헌의 저자명, 문헌명, 학술지명은 검색·추적 가능성을 위해 원문 표기를 유지했다. 이는 본문 누락이 아니라 학술 번역의 표준적인 서지 보존 처리다.

## 설치·설정 점검 결과

- Codex CLI 0.162.1: 최신이며 npm 설치 일관성, 인증, 네트워크, 상태 DB는 정상.
- 충돌 1: PowerShell의 유효 실행 정책이 npm `codex.ps1`을 차단한다. `codex.cmd` 직접 호출 또는 프로세스 한정 `-ExecutionPolicy Bypass`로 안전하게 우회 가능하며, 영구 정책은 변경하지 않았다.
- 충돌 2: `codex doctor`가 Windows elevated sandbox provisioning의 `helper_unknown_error`를 기록했다. 진단 권고는 승인된 배포판으로 CLI 복구 또는 재설치다. 본 작업은 승인된 외부 실행과 제한된 작업 폴더를 사용해 완료했다.
- 경고: `CODEX_WINDOWS_REGISTERED_CORE` 환경변수 누락으로 선택적 `node_repl` MCP 경고가 있다. PDF 번역·출력에는 영향을 주지 않았다.
- Claude Code 2.1.296은 정상 실행되었고 126쪽 번역 배치를 모두 성공시켰다.
