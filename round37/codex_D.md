## 자료와 판정 범위

- 대상: `round37/audit_p33.txt`의 `===== HTML SLIDE N =====` 기준 1~33. 전체 32개 `[EQUATION TeX]` 블록, 모든 비어 있지 않은 행, 각 행의 문장·표 셀·수치·인용을 대조했다.
- 기준 자료: Kyle Schmitt, EPRI, *xLPR Models Subgroup Report—Crack Growth and Coalescence*, xLPR-MSGR-CGR Ver.1.0, 2016-06-29. 원문 파일: `J:\Desktop\XLPR\2026_10_13_XLPR모델분석\cgr_text.txt`. 이하 모든 영어 인용은 이 보고서에서 가져왔다. 페이지는 인쇄 쪽이며, `=====PAGE n=====`의 n−1이다.
- 이미지 확인: `pages/p022.png, p028.png, p034.png, p035.png, p039.png, p040.png, p041.png, p043.png, p044.png, p045.png, p049.png, p050.png, p053.png, p056.png, p057.png, p058.png, p073.png, p074.png, p120.png, eq225.png`. 제공된 수식 이미지와 텍스트를 함께 확인했다. 표 2-1·3-1·3-2·3-3·3-4·3-5는 원문 텍스트의 해당 행을 대조했다.
- CONFIRMED는 제공된 대상 파일과 원문 사이의 차이를 직접 확인했다는 뜻이다. 수식 2-22·6-2의 잘림은 대상 추출본에서 확정되지만, 실제 HTML 렌더링까지 손상됐는지는 확인 불가다. 원문/HTML 재추출이나 자동화 스크립트 실행은 하지 않았다.
- 원문 자체에 있는 수치·식·내부 불일치는 임의로 고치거나 HTML 오류로 돌리지 않았다. 원문의 다른 쪽에 실제로 있는 설명은 ‘추가 주장’으로 판정하지 않았다.
- COINED-TITLE은 사용자 규칙에 따른 편집 형식 지적이다. 수식 설명의 물리적 오류와 같은 의미가 아니다. 한 슬라이드의 새 제목·소제목·라벨을 한 건으로 묶었다. 순수 번역어, 식 번호, 기호의 통상적 한글 표기는 그 자체로 오류로 세지 않았다.
- git pull은 시작할 때 시도했으나 `.git/FETCH_HEAD: Permission denied`로 실패했다. 검사는 현재 로컬 파일 기준이다. 결과 작성 후 이 파일만 지정하여 git add를 시도했으나 `.git/index.lock: Permission denied`로 실패했으므로 커밋·푸시는 수행하지 못했다.
