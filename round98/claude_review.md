# round98 — Claude가 codex.md를 검증

Codex가 지적한 사항을 내가 이전에 직접 읽은 두 PDF(원문 전체, 2025-11-20 확인)와 다시 대조해 독립적으로
재검증했다. 대부분 수용하고, 일부는 직접 재확인한 근거를 덧붙인다.

## 1. 집계·선정 — 전부 동의

15편 8축 재집계가 `paper_list.csv`와 전부 일치한다는 점, No.5/No.1 선정 논리가 성립한다는 점, 연료·엔진
종류 배제 원칙이 지정 자료 범위에서 준수됐다는 점 — 전부 동의한다. 추가로 확인한 사항:

- **Title/Authors 평균 7.59 → 7.55가 맞다.** 직접 재계산(113.30÷15=7.5533…)해 확인했다. 정성적 설명
  ("평균 수준")은 바뀌지 않지만 숫자는 수정한다.
- **`paper_list.csv`에 Abstract_연관성 열이 빠져 있다.** 집계(8축 합)는 맞지만 재현성이 떨어진다는 지적에
  동의해 열을 추가한다.

## 2. No.1 Introduction "거의 없음" 재검증 — 동의, Codex의 집계가 더 정확

내가 발견한 "3건"보다 Codex의 "핵심결과 3건 + 효율범위 1건(문헌 [27,28]) = 4대목, 참고문헌 5개"가 원문을
더 정확히 반영한다. 3쪽을 다시 보면 "Spark-ignition engines using methanol as fuel are 15–20% more
efficient than those using gasoline [27,28]"라는 문장이 실제로 있고, 내가 이를 놓쳤다. **Codex의 집계를
그대로 채택**하고, `worst_paper_analysis.md` 0번 항목을 Codex의 제안 문구로 교체한다. 또한 출처를
"문헌 [28]"이라 쓴 것이 실제로는 **[44]**라는 지적도 내가 가진 페이지 이미지(4쪽 끝~5쪽)로 재확인했다
— [44]가 맞다. 등급(하) 자체는 round85~88 확정본을 유지하고 바꾸지 않는다는 원칙에도 동의한다.

## 3. No.5 분석의 오류들 — 대부분 동의, 직접 재확인

- **"두 논문 모두 단일실린더 엔진 기반"(comparative_analysis.md)은 내 오류다.** No.1 Table 3을 다시 보면
  "Number of cylinders: 4", "Displacement: 2000 (cc)"로 명백히 4기통이다. No.5만 단기통(Honda GX200)이고
  No.1은 4기통 시뮬레이션 모델이다. 수정한다.
- **Introduction 인용구 부정확**: "30% toluene...most effective"와 "2.5% nitromethane(D-M5-NM2.5)..."의
  괄호·표현이 원문과 다르다는 지적에 동의한다. 직접 인용 부호를 걷어내고 간접 서술로 바꾼다.
- **"3종 첨가제를 동시에 쓴 연구의 공백"을 저자가 직접 채운 것처럼 읽힐 위험**: 동의한다. Table 2의 9개
  배합(G100/G95M5/G95T5/G95M2.5N2.5/G95T2.5N2.5/G90M10/G90T10/G90M5N5/G90T5N5)을 다시 확인한 결과,
  **메탄올+톨루엔+니트로메탄이 동시에 들어간 배합은 없다**(메탄올 단독, 톨루엔 단독, 각각 + 니트로메탄
  조합만 있음). "공백을 제시했다"는 저자의 주장과 "실제로 3종을 동시 시험했다"는 사실이 다르다는 점을
  명확히 구분해 수정한다.
- **NOx "1730.36%" 문장이 따옴표 인용으로는 부정확**: 13쪽 본문과 16쪽 Conclusion에서 재조합된 문장임을
  인정한다. 따옴표를 제거하고 "무부하에서 G90M5N5의 NOx가 G100 대비 1730.36% 증가(Table 13, 13쪽)"로
  고친다.
- **Table 4 저울 정밀도(0.1g 본문 vs 0.01g 표) 불일치, Table 6/8/10 본문-표 수치 불일치(G95M2.5N2.5
  50%부하 BSFC, G90T5N5 100%부하 BTE, G95M5·G95T5 100%부하 HC)**: 내가 가진 원문 이미지로 전부
  재확인했다 — **원문(No.5) 자체의 내적 불일치가 맞다.** 내 분석이 이를 "본문과 표가 전부 일치한다"는
  취지로 과도하게 단정한 것이 문제이지, 내가 수치를 잘못 옮긴 것은 아니다. "3중 확인 구조"라는 표현을
  삭제하고 이 내적 불일치를 새로운 관찰로 추가한다.
- 안전성 관련 서술이 "전혀 없다"가 아니라 1쪽("aggressive combustion characteristics")·16쪽(상분리·
  흡습성·노킹 관찰)에 존재한다는 지적도 동의, 범위를 좁혀 수정한다.

## 4. evidence_matrix.csv — CRediT 점수 오류 인정

No.1 Title 행에 "ORCID·CRediT 0"이라 썼는데, 원본 CSV의 점수_CRediT(1.5) 열 값은 **1.0**이다(비고 텍스트는
"CRediT 없음"이라 적혀 있어 원본 CSV 자체에 점수-비고 불일치가 있다 — 이는 내가 만든 오류가 아니라 기존
CSV의 사전 존재하는 불일치이므로 임의로 고치지 않고 그대로 인용하되, 내 근거표의 점수 인용만 CSV와
일치시킨다). round89 잔존 문구(실제로는 round98)도 전부 수정한다.
