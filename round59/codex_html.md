# round59 HTML 전수 대조 (Codex)

## 대상과 판독 기준

- 읽은 HTML은 `round59/input/b052_html.html` 복사본뿐이다. XLPR 폴더의 원본 HTML은 열거나 수정하지 않았다.
- 근거는 B052 PDF 93쪽의 지면이다. PDF 11~93쪽은 기존 300dpi PNG(2550×3300)를 전쪽 직접 판독했고, PDF 1~10쪽은 이번에 300dpi로 렌더링해 판독했다. 작은 식·첨자는 600dpi 확대도 확인했다. PDF 텍스트 추출은 판정 근거로 사용하지 않았다.
- `round59/PROBLEM.md`, 본인의 이전 `round59/codex.md`를 참고했다. 다른 AI의 보고서는 읽지 않았다. 이전 전사도 지면과 다르면 그대로 채택하지 않았다.
- 카드 번호는 HTML의 `id="pN"`이다. 아래 쪽수는 **인쇄쪽 / PDF쪽** 순서다. 앞부분의 인쇄쪽 미표기는 PDF쪽만 적었다.
- 실제 집계는 **data-tex 40개, table 요소 63개**다. 수식은 HTML 엔티티를 해석한 값으로 비교했다. 표는 문자열뿐 아니라 `rowspan`·`colspan`이 만드는 행·열 대응까지 비교했다.
- 접힌 **원문 영어 보기(details)**도 HTML에 포함된 내용으로 보았다. 그 안에 남아 있는 문장은 HTML 전체 누락으로 세지 않았다. 번역에서만 빠진 내용은 별도로 표시한다. 편집용 제목·쪽 안내와 원문 밖의 실질적 설명/검증 주장을 구분한다.
- 확신도 높음: 지면과 HTML에서 직접 확인. 중간: 작은 그림의 원래 해상도 때문에 판독 한계가 있음. `원문그대로`는 HTML 오류가 아니다. 아래 판단은 외부 문헌에 따른 교정이나 모델의 타당성 판단을 포함하지 않는다.
