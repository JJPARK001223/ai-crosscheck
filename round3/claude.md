# Round 3 — Claude blind 유도 (완전한 식 경로)

작성: Claude (오케스트레이터). Codex 답을 보지 않은 상태에서 독립 유도.

주제: Kwon et al. (2024) *Materials* 17, 569 §4 (HCP 3점굽힘 균열) 재현 + 파괴하중 역산
과업에 필요한 **모든 식의 유도 경로**.

## Part A. 파괴기준 자체

### A1. 변형에너지밀도 U = σ²/2E
1축 선형탄성: σ = E ε.
단위부피당 변형에너지(변형에너지밀도):
  U = ∫₀^{ε} σ(ε') dε' = ∫₀^{ε} E ε' dε' = ½ E ε².
ε = σ/E 대입:
  U = ½ E (σ/E)² = σ² / (2E) = ½ σ ε.
→ **정확**. σ–ε 선도의 삼각형 넓이와 동일.

### A2. 선1 식(2) → 식(3)
식(2) 좌변 =
  [ σ_l² / (2E) ] ÷ [ (1/σ_l) |dσ_l/ds| ]
  = [ σ_l² / (2E) ] · [ σ_l / |dσ_l/ds| ]
  = σ_l³ / ( 2E |dσ_l/ds| ).
|dσ_l/ds| = 1 / |ds/dσ_l| 이므로
  = ( σ_l³ / 2E ) |ds/dσ_l|  ≥ w_f.
→ **정확**. 식(3)과 일치.

### A3. 선3 식(2) ⇔ 선1 식(3)
선3 식(2): σ_e ≥ ( 2 E Y |dσ_e/ds| )^{1/3}.
양변 3제곱(양변 ≥ 0):
  σ_e³ ≥ 2 E Y |dσ_e/ds|
  ⇔ Y ≤ σ_e³ / ( 2E |dσ_e/ds| ) = ( σ_e³ / 2E ) |ds/dσ_e|.
파괴 임계에서 등호. 선1 식(3)에서 w_f→Y, σ_l→σ_e 로 치환한 것과 **형태 동일**.
→ **정확**. 두 논문의 구배조건은 같은 식, 이름만 w_f ↔ Y.

단위 점검: [σ³ / (E · σ/길이)] = [σ² · 길이 / E] = (Pa²·m)/Pa = Pa·m = J/m³·m = J/m². ✓

## Part B. 균열에 적용 → K 연결

### B1. Mode I 근접장 (θ = 0)
Williams/Irwin 급수의 선단항, θ=0:
  σ_xx = σ_yy = K_I / √(2πr),  τ_xy = 0.
선1 식(4): σ_x = K_I / √(2πr) = ( K_I / √(2π) ) · r^{−1/2}.
선3 식(3): σ_e = K / √s,  여기서 s ≡ r,  **K ≡ K_I / √(2π)**
  (표준식 σ = K_I/√(2πs) 와 비교하면 자동으로 나옴).
→ **정확**. 단 K(선3)와 K_I(표준)의 정의 차이 √(2π) 를 명시해야 함.

### B2. 응력 구배
선1 식(5):
  dσ_x/dr = ( K_I / √(2π) ) · ( −1/2 ) · r^{−3/2} = − K_I / ( 2 √(2π) · r^{3/2} ).
  |dσ_x/dr| = K_I / ( 2 √(2π) · r^{3/2} ).
선3:
  dσ_e/ds = K · ( −1/2 ) · s^{−3/2} = − K / ( 2 s^{3/2} ).
  |dσ_e/ds| = K / ( 2 s^{3/2} ).
→ **정확** (거듭제곱 미분: d/dr[r^{−1/2}] = −½ r^{−3/2}).

### B3. 선1 식(3) 등호에 B1·B2 대입 → w_f (선1 식 6)
w_f = σ_x³ / ( 2E |dσ_x/dr| ).

분자:
  σ_x³ = ( K_I / √(2π) )³ · r^{−3/2}
       = K_I³ / (2π)^{3/2} · r^{−3/2}.

분모:
  2E |dσ_x/dr| = 2E · K_I / ( 2 √(2π) r^{3/2} )
              = E K_I / ( √(2π) · r^{3/2} )
              = ( E K_I / (2π)^{1/2} ) · r^{−3/2}.

나눗셈 (r^{−3/2} 소거):
  w_f = [ K_I³ / (2π)^{3/2} ] / [ E K_I / (2π)^{1/2} ]
      = ( K_I³ / (2π)^{3/2} ) · ( (2π)^{1/2} / (E K_I) )
      = K_I² · (2π)^{1/2} / [ (2π)^{3/2} · E ]
      = K_I² / [ (2π)^{3/2 − 1/2} · E ]
      = K_I² / ( (2π)^{1} · E )
      = **K_I² / (2πE)**.   → 선1 식(6). ✓ r 소거됨.

핵심 대수: (2π)^{1/2} / (2π)^{3/2} = (2π)^{1/2 − 3/2} = (2π)^{−1} = 1/(2π). **정확**.

식(7): w_f = K_I²/(2πE) 를 K_I 에 대해 풀면
  K_I² = 2πE w_f  →  **K_IC = √(2πE w_f)**. ✓

### B4. 선3 식(4) → Y
Y = σ_e³ / ( 2E |dσ_e/ds| ).
분자: σ_e³ = ( K/√s )³ = K³ s^{−3/2}.
분모: 2E · K/(2 s^{3/2}) = E K s^{−3/2}.
  Y = K³ s^{−3/2} / ( E K s^{−3/2} ) = K² / E.  → **선3 식(4)**. ✓ s 소거됨.

### B5. w_f ≡ Y, 그리고 G 관계
  Y = K²/E = ( K_I/√(2π) )² / E = K_I² / (2πE) = w_f.  → **정확, 두 논문 완전 일치**.

에너지방출률(평면응력): G = K_I² / E.
  → Y = K_I²/(2πE) = **G / (2π)**  (≈ G/6.283).
논문 문장 "Y is equivalent to the critical energy release rate" 는
  **정성적으론 맞고(에너지/면적 차원, J/m²) 수치적으론 2π배 틀림**.
  실무 영향: Y 를 시험에서 역산하므로 정규화 상수는 상쇄 → 예측엔 무해.
  금지: 문헌의 G_c (J/m²)를 Y 자리에 그대로 대입 → 2π배 오차.

평면변형: G = K_I²(1−ν²)/E. 논문은 E 를 그대로 써서 Y=K²/E 로 정의 →
  **평면응력 관례**. (여기서 ν 논의가 등장, B/C7 참조)

## Part C. 시멘트 3PB 균열 모델 해석에 필요한 식

### C1. 기하 관계
- L / H = 4  (논문 §4.1 명시).
- a / H ∈ {0.1, 0.3, 0.5}  (Fig 11 x축).
- H ∈ {50, 100} mm  (Fig 11 범례 "H = 0.05 / 0.1 m").
- W = 100 mm  (논문 §4.1 명시, 균열 폭방향 관통).
- a = (a/H) · H  →  {5, 15, 25} mm (H=50),  {10, 30, 50} mm (H=100).
- 지지 스팬 S ≈ L = 4H  (Fig 8: 양단 롤러, 절반모델 L/2). 3점굽힘.
→ 이 관계들은 유도가 아니라 **채택·판독값**. "식"이라기보다 입력.

### C2. FE에서 K 추출 — 곡선맞춤 (Fig 10)
1. 선형탄성 FE, 임의 단위하중 P₀ 적용.
2. 균열선(균열면 연장선, 최대주응력에 수직) 따라 절점 응력 σ_e(s) 추출,
   s = 균열 선단에서의 거리.
3. 이론형 σ_e(s) = K̂ / √s = K̂ · s^{−1/2} 로 **최소자승 피팅**.
   실무: ln σ_e = ln K̂ − ½ ln s → 기울기 −½ 확인, 절편 = ln K̂.
   (선단 극근방 절점은 FE 특이점 오차로 제외, K-지배영역 구간만 사용.)
4. 하중 선형성(LEFM): K ∝ P →  **K / P = K̂ / P₀**  (단위하중당 K).
→ 이것이 논문이 §4.3에서 말한 "K was obtained from 2D FE ... curve fit using Eq (3)".

### C3. 파괴값 Y 보정 (케이스 4: a/H=0.1, H=100 mm)
- 이 시편의 실험 파괴하중 P_f,4 는 Ref [39](Karihaloo et al.)에서 알려짐.
- 파괴 순간의 K:  K_f,4 = ( K/P )_4 · P_f,4.
- 식(4) 적용:  **Y = K_f,4² / E**.   (E = 20.8 GPa, 논문 §4.1)
- 이 Y 는 재료상수이므로 **딱 1회만** 계산, 나머지 5개에 재사용.
- 왜 케이스 4?  H 최대 + a/H 최소 → 리가먼트 (H−a) 최대 → FPZ 상대크기 최소,
  K-지배영역 최대 → 곡선맞춤 K 신뢰도 최고 (논문 §4.3 명시적으로 이 시편 사용).

### C4. 나머지 5개 파괴하중 예측
파괴 조건: 케이스 i 의 응력장이 식(4)를 만족, 즉 Y = K_{f,i}² / E.
  → K_{f,i} = √( E Y )   (논문 정의 K 기준).
논문 K 기준 일관 표기:
  **P_pred,i = √(E Y) / ( K/P )_i**.
표준 K_I 기준으로 바꾸면 K_I = √(2π) K 이므로 K_{I,f} = √(2π) √(EY) = √(2πEY),
그리고 (K_I/P)_i = √(2π) (K/P)_i 이므로
  **P_pred,i = √(2πEY) / ( K_I/P )_i**.
두 표기는 √(2π) 가 분자·분모에 동시에 곱해져 **동일 값**. ✓
(주의: (K/P)_i 를 FE에서 뽑을 때 σ_e = K̂/√s 로 피팅했으면 그 K̂ 는 "논문 정의 K".
 σ_e = K_I/√(2πs) 로 피팅했으면 K_I. 표기를 섞지 말 것 — 이게 실수 포인트.)

### C5. Fig 11 비교
P_pred,i (i=1..6, i=4 는 보정점이라 자동 일치) vs P_exp,i.
논문 결과: 5/6 일치, 케이스 5(a/H=0.3, H=100mm)만 불일치 (논문도 원인 미규명).

### C6. (검산 옵션 — 논문엔 없음) SENB 핸드북 K
논문은 FE 곡선맞춤으로 K 를 얻지만, 사전 검산·타당성 확인용으로 ASTM E399
3점굽힘(SENB) 핸드북식:
  K_I = [ P · S / ( B · D^{3/2} ) ] · f(α),   α = a / D.
표기 충돌 주의:
  D = 시편 깊이(빔 높이) = **우리 H**,
  B = 시편 두께 = **우리 W = 100 mm**,
  S = 지지 스팬 = **4H** (S/D = 4).
형상함수 (S/D = 4):
  f(α) = 3√α · [ 1.99 − α(1−α)(2.15 − 3.93α + 2.7α²) ] / [ 2(1+2α)(1−α)^{3/2} ].
  f(0.1) ≈ 0.847,  f(0.3) ≈ 1.52,  f(0.5) ≈ 2.66.
이걸로 (K_I/P)_i 를 근사 → C3·C4 에 넣어 사전검산.
정식 재현은 반드시 FE 곡선맞춤 사용.

### C7. 평면응력 / 평면변형 & ν
- LEFM 에서 **K_I 자체는 기하 + 하중만의 함수**, ν 무관.
- 2D 해석 선택(평면응력 vs 평면변형)은 균열선 응력분포·변위엔 영향을 주지만,
  K 값(원거리장 대비 스케일)은 사실상 불변. 곡선맞춤 K 도 거의 불변.
- ν 가 들어가는 곳은 **G–K 관계뿐**: 평면변형 G = K_I²(1−ν²)/E.
- 논문은 Y = K²/E (E 그대로) → **평면응력 관례**를 따름.
- 따라서 ν = 0.20 가정은 FE 실행(재료물성 입력)엔 필요하지만
  **최종 Y 역산·파괴하중 예측엔 거의 상쇄**되어 결과 민감도 낮음.
- W = 100 mm 로 두껍고 관통균열이므로 물리적으로는 평면변형에 가깝지만,
  논문 방법론과 일관성을 위해 **평면응력 + E 그대로** 사용 권장 (논문 재현이 목적).

## 누락/과잉 점검 (Claude 자체 평가)

### 반드시 필요한데 위에 명시 안 된 것 (보완)
- **σ_e 의 정의**: 등방 취성재 → σ_e = 최대 주응력 σ_1 (논문 §2). HCP 는 취성이므로
  균열선에서 σ_e = σ_yy (개구응력). 이걸 명시해야 C2 의 "어떤 응력을 뽑나"가 확정됨.
- **파괴 경로 s 의 방향**: "취성재는 최대 주응력축에 수직" (논문 §2 식(2) 밑).
  3PB 균열에서 s = 균열면 연장선(수평), σ_1 은 수직(개구) → s ⊥ σ_1. |dσ_e/ds| 방향 확정.
- **응력조건(식 1)의 처리**: 균열 선단은 σ_e → ∞ 이므로 식(1)은 자동 만족.
  → 파괴하중은 **식(2)(구배조건) 단독**으로 결정된다는 점 (논문 §4.3 명시).

### 과잉(이 과업엔 불필요)일 수 있는 것
- C6 (핸드북 K): 정식 재현엔 불필요, 검산용으로만. 발표엔 "옵션"으로 표시.
- 선1 식(7) K_IC = √(2πE w_f): HCP 과업은 Y 로 직접 예측하므로 K_IC 환산은 참고용.
