# round48 Codex blind 검증

## 검증 범위와 방법

- `round48/problem.md`에 따라 `round48/html_cards.txt`의 p1–p109를 원문 텍스트 및 필요한 PDF 지면과 독립 대조했다. 다른 AI의 결과 보고서는 읽지 않았다. HTML은 수정하지 않았다.
- 평문 추출의 `[식 TeX]`에는 `<` 뒤가 잘린 부분이 있다. 이 추출 손실을 HTML 오류로 세지 않고, 지정된 현재 HTML의 `data-tex` 속성을 HTML 엔터티 해제 후 직접 읽어 보완했다.
- 식 5-1–5-6, 6-1–6-6, A-1–A-2, C-0–C-11을 대조했다. 6-5의 일반 재귀식은 카드에 원문에 없는 Claude 보충임이 표시되어 있음을 확인했다. F29–F55는 PDF 61–78의 축·후프 규칙 상자를 직접 보면서 계수, 부호, 거듭제곱, 분모와 구간 부등호를 대조했다. 카드가 명시적으로 보존한 원문 오류·모호함은 새로운 전사 오류로 세지 않았다.
- Table 7–34는 현재 HTML에서 다시 추출하여 PDF 102–129에 해당하는 원문 텍스트와 28표 × 26행 = **728행 전수 대조**했다. x/t, Stress, Distribution Type, Param1, Param2의 **3,640개 데이터 셀이 모두 일치**했다. 이전 round45 결과를 판정 근거로 사용하지 않았다.
- 서술의 수치·고유명사·쪽 번호·한정어를 대조했다. 도상 근삿값은 해당 그림의 눈금과 비교했으며, 명시된 해설·계산값과 원문 전사를 구분했다. 오류 대장의 기존 지적은 해당 원문 근거를 다시 확인했다. 원문 밖의 실제 코드·워크북 구현 여부는 확정하지 않았다.
