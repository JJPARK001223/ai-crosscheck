# round85 — Claude의 codex.md 검증

범위: `round85/codex.md`가 `round85/input/evaluation_data.md`의 등급·근거를 정확히 보존했는지, 새 평가를 추가하지 않았는지,
PROBLEM.md의 "포함할 내용"을 충족했는지 확인한다. Claude 자신의 claude.md는 이 검증 작성 중 다시 참조하지 않았다(blind 단계 이후 작성).

## 1. 사실 일치 검증 — 등급·근거 왜곡 없음

codex.md에 적힌 15편 × 4섹션 × 2기준 = 60개 등급과 근거 문장을 input/evaluation_data.md와 대조했다.
표본 확인(No.1, No.9, No.11, No.13의 전체 8개 섹션 축) 및 분포표(섹션별 상/중/하 논문 번호 목록)를 전부 대조한 결과,
**등급을 바꾸거나 근거 문장을 왜곡·추가한 부분은 발견되지 않았다.** 분포표(No.184~193행)의 논문 번호 집계도 claude.md의 집계와 완전히 일치한다
(Abstract 구체성 상6/중2/하7, Introduction 구체성 상10/중3/하2, Methodology·Results 연관성 전원 상 등). → **CONFIRMED**(두 독립 blind 보고서가 동일 집계에 도달).

## 2. codex.md가 더 낫다고 판단하는 점

- **사실/해석 분리가 claude.md보다 엄격하다.** 각 섹션마다 "확정 사실" 블록(input 인용)과 "해석" 블록(Codex 의견)을 구조적으로 분리해,
  어디까지가 input 근거이고 어디부터가 Codex의 판단인지 문장 단위로 구분 가능하다. claude.md는 산문 안에서 사실과 해석을 섞어 쓴 구간이 있어
  (예: "가장 완결성 높은 사례"라는 평가어를 근거 나열과 같은 문장에 바로 붙임), 독자가 둘을 분리하기 더 어렵다. → 보고서 투명성 측면에서 codex.md의 서술 구조가 더 우수하다.
- **Abstract의 구체성·연관성 경계가 겹친다는 지적(202행대)은 claude.md에 없는 유효한 관찰이다.** codex.md는 "Abstract에서는 수치 부족이
  구체성과 연관성의 공통 근거로 자주 쓰인다"며 No.1·7(주제 일치+수치 부족→연관성 중)과 No.4(수치 부족→연관성 하)를 예로 들어
  두 평가축의 경계가 Abstract 섹션에서 서로 겹친다는 점을 짚었다. evaluation_data.md를 다시 확인하면 실제로 그렇다 — No.1 Abstract 연관성 "중"의 근거는
  "Abstract는 정량적 수치 없이 서술에 그침"으로, 이는 구체성 축의 근거("정성적 서술 위주... 구체 수치 없음")와 거의 동일한 문장이다.
  claude.md는 이 중첩을 짚지 않고 두 축을 독립적인 것처럼 다뤘다. → codex.md의 지적이 더 정확하며, Claude는 이 점을 인정한다.
- **No.11에 대한 과잉일반화 경계(226행)가 claude.md보다 신중하다.** claude.md는 No.11을 "구조적 약점(실험 정량검증 부족)을 가진 논문"으로
  다소 단정적으로 요약했다. codex.md는 "부족·제한적"이라는 input의 표현을 "전무"로 확대 해석해서는 안 된다고 명시하며,
  "물리적 실험이 전혀 수행되지 않았다고 단정할 수 없다"고 선을 긋는다. 이는 evaluation_data.md의 실제 표현(예: Results "일부 수치는 제시되나... 제한적")에 더 충실한 독해다.
  → Claude는 claude.md의 No.11 요약이 다소 과장되었음을 인정하고, codex.md의 절제된 표현이 더 정확하다고 판단한다.
- **"확인 불가" 처리가 일관적이다.** codex.md는 거의 모든 해석 단락 끝에 "~는 확인 불가"를 명시해 input 범위를 벗어난 추측(선행연구 공백 주장이 실제 문헌에서 성립했는지, 모델의 실제 재현 가능성 등)을 차단한다.
  claude.md도 "사실/해석 구분"을 선언했지만 매 해석 단락마다 한계를 명시하지는 않았다. 사용자의 전역 규칙("사실만 전달, 모르면 모른다고")에 더 충실한 쪽은 codex.md다.

## 3. codex.md에서 보완이 필요하다고 보는 점

- **연관성 축이 Methodology·Results에서 15편 전원 "상"인 이유에 대한 설명이 claude.md보다 얕다.** codex.md는 "그 축만으로 논문 간 차이를
  구분하는 능력은 제한된다"고만 말하고 멈춘다. claude.md는 여기서 한 걸음 더 나가 "SCI(E) 심사를 통과한 논문이라면 본문이 제목 범위를
  벗어나는 경우가 사실상 없다"는 모집단 선정효과(ceiling effect) 가설을 제시했다. 이는 input에 직접 쓰여 있지 않은 추가 해석이므로
  PROBLEM.md의 "입력에 없는 새 평가는 추가하지 말 것" 제약과 "해석은 밝혀도 된다"는 지침 사이에서 Claude가 선택한 해석적 설명이며,
  codex.md는 이 설명을 제시하지 않았다. 이는 틀림이 아니라 해석의 깊이 차이다 — codex.md의 절제가 더 안전한 선택일 수도 있다.
- **분포표 형식 외에는 통계적 요약(예: 비율 %)을 전혀 제시하지 않아 다소 건조하다.** PROBLEM.md가 "새로운 등급과 통계 수치는 만들지 않는다"는
  제약을 codex.md 스스로 7행에 명시했기 때문으로 보이며, 이는 과도한 보신(input에 없는 숫자를 만들지 않으려는 태도)이지만 PROBLEM.md의
  제약을 가장 엄격하게 지킨 선택이다. 보고서 가독성 면에서는 claude.md의 분포표(섹션별 상/중/하 개수를 숫자로 명시)가 더 읽기 쉽다.

## 4. 결론
codex.md는 input 자료를 사실과 다르게 쓴 부분이 없고, PROBLEM.md의 제약(새 평가 금지, 사실/해석 구분)을 claude.md보다 더 엄격하게 지켰다.
특히 "Abstract 두 축의 근거 중첩"과 "No.11 과잉일반화 경계"는 claude.md에 없던 유효한 관찰로, 최종 종합 보고서에는 codex.md의 이 두 지적을
Claude 단독 분석의 보완으로 반영해야 한다고 판단한다. 반대로 Methodology·Results 연관성 "전원 상"에 대한 모집단 선정효과 설명은 claude.md만의
해석이며, 이는 input에 없는 추가 가설이므로 최종 보고서에서는 "Claude의 해석(확정 사실 아님)"으로 명확히 표시해 전달한다.
