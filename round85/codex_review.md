# round85 — Codex의 Claude 독립 보고서 검증

검증 대상: [claude.md](claude.md). 판단 근거: [evaluation_data.md](input/evaluation_data.md). 비교 대상: [codex.md](codex.md). 원문 PDF·외부 문헌을 통한 재평가는 하지 않았으며 기존 등급을 바꾸지 않는다. 아래의 **사실**은 입력 대조 결과, **해석**은 그 결과에 관한 검토 의견, **확인 불가**는 입력으로 입증되지 않는 사항이다. 다른 검증 보고서는 참조하지 않았다.

## 1. 검증 결론과 일치한 부분

**사실:** Claude의 논문별 요약표에 적힌 No.1~15의 네 섹션 구체성/연관성 등급은 모두 입력과 일치한다. 섹션별 분포표도 맞다. 다만 표와 달리 요약 문장·특이사례·결론에는 잘못된 유일성 주장, 등급 예외 누락, 근거의 적용 범위 확대가 있다. 따라서 “모든 등급·수치·인용문은 input 파일에서 그대로 가져왔다”는 서두 및 “등급·근거는 … 그대로”라는 결론은 보고서 전체에 대해서는 성립하지 않는다.

다음은 입력 등급을 직접 세어 재확인한 집계다. 신규 평가 점수나 실측 수치가 아니다.

| 섹션 | 구체성 상/중/하 | 연관성 상/중/하 |
|---|---|---|
| Abstract | 6/2/7 | 7/7/1 |
| Introduction | 10/3/2 | 11/3/1 |
| Methodology | 12/3/0 | 15/0/0 |
| Results | 12/3/0 | 15/0/0 |

**해석:** 등급의 전체 경향, No.9의 문헌 연결 약점과 실제 시험대상의 일치가 공존한다는 설명, No.13~15의 가솔린 범위 이탈과 자체 제목에 대한 연관성을 구별한 취지는 입력에 근거한다. Methodology·Results의 연관성 축이 이 자료에서 논문 간 차이를 구별하지 못한다는 지적도 맞다. 이 장점들은 아래 오류를 수정해도 유지된다.

## 2. 사실·등급·근거의 불일치

### 2.1 No.2가 유일한 ‘전 섹션 연관성 상’이라는 주장은 틀림

- **Claude 위치·표현:** §1 No.2 특징란의 “유일한 ‘전 섹션 상’ 사례(연관성 기준)”.
- **입력 사실:** No.2 외에도 No.3·5·8·13·15의 연관성이 네 섹션 모두 상이다. No.2 Abstract 구체성은 중이므로 두 축 모두 전 섹션 상이라는 의미로 읽어도 맞지 않는다.
- **검토:** No.2에 대해 “CCV라는 핵심 변수가 Abstract의 COV 수치와 후속 섹션에서 직접 연결된다”고 요약하는 것은 타당하지만, 유일성은 삭제해야 한다.

### 2.2 No.13~15가 ‘No.13 Methodology만 중이고 나머지 전부 상’이라는 주장은 틀림

- **Claude 위치·표현:** §3 No.13·14·15의 두 번째 항목.
- **입력 사실:** No.14 Abstract는 구체성 **하**, 연관성 **중**이다(input No.14, 146~147행). Claude 자신의 §1 표에도 이 예외가 정확히 적혀 있다.
- **검토:** No.13 Methodology 구체성 중과 No.14 Abstract 하/중을 모두 예외로 명시해야 한다. 자체 제목과의 일치가 높다는 취지에서 낮은 등급을 생략하면 사실 왜곡이 된다.

### 2.3 Introduction ‘중/하 4편’ 집계와 사례 목록이 틀림

- **Claude 위치·표현:** §2 마지막 항목의 “Introduction의 ‘중/하’(4편: …)”.
- **입력 사실:** 구체성 중/하는 No.1·4·8·11·12, 연관성 중/하는 No.1·4·9·11이다. 둘 중 하나라도 중/하인 논문은 No.1·4·8·9·11·12, 즉 6편이다. 구체성만 보면 5편이며 연관성만 보면 4편이다.
- **검토:** Claude는 두 축의 사례를 섞으면서 ‘4편’으로 썼고 No.12를 누락했다. No.12는 반응식·반응열 수치는 있어도 선행 촉매 성능 서술이 주로 정성적이라는 구체성 중의 별도 사례다(input 128행). 어느 축을 집계하는지 밝혀야 한다.

### 2.4 No.1 Methodology와 Results가 중인 이유를 잘못 합침

- **Claude 위치·표현:** §1 No.1의 “시뮬레이션 모델 검증이 선행연구[49]에 위임되어 Methodology·Results 모두 ‘중’”.
- **입력 사실:** 선행연구에 보정·검증을 위임한 것은 Methodology 구체성 중의 근거다. Results 구체성 중의 근거는 Figure 2·3의 경향에 비해 본문 설명이 정성적이고 블렌드별 구체적 % 비교가 제한적이라는 것이다.
- **검토:** 등급은 맞지만 원인을 Results로 전용했다. 두 섹션의 중 판정 근거를 따로 써야 한다. ‘중’은 두 섹션의 구체성에 해당하며 연관성은 모두 상이라는 점도 명시하면 정확하다.

### 2.5 Abstract 하의 근거를 ‘수치 없음’으로 일괄 요약한 것은 부정확

- **Claude 위치·표현:** §2 첫 항목의 “7편 … 공통적으로 … 구체 수치 없음”.
- **입력 사실:** No.6에는 7.7mm, No.10에는 1800rpm이 있다. No.14는 “구체 수치 거의 없음”이다. No.11의 근거는 기법 설명 위주라는 별도 맥락을 가진다.
- **검토:** 공통점은 ‘정량적 결과의 뒷받침이 부족함’으로 한정해야 한다. 치수·설정값의 존재와 결과 비교수치의 충분함은 다르다. 같은 문단에서 No.1·4·6·7·10·14를 열거하며 후속 섹션이 “거의 전부 상”이라고 한 것도 예외를 가린다. No.1은 Methodology·Results 구체성 모두 중이고 No.10 Results도 중이다. 전체 분포의 상승이 각 논문의 모든 축에서 단조롭게 상승한다는 뜻은 아니다.

### 2.6 평가항목 단위 표기에 산술상 혼동이 있음

**사실:** Claude 서두의 “60개 평가항목(15편 × 4섹션 × 2기준)”은 곱셈과 개수가 맞지 않는다. PROBLEM.md 자체가 ‘60개 평가항목’을 사용하는 것은 맞지만, 이는 논문-섹션 조합의 수다. 각 조합의 두 축 등급을 개별 판정으로 세면 120개다.

**검토:** “60개 논문-섹션 조합, 각 두 기준”이라고 쓰면 문제문의 용어를 보존하면서 혼동을 해소한다. 이는 입력 등급의 재평가가 아니라 단위 정리다.

## 3. 해석의 근거 강도와 확인 불가 사항

| Claude의 해석 | 입력으로 뒷받침되는 범위 | 검토 의견·확인 불가 |
|---|---|---|
| Abstract 저평가는 글자수 제한·요약 관행 때문에 수치를 생략한 결과 | 일부 논문에서 Abstract보다 본문의 구체성 등급이 높다는 사실 | 저널의 글자수 규정·저자 의도·실제 생략 이유는 입력에 없다. “본문에는 수치가 있어도 Abstract의 정량적 뒷받침은 부족한 사례가 있다”까지 가능하다. 이를 ‘요약문 서술 관습의 문제’로 확정하는 결론은 근거가 약하다. |
| Methodology·Results 연관성 전원 상은 SCI(E) 심사를 통과한 모집단의 자연스러운 결과 | 이 목록의 해당 축이 모두 상이라는 분포 | SCI(E) 논문 일반의 제목-본문 일치 빈도나 심사의 인과효과는 확인 불가다. ‘상으로 집중되어 이 자료에서 변별되지 않는다’는 기술은 가능하지만 그 원인을 심사 통과로 돌릴 근거는 없다. |
| No.9는 관련 문헌이 부족한 ‘신소재’라서 알코올 문헌으로 대체 인용했다 | 서론에서 알코올 첨가제 문헌 비중이 크고 프탈로시아닌 직접 연계가 약하다는 지적, 실제 방법·결과가 프탈로시아닌을 다룬다는 사실 | ‘신소재’라는 지위, 관련 선행문헌의 실제 부족, 저자의 대체 인용 동기는 확인 불가다. 해석이라고 표시해도 입력 밖의 원인을 도입한 추측은 정당화되지 않는다. |
| No.11의 4섹션 진단이 시뮬레이션 전용 연구라는 구조적 약점을 독립적으로 입증 | 입력의 교차-섹션 특이사항이 실험 정량검증 부족을 일관 지적한다는 점 | 공통 진단을 옮긴 것은 맞다. 다만 Abstract의 결과수치 부족, Introduction의 선행연구 정량 인용 부족은 서로 다른 관찰이다. 네 근거의 추출이 통계적·절차적으로 독립적이었다는 기록도 없다. ‘전용’은 실험 부재를 단정하므로 피해야 한다. |
| No.5가 ‘가장 완결성 높은’ 사례, No.3·5·15가 ‘가장 일관된 고품질’ 사례 | No.3·5·15는 두 축 모두 네 섹션에서 상, No.5에는 불확도 수치가 제시됨 | 전 섹션 상이라는 등급 패턴은 확인된다. 하지만 No.5의 단독 최상위 완결성이나 논문 전체 품질 순위는 입력에 없다. 기존 두 축을 넘어선 최상급 평가는 제거하고 패턴만 기술해야 한다. |
| 구체성 근거가 구체적이므로 재현 가능한 판단이다 | 각 근거에 수치·사양·누락 정보가 적혀 있어 판단을 추적하기 쉬움 | 동일 자료에 다른 평가자가 같은 등급을 부여하는지는 확인 불가다. 추적 가능성과 평가 재현성은 같지 않으며 경계 규칙·평가자 합의 자료가 없다. |

**No.11 보완 근거:** input Results에는 “연료질량 15% 고장 주입, 추정오차 0.03s 내 수렴”이 명시되어 있다(121행). 따라서 ‘정량 수치가 전혀 없는 연구’로 읽어서는 안 된다. 본문 밖 부록·선행문헌에 정보가 있다는 것과 그 정보가 존재하지 않는다는 것도 다르다. No.4·6·14의 높은 수치해석 관련 등급은 시뮬레이션 자체가 낮은 등급의 원인이라는 일반화를 반박한다. 물리 실험·원문 정보의 실제 충분성은 이번 자료만으로 확인 불가다.

**No.9의 ‘유일한 역전’ 표현:** 연관성이 Abstract 상 → Introduction 중 → Methodology·Results 상으로 내려갔다가 회복되는 정확한 패턴은 No.9만 해당한다. 이 뜻으로 한정하면 맞다. 단순히 섹션별 연관성이 달라지는 유일한 논문이라는 뜻이라면 No.1·4 등 반례가 있다. 입력은 No.9의 차이를 강조하지만 그 원인을 신소재의 문헌 부족으로 규정하지 않는다.

## 4. 놓친 점과 요구사항 충족 여부

1. **등급별 근거 설명이 충분하지 않다.** PROBLEM.md는 각 등급이 왜 부여되었는지 입력 근거를 포함하도록 요구한다. Claude의 논문별 표에는 모든 등급이 있지만 특징 한 문장으로 일부 근거만 제시한다. 예를 들어 No.4 Introduction 중/중의 배플 치수·로켓엔진 기원 및 제목 범위 연결 부족, No.6 Introduction 상/상의 정량 인용과 세부 형상 연구공백이 개별적으로 설명되지 않는다. 섹션별 일반 요약만으로 모든 논문·등급의 이유가 보존되지는 않는다. 특징 1~2개 요약이라는 요구와 별개로 근거 보존 요구도 충족해야 한다.
2. **두 평가축의 중첩과 경계가 모호하다.** 연관성은 제목 범위 일치로 정의되지만 Abstract에서는 수치 부족이 구체성·연관성 양쪽을 낮추는 근거가 된다. No.2와 No.12는 Abstract 구체성이 모두 중이나 연관성은 상/중으로 다르다. 입력은 핵심 변수의 직접 뒷받침 여부 등을 설명하지만 이를 일관되게 재현할 임계값·가중치는 없다. 기존 판정을 바꾸지 않으면서 이 한계를 밝혀야 한다.
3. **구체성은 숫자 밀도만을 뜻하지 않는다.** No.1·11·13 Methodology는 식·사양이 있어도 본문 밖으로 위임된 검증·실험 정보 때문에 중이다. 평가에는 수치 밀도 외에 본문 설명의 자족성·재현 가능성에 관한 판단도 들어간다. 단순한 수치 개수로 등급을 설명하면 부족하다.
4. **표의 수치와 본문 서술의 역할을 구별할 필요가 있다.** No.8 Results는 본문 메커니즘 설명 비중이 높아도 Table3의 실측값을 근거로 상이다. No.1·10의 정성적 본문 지적과 나란히 보면, 평가가 어디의 정보까지 포함하는지 설명할 수 있는 중요한 사례다.
5. **No.10 Results 근거는 ‘확인된 구간’으로 제한된다.** input 111행의 이 한정을 생략해 전체 Results에 정량 비교가 부족하다고 확정하면 관찰 범위를 넓힌다. 원문 전체의 서술 상태는 확인 불가다.
6. **높은 등급과 과제 적합성·전체 논문 품질을 분리해야 한다.** No.13~15의 범위 이탈을 짚은 Claude의 취지는 맞다. 그러나 선정 경위, 가솔린에 대한 결과 전이 가능성, SCI(E) 등재·원문 정확성은 입력으로 입증되지 않는다. 높은 자체 제목 연관성은 이 문제들을 대신 확인해 주지 않는다.

## 5. Codex 독립 보고서와의 구체적 비교

| 비교 지점 | Claude | Codex | 입력 대조에 따른 판단 |
|---|---|---|---|
| 전체 등급과 분포 | 한 표와 집계표로 간결하게 제시 | 개별 근거 표와 등급별 논문 번호로 제시 | 둘 다 기존 등급·분포와 일치한다. Claude의 집계표는 경향을 빨리 읽기 좋고 Codex 번호표는 소속을 추적하기 좋다. 집계는 파생 계산이라고 명시해야 하며 입력의 직접 인용 수치와 구별해야 한다. |
| No.1의 두 중 판정 | 검증 위임을 Methodology·Results 공통 원인으로 서술 | Methodology의 위임과 Results의 정성적 비교를 별도 보존 | Codex 설명이 입력에 더 정확하다. |
| No.13~15 예외 | §3에서 No.14 Abstract 하/중을 누락 | No.13 Methodology 중 및 No.14 Abstract 하/중을 모두 명시 | Codex가 더 정확하다. Claude의 §1 표 자체는 맞다. |
| No.9 원인 | 신소재·문헌 부족·대체 인용으로 설명 확대 | 문헌 연결 약점과 실제 대상 시험의 차이로 한정, 선행문헌 존재 정도는 확인 불가 | Codex의 한정이 입력 범위에 부합한다. 정확한 상→중→상 패턴을 Claude가 강조한 것은 유용하다. |
| Abstract·연관성 분포의 원인 | 요약 관행·SCI(E) 심사 효과를 도입 | 저자들이 수치를 적게 쓴 이유와 SCI(E) 등재 확인은 확인 불가 | 입력만 사용하라는 제약에는 Codex가 더 충실하다. |
| No.11 | 교차-섹션 공통 진단을 잘 인용하나 ‘전용’·독립 추출·구조적 약점으로 확대 | 공통 진단과 섹션별 직접 근거를 구별하고 수치의 존재·실험 부재 단정의 한계를 명시 | 공통 진단은 양쪽 모두 맞고, 확대 해석을 제한한 Codex가 더 엄밀하다. |
| 평가체계 | 변별력과 상 집중을 간결히 지적 | 같은 점에 더해 축 중첩·경계 미명시·본문 밖 정보 위임을 논의 | 공통 지적은 타당하다. 평가 재현성이 확인되었다는 Claude의 주장은 근거가 부족하다. |

**Codex 자체에 대한 한계:** codex.md는 모든 근거를 길게 나열하여 Claude보다 읽기 부담이 크다. 번호별 분포와 논문별 표를 확인할 수 있으나, Claude의 집계표 같은 간결한 조망은 덜 직접적이다. 또한 Codex의 “등급과 근거 문장을 그대로 옮겼다”는 표현도 원문 논문을 직접 확인했다는 뜻으로 읽어서는 안 된다. 양쪽 모두 입력 내부 일관성에 대한 검토이며 기존 평가의 외부 타당성을 입증한 것은 아니다. 이번 대조에서 Codex 등급표·분포 소속을 바꿔야 할 입력 불일치는 발견하지 못했지만, 이것이 두 보고서의 모든 해석을 외부 검증했다는 뜻은 아니다.

## 6. 수정 우선순위

**검토 의견:** 우선 No.2 유일성, No.13~15의 예외 누락, Introduction 집계, No.1의 근거 전용을 고쳐야 한다. 이어 Abstract의 수치 유무를 구별하고, 신소재·저널 관행·심사 효과·독립 추출·최상위 품질 등 입력 밖 설명을 삭제하거나 확인 불가로 표시해야 한다. 마지막으로 빠진 등급별 근거와 평가기준의 경계·적용 범위를 보완하면 된다. 이 검증은 Claude 보고서를 직접 수정하거나 새로운 논문 등급·순위를 확정하지 않는다. 최종 채택·수정 결정은 사용자에게 남긴다.
