# Claude 독립 진단 요약

Claude Code의 읽기 전용 독립 진단(stdout)을 Codex가 요약 기록했다. 진단은 최종 코드 리뷰가 아니다.

- 전역 CLAUDE.md의 Codex 실행 예시에는 승인 옵션이 없고 저장소 규칙과 불일치한다.
- 실제 적용된 승인 정책이 never이면 승인 재시도를 지시해도 수행할 수 없다.
- Git 인계 완료는 실제 실행 로그, 지정 파일만 포함된 커밋, 원격 반영으로 확인해야 한다.
- 승인 설정과 호출 명령, 프롬프트가 일치해야 하고 UTF-8 로그가 필요하다.
- 기존 작업 변경을 건드리지 않고 결과 파일만 인계해야 한다.
- 진단 시 현재 수정된 스크립트와 이전 로그를 대조해 플래그가 작동하지 않았을 가능성을 제기했으나 미확정이었다. 이후 실제 테스트에서 --approve-for-me 단독 실행이 on-request/workspace-write로 동작함을 확인했으므로 비대화형 실행에서 승인 자체가 불가능하다는 추론은 채택하지 않는다.

추가로 Codex 실측에서 --sandbox와 --approve-for-me 동시 지정이 CLI 인자 충돌임을 확인했다. 최종 검토는 구현 및 복구 증거를 읽은 후 별도 DECISION.md로 받는다.
