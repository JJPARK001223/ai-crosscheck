# round 1 교차검증

## 검토 범위와 검증 방법

- `PROBLEM.md`, `round1/codex.md`, `round1/claude.md`, Claude의 실제 산출물 `round1/lefm_초보자_설명.html`을 대조했다.
- 지정된 두 PDF에서 핵심 문구를 `pdftotext`로 다시 추출해 확인했다. 일부 PDF 스트림 경고가 있었지만, 다음 본문은 추출되었다: 선행연구 1의 “linear elastic until failure”, “The stress at the crack tip is infinite”, `w_f`의 단위 및 `K_Ic` 설명; 선행연구 3의 구멍 관련 문단과 “Y is equivalent to the critical energy release rate …”.
- Claude HTML의 `<script>`를 Node.js 26.4.0의 `vm`에서 모의 canvas/document와 함께 실제 실행했다. 스크립트는 예외 없이 끝났고 존재하는 두 `console.assert`는 모두 통과했다(`JS_EXEC_OK 2 assertions`). 브라우저 렌더링은 이 환경에서 사용 가능한 브라우저 표면이 없어 별도로 확인하지 못했다.

## 공통점

1. 두 답 모두 지정된 두 논문만 참고문헌으로 제시했다.
   - Y. W. Kwon, *Journal of Pressure Vessel Technology*, 143, 064503 (2021), DOI 10.1115/1.4050989.
   - Y. W. Kwon, E. K. Markoff, S. DeFisher, *Materials*, 17, 569 (2024), DOI 10.3390/ma17030569.
2. 핵심 설명 흐름은 같다. 선형탄성 가정 → 균열선단의 `1/√r` 응력 특이성 → 응력확대계수 `K` → `K`와 `K_Ic`의 비교 → 적용 한계 순서다.
3. 선행연구 1의 표기를 따라 `σ_x = K/√(2πr)`, `w_f = K²/(2πE)`, `K_Ic = √(2πEw_f)`를 사용했다.
4. `K < K_Ic`는 임계 미도달, `K ≥ K_Ic`는 Mode I 균열 진전 개시 조건 도달로 시각화했다.
5. 구멍·둔한 노치에는 균열의 특이 응력장과 동일한 판정을 그대로 적용하지 말아야 한다는 취지는 일치한다.

## 차이와 충돌

### 산출물 및 시각화

- Codex는 `codex.md` 자체에 완결된 HTML 원문을 넣었지만 확장자가 `.md`이며, 별도의 실행 가능한 `.html` 파일은 만들지 않았다. Claude는 `round1/lefm_초보자_설명.html`을 실제로 만들었다. 사용자의 “단일 HTML 문서”를 즉시 열어 보는 산출물이라는 관점에서는 Claude가 더 완결적이다.
- Codex는 정적 SVG 두 개(균열선단 개념도/정성 곡선, `K` 대 `K_Ic` 게이지)를 사용했다. Claude는 canvas/JS로 정량 곡선, log–log 곡선, 하중에 따른 `K/K_Ic` 및 막대를 만들었다. Claude 쪽이 `1/√r` 기울기와 임계점의 의미를 더 직접적으로 보여 주지만, JS가 꺼지면 그림이 나타나지 않는다는 대가가 있다. Codex SVG는 JS 없이도 보인다.

### 두 논문의 `K` 정규화

- Codex는 두 논문의 근접장 상수 표기가 다르므로 섞지 말라고만 경고했다.
- Claude는 선행연구 1의 `K/√(2πr)`와 선행연구 3의 `K/√s`를 나란히 적고, 그 정의에 대응하는 `K²/(2πE)`와 `K²/E`의 계수 차이를 `2π`로 명시했다. 이 차이는 물리적 모순이라기보다 **서로 다른 `K` 정규화의 결과**라는 Claude의 설명이 더 명확하다.

### 설명 범위

- Codex는 요청된 입문 설명과 두 필수 시각화에 집중했다.
- Claude는 응력구배 식, 에너지 관점, 수식 요약표, 자료의 한계를 추가했다. 교육적 범위는 넓지만 아래와 같은 과잉 단정과 출처 경계 문제가 생겼다.

## Claude의 오류 및 수정이 필요한 점

1. **자가검사 개수 주장이 틀렸다.** `claude.md`는 “console.assert self-check 3개”라고 했지만 실제 HTML에는 413행과 414행의 **2개**만 있다. 실행 결과도 `2 assertions`였다.
2. **차원이 같다는 사실을 물리량의 동일성으로 확대했다.** HTML 167행은 `w_f`의 단위가 `J/m²`라는 이유로 “즉 단위면적당 에너지(에너지방출률)”라고 썼다. 선행연구 1은 `w_f`를 응력구배에서 얻은 파손 임계값으로 도입하고 그 단위가 에너지/면적과 같다고 설명한다. 같은 차원이라는 사실만으로 `w_f` 자체가 고전 LEFM의 에너지방출률이라고 단정할 수는 없다. “에너지방출률과 같은 차원을 갖는다”가 정확하다. Codex의 “응력구배 기반 재료 임계값” 표현이 더 안전하다.
3. **출처 밖 기호를 사실상 도입했다.** HTML 189행과 238행의 `G_c`는 두 지정 논문의 해당 본문에서 직접 전개한 기호가 아니다. Claude 스스로 “Griffith/에너지평형 유도는 본문에 없음”이라고 밝혔으므로, 엄격한 “두 PDF만 사용” 조건에서는 `Y` 또는 논문이 직접 쓴 표현에 머무는 편이 맞다.
4. **“LEFM은 균열 전용”은 지나치게 절대적이다.** 지정 논문이 강조하는 것은 균열의 특이장과 구멍의 유한 응력장을 구분해야 한다는 점이다. HTML 210행 및 결론의 “균열 전용”은 이 문맥을 초보자용으로 압축한 표현이지만, LEFM의 전체 적용 범위를 보편적으로 정의하는 문장으로는 과도하다. “이 두 논문에서 사용하는 `K` 기반 판정은 날카로운 균열에 적용한다”로 한정해야 한다.
5. **‘오직 두 PDF’라는 선언과 예시 상수의 출처 처리가 완전히 일치하지 않는다.** `K=1 MPa√m`, `E=3 GPa`, `σ_f=70 MPa` 등은 “개념 설명용 예시”라고 표시되어 있어 데이터 인용으로 오인될 가능성은 낮다. 그러나 JS 주석의 “PMMA 급”은 두 PDF에서 뒷받침한 사실이 아니며 불필요하다. 출처 제한을 엄격히 지키려면 재료명 연상을 삭제하고 무차원 정규화만 사용하는 편이 낫다.
6. **선행연구 3의 명백한 문장 오류 처리는 추론임을 유지해야 한다.** PDF에는 실제로 “fracture mechanics is suitable for holes”라고 인쇄되어 있으나 곧이어 구멍에는 entirely different criteria가 쓰인다고 설명한다. Claude가 `not` 누락으로 본 것은 문맥상 합리적인 편집 추론이지만 원문 사실은 아니다. `claude.md`에서는 “오타로 보임”이라고 구분했으므로 적절하며, 최종 HTML에서도 논문의 문맥적 취지만 서술해야 한다.

## Codex가 놓친 점

1. **실제 `.html` 산출물과 실행 검증이 없다.** HTML 원문은 완결되어 있지만 파일 확장자와 실행 확인까지 포함한 납품 상태는 Claude보다 부족하다.
2. **응력 특이성의 정량적 확인이 약하다.** SVG 곡선은 `σ ∝ 1/√r`을 정성적으로만 보인다. Claude의 log–log 기울기 `−1/2` 그림은 특이성 검증에 더 유용하다.
3. **두 논문의 정규화 차이를 수치적으로 설명하지 않았다.** Codex는 상수 표기가 다르다고만 썼으며, 동일 기호 `K`를 그대로 대입하면 관계식 계수가 `2π`만큼 달라지는 이유를 초보자가 확인하기 어렵다.
4. **자료 자체의 한계를 명시하지 않았다.** 두 논문은 표준 LEFM 교과서가 아니라 응력·응력구배 통합 파손기준을 제안하는 논문이다. Griffith 유도, 소규모 항복 조건, 평면변형률 유효성 등 표준 LEFM의 중요한 조건이 이 두 PDF 본문만으로 충분히 정리되지 않는다는 Claude의 경계 표시는 유익하다.
5. **응력구배 연결을 식으로 보여 주지 않았다.** Codex는 개념만 설명했지만 Claude는 선행연구 1 Eq. (5)와 선행연구 3 Eq. (2)를 표시해 두 논문에서 `K`와 파손 임계값이 어떻게 연결되는지 더 투명하게 했다.
6. **접근성/표현상 장점은 있으나 정량 판정의 맥락이 부족하다.** Codex의 SVG에는 `<title>`과 `<desc>`가 있어 접근성이 좋고 외부 의존도도 없다. 반면 `K` 대 `K_Ic` 게이지는 하중 증가에 따른 교차점이나 정규화된 축을 보여 주지 않아 Claude 그림보다 판정 과정 설명이 약하다.

## 종합 판정

- **요구 산출물의 완결성 및 검증 가능성:** Claude 우세. 별도 단일 HTML을 만들었고 JS는 실제 실행된다.
- **간결성, 무의존성, 접근성 및 출처 밖 개념 억제:** Codex 우세.
- **과학적 수정 우선순위:** Claude HTML의 `w_f = 에너지방출률` 단정과 `G_c` 도입을 먼저 고치고, “균열 전용”을 논문 문맥으로 제한해야 한다. 그 다음 자가검사 개수와 “PMMA 급” 주석을 바로잡아야 한다.
- 두 답의 `K < K_Ic` / `K ≥ K_Ic` 핵심 판정과 `1/√r` 특이성 자체에는 실질적 충돌이 없다.
