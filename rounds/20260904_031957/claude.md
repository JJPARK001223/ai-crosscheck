## 선행연구 1 (Kwon 2021)

### 항목 1 — 식(2) → 식(3)

식(2): `[ σ_l² / (2E) ] / [ (1/σ_l) · |dσ_l/ds| ]  ≥  w_f`

분자 = 변형에너지밀도(단축, 선형탄성) `U = σ_l²/(2E)`.
분모 = 단위응력당 응력구배 `(1/σ_l)|dσ_l/ds|`.

정리:
```
[ σ_l²/(2E) ] · [ σ_l / |dσ_l/ds| ]  =  σ_l³ / ( 2E |dσ_l/ds| )
                                     =  ( σ_l³ / 2E ) · |ds/dσ_l|
```
→ 식(3) `( σ_l³ / 2E ) · |ds/dσ_l| ≥ w_f`.  **유도 맞음.**

차원: `[Pa³]/[Pa] · [m/Pa] = Pa·m = N/m = J/m²`. 논문이 밝힌 w_f 단위와 일치. **맞음.**

### 항목 2 — Case 2 (중앙균열)

식(4): `σ_x = K / √(2πr)` = `K (2π)^(-1/2) r^(-1/2)` (선단 근방 주항).

식(5): 균열은 y축(하중 수직, 균열 진전방향)으로 전파. r→y로 놓고
```
dσ_x/dy = K(2π)^(-1/2) · (-1/2) y^(-3/2)
|dσ_x/dy| = K / ( 2√(2π) · y^(3/2) )
```
→ **식(5) 맞음.**

식(6): 식(3)에 σ_l = K/√(2πr) 대입 (파괴개시 등호).
```
σ_l³ = K³ / (2πr)^(3/2)
dσ_l/dr = K(2π)^(-1/2)(-1/2) r^(-3/2)  →  |dr/dσ_l| = 2√(2π) r^(3/2) / K

w_f = (σ_l³/2E)|dr/dσ_l|
    = [ K³ / (2E (2π)^(3/2) r^(3/2) ) ] · [ 2√(2π) r^(3/2) / K ]
    = K² · 2√(2π) / ( 2E (2π)^(3/2) )
    = K² / ( 2πE )
```
→ **식(6) `w_f = K²/(2πE)` 맞음.** r 이 소거되어 상수 = 재료상수, 개념도 타당.

식(7): (6)을 K 에 대해 풀면 `K² = 2πE w_f` → `K_IC = √(2πE w_f)`. **맞음(단순 역산).**

### 항목 3 — Case 3 (원형홀, Kirsch)

식(9): `σ_θ = (σo/2)[ (1 + R²/r²) − (1 + 3R⁴/r⁴) cos2θ ]`

r = R, θ = π/2 (cos2θ = cosπ = −1):
```
σ_θ(R,π/2) = (σo/2)[ (1+1) − (1+3)(−1) ] = (σo/2)(2 + 4) = 3σo
```
→ **`σ_θ(R,π/2) = 3σo` 맞음** (Kirsch 응력집중계수 3).

식(11): θ = π/2 고정, r 함수로.
```
σ_θ(r,π/2) = (σo/2)[ 1 + R²/r² + 1 + 3R⁴/r⁴ ] = (σo/2)[ 2 + R²/r² + 3R⁴/r⁴ ]
∂σ_θ/∂r = (σo/2)[ −2R²/r³ − 12R⁴/r⁵ ]
r=R:  (σo/2)[ −2/R − 12/R ] = (σo/2)(−14/R) = −7σo/R
|∂σ_θ/∂r (R,π/2)| = 7σo/R
```
→ **식(11) 맞음.**

식(12): `σ_θ(R,π/2) = 3σo ≥ σf` → `σo ≥ σf/3`. **맞음.**
식(13): `σ_θ³ / ( 2E |∂σ_θ/∂r| ) ≥ w_f` — 식(3)의 홀 버전. 형태 일치. **맞음.**

### 선행연구 1 — 느슨한 점 / 코멘트
- 식(4)(5): r(반경거리)과 y(축)를 혼용. 선단 근방 **주항만** 사용 → 고차항·각도의존 무시. 논문의 명시적 가정으로 봐야 함. 유도 자체는 일관됨.
- s의 정의("|dσ_l/ds|를 최소로 하는 방향")는 방향 최소화 → 실제로는 예상 진전방향을 택함. 다소 순환적이나 물리적 동기 있음.
- **w_f = K²/(2πE) 는 Irwin 에너지방출률 G = K²/E'(평면응력) 의 1/(2π) 배.** 논문은 w_f를 "failure gradient"로 부르고 G라 하지 않음 → 내부적으로는 문제 없음. (선행연구 3과의 관계는 항목 6 참조.)

## 선행연구 3 (Kwon·Markoff·DeFisher 2024)

### 항목 4 — 식(1)(2), w_f 와 Y 의 관계

식(1) `σe ≥ σf` (유효응력 조건). 등방취성 → 최대수직응력, 등방연성 → 최대전단/팔면체전단.
식(2) `σe ≥ ( 2EY · |dσe/ds| )^(1/3)`  ⟺  `σe³ ≥ 2EY |dσe/ds|`.

선행연구 1 식(3)을 등호·정리: `σ_l³ = 2E w_f |dσ_l/ds|`.
→ **선행연구 3의 Y ≡ 선행연구 1의 w_f. 동일 기준의 재표기.** 표기만 σ_l→σe, w_f→Y, s 정의 동일.

### 항목 5 — 식(3) → 식(4)

식(3): `σe = K / √s = K s^(-1/2)`  (※ 선행연구 1의 K/√(2πr) 과 달리 **2π 없음**).
```
|dσe/ds| = (1/2) K s^(-3/2)
식(2) 등호:  σe³ = 2EY |dσe/ds|
(K s^(-1/2))³ = 2EY · (1/2) K s^(-3/2)
K³ s^(-3/2) = EYK s^(-3/2)
K³ = EYK  →  K² = EY  →  Y = K²/E
```
→ **식(4) `Y = K²/E` 맞음** (s 소거).

### 항목 6 — "Y = 임계 에너지방출률" 주장 + 2π 문제

- Irwin: `G = K_I² / E'` ( 평면응력 E'=E, 평면변형 E'=E/(1−ν²) ). 표준 K_I 정의는 `σ_yy(θ=0) = K_I/√(2πs)`.
- **선행연구 3의 식(3)은 `σe = K/√s` (2π 없음).** 이 K를 실제 FEA 응력–거리 데이터에 곡선맞춤(Fig 10)으로 뽑으면
  `K(논문) = K_I / √(2π)`.
  → `Y = K(논문)²/E = K_I² / (2πE) = G/(2π)`  → **선행연구 1의 w_f 와 정확히 일치.**
- 즉 **두 논문은 같은 재료상수**(G/2π)를 쓰고 있고, 표기만 K 정의가 다름.
- 논문이 "Y 는 임계 에너지방출률과 동등"이라고 한 문장은 **느슨함**: K 를 표준 K_I 로 해석하면 Y = G 지만, 논문 자신의 식(3)(2π 없음)과 Fig 10 곡선맞춤 절차를 그대로 따르면 Y = G/(2π). 
  - 실무 영향은 **없음**: Y 를 한 시험에서 역으로 뽑아 다른 시편에 쓰는 방식이라 정규화 상수는 상쇄됨.
  - 다만 "Y 를 G_c 문헌값으로 바로 대입"하면 2π 배 오차. 논문은 그렇게 안 함(Karihaloo 시험값에서 추출).

### 항목 7 — Figure 8·9 (경화 시멘트 페이스트 3점굽힘)

**형상 (Fig 8, 대칭 반쪽 모델):**
- 3D 블록: 높이 H, 반쪽 길이 L/2, 폭 W. `L/H = 4`, `W = 100 mm` 고정.
- 균열: 하단면(인장측), 스팬 중앙(= 대칭면)에 깊이 a. 폭 W 전체 관통(through-thickness edge crack).
- `a/H` = 0.1, 0.3, 0.5. `H` = 50 mm 또는 100 mm. `E = 20.8 GPa`, 취성.
- 실험 데이터 출처: Karihaloo, Abdalla, Xiao, "Size effect in concrete beams,"
  *Eng. Fract. Mech.* 2003, 70, 979–993 (ref [39]).

**경계조건 (Fig 9, 3D FE 메쉬):**
- 균일 메쉬, 요소 길이 ≈ 0.3 mm.
- 우측 면(스팬 중앙 대칭면): 대칭 경계조건 — **단, 하단의 균열면은 제외**(자유면).
- 좌측 하단: 롤러 지지(3점굽힘 바깥 지지점).
- 상단면 스팬 중앙 쪽: 폭 전체에 분포하중(3점굽힘 중앙 하중의 절반).

**모델링 절차 타당성:**
1. 3D 선형탄성 해석 → 균열선 따라 응력 분포가 폭방향으로 거의 균일 → 2D(평면) 근사 정당화.
2. 2D 3점굽힘, 4절점 사각형, 메쉬 민감도 후 ≈ 10,000 요소.
3. K 추출: 통상 FEA 는 선단 특이응력 부정확 → 선단에서 조금 떨어진 구간의 σe vs √s 데이터에
   `σe = K/√s` (식3) 곡선맞춤 → 단위하중당 K. (Fig 10: 곡선맞춤이 중간영역은 잘 맞고 선단 극근방만 과대 — 예상된 거동, 방법 타당.)
4. 파괴하중: `Y = K²/E` 가 재료 Y (a/H=0.1, H=100mm 시험서 역추출) 에 도달할 때.

**표준 핸드북식 비교 (참고용, SENB 3점굽힘, ASTM E399, S/W=4):**
```
K_I = [ P S / ( B W^{3/2} ) ] · f(a/W)
f(α) = 3√α [ 1.99 − α(1−α)(2.15 − 3.93α + 2.7α²) ] / [ 2(1+2α)(1−α)^{3/2} ]
```
여기서 W→H(보 깊이), B→W(폭 100mm), S→L(스팬, ≈4H), α = a/H.
- 논문은 이 핸드북식을 **쓰지 않고** FEA+곡선맞춤으로 K 를 직접 얻음 → 유한폭·유한스팬·재료 세부를 자동 반영. 방법론적으로 더 일반적. 핸드북식은 크로스체크용으로만 유효.
- 개념 일치: 둘 다 `K ∝ P·√a · (형상함수)`.

**느슨한 점:**
- a/H = 0.3, H = 100 mm 한 시편만 이론–실험 불일치. 논문도 "추가 정보 없어 규명 못 함"이라고 인정.
- Y 를 단 1개 시편에서 뽑음 → 그 시편의 실험오차가 전체 예측에 전파. (다만 size-effect 검증이 목적이라 허용 가능.)
