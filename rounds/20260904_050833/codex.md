# 독립 조사: LEFM 에너지 접근법 오류 점검 및 2장 보고 구성안

## 0. 결론 요약

기존 HTML의 가장 중요한 문제는 다음 네 가지다.

1. **Griffith 도식의 탄성에너지 곡선 방향이 반대다.** 본문과 SVG 주석은 탄성 퍼텐셜에너지 변화가 `−a²`라고 쓰지만, 실제 파란 곡선은 화면상 위로 상승한다. 그 결과 표시된 빨간 전체에너지 곡선은 그 두 곡선의 합이 될 수 없다.
2. **기호 `Π`를 서로 다른 뜻으로 사용한다.** 식에서는 `G=-dΠ/dA`의 `Π`를 기계계의 총 퍼텐셜에너지로 정의하면서, 그림에서는 `Π+W_s`를 다시 “전체 에너지”라 쓴다. 따라서 `Π`가 (i) 외력까지 포함한 기계적 퍼텐셜인지, (ii) 표면에너지까지 포함한 전체 에너지인지 명시적으로 분리해야 한다.
3. **Kwon의 `Y`는 표준 LEFM의 `G_c`와 수치적으로 같지 않다.** Kwon 논문의 `K`는 `σ_e=K/√s`로 정의된 비표준 계수다. 표준 모드-I 전방 응력식 `σ=K_I/√(2πr)`과 비교하면 `K=K_I/√(2π)`이고, 논문 식 `Y=K²/E`는 `Y=K_I²/(2πE)`가 된다. 그러므로 평면응력에서 `Y=G_c/(2π)`이며, 평면변형에서는 `Y=G_c/[2π(1−ν²)]`이다. 논문의 “equivalent”는 같은 에너지 차원 및 비례성을 뜻할 수는 있지만, 동일한 수치라는 뜻으로 사용하면 틀린다.
4. **기존 설명은 Griffith의 이상취성 표면에너지와 일반 재료의 파괴저항을 빨리 섞는다.** `G_c=2γ_s`는 새 자유표면 생성만 소산으로 보는 이상취성 Griffith 모델의 결과다. 시멘트계 준취성재에서는 균열가교, 미세균열, 마찰 등 파괴공정영역의 소산 때문에 일반적으로 저항 `R` 또는 조건부 임계값 `G_c`를 사용해야 하며, 이를 열역학적 표면에너지 `2γ_s`와 동일시해서는 안 된다.

따라서 새 HTML은 “에너지 수지의 정의와 도식”을 1장, “`G–K_I–Y` 환산 및 계수 오류”를 2장으로 구성하는 것이 가장 명확하다.

## 1. 기존 HTML에서 직접 확인한 내용과 판정

검토 대상: 문제에 명시된 `보고서_LEFM_에너지접근_모델수치역산.html`의 제2장.

### 1.1 맞는 내용

- 균열 진전 구동력을 `G=-∂Π_m/∂A`로 나타내는 것은 맞다. 단, `Π_m=U-W_ext`는 **기계계의 퍼텐셜에너지**이고 미분 시 하중·변위 제어 조건을 명시해야 한다.
- 한 개의 투영 균열면적 증가 `dA`가 두 자유표면을 만들도록 `A`를 정의하면 이상취성체의 저항은 `dW_s/dA=2γ_s`다.
- 등방 선형탄성 순수 모드 I에서 `G=K_I²/E'`, `E'=E`(평면응력), `E'=E/(1−ν²)`(평면변형)는 맞다.
- Kwon의 정의를 그대로 대수 전개하면 `Y=K²/E`가 되는 것도 맞다.
- 실제 시멘트 페이스트의 유효 파괴저항이 단순한 `2γ_s`보다 클 수 있다는 방향은 맞다.

### 1.2 반드시 고쳐야 할 내용

#### (a) 에너지 그림의 부호/형상 오류

기존 SVG에서 주황선 `W_s∝+a`는 위로 증가하고, 파란선에는 `−U∝−a²`라고 쓰였지만 역시 위로 증가한다. 수직축이 통상처럼 위쪽이 양이라면 파란선은 **아래로 굽어 내려가야** 한다. 또한 현재 빨간선은 처음 증가한 뒤 극대에서 감소하는데, 현재 표시된 두 증가곡선의 합으로는 만들 수 없다.

무한판 중앙 관통균열(반길이 `a`), 원격 일정응력 `σ`, 단위 두께, 평면응력을 예로 들면

```math
\Delta\Pi_m(a)=-\frac{\pi\sigma^2a^2}{E},\qquad
W_s(a)=4\gamma_s a,
```

```math
\Delta\Pi_{tot}(a)=4\gamma_s a-\frac{\pi\sigma^2a^2}{E}.
```

여기서 `W_s=4γ_sa`인 이유는 전체 균열길이가 `2a`이고 두 면이 생기기 때문이다. 반면 `G`의 면적 `A`를 한쪽 투영면적으로 두면 `dW_s/dA=2γ_s`다. **`a`, 전체 균열길이 `2a`, 한 면의 투영면적 `A`, 실제 생성된 두 면의 면적을 혼용하면 계수 2 또는 4 오류가 난다.**

#### (b) `Π` 정의의 혼용

권장 기호는 다음과 같다.

```math
\Pi_m=U-W_{ext},\qquad
\Pi_{tot}=\Pi_m+W_s,
```

```math
G=-\left(\frac{\partial\Pi_m}{\partial A}\right)_{control},\qquad
R=\frac{\partial W_{diss}}{\partial A},\qquad
\text{진전 조건: }G\ge R.
```

이상취성·평탄 저항이면 `R=G_c=2γ_s`; 일반 재료라면 `R=R(Δa,...)`일 수 있다. 평형점은 `∂Π_tot/∂A=0`, 즉 `G=R`이다. 안정성은 이것만으로 결정되지 않고 `∂²Π_tot/∂A²` 또는 `dG/dA`와 `dR/dA`의 비교가 추가로 필요하다. 따라서 기존 그림의 “극대 → 불안정 전파”는 특정 일정응력 무한판 예에서는 맞지만 일반 정의처럼 쓰면 안 된다.

#### (c) “방출 변형에너지”라는 명칭

`G`는 단순히 저장 변형에너지 `U`의 감소율이 아니라, 외력의 일까지 포함한 **총 기계적 퍼텐셜에너지의 감소율**이다. 하중제어에서는 균열 성장과 함께 `U` 자체가 증가할 수 있어도 외력이 더 큰 일을 하므로 `Π_m=U-W_ext`는 감소한다. 따라서 슬라이드에는 “방출 변형에너지”보다 “기계적 퍼텐셜에너지 감소”라고 쓰는 편이 정확하다.

#### (d) `Y`와 `G_c`의 계수

Kwon et al. (2024)의 식은

```math
\sigma_e\ge[2EY(d\sigma_e/ds)]^{1/3},\qquad
\sigma_e=K/\sqrt{s},\qquad Y=K^2/E
```

로 제시되어 있다. 그러나 균열 전방에서 `dσ_e/ds<0`이므로 첫 식은 실수값·물리적 문턱값을 위해 `|dσ_e/ds|` 또는 `−dσ_e/ds`로 써야 한다. 절댓값을 사용해 직접 계산하면

```math
\frac{\sigma_e^3}{2E|d\sigma_e/ds|}
=\frac{K^3s^{-3/2}}{2E(K/2)s^{-3/2}}
=\frac{K^2}{E}=Y.
```

표준 LEFM 정규화는

```math
\sigma_{opening}(r,0)=\frac{K_I}{\sqrt{2\pi r}},
\qquad K=\frac{K_I}{\sqrt{2\pi}}.
```

따라서

```math
Y=\frac{K_I^2}{2\pi E}.
```

한편 표준 관계는

```math
G=\frac{K_I^2}{E'},\qquad
E'=\begin{cases}E&\text{평면응력}\\E/(1-\nu^2)&\text{평면변형}\end{cases}.
```

그러므로 임계상태에서

```math
Y=\begin{cases}
G_c/(2\pi),&\text{평면응력},\\
G_c/[2\pi(1-\nu^2)],&\text{평면변형}.
\end{cases}
```

즉 `Y≡G_c`라고 표기하면 안 된다. 또한 Kwon 식의 탄성계수는 항상 `E`이므로, 평면변형 환산에서 임의로 `E'`를 Kwon 식에 대입해서도 안 된다. 그것은 원래 제안된 기준을 바꾸는 일이다.

## 2. 새 단일 HTML의 2장 구성안

### 슬라이드 1 — “균열은 언제 자라는가? 에너지 수지”

**한 줄 메시지:** 균열은 기계계가 내놓는 에너지 `G`가 재료가 요구하는 저항 `R`에 도달할 때 진전한다.

왼쪽 55%에는 검은 테두리 수식 박스와 빨간 화살표의 세로 흐름도를 둔다.

```text
┌──────────────────────────────────────────┐
│ 기계적 퍼텐셜에너지  Π_m = U − W_ext     │
└──────────────────────────────────────────┘
                    ↓ 빨간 화살표: 균열면적 A로 미분
┌──────────────────────────────────────────┐
│ G = −(∂Π_m/∂A)_control   [J/m²]           │
└──────────────────────────────────────────┘
                    ↓ 빨간 화살표: 재료저항과 비교
┌──────────────────────────────────────────┐
│ G < R: 정지 │ G = R: 개시 │ G > R: 진전  │
└──────────────────────────────────────────┘
```

오른쪽 45%에는 **수정된 Griffith 에너지 곡선**을 SVG로 그린다.

- 가로축: 균열 반길이 `a`; 세로축: `a=0` 대비 에너지 변화.
- `W_s=+4γ_sa`: 0에서 시작해 우상향하는 직선(주황).
- `ΔΠ_m=−πσ²a²/E`: 0에서 시작해 우하향하는 포물선(남색).
- `ΔΠ_tot=W_s+ΔΠ_m`: 처음 상승하고 `a_c`에서 극대 후 감소(빨강).
- `a_c`에 점선과 `dΠ_tot/da=0 ⇔ G=2γ_s` 표기.
- 캡션에 “무한판 중앙균열·일정 원격응력·단위두께의 개념 예; 유한 SENB에는 그대로 적용하지 않음”을 명시.

하단 주의 박스:

> `G`의 `A`는 한쪽 투영 균열면적 기준이다. 새 자유표면은 두 개이므로 이상취성 저항은 `2γ_s`다. 시멘트계 준취성재에서는 일반적으로 `R≠2γ_s`이다.

### 슬라이드 2 — “표준 LEFM와 Kwon의 Y: 같은 차원, 다른 정규화”

**한 줄 메시지:** Kwon의 `K`에는 표준 LEFM의 `1/√(2π)`가 흡수되어 있으므로 `Y`와 `G_c` 사이에 반드시 `2π` 계수가 남는다.

중앙에 가로 흐름도를 둔다.

```text
┌─────────────────────────────────┐
│ 표준 균열 전방 응력              │
│ σ = K_I / √(2πr)                │
└─────────────────────────────────┘
                → 빨간 화살표: K = K_I/√(2π)
┌─────────────────────────────────┐
│ Kwon 표기                        │
│ σ = K/√s,   Y = K²/E            │
└─────────────────────────────────┘
                → 빨간 화살표: 표준 K_I로 환산
┌─────────────────────────────────┐
│ Y = K_I²/(2πE)                  │
└─────────────────────────────────┘
                → 빨간 화살표: G = K_I²/E′
┌─────────────────────────────────┐
│ 평면응력: Y = G_c/(2π)          │
│ 평면변형: Y = G_c/[2π(1−ν²)]   │
└─────────────────────────────────┘
```

하단에는 3열 비교표를 둔다.

| 양 | 정의 | 단위/주의 |
|---|---|---|
| `G`, `G_c` | 표준 에너지방출률과 임계값 | J/m²; `K_I²/E'` |
| `K_I` | 표준 모드-I 응력확대계수 | MPa√m; `1/√(2πr)` 포함 |
| Kwon `K` | `σ=K/√s`의 곡선맞춤 계수 | MPa√m; `K_I/√(2π)` |
| `Y` | Kwon 응력구배 기준의 재료값 | J/m²; `G_c`와 수치 동일하지 않음 |

오류 경고는 빨간 띠로 다음처럼 쓴다.

> **금지:** 문헌의 `G_c`를 Kwon의 `Y` 자리에 직접 대입. 평면응력에서도 2π배 오류가 발생한다.

## 3. HTML 구현 요구사항

- 하나의 자립형 HTML 파일로 구성하고, 각 장은 화면/인쇄에서 정확히 16:9 한 페이지가 되도록 `.slide { aspect-ratio:16/9; break-after:page; }`를 사용한다.
- 수식은 MathJax로 렌더링하되, 흐름도 박스·화살표·곡선은 외부 이미지가 아니라 인라인 HTML/CSS/SVG로 넣어 확대·인쇄 시 선명도를 유지한다.
- 수식 박스: 흰 배경, `2px solid #111`, 8–12 px 모서리, 그림자 최소화.
- 화살표: 진한 빨강(`#c62828`), 굵기 3–4 px, 화살촉 명확히. 의미 있는 변환 문구를 화살표 옆에 둔다.
- 에너지 도식은 좌표축에 0을 표시하고 `ΔΠ_m`가 반드시 0 아래로 내려가게 한다. 세 곡선의 합 관계가 시각적으로 일치해야 한다.
- “`G=R`이면 언제나 불안정”이라고 쓰지 않는다. 안정/불안정은 구동력과 저항의 기울기 및 제어조건에 달려 있음을 각주로 둔다.
- 혼동을 막기 위해 `Π_m`, `Π_tot`, `W_s`, `A`, `a`, `K_I`, Kwon `K`, `G`, `R`, `Y`를 처음 등장할 때 정의한다.
- 첨부 이미지의 실제 픽셀 자료는 문제 입력에서 확인되지 않았으므로, 요구된 시각 문법(검은 테두리 박스·빨간 화살표)만 위 설계로 재현한다.

## 5. 최종 판정

- 기존 HTML의 에너지 접근법은 기본 방향은 맞지만, **그림의 부호가 물리적으로 틀리고**, `Π`의 의미가 혼용되어 있으며, `Y`와 `G_c`의 관계는 비표준 `K` 정규화 때문에 **수치적 동일성이 성립하지 않는다**.
- 보고용 두 장에서는 Griffith–Irwin–Kwon을 하나의 동일식처럼 연결하지 말고, 첫 장에서 표준 에너지 수지 `G↔R`, 둘째 장에서 표준 `K_I`와 Kwon `K`의 정규화 차이를 분리해야 한다.
- 시멘트 페이스트에는 `G_c=2γ_s`를 재료값으로 직접 쓰지 말고, 실험 정의와 시험법에 부합하는 유효 파괴저항을 사용해야 한다.
