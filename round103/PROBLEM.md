## Title/Authors → 상/중/하 환산 규칙 (기존 세션에서 적용, 변경 없음)

Title/Authors는 10점 만점 체크리스트 점수를 상/중/하로 환산한다. 환산 규칙: **상 = 8점 이상 / 중 = 6~8점
미만 / 하 = 6점 미만**. 15편 원점수(CSV 기준): No.1=7.65, No.2=5.45, No.3=4.65, No.4=7.15, No.5=7.45,
No.6=9.4, No.7=8.25, No.8=8.75, No.9=7.15, No.10=7.15, No.11=7.55, No.12=8.65, No.13=7.45, No.14=9.15,
No.15=7.45.

슬라이드 3엔 이 숫자 기준은 노출돼 있지 않고 대신 "상 = 기본요건 충족 + ORCID 기재 / 중 = 기본요건
충족하나 ORCID 미기재 / 하 = 제목 간결성 기준(단어수) 초과"라는 정성적 설명으로 대체돼 있다. 이 정성적
설명 자체가 실제 15편 데이터 패턴과 맞는지도 검증 대상이다(아래 항목 2).

## 검증 요청

스냅샷 pptx의 12장 전체를 직접 열어 읽고, 아래 관점에서 독립적으로 점검해 **새로 발견한 문제**를 보고하라.
(이미 round98~100에서 다뤄진 Best/Worst 선정의 타당성 자체는 재검토 대상이 아니다.)

1. **텍스트 무결성**: 문장이 끊기거나 괄호가 안 닫히는 등 깨진 텍스트가 있는가. 슬라이드 전체를 훑어서
   찾아라(한 군데는 이미 알려져 있을 수 있으나, 어디인지 미리 알려주지 않을 것이니 직접 찾아라).
2. **Title/Authors 상/중/하 환산 정확성**: 슬라이드 4~6 표와 7·9의 등급(상/중/하)이 위 환산 규칙과 CSV
   원점수로 정확히 재현되는가(15편 전부 직접 재계산). 또한 슬라이드 3의 ORCID 기준 설명("상 = 기본요건
   충족 + ORCID 기재 / 중 = 기본요건 충족하나 ORCID 미기재 / 하 = 제목 간결성 기준 초과")이 CSV의 실제
   ORCID·간결성 세부점수 패턴과 맞는 설명인지 검증하라.
3. **슬라이드 4~6 표의 비고란 단일 등급**이 위에 제시한 원래 쌍 데이터에 "최솟값 규칙"을 적용한 결과와
   정확히 일치하는가(60칸 전부 재계산). 불일치가 있으면 어느 칸인지 구체적으로 지적하라.
4. **결론(슬라이드 11)의 통계 주장 검증**: "Methodology·Results는 15편 중 '하' 등급 0편", "Introduction은
   1편(No.11)", "초록(Abstract)은 7편"이라는 주장을 위 원래 쌍 데이터(구체성 축 기준)로 직접 재집계해
   검증하라. 슬라이드에 그 축(구체성 기준이라는 사실)이 명시돼 있지 않다면 지적하라.
5. **슬라이드 7·9의 논문 인용 수치**(BSFC 9.70%, BTE 17.14%, 고장 크기 15%, 수렴시간 0.03초, "the desired
   objective is achieved" 등)가 해당 PDF 원문과 정확히 일치하는가. 가능하면 페이지까지 확인하라.
6. **슬라이드 간 일관성**: Contents(슬라이드2)가 실제 슬라이드 구성과 맞는가, 제목·번호 표기에 모순은
   없는가.
7. 그 외 임의로 발견한 사실 오류·오탈자·서식 문제가 있으면 전부 보고하라.
