# round103 독립 검증 — Claude

검증일: 2026-11-24. 대상: `round103/input/기말_발표자료_snapshot.pptx` 12장. 작성 시점에 Codex의 `codex.md`를 이미 읽었으므로 이는 blind 조사가 아니라 교차검토(review) 성격을 겸한다. Best=No.5, Worst=No.11 확정 결정은 재심하지 않는다.

## 검증 방법

python-pptx로 12장 텍스트·표를 직접 읽고, `SCI논문15편_Title_Authors_분석표.csv`·`SCI논문15편_Abstract_분석표.csv`를 재대조했다. No.11 PDF(`Model-Based Unified Framework...pdf`)를 pdf2image로 전체 페이지를 직접 렌더링해 Methodology·Results·Lyapunov 안정성 증명·결과 그래프(Fig.4~11)를 확인했다.

## Codex 보고서(`codex.md`) 검토 결과 — 핵심 항목 재확인, 전부 동의

1. **슬라이드 7 미폐쇄 괄호**: `단점: 저널 분량 규정은 확인 불가(판정보류` — 직접 확인. 이번 세션 이전부터 있던 결함.
2. **슬라이드 3 ORCID/간결성 설명 오류**: CSV 재계산 결과 상 등급 5편(No.6,7,8,12,14) 중 **No.8만 ORCID 0점**인데도 8.75점으로 상이다. 간결성도 No.4·5·7·10이 감점됐지만 중/상이므로 "간결성 기준 초과 → 하"는 전칭 규칙이 아니다. Codex 판정에 동의.
3. **공동1저자(0.5) 항목 누락**: 슬라이드 3 체크리스트 나열에서 확인. 이전 제 검토에서도 동일하게 발견했던 항목.
4. **비고란 최솟값 규칙 미표시**: 슬라이드 3·4~6 어디에도 "min(구체성,연관성)" 산식이 없음. 직접 확인.
5. **슬라이드 7·9의 선정 근거 축 불일치**: No.4·No.11 "하 등급 동률" 주장은 원래 8축(구체성+연관성 개별 평가) 기준으로만 성립한다. `paper_ranking.csv`로 재확인: No.4=상4/중2/하2, No.11=상2/중4/하2로 하 2개 동률 맞음. 현재 PPTX 4축 요약표만으로는 No.11이 하 2개, No.4가 하 1개로 안 보이므로 재현 불가. Codex 판정에 동의.
6. **슬라이드 11 통계에 축 명시 누락**: 동의. "하" 집계는 구체성 축 기준.
7. **No.11 "결과 수치 없음" 과도 일반화**: No.11 PDF 9~10쪽을 직접 렌더링해 확인한 결과, Fig.5(엔진각도·속도 추정), Fig.7(피스톤력 추정), Fig.8(완화 효과), Fig.11(고장 추정, % 축)에 수치 축을 가진 결과 그래프가 분명히 존재한다. 다만 검출지연·정상상태오차·완화율 같은 **성능 지표를 본문 문장이나 표의 숫자로 명시하지는 않았다**. "수치로 보여주지 못함"은 과도하고, "수치 지표로 명시하지 않음"이 정확하다. Codex 판정에 동의.
8. **"측정·실험은 꼼꼼했음" 과도 일반화**: No.11은 슬라이드 9 자체가 "전부 컴퓨터 시뮬레이션으로 검증"이라 명시하며, PDF Results 섹션(6장) 제목도 "Results and Discussion"이지만 전부 MATLAB/SIMULINK 시뮬레이션 결과다. 실측(측정)이 아니므로 "측정·실험은 꼼꼼했다"는 서술은 No.11에는 맞지 않는다. 구체성 하 0편(Methodology/Results)이라는 사실과 "측정을 꼼꼼히 했다"는 해석은 구분해야 한다. Codex 판정에 동의.
