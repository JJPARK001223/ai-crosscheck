# Kamaya (2009) J-적분 해: 반타원 표면균열 표에 적용 가능성 검토 (blind review)

(시스템 언어 규칙에 따라 한국어로 작성했습니다. 수식과 용어는 원문 그대로 두었습니다. 영어 보고서가 필요하면 말씀해 주세요.)

원문은 PDF 텍스트 추출본이라 그리스 문자가 `?`로 깨져 있습니다. 아래에서 "재구성"이라고 쓴 항목은 문맥과 극한값으로 복원한 것이며, 원본 PDF 대조가 필요합니다.

## 1. 결론 요약

1. 이 논문의 ML(식 7)과 h1은 **uniform-depth(깊이가 일정한) 내면 원주방향 표면균열, 순수 굽힘 하중**에 대한 값입니다. 반타원 균열은 FEA 대상이 아닙니다(p.1116–1118, 결론 p.1125).
2. 반타원 표에서 읽은 값에 이 논문의 h1을 쓰거나, 반대로 이 h1에 반타원 해의 정규화를 맞추는 것은 논문으로 정당화되지 않습니다. 반타원 균열은 같은 최대 깊이에서도 K가 작다고 논문이 직접 말합니다(p.1120). ML도 균열 면적이 달라 같지 않습니다.
3. **factor 2는 이 논문에서 나오지 않습니다.** 논문은 1/4 모델이라고만 쓰고(p.1118), 반 모델에서 기준 노드에 걸 모멘트가 전체 M인지 M/2인지는 쓰지 않았습니다. 식 (2)의 M은 파이프 전체에 작용하는 모멘트입니다.
4. 조건부 ML은 Rm=300, t=60, a=30, θ=π/2, σy=200일 때 **ML ≈ 2.9112×10⁹ N·mm** 입니다.
   - 가한 모멘트 −4.36674×10⁹은 이 ML의 정확히 **1.5배**입니다(아래 §4).
   - Excel의 ML=5×10⁸은 이 식과 이 치수로 재현되지 않습니다.

## 2. 식과 정확한 적용 범위

| 식 | 내용 | 페이지 |
|---|---|---|
| (1) | 완전소성 재료: ε/ε₀ = α(σ/σ₀)ⁿ | 1115–1116 |
| (2) | Jp = h1 · (ασy²t/E) · (M/ML)^(n+1) | 1116 |
| (3) | Ramberg-Osgood: ε/εy = σ/σy + α(σ/σy)ⁿ | 1116 |
| (4) | J = Je + Jp = K(ae)²/E′ + h1(ασy²t/E)(M/ML)^(n+1), E′ = E/(1−ν²) | 1116 |
| (5) | K(ae) = f1·σ·√(πae) | 1116 |
| (6) | Kumar 소성보정 ae: a + [1/(6π)]·[(n−1)/(n+1)]·(K/σy)²·1/(1+(M/ML)²) | 1116 |
| (7) | ML = 2σy·Rm²·t·[2 sinβ − (a/t) sinθ] | 1117 |
| (8) | β = ½[π − (a/t)θ] (재구성) | 1117 |
| (9)–(11) | ae의 수정식. 최종 상수는 (0.5n−1.5), 2, 1. 식 (11)은 p.1124 | 1123–1124 |

- **식 (5)의 σ**: 추출본에서 정의를 확인할 수 없습니다. Fig. 4의 f1 = KI/(σ√πa)로만 나옵니다. 그래서 Je는 계산하지 않았습니다.
- **식 (7) 재구성의 근거**: 균열이 없을 때(a=0) β=π/2이므로 ML=4σyRm²t로 무결 파이프 한계모멘트와 맞습니다. 추출본에 "2π" 형태 표기가 있어 β=1/(2π)(…)일 가능성도 있었지만, 그 경우 a=0에서 성립하지 않아 배제했습니다. 단, 식 (7)의 σy 표기와 식 (8)은 PDF에서 확인이 필요합니다.
- **θ**: 균열각의 **절반**이며, 균열 전체각은 2θ입니다. 균열은 내면에 있고 깊이가 일정합니다(Fig. 1, p.1117).
- **식 (9)의 구조**: 추출본이 심하게 깨져 있어 상수 φ, ψ, ξ(기호 확인 불가)의 정확한 배치를 단정하지 않습니다.

**해석 범위**
- 파라미터 범위(p.1117): Rm/t = 5, 10, 20, a/t = 0.1–0.8, θ/π = 0.05–0.5, n = 3, 5, 7, 10, 13.
- α는 1.5로 고정했습니다. 추가로 α=4, 8을 Rm/t=10에서만 검증했습니다(p.1117, Fig. 10).
- 재료 상수: σy=200 MPa, E=180 GPa(정규화용), ν=0.3, t=40 mm.
- 모델: ABAQUS 6.5, 20절점 감차적분 요소, **1/4 모델**, 단부 길이 L=5(Ri+t)(p.1118).
- J와 K는 균열 중앙에서 2–4번째 contour 평균으로 구했습니다(p.1118).
- h1은 M=ML에서 완전소성 재료로 구했습니다. 재료는 매우 큰 영률의 poly-linear 곡선입니다(추출본 "3×100 TPa"는 범위 표기 가능성이 있어 원문 확인 필요).
- 메시 수렴: 최대 2.4% 차이(p.1119).
- 추정식 오차(p.1123–1125): F가 −25% ~ +48%이고 평균은 약 0입니다. M/ML = 1.0, 1.2, 1.5, 1.8에서 평가했습니다.
- 하중은 굽힘만 다뤘고, 내압과 축력은 없습니다.

**반타원과의 구분 (논문이 직접 밝힌 것)**
- 반타원 해는 Ref.(16) Chapuliot와 비교한 K(Fig. 4)뿐이고, J나 h1은 비교하지 않았습니다.
- 반타원 균열의 최심점 K는 uniform-depth보다 작습니다(p.1120).
- 논문은 ML이나 J를 반타원 균열로 확장하지 않았습니다. 이 확장은 논문에 없는 추론입니다.

## 3. 벤치마크 조건에서의 값 (uniform-depth 가정 시에만 유효)

Rm/t=5, θ/π=0.5, a/t=0.5, n=5에서 표 값은 다음과 같습니다.
- Table 1: f1 = 1.29 (p.1119)
- Table 2(a), n=5: h1 = 1.52 (p.1120)

α=2는 논문의 α 집합(1.5, 4, 8)에 없습니다. 다만 식 (2)는 α를 인수로 분리해 두었으므로 h1 자체는 α와 무관하다고 볼 수 있습니다. 식 (11) 보정의 검증은 α=1.5, 4, 8에 한합니다.

M/ML=1에서 식 (2)로 계산한 Jp는 다음과 같습니다.
- ασy²t/E = 2·200²·60/200000 = 24 N/mm
- Jp = 1.52 × 24 = **36.5 N/mm** (kN/m와 같음)
- M/ML=1.5이면 ×1.5⁶ = 11.39 → **약 415 N/mm**

이 값은 uniform-depth 균열에 대한 값일 뿐, 반타원에 대한 값이 아닙니다.

## 4. 조건부 ML 계산

가정은 Rm=300, t=60, a=30 mm, σy=200 MPa, θ=π/2입니다.

- β = ½(π − 0.5·π/2) = 3π/8 = 67.5°
- 2 sinβ = 1.847759, (a/t) sinθ = 0.5 → 괄호 = 1.347759
- 2σyRm²t = 2·200·300²·60 = 2.16×10⁹ N·mm
- **ML = 2.9112×10⁹ N·mm** (2.911 kN·m×10³)

**수치 일치**: 1.5 × 2.911159×10⁹ = 4.36674×10⁹로, 가한 모멘트와 유효숫자 6자리까지 일치합니다. 이는 하중이 이 식과 이 치수로 M/ML=1.5를 목표로 만들어졌음을 강하게 시사하는 정황입니다. 다만 치수가 검증된 것은 아닙니다.

**factor 2의 해석 (논문 외 추론)**
- 기준 노드가 반단면에만 결합되어 있다면, 전체 M에 해당하는 반 모델의 입력은 M/2입니다.
- 4.36674×10⁹을 그대로 M_ref로 쓰면 실제 M/ML은 3.0일 수 있습니다.
- 반대로 이 값이 이미 전체 M을 뜻하고 모델 쪽에서 분배된다면 1.5입니다.
- 어느 쪽인지는 모델 파일(결합 방식, 기준 노드가 걸린 면)로만 판단할 수 있습니다.

**Excel 값과의 불일치**
- ML=5×10⁸은 식 (7)로 재현되지 않습니다. Rm=300, t=60에서는 5.8배 작은 값입니다.
- StepTime·1.5e9·2 = 3×10⁹·t이고, 4.36674×10⁹과 일치하지 않습니다. ML=5×10⁸로 나누면 M/ML이 6까지 갑니다.
- 3×10⁹/2.9112×10⁹ ≈ 1.03이라 식 (7)의 ML과도 1.5가 되지 않습니다.
- 두 값 모두 근거가 없으므로 수정 전에는 사용하지 않는 편이 안전합니다.

## 5. 필요한 누락 증거

1. **원본 PDF**: 식 (7), (8), (9)의 기호와 σy 표기 확인. 식 (5)의 σ 정의, "3×100 TPa" 표기 확인.
2. **반타원 표의 출처와 정의**: 정규화(ML 정의, J 무차원화, f1/h1 정의), 반타원의 a, c와 θ 대응, 최심점과 표면점 중 어디의 값인지. 인용된 Chapuliot(2000)이나 다른 문헌 가운데 어느 것인지.
3. **Abaqus 입력 파일(.inp)**: 기준 노드와 결합(coupling) 대상 면, 대칭면의 실제 방향, 모멘트가 걸리는 축, 기준 노드의 reaction moment 출력(RM1). 이것이 factor 2의 유일한 직접 증거입니다.
4. **기하 검증**: 메시에서 실제 Rm, t, a, 균열 전체각(2θ)과 균열 위치(내면/외면). 논문은 내면 균열입니다.
5. **Excel**: StepTime 정의, "×2"와 ML=5×10⁸의 산출 근거.
6. **재료 모델 정의**: Abaqus의 R-O 입력(yield offset α, n)이 식 (3)과 같은 정규화인지.
7. **정당화 불가 항목**: 반타원에 대한 ML과 h1은 별도 FEA 또는 해당 표의 정의가 있어야 합니다. 같은 균열에서 ML만 바뀌는 경우에는 h1′ = h1(ML′/ML)^(n+1) 재스케일이 수학적으로 가능합니다(n=5이면 6제곱).
