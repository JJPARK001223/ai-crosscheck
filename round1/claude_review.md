## 0. 총평

두 답변은 **사실 관계에서 정면 충돌하는 부분이 없다.** 핵심 수식(σ = K/√(2πr),
w_f = K²/(2πE), K_Ic = √(2πE·w_f), Y = K²/E)과 인용 위치는 양쪽 다 원문과 일치한다.

차이는 **충실도(coverage)** 다.
- **claude.md**: 두 논문이 실제로 제안하는 **응력구배(stress gradient) 조건**을 균열 파손의
  본 기준으로 소개하고, K = K_Ic 는 그로부터 유도되는 등가 관계로 배치. 원문에 더 충실.
- **codex.md**: 응력구배 조건을 **전혀 언급하지 않고** 고전적 LEFM(K = K_Ic)만으로 서술.
  초보자 가독성·인라인 시각화는 낫지만, "이 두 논문이 말하는 LEFM"이라기보다
  "교과서 LEFM"에 가깝다.

시각화 요구(사용자가 명시)는 **양쪽 다 미흡**하다(§4).

## 2. 충돌 / 차이 (중요)

정면 사실 충돌은 없음. 아래는 서술 범위·강조점 차이.

### A. 응력구배 조건의 취급 — **가장 큰 차이**
- **claude.md**: [선행1] Eq.(2)–(3), [선행3] Eq.(2)의 응력구배 파손조건을 균열 파손의
  **실제 기준**으로 제시(§2-1, §2-4, §3 표, §4). K = K_Ic 는 w_f 임계 도달의 등가 표현으로 배치.
- **codex.md**: 응력구배 조건을 **한 번도 언급하지 않음.** 균열 파손 = "K가 K_Ic에 도달"
  (mermaid 순서도 포함)으로만 서술.
- 판정: **claude.md가 원문에 충실.** 두 논문의 표제 자체가 "Stress and Stress Gradient
  Conditions"이고, [선행3] §4.3은 "Because of the crack ... the stress gradient condition
  is used for the prediction of the failure loads. ... the stress condition is already
  satisfied at the crack tip."라고 명시한다. codex.md만 읽으면 독자는 이 논문들의
  실제 방법을 알 수 없다.

### B. 구멍의 응력집중 수치
- **codex.md**: σ_θ(R, π/2) = 3σ_o (Kirsch)를 수치로 제시하여 균열(특이) ↔ 구멍(유한) 대비.
- **claude.md**: 정성 서술만("구멍은 유한"), 3σ_o·구배 7σ_o/R([선행1] Eqs.(9),(11)) 누락.
- 질문이 "LEFM(=균열)"이므로 치명적이진 않으나, codex.md의 대비가 더 구체적.

### C. 시각화
- **codex.md**: 마크다운에 ASCII 개념도 + mermaid 순서도를 **인라인**으로 넣어 즉시 열람 가능
  (단, 정량 그래프 아님).
- **claude.md**: `lefm_viz.py`(matplotlib) 스크립트만 저장. **이 세션에서 실행 못 함 →
  실제 이미지 0장.** 사용자가 "시각화 자료도 필요"라고 명시했는데 산출물이 미완.

### D. [선행3] 서론의 오문 처리
- 원문 p.1: *"...an entirely different set of failure criteria was used because fracture
  mechanics **is suitable for** holes."* — 앞뒤 논리상 "is **NOT** suitable"이어야 함.
- **claude.md**: 오타/누락으로 판단한다고 명시(§4-3).
- **codex.md**: 의도된 뜻으로 조용히 바꿔 서술(p.1 인용). 과학적으론 맞지만 원문 결함을
  독자에게 알리지 않음. 교차검증 관점에선 claude.md의 처리가 낫다.

## 3. Codex의 오류 / 부정확

1. **응력구배 조건 전면 누락 (중대).** 두 논문의 핵심 명제를 빠뜨리고 균열 파손을
   교과서 LEFM(K = K_Ic)으로만 제시. "이 두 자료로 설명한 LEFM"이라는 과제 취지에서
   이탈. (근거: [선행1] Eqs.(2)–(3), [선행3] Eq.(2), §4.3)
2. **[1, p.2] 미세 오귀속.** codex.md: "균열 문제에서는 ... K와 임계값의 비교가 핵심이
   된다고 설명한다." → [선행1] p.2 Case 2 원문은 *"the stress gradient is the dominating
   factor for the failure."* K–K_Ic 비교가 아니라 응력구배가 지배 인자라고 되어 있음.
3. **인용 범위 부정확(경미).** codex.md "[1, p.2 ... Eqs. (9)–(12)]" — 구멍 응력은
   Eqs.(8)–(10), 구배 (11), 파손조건 (12)–(13). "(9)–(12)"는 어긋남.
4. **원문 오문 미표시(경미).** §2-D 참조.
5. **출처 한계 고지 약함.** 두 논문이 LEFM을 "가르치는" 글이 아니라 비교 대상으로만
   짧게 다룬다는 점을 claude.md는 §0에서 분명히 하지만 codex.md는 끝에 한 줄뿐.

**오류가 아님(정확 확인):** σ_x = K/√(2πr), 3σ_o, Y = K²/E, w_f = K²/(2πE),
K_Ic = √(2πE·w_f), 그리고 p.1·p.2 인용 위치.

## 4. Claude가 놓친 점

1. **시각화 산출물 미완 (사용자 요구 직결).** `lefm_viz.py`가 실행되지 않아 이미지가
   하나도 생성되지 않음. 최소한 codex.md처럼 ASCII/텍스트 개념도라도 `claude.md` 본문에
   인라인했어야 함. (main 세션에서 `python round1/lefm_viz.py` 실행 필요 — 검산 assert 포함)
2. **`lefm_viz.py` 폰트 버그.** 주석은 "라벨은 영어로 둠"이라 하지만 45·79·116행 라벨에
   `[선행연구1]`/`[선행연구3]` 한글이 그대로 남아 있음 → Agg + CJK 폰트 없음 환경에서
   글리프 깨짐(□) + 경고. 해당 문자열을 ASCII로 교체 필요.
3. **구멍 응력집중 수치 누락.** σ_θ,max = 3σ_o, |∂σ_θ/∂r| = 7σ_o/R ([선행1] Eqs.(9),(11)).
   균열↔구멍 대비를 정량화하는 데 유용하고 과제 범위 내.
4. **[선행1] 일반형 Eq.(2)–(3) 미수록.** claude.md 표는 [선행3] Eq.(2)만 싣고,
   [선행1]의 (σ_l²/2E)/((1/σ_l)|dσ_l/ds|) ≥ w_f 및 간략형 (σ_l³/2E)|ds/dσ_l| ≥ w_f 는
   본문·표에서 빠짐(Eq.5·6만 인용). 응력구배 기준의 "원형"을 보여주려면 넣는 게 좋음.
5. **정의 첫 줄의 내적 긴장.** §1 한 줄 정의가 "K가 K_Ic에 도달하면 파손"으로 시작 —
   이후(§0·§4)에 "표준형은 이 파일에 없음"이라 스스로 단서를 다는 내용과 톤이 어긋남.
   "응력구배 조건 충족 시 파손(등가적으로 K = K_Ic)"으로 다듬는 편이 일관됨.
