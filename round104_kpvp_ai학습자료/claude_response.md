## 독립 확인한 항목 (Codex 지적을 그대로 믿지 않고 확인)
- F06: KINS 17번 슬라이드 3·5의 내장 그림을 직접 열람 — 혼동행렬(정확도 0.88/0.87), PCA, Grad-CAM이 있음을 확인. Codex가 옳다. 해당 그림은 초음파 열화 분류 예시여서, 기존 HTML의 "ECT 관련" 암시도 정정.
- F07: 앤스코 14번 슬라이드 9 노트에 "전체 124개 마모 결함"이 있고 표 합계는 145 — 원본 내부 불일치 확인. 03번 11%는 (142.66−128.66)/142.66=9.81%, /128.66=10.88%로 재계산해 확인.
- F09: ε=σ/E+α(σ0/E)(σ/σ0)^n에서 기준응력을 σ0'로 바꾸면 α'=α(σ0'/σ0)^(n−1) — 직접 유도해 일치. "α,n 독립 아님" 서술 정정.
- F10/F11/F13: h'=h(ML'/ML)^(n+1), a/c=(a/t)/[(Rm/t)θ], (4/3)σf(Ro³−Ri³)=4σf Rm²t+σf t³/3 — 직접 계산해 일치.
- F15/F16: 음수 J 입력과 MRR@K 불일치를 브라우저에서 재현·수정·재측정(수정 후: 음수 입력은 판정 거부, K=1에서 Recall@1=MRR@1=0.375).

## 반영 못 한 것·미해결
- 확인 불가 서지(Kumar 1981 원보고서, Zahoor 권별 정보, Robertson&Zaragoza, Manning, Grieves, Kirk 2022, RG 1.99/ASTM E900 세부, ML26148A433 본문)는 추측으로 채우지 않고 "확인 필요"로 남김.
- PPTX 그림 내부의 AI 언급 전수 부재는 증명하지 못함(HTML에 잠정 판정으로 명시).
- Abaqus 설치 환경에서의 실행 검증은 수행하지 않음.
- Codex가 "해당하지 않는다"고 한 R² 계산식 지적은 양측 일치.

두 모델의 의견 일치를 검증 근거로 쓰지 않았다. 최종 채택은 사용자가 결정한다.
