## 4. 새 과학 문장과 잔여 F10·F12·F13·F15

### F10 — 재료비 처리: 핵심 보완 확인

7.2(d)에 **σf/σ0를 변화시키면 h 입력에 포함하거나 고정·기록**하라는 문장이 들어갔다. 7.2(b)의 숨은 재료비 경고를 최종 모델 설계와 연결한 점은 맞다.

직접 대수 확인: `Mref=σf×G(형상)`으로 정규화하면 같은 실제 M에서 하중비는 σf에 역비례한다. 같은 Jp를 유지하려면 h는 기준하중 변경의 `(n+1)`제곱 인자를 흡수한다. 따라서 σf/σ0가 독립적으로 변하는데 h를 순수 형상·n 함수로만 고정하면 일반적으로 충분하지 않다. 비를 입력으로 넣거나 고정하는 새 조치는 이 누락을 해소한다. 기준하중 변환 `h′=h(Mref′/Mref)^(n+1)`도 보존됐다.

**범위 한정:** ‘고정’은 데이터셋 설계 단계의 선택이다. 이미 서로 다른 비로 생성된 사례를 입력 열만 삭제해 고정 처리할 수 있다는 뜻은 아니다. GE/EPRI 문헌별 h표·기준하중·재료모델의 일치와 독립 FE 잔차 검증은 여전히 별도다. 이번 보완으로 문서의 입력 누락은 해결됐지만 실제 대리모델 검증 완료로 확대하지 않는다.

### F12 — Paris C 단위는 맞음, J 방향 정의는 미해결

7.4의 새 예시 **`(m/cycle)/(MPa√m)^m`은 맞다.** `da/dN=C(ΔK)^m`에서 직접 차원을 나누면 그렇다. 앞의 m은 길이 단위 미터, 지수 m은 무차원 재료 지수다. 예를 들어 지수 m=3이면 `MPa^(-3)·m^(-1/2)·cycle^(-1)`이다. 사이클 수를 무차원으로 취급하는 표기에서도 수치의 ‘사이클당’ 의미는 유지해야 한다. a나 K 단위계를 바꾸면 C의 수치도 바뀐다. Paris 관계의 기준은 [AFGROW DTD Handbook의 성장률 설명](https://www.afgrow.net/applications/DTDHandbook/examples/page2_2.aspx)과 대조했으며, 위 단위 판정 자체는 식의 차원 계산에 근거한다.

그러나 **7.2(a)의 J식은 여전히 x가 균열 진행 방향이라는 정의와 Γ의 적분 방향을 주지 않는다.** 새 단위 문장은 이 부분을 고치지 않았다. 경로독립성과 J 지배성의 구별·제하/비비례하중 주의는 보존됐다. 표준적인 균열 좌표와 아래 균열면→위 균열면의 반시계 경로를 식의 부호 규약에 맞춰 명시하는 보완이 필요하다. 경로 방향은 [J-STAGE 게재 논문의 J 적분 정의](https://www.jstage.jst.go.jp/article/aem/advpub/0/advpub_aem.26-0005/_html/-char/en)도 참고했다. **F12 전체 판정은 부분 해결**이다.

### F13 — 순수 굽힘 한정은 개선, 목표 정의 한정은 남음

7.3은 이제 순수 굽힘에만 무결함 환상단면 식을 적용하고, 내압·축력이 있으면 같은 하중 조합의 극한값과 비교하도록 썼다. 이전의 복합하중 혼동은 해소됐다. 직접 전개하면

`(4/3)σf[(Rm+t/2)^3−(Rm−t/2)^3] = 4σf Rm²t + σf t³/3`

이므로 정확식·박관 근사의 구별도 맞다. 7.2·8.2의 단조성에 **실제 M 고정** 조건을 붙인 수정 역시 보존됐다.

다만 바로 앞 항목은 **이상소성 한계하중·경화재료 붕괴하중·실제 최대하중 중 하나를 고르도록** 허용한다. 뒤에서 ‘순수 굽힘만’이라고 해도, 순수 굽힘 **경화재료의 최대하중**까지 반드시 이상소성 σf 식에 수렴하는 것은 아니다. 해당 극한을 요구하려면 **이상소성 재료·그 σf 정의·그 목표값을 택한 경우**라는 조건도 필요하다. 다른 목표면 동일 재료모델·붕괴 기준의 무결함 FE/기준해와 비교해야 한다. **F13은 부분 해결(P2)**이다.

### F15 — 영점 문구 개선, 기준 스케일은 미해결

0 입력 시 물리적으로 J=0이 가능하지만 이 계산기는 판정하지 않는다는 안내가 나온다. 이전 ‘J는 양수여야’라는 물리적 단정을 완화한 것은 맞다. 직접 입력에서 모두 5이면 평균 5.000·편차 0%, 모두 0이면 거부, 모두 1e−15이면 평균 1.00e−15와 판정 보류 문구가 나왔다. 극소값이 평균 0.000으로 표시된 채 통과하는 문제는 재발하지 않았다.

그러나 차단 조건은 여전히 **`mean<1e−6` 고정값**이다. 입력 J의 단위·기준 J 스케일·사용자 절대허용오차를 받지 않는다. 같은 물리량을 단위만 바꿔 입력해도 판정 허용 여부가 달라질 수 있어, 단위에 독립적인 수치 안정성 기준이라고 볼 수 없다. 단위를 고정·표시하고 기준 스케일로 정규화하거나 절대오차 기준을 제공해야 한다. **F15는 부분 해결(P2)**이다.
