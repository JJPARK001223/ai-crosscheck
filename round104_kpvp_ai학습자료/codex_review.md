- 원본 HTML·발표·기존 추출텍스트에 수정·삭제·이동 작업을 하지 않았다. 공개 저장소에는 이 보고서만 전달하며 발표 원문·이미지·추출본을 첨부하지 않는다. 이하 원본 요지는 짧게 재서술한다.

## 발견사항

### F01. 중요 — AI 사용·논의·DT의 분류와 요약이 서로 충돌

- 위치: 1장 요약·1.2, 2장 요약·2.2·2.4, 3장 요약·3.1, 12.1 / 원본 13번 20장, 17번 2~8장.
- 문제: “실제로 AI가 쓰인 5건”, “5건 모두 신호/표→수치 예측”, “5건 모두 L2”, “모두 예측·분류 ML/DL”은 규제 논의 중심인 17번을 포함한 자기 분류와 맞지 않는다. 3.1 표 자체도 KINS 생성형 증강 언급을 L1에 놓는다. 사용자 범위인 DT 13번은 2.4에만 배치됐다.
- 근거: 17번은 적용 유형·대표성·역할·규제 축을 설명한다. 13번은 DT를 명시하지만 ML 사용 증거는 확인되지 않는다.
- 제안: 위의 4+1+DT 분류로 집계를 통일하고, DT 카드를 관련 기술 사례로 추가한다. DT를 무조건 AI라고 재분류하지는 말 것. 검토하지 않은 그림에 대한 부재 단정을 피한다.

### F02. 중요 — 서로 다른 연구의 ECT를 “같은 데이터”로 표현하고 해석을 발표 사실에 혼합

- 위치: 2장 요약, 2.2 A~D의 “파괴역학 연관성”, 2.3 / 원본 14번 5~9장, 16번 4~6장, 17번 3장.
- 문제: 앤스코의 시험편 신호와 성균관대의 현장 신호는 같은 데이터셋임이 입증되지 않았다. KINS의 적용 예시는 ECT만이 아니라 UT 등을 포함한다. “같은 ECT 신호 데이터”는 독자에게 공유 데이터셋 비교로 읽힌다. 카드의 파괴역학·xLPR 연결 및 직접 연관성 평가는 발표에서 직접 확인한 주장과 분리해야 한다.
- 제안: “같은 검사 방식 계열의 서로 다른 데이터”로 고친다. 연관성·파이프라인·xLPR 제안에는 해당 셀 안에서 [AI 분석]을 붙인다. 2.2 서문이 분석은 표 아래 박스에만 있다고 설명하므로 표 안의 해석도 예외를 명시한다.

### F03. 중요 — KAERI 원본 그림의 시점·증분 출력 구조 누락

### F09. 중요 — R-O 매개변수의 상관을 수학적 종속으로 단정

- 위치: 7.2(a)(b), 4.1 입력 예시.
- 문제: 같은 곡선에서 적합한 α·n이 통계적으로 상관될 수 있다는 사실과 α가 n의 함수로 정해진다는 주장은 다르다. 기준응력을 고정한 R-O 모델에서 α와 n은 별도 형상 매개변수다. 임의 조합이 특정 재료군에 비현실적일 수 있다는 권고는 타당하지만 “독립 변수가 아님”은 과도하다.
- 직접 계산: `ε=σ/E+(α/E)σ^n σ0^(1-n)`. 같은 곡선을 다른 기준응력 σ0′로 표현하면 n이 같을 때 `α′=α(σ0′/σ0)^(n-1)`이다. 기준응력의 재정의와 재료 간 적합 상관을 구분할 수 있다.
- 제안: “σ0 정의를 고정하고 α,n의 실제 재료군 공동분포를 사용”으로 바꾼다. α,n 중 하나를 자동 삭제하지 않는다. E/σ0 사용과 J/(σ0t) 무차원화는 타당하다.

### F10. 중요 — GE/EPRI 식과 h 학습의 정규화·유효 범위가 불충분

- 위치: 7.2(a)(b)(d)(f), 6.3①.
- 문제: `Jp=ασ0ε0 ℓ h (M/ML)^(n+1)`는 차원상 맞는 **일반형**이지만 ℓ와 ML을 임의로 바꾼 뒤 기존 h표를 그대로 쓸 수 없다. n+1은 소변형·멱법칙의 완전소성 해와 비례하중 조건에서 나오는 구조이며, 임의 복합하중·유한변형·모든 하중 구간의 FE J를 정확하게 보장하는 법칙이 아니다. Je+Jp는 공학적 추정 분해임을 표시해야 한다.
- 직접 계산: p=n+1일 때 다른 정규화 하중 `ML′`를 쓰면 같은 Jp를 유지하는 계수는 `h′=h(ML′/ML)^p`다. 따라서 ML에 σf를 쓰면서 σf/σ0를 가변으로 두면 h가 형상·n에만 의존한다고 하기 어렵다.
- 제안: 특정 문헌의 형상·하중·ℓ·기준응력·기준모멘트를 먼저 고정한다. `Jp/(σ0t)=α(σ0/E)(ℓ/t)h(M/Mref)^(n+1)`로 차원을 확인한다. 탄소성 전이·대변형에서 계수 잔차가 하중에 의존하는지 독립 FE로 검증하고 필요하면 하중 의존 보정항을 허용한다. “구조를 고정하므로 안전”이라고 결론내리지 않는다.
- 근거 범위: [Rice 원논문](https://esag.harvard.edu/rice/015_Rice_PathIndepInt_JAM68.pdf), [Ainsworth 원논문 서지·초록](https://www.sciencedirect.com/science/article/pii/0013794484900961) 및 직접 차원 계산. NP-1931의 특정 표·식 번호는 원보고서 직접 열람에 실패하여 확인 불가다. 이 보고서 역시 원표의 숫자를 검증했다고 주장하지 않는다.

### F11. 중요 — 3D 선단 위치가 실제 학습식에서 다시 빠지고 형상비를 중복 요구

- 위치: 7.2(b)(c)(d), 6.2.
- 문제: (b)는 선단 위치 φ 누락을 잘 지적하지만 (d)의 h 학습 입력에는 φ가 다시 없다. 깊이점·표면점·최대값을 정하지 않은 단일 J 출력은 재현 불가능하다. 반타원에서 길이 2c와 a/c를 모두 추가로 요구하는 표현도 독립 변수 수를 부풀린다.
- 직접 계산: 문서처럼 `c=Rm θ`를 정의하면 `a/c=(a/t)/[(Rm/t)θ]`다. 기존 a/t·Rm/t·θ로 이미 결정된다. 내면 기준 c=Riθ를 쓰는 문헌이면 변환식을 그에 맞춰 바꿔야 한다.
- 제안: `h(...,φ)` 또는 선단 지점별 출력/최대값을 명시한다. c가 호길이인지 투영길이인지와 내·평균·외반경 기준을 고정한다. 3D 자유표면 끝점에는 단순 평면변형률 Je식을 일률 적용하지 않는다. 혼합모드라면 일반 탄성 에너지 관계를 별도로 사용한다. 도식의 횡단면 직사각 결손과 전개도 반타원은 각각 다른 형상임을 더 분명히 표시한다.

### F12. 중요 — J 및 Paris식의 성립 조건·외삽 보장이 과도함

- 위치: 7.2(a)(f), 7.4, 8.3, 11장.
- 문제: 기본 Rice 적분과 평면변형률 Je식은 맞지만, 임의 이력의 증분소성·제하·잔류응력까지 동일한 경로독립성을 갖는 것은 아니다. 큰 소성영역이라는 사실 하나만으로 J 자체가 부적절하다고 단정할 수 없고, 경로독립성과 J 지배 균열선단장의 성립도 별개다. “기존 모델은 식 구조에서 외삽 가능” 역시 경험식인 Paris식의 적용 범위 밖을 보증하지 않는다.
- 제안: 정지균열·준정적 단조/비례하중, 재료·경로 조건을 명시하고 J를 계산할 수 있는지와 단일 J로 파괴를 지배하는지를 나눈다. Paris식은 중간 성장률 구간에서 사용하며 ΔK 임계·급속파괴 부근, 하중비·폐구·환경·이력 영향에 별도 검증이 필요하다. `a`=균열길이, `N`=사이클수, `ΔK=Kmax-Kmin`, C의 단위 및 m을 함께 정의한다.
- 근거: [Rice(1968) 원문](https://esag.harvard.edu/rice/015_Rice_PathIndepInt_JAM68.pdf), [Abaqus contour 평가 문서](https://docs.software.vt.edu/abaqusv2026/English/SIMACAEANLRefMap/simaanl-c-contintegral.htm)의 단조하중·잔류응력·비례응력 조건. 공식 설명도 보정 기능과 제약을 나눠 제시한다.

### F13. 중요 — 한계하중 보정의 대상과 단조성 조건 혼합

- 위치: 7.2(d), 7.3, 8.2(e).
- 문제: 이상소성 limit load와 경화재료의 설계 소성붕괴하중(예: twice-elastic-slope), 실제 최대하중은 서로 다른 목표다. “기준만 하나로 고정”하는 것으로 동등해지지 않는다. 순수 굽힘 무결함 박관식과 내압/축력/좌굴이 섞인 케이스를 같은 극한 검사로 다뤄서도 안 된다. 균열 깊이에 대한 J 단조성도 실제 M을 고정할 때와 형상 의존 ML로 정규화한 M/ML을 고정할 때 구분해야 한다.
- 직접 적분: 원형 환상단면의 순수 굽힘 이상소성 모멘트는 `Mp=(4/3)σf(Ro³-Ri³)=4σf Rm²t+σf t³/3`. 박관에서는 뒤 항을 무시해 HTML의 `4σf Rm²t`가 된다. **해당 식 자체는 맞다.**
- 제안: 하중 조합·재료모델·σf 정의·붕괴 기준별 데이터셋을 분리한다. 압력/축력 비와 구속·좌굴 가능성을 기록한다. 보정계수 입력은 일관된 무차원군으로 두고, σy/σu와 차원량 σf가 동등한 선택지라는 표현을 수정한다. h/모멘트식의 유효 범위 안에서만 물리 제약을 건다.

### F14. 중요 — 앙상블 분산을 재료 산포·PFM 입력 분포로 바로 연결

- 위치: 6.3③④, 7.4, 10장 4단계 / 4.2 불확실성 설명과 연결.
- 문제: 4장은 모델 불확실성과 측정 잡음을 구별하지만 후반은 앙상블로 C·m의 분포나 결함 깊이 분포를 직접 추정·전파할 수 있는 것처럼 설명한다. 모델들 예측의 산포만으로 재료의 우연 산포, 측정 오차, 공간·시간 상관, 검출되지 않은 결함을 복원할 수 없다. `p(a|신호)`도 모집단 초기 결함 분포와 같지 않다.
- 제안: 조건부 잡음 모델/반복 실험, 관측 선택·POD, 모수 상관과 보정 데이터를 포함해 불확실성 원천을 분리한다. 예측분산은 개념적으로 `E_model[Var(y|x,model)]+Var_model[E(y|x,model)]`. MC Dropout/모델 분산은 후자를 근사하며 자동 보정된 신뢰구간이 아니다. PFM에서는 같은 모델 오차의 케이스 간 상관도 보존한다.
- 근거: [Deep Ensembles 공식 논문](https://proceedings.neurips.cc/paper_files/paper/2017/hash/9ef2ed4b7fd2c810847ffa5fa85bce38-Abstract.html), [Gal·Ghahramani 공식 논문](https://proceedings.mlr.press/v48/gal16.html). 특정 발표 데이터에서 총 불확실성 분해가 검증됐는지는 확인 불가.

### F15. 중요 — contour 판정 원칙과 계산기의 잘못된 통과

- 위치: 8.3 표·판정기, 내장 script `guard("jc",...)`.
- 재현: contour 1은 기본값, contour 2~6을 **-1,-2,-3,-4,-5**로 입력하면 평균 -3, 최대 편차 0.00%, “기준 이내: 경로 독립성 만족”으로 나온다. 모든 선택 contour가 0이면 NaN%가 표시된다. 원인은 상대 편차 분모가 `mean`이고 입력 양수성·영점 처리가 없기 때문이다. 빈칸을 filter로 지우면 contour 번호 의미도 바뀔 수 있다.
- 개념 문제: 첫 contour 하나를 일괄 버리는 규칙이 보편적이지 않다. [Abaqus 공식 문서 Domain Dependence](https://docs.software.vt.edu/abaqusv2026/English/SIMACAEANLRefMap/simaanl-c-contintegral.htm)는 plateau를 찾아 부정확한 contour를 버리고, 선형탄성에서 첫 두 contour를 보통 제외한다고 설명한다. 작은 contour 편차는 J 지배성·메쉬 수렴·균열 정의가 모두 맞다는 충분조건이 아니다.
- 제안: 입력 번호를 보존하고 유한값·물리적 부호·최소 contour 개수를 검증한다. 분모 `max(|평균|,Jscale·ε)` 또는 사전 절대오차 기준을 사용한다. 0 근처는 상대편차를 계산하지 않는다. 제외 contour를 선택 가능하게 하고 판정을 “선택 구간의 수치적 plateau 후보”로 낮춘다. 선단 위치·하중별 plateau와 메쉬 수렴은 별도 검사한다.

### F16. 경미 — MRR 정의와 구현 불일치

- 위치: 8.1 표·계산기, script `guard("rk",...)`.
- 재현: 기본 순위 1,2,1,5,0,3,1,2에서 K=1이면 Recall@1=0.375, MRR=0.567. 코드 MRR은 K 밖 순위도 포함한다. 표의 “상위 K에 없으면 0”을 적용한 MRR@1은 0.375여야 한다.
- 제안: 전체 결과 MRR을 유지한다면 표에서 K 제한을 삭제한다. MRR@K를 원하면 `1≤rank≤K`일 때만 역수를 더한다. 미검색은 0으로 유지한다. Recall@K의 현재 정의는 질문당 정답 하나일 때라는 단서가 있어 적절하다. 다중 정답은 `|Retrieved_K∩Relevant|/|Relevant|`로 정의할 것.

### F17. 중요 — 검증 성공을 과도하게 단정하는 표현

- 위치: 8.1 인용 일치율, 8.2(a)(b)(e), 7.2 log 출력.
- 문제: 문자열 인용 불일치가 전부 환각인 것은 아니며 OCR·공백·판 차이·의역도 원인이다. 반대로 문장이 원문에 있어도 답변의 결론을 지지하지 않을 수 있다. 성균관대의 학습 세트만 증강은 **그 경로의 누출**을 막을 뿐, 동일 관/검사 이력 그룹 누출을 모두 방지했다는 뜻이 아니다. min/max 안이라는 것만으로 다변량 보간이 보장되지 않는다.
- 제안: 인용 존재성·주장 지지성·수식 정확성을 분리한다. 독립 시험은 하이퍼파라미터/조기 종료/구간 보정에 쓰지 않은 자료로 둔다. 그룹/시간/원전 분리와 그룹 유효 표본 수를 보고한다. coverage는 구간폭·조건부 coverage·표본 오차와 함께 평가하고 별도 calibration 세트를 사용한다. 80%는 q10~q90의 **명목 목표**이며 자동 보장이 아니다. J≈0에서는 상대오차와 log J가 정의/수치 문제를 만들므로 절대오차·기준 스케일 또는 영점 보존 구조를 둔다. R²는 음수가 가능하고 상수 정답에서는 분모가 0임을 추가한다.

## Abaqus 자동화 가능성 표의 검증

`abaqus cae noGUI=...`, Python 모델 생성·입력 파일 작성·job 실행·`odbAccess` 후처리라는 구성은 기술적으로 타당하다. [공식 Python/ODB 예제](https://docs.software.vt.edu/abaqusv2026/English/SIMACAECMDRefMap/simacmd-c-odbintrostressrangepyc.htm)에서 `openOdb`와 필드 접근을 확인했다. [공식 contour 출력 요청 문서](https://docs.software.vt.edu/abaqusv2026/English/SIMACAECAERefMap/simacae-t-enghelpcrackoutput.htm)는 crack domain의 history output 요청을 설명한다.

다만 표에는 다음 조건을 덧붙여야 한다.

- contour 적분의 해당 기능은 Abaqus/Standard의 지원 절차·요소·재료 조합에서만 사용한다. crack front·가상 균열 진전 방향·선단별 history 이름을 올바르게 지정해야 한다. 모든 ODB에 기존 응력장이 있다고 J를 원하는 방식으로 바로 추출할 수 있는 것은 아니다.
- 선택한 mesh·하중 조건에서 공식 지원 여부와 설치 버전 Python/API 호환성을 점검한다. ODB 열람은 읽기 전용으로 하고 출력 누락·job 실패·경고·frame/단위·균열명·front 위치를 함께 검증한다.
- “MCP 서버 선택”은 별도 구현 가능한 설계이지, 검증된 내장 Abaqus MCP 기능이 확인됐다는 뜻은 아니다. HTML은 선택 구현임을 표시하고 있어 존재하지 않는 기본 기능을 단정한 사례는 찾지 못했다.
- 이번 작업에서 Abaqus 라이선스·모델·ODB를 실행 검증하지 않았다. 이 부분의 판정은 **공식 API의 기능 가능성 확인**이지 사용자 환경의 실행 성공 확인이 아니다.

## 수정 후 재검토 시 우선 확인할 항목

1. **F15 contour 판정기**: 음수·전부0·빈칸·선단별 plateau·첫 두 contour 제외·메쉬 수렴 분리. 잘못된 물리 입력이 통과하지 않는지 먼저 확인한다.
2. **F09~14 물리 모델**: σ0/σf/ML/ℓ/h의 정의, α·n의 취급, 선단 위치 φ, 복합하중·3D 제약, 소변형 멱법칙과 FE 잔차, 인식/우연 불확실성 및 POD의 구별.
3. **F03~06 원본 대조**: KAERI의 Δg_(i+1)와 증분 출력, kNN의 Φ 역할·결과16~18쪽, KINS 그림의 확인 가능/불가 범위. 14·16의 수치가 수정 중 훼손되지 않았는지도 확인한다.
4. **F01~02 출처 분류**: 4개 ML+규제+DT로 요약·표·본문 집계 일치, 서로 다른 ECT 데이터의 구별, 카드 안 추론 태그 정리.
5. **F18·F16 HTML**: 320/390px 전역 폭이 viewport를 넘지 않는지, 긴 출처 태그·1.1표, MRR의 정의/계산 일치를 재측정한다.
6. **F19·서지표·투명성**: Ainsworth 정정, 원보고서와 규제 원문의 미확인 항목 보강, 개인자료/과거 전송 등 검증하지 않은 이력의 확정 표현 방지. 변경 후 HTML 버전 해시를 함께 기록한다.
