[역할] Claude Code가 만든 HTML 학습자료를 비판적으로 검토한다. Claude의 결론을 믿지 말고 원본·공식 문헌·직접 계산으로 확인한다. 두 모델의 답이 일치한다는 이유로 옳다고 하지 말 것. HTML, 발표 원본, 추출텍스트는 절대 수정·삭제·이동하지 않는다(읽기 전용). 임시 파일이 필요하면 시스템 임시 폴더를 쓴다.

[검토 항목] (각 항목마다 판정: 이상 없음 / 수정 필요 / 확인 불가, 그리고 근거)
1. 발표 분석 누락: 발표 원본 21개 중 AI(ML/DL/RAG/LLM/Digital Twin 등)를 실제로 다루는 발표가 HTML 2.1~2.2절 목록에서 빠지거나 잘못 분류되지 않았는가. PPTX는 슬라이드 본문·노트·표를 모두 확인하고, PDF는 쪽 이미지로 확인 가능한 범위를 밝혀라. 특히 HTML이 "AI 없음"이라 한 발표(00,01,02,03,04,05,06,08,09,10,12,13,15,18,19,20)에 AI/ML 내용이 숨어 있는지 점검하라.
2. 원문-HTML 일치: 2.2절의 앤스코(14), 성균관대(16), KAERI 권태현(11), KINS(17), kNN(07) 카드의 수치·구조·슬라이드/쪽 번호가 원본과 맞는가. 틀린 숫자, 잘못된 페이지 번호, 발표에 없는 내용을 발표 주장처럼 쓴 곳을 모두 찾아라. 추정이 [AI 분석] 태그 밖에 섞였는지도 보라.
3. AI 기술 정의·분류의 정확성 (4장, 3장 7개 층 분류).
4. 수식·변수 정의 (4장, 7장, 8장, 11장): 코사인 유사도, attention, 핀볼 손실, MC Dropout/앙상블, J-적분, Ramberg–Osgood, J=Je+Jp, Je=K²(1-ν²)/E, GE/EPRI 형태 Jp 식과 (M/ML)^(n+1), Paris식, RRF, MAE/RMSE/R², 얇은 원관 완전소성 모멘트 4σf Rm² t 등. 틀리거나 오해 소지가 있으면 올바른 식과 근거를 제시하라.
5. 파괴역학·배관 파손 적용 방안의 타당성 (6~7장): 입력 변수 검토(E/σ0, n, α 종속성, M/ML 종속성, 균열선단 위치 변수 등), 하이브리드 구조 제안, 한계하중 보정 접근, Abaqus 자동화 가능성 표(Abaqus Python/odbAccess, contour integral 출력 등).
6. 검증 방법의 적절성 (8장): 지표 정의, 누출·외삽·피복률, contour 독립성 판정.
7. 출처와 참고문헌 (12장): 서지 정보가 실제와 맞는지(저자·연도·저널·권·쪽·보고서 번호). 확신할 수 없으면 "확인 불가"로 쓰고 추측하지 말 것. 웹 확인이 가능하면 공식 출처로 확인하라.
8. 확인되지 않은 주장·환각: 근거 없는 수치, 존재하지 않는 기능, 과장.
9. HTML 기능: 내장 <script>를 node 등으로 구문 검사하고, 가능하면 headless 브라우저로 콘솔 오류를 확인하라. 라이트/다크, 모바일 폭에서 명백한 깨짐이 있는지.
10. 투명성: 1.3절의 한계 고지(개인 AI 학습 자료 미제공 등)가 정확하고 충분한가.
