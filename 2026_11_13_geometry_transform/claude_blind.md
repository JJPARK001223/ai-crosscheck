# 독립 검토: Abaqus orphan mesh 좌표 변환 (geometry-only 후보)

원본 `Job-1.inp`와 `codex.md`는 열지 않았고, 주어진 서술만으로 유도했습니다. 아래 가정은 모두 **offline audit 스크립트가 원본에서 assert로 확인**해야 합니다.

## 0. 해석 및 가정

- 각도 φ를 +y에서 +x 방향으로 잰다: φ = atan2(x, y) ∈ [0, π] (x ≥ 0 반단면), r = √(x²+y²).
- 균열은 z = 1500 평면(대칭면)에 있고 φ ∈ [0, θ]를 차지한다. 원본 θ = π/2, 목표 θ′ = 0.3π = 54°.
- 균열 front는 두 부분이다.
  - 호: r = Rm, φ ∈ [0, θ]
  - 반경 방향 직선 끝단: φ = θ, r ∈ [Ri, Rm]
- a = Rm − Ri이므로 원본은 300 − 270 = 30, 목표는 600 − 570 = 30이다. a/t = 0.5로 양쪽이 일치하고 front는 r = Rm에 놓인다. 이 점은 해석만으로 확인되며 PNG 형상과는 무관하다.

## 1. 좌표 변환 전략 (노드 ID·연결성 불변, 좌표만 변경)

```
r′ = r + 300          (Ri 270→570, Ro 330→630, 두께 60 불변)
z′ = z
φ′ = g(φ) = 0.6 φ                       , 0 ≤ φ ≤ π/2   (기울기 0.6)
          = 0.3π + 1.4 (φ − π/2)        , π/2 ≤ φ ≤ π   (기울기 1.4)
x′ = r′ sin φ′ ,  y′ = r′ cos φ′
```

- g는 단조 증가이고 g(0)=0, g(π)=π다. 따라서 x=0 대칭면(φ=0, π)과 z=1500 평면은 보존되고, 방향(orientation)도 보존된다.
- 각 변의 길이 변화
  - (r,z) 단면에서는 r′ = r + 300, z′ = z이므로 **엄밀한 평행이동**이다. 호 front를 따라 만든 tip 단면(focused/rosette) 형상이 그대로 보존된다.
  - front 접선 방향(호 길이) 비율은 (r′/r)·g′이다. r = 300일 때 2 × 0.6 = **1.2배**다.
- 면적 및 Jacobian 배율은 (r′/r)·g′이다.
  - 균열 영역: 0.6 × [1.909, 2.111] = **[1.145, 1.267]**
  - 리가먼트: 1.4 × [1.909, 2.111] = **[2.67, 2.96]**
  - 이 값은 전 요소에서 양수이고 z 방향은 항등이다. 따라서 detJ_target/detJ_source가 이 범위 안에 있는지가 변환 구현 오류를 잡는 강한 offline 검사다. 2차 요소의 보간 오차 O(h²)는 허용한다.
- 절점 처리
  - **모든 노드(corner·midside)에 같은 해석적 map을 점별로 적용**한다. midside를 다시 계산하지 않는다.
  - 근거: 각 요소 변은 r선, φ선, z선 위에서 이 map에 대해 아핀이다. 그래서 midside 비율(0.5)과 quarter-point 비율(0.25)이 보존된다.
  - 전제: kink φ = π/2가 요소 경계에 정확히 있어야 한다. 균열 끝 평면이 요소 면이므로 성립해야 하며, audit에서 corner φ가 π/2를 가로지르는 요소가 0개인지 확인한다.
- 부수 영향: 같은 이유로 균열 영역과 리가먼트 영역의 둘레 방향 요소 길이 비가 인접 요소 사이에서 1.4/0.6 ≈ 2.33배 점프한다.
  - 완화 대안: 단조 Hermite/PCHIP로 g를 매끈하게 한 map. 단 이 경우 midside가 정확한 중점에서 벗어나므로 비교 audit가 필요하다.
  - 1차 후보는 piecewise-linear를 권장한다. 이유는 단순하고 직선 보존 여부를 검증하기 쉽기 때문이다.

## 2. 함정

1. **YFIX / 평면 소속.** y = 0 평면(φ = π/2) 노드는 목표에서 φ′ = 54° 평면으로 옮겨지므로 더 이상 y = 0이 아니다. YFIX가 y = 0 평면 집합이면 구속 의미가 달라진다. 이 경우 좌표계 회전 또는 구속 재정의가 필요한데, 이는 사용자 결정 사항이다.
   - 반면 x = 0(φ = 0, π)과 z 평면 집합은 보존된다.
   - 집합의 이름·내용은 ID 기준으로 유지하고, 좌표로 재분류하지 않는다.
2. **atan2 부호/랩.** x = −1e-14인 y < 0 노드는 φ = −π가 되어 잘못된 가지를 탄다. x의 부동소수 잡음이 원인이다.
   - 대응: x ≤ tol이면 φ를 정확히 0 또는 π로 고정한다.
   - 출력 시 원본에서 정확히 0인 x는 x′ = 0으로 쓰고, sin π의 잔차는 제거한다.
   - 소수점 12자리 이상으로 출력한다.
3. **퇴화 요소.** collapsed 노드는 동일 ID를 공유하므로 점별 map에서 자동 보존된다.
   - 금지: 좌표 허용오차로 노드를 병합하거나 분리하는 것.
   - 확인: 원본에서 같은 좌표였던 노드 쌍이 목표에서도 같고, 새로 겹치는 쌍이 없다.
4. **Quarter-point.** 반경 방향 변의 midside 비율 δ가 0.25 ± 1e-9인지 확인한다.
   - 1차원 사상 x(s) = (4δ−1)Ls + (2−4δ)Ls²에서 x′(0) = (4δ−1)L, x′(1) = (3−4δ)L이다.
   - 따라서 양의 Jacobian 조건은 δ ∈ [1/4, 3/4]이고, δ = 1/4(tip의 J = 0)은 tip 위에서만 허용한다.
5. **균열 끝 반경 front의 비등방 변형.** 이 부분의 단면 평면은 (φ방향, z)다. 접선 배율이 r에 따라 0.6 × 2.11 = 1.27에서 0.6 × 1.909 = 1.15 사이로 변한다. 즉 z 방향 대비 1.15~1.27배의 변형이 생기고, 이 위치의 quarter-point rosette가 약간 타원화된다.
6. **midside 곡률.** 원본의 원주 방향 변이 호 중점이면 map 후에도 호 중점이다. 현(chord) 중점이었다면 sagitta 오차가 생기지만 O(Δ²R) 수준이다.
   - 수정하지 말고 원본/목표 비율을 보고만 한다.
7. **RP.** RP가 축(r = 0)에 있으면 r′ = r + 300 map이 정의되지 않는다. RP는 map 대상에서 제외하고 좌표를 유지한다. 축 밖이라면 별도로 판단한다.
8. 원본에 *Instance transform, *Orientation/local CS, *Contour integral의 q-vector·normal, coupling 반경 등 좌표 의존 키워드가 있는지 grep한다. 있으면 자동 변환하지 말고 목록으로 보고한다.
   - 예: 끝단 front의 확장 방향 (cos φ, −sin φ)는 (0, −1)에서 (0.588, −0.809)로 바뀐다.
9. 원본 파일은 읽기 전용으로 열고, 새 이름으로 *Node 블록만 교체해 출력한다. 변경 전후 SHA-256과 diff로 *Node 외 영역이 동일함을 확인한다.

## 3. Offline audit 항목 (기하 필요조건)

1. **구조 불변성**
   - 노드·요소 수와 ID의 유일성
   - 연결성 해시 동일
   - 모든 *Nset/*Elset 내용 해시 동일
   - *Node 외의 차이 없음
2. **해석적 불변량 (ID 집합 기준, tol 사전 선언)**
   - 내/외면: r′ = 570/630
   - front 호: r′ = 600, z = 1500, φ′ ∈ [0, 54°]
   - 끝단 front: φ′ = 54°, r′ ∈ [570, 600]
   - XSYMM: x′ = 0
   - ZSYMM: z = 1500
   - 목표 좌표 예: 호 끝점 r = 600에서 (485.41, 352.67), r = 570에서 (461.14, 335.05)
3. **Jacobian**
   - 모든 요소에 대해 2×2×2(C3D20R), 3×3×3, 8 corner, 12 midside에서 detJ를 계산한다.
   - 퇴화 요소의 tip 좌표 J = 0은 예상값이므로 제외한다. 나머지는 부호 있는 detJ > 0이어야 한다(절댓값 금지).
   - min/max detJ 비를 계산한다.
   - detJ_target/detJ_source가 §1의 범위 안에 있는지 확인한다.
4. **부피**
   - 이론값: V = z·Δφ·(Ro² − Ri²)/2
   - 원본: π·18000·1500 = 8.48×10⁷ mm³
   - 목표: π·36000·1500 = 1.696×10⁸ mm³
   - 2차 요소의 곡면 근사 오차 내에서 일치해야 한다.
5. **품질 지표 (원본 대비 분포, 임계값 사전 등록, 그래프 fitting 금지)**
   - 종횡비, 변 길이 비, 면 warp/taper, 각도
   - 인접 요소 크기비 (kink에서의 2.33배 점프)
   - 균열 front 접선 방향 1.2배 신장 보고
6. **tip 전용**
   - 퇴화 패턴 보존
   - δ = 0.25 및 front 변 δ = 0.5의 보존
   - 요소 내 11³ 격자에서 J ≥ 0 (tip 변 제외)
   - tip 요소 내각

## 4. 검증 범위 구분

| 구분 | 확인 가능 | 확인 불가 (별도 단계) |
|---|---|---|
| Offline Jacobian/기하 | 요소 반전 없음, 불변량, 퇴화·quarter-point 보존 | 해의 정확도 전반 |
| 메쉬 수렴 | – | J-적분 contour 독립성, front 방향 해상도(1.2배 거칠어짐), tip 세분화 민감도, 길이 L 민감도 |
| Abaqus 검사 | – | 전처리 경고(음의 부피, 왜곡), set/BC 인식, *Contour integral 정의 (해석 실행이 필요하므로 지금 단계에서는 불가) |

Jacobian이 양수라는 것은 "기하가 유효하다"는 필요조건일 뿐입니다. 정확도·수렴·Abaqus 수용 여부는 보장하지 않습니다. 따라서 이번 산출물은 **"조건부(균일 깊이 a = 30) geometry-only 후보 + offline 감사 결과"**로 표기하고 검증된 모델이라고 주장하지 않아야 합니다.

## 5. 길이 및 하중 (이번 단계에서 변경하지 않음)

**길이 L = 1500 (draft 유지).** shell 감쇠 길이 ∼ √(Rm·t)는 134 mm에서 190 mm로 늘어난다(1.41배). 균열 반길이 Rm·θ는 471 mm에서 565 mm로 늘어나고, L/(Rm·θ)는 3.18에서 2.65로 줄어든다. 개략 지표상 여유가 감소하므로 이후 L 민감도 검증이 필요합니다.

**CLOAD −4.36674e9 (그대로 유지, "solve 전 조정 필요" 플래그).**

- 축력으로 보면 이 값을 A = π(330² − 270²) = 1.131×10⁵ mm²로 나눈 값이 3.9×10⁴ MPa다. 비현실적이므로 N·mm 단위 모멘트일 가능성이 높다(추정).
- 반단면 해석 여부에 따라 공칭 외면 응력이 약 280 또는 560 MPa로 갈린다. DOF, RP, coupling 방식은 원본에서 확인해야 한다.
- 후일 조정 기준 후보(선택은 사용자 결정, 여기서는 확정하지 않음)
  - 동일 외면 공칭 굽힘응력: M′/M = (I′/I)(Ro/Ro′) = 7.94 × 0.524 ≈ 4.16 → ≈ 1.82×10¹⁰ N·mm
  - 동일 R²t 비: ×4
  - 축력이면 면적비 ×2
- 이 숫자들은 형식 비교용이며 어느 기준이 연구 목적에 맞는지는 별개 문제입니다.
- 목표 R/t = 10이어서 원본(R/t = 5)과 shell 거동이 다릅니다. 따라서 하중 등가를 단순 비례로 가정하지 말아야 합니다.

## 6. 결론

- 점별 해석적 map(r 평행이동 + φ piecewise-linear)이 ID·연결성·midside 비율을 보존하는 가장 단순한 방식이다.
- 위험 지점은 YFIX 및 y = 0 평면 소속, 끝단 front의 비등방 신장, kink에서의 크기 점프, atan2 랩, RP 처리다.
- 이번 단계 산출물은 조건부 geometry-only 후보와 offline 감사 보고서이며, 검증 모델이 아니다.
