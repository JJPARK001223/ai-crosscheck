# Round 4 — Claude blind 자체 분석 (FE 재현 계획서)

작성: Claude (오케스트레이터). 이 계획서를 내가 작성했으므로 "blind" 는 아니지만,
Codex 독립 분석과 대조하기 위해 **내가 의심하는 부분**을 미리 적어 둔다.

## 1. 논문 §4.2~4.3 방법 구현

### 맞다고 보는 것
- 절반 대칭 모델 + BC 구조 (대칭면 $U_1=0$ 단 균열면 $Y\in[0,a]$ 제외, 롤러 $U_2=0$,
  상단 스트립 분포하중) 는 원문 서술 "The right face had a symmetric boundary
  condition except for the crack face at the bottom side" 와 일치.
- K 추출 경로 A (곡선맞춤): $\sigma_{yy}(s)=\hat K/\sqrt s$, log–log 기울기 $-1/2$,
  팁 제외, $s$=mm — 논문 §4.2 "curve fit ... using Equation (3)" 재현으로 타당.

### 내가 의심하는 것 (Codex 확인 요망)
- **`ContourIntegral(crackNormal=(1.0,0.0,0.0), extensionDirectionMethod=CRACK_NORMAL)`**
  — 균열면은 X=L/2 평면, 균열은 +Y 로 성장, 균열전선은 Z축 직선.
  - Abaqus 에서 `extensionDirectionMethod=CRACK_NORMAL` 이면 확장방향 $q$ 는
    "균열전선에 수직 + 균열면 내" 로 자동 계산. 이때 `crackNormal` 은 **균열면의 법선**
    을 정의 (보통 두 점). X=L/2 평면의 법선 = X = (1,0,0). 균열전선 접선 = Z.
    → $q$ = (균열면 내 ∧ 전선 수직) = ±Y. **결과적으로 맞을 수 있음.**
  - 그러나 (a) 인자를 **단일 벡터** 로 주는 게 유효한지 (보통
    `((x1,y1,z1),(x2,y2,z2))` 두 점), (b) `symmetric=True` 반모델에서 K 가
    물리적 K 인지 절반인지 — **Abaqus Scripting Reference 확인 필요.**
- **`crackTip=crackRegion` (crackFront 와 동일)** — 3D 에서 crackTip 은 보통
  crackFront 와 같은 edge 로 주는 게 맞으나, seam/tip region 정의가 필요한 경우가 있음.

## 3. 강체이동 구속 — 내가 불안한 부분
- $Z$(폭) 방향: 1점 $U_3=0$ 만. **X축/Y축 회전 구속이 불완전할 수 있음.**
- 더 나은 방법: 균열·하중이 폭 전체 균일 → **$Z=W/2$ 대칭(Zsymm) 써서 1/4 모델**.
  그러면 $Z$ 강체이동·회전 자동 구속 + 요소수 절반.
- 현행 스크립트(97~108행)의 롤러 edge + 1점은 최소 구속이라 조대 메시에서
  수치 불안정 가능. **Codex 판정 요망.**

## 4. H=50 vs H=100 무차원화
- 계획서 §7 마지막: "$K/(P\,H^{-3/2})$ 경향". 이건 느슨하게 쓴 것.
- 정확히는 SENB 무차원 SIF: $Y(\alpha) = \dfrac{K_I\,B\,H^{3/2}}{P\,S}$ 형태
  (또는 $K_I\sqrt{H}/(\sigma\sqrt{\pi})$, $\sigma=6M/BH^2$).
- 여기선 $B(=W)=100$, $S/H=4$ 가 6케이스 모두 동일 → $K_I\sqrt H/P$ 로 비교해도
  $H$ 간 상쇄되어 OK. **하지만 계획서 표기 $K/(PH^{-3/2})=KH^{3/2}/P$ 는 차원이 틀림**
  (지수 부호). $K H^{-1/2}/P$ 또는 $K\sqrt H /P$ 로 정정 필요. — 내 실수.

## 5. 2D vs 3D 역할
- 논문: 3D 로 "K 폭방향 균일" 1회 확인 → **2D 4절점으로 6케이스 예측**.
- 계획서는 3D Contour Integral 을 주 경로로, 2D 를 "열림" 으로 둠 — **논문 재현
  관점에선 뒤바뀐 것.** 6케이스 K 추출은 2D 가 맞음. 3D 는 검증용 1~2케이스.
- 현행 스크립트 `01` 은 3D only. → **2D 스크립트가 사실상 본체가 돼야 함.**
- 2D 평면가정: 논문 $Y=K^2/E$ → 평면응력. 계획서가 "열림" 으로만 둔 건
  DECISION §3 충돌항목 반영이지만, **논문 재현이 목적이면 평면응력으로 확정**하고
  평면변형은 민감도로 돌리는 게 맞음.
