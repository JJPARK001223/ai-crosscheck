## 검증할 것 — `round4/FE재현계획.html` 을 읽고 아래를 판정

1. **논문 §4.2~4.3 방법 구현 정확성**
   - 절반 대칭 모델 + BC (대칭면 $U_1=0$ 단 균열면 제외 / 롤러 / 폭전체 하중) 가
     원문 서술과 일치하는가.
   - 논문의 K 추출 = "균열첨단 응력을 식(3) $\sigma_e=K/\sqrt s$ 에 곡선맞춤" 인데,
     계획서의 **경로 A(곡선맞춤)** 절차(응력 성분 $\sigma_{yy}$, log–log 기울기 $-1/2$,
     팁 제외, $s$ = mm 물리길이)가 타당한가. 빠진 게 있나.
   - 계획서는 **경로 B(Abaqus Contour Integral)** 도 병행. `01_cement_paste_3PB_model.py`
     의 `ContourIntegral(symmetric=True, crackNormal=(1.0,0.0,0.0),
     extensionDirectionMethod=CRACK_NORMAL, ...)` 설정이 **이 형상(균열면 X=L/2 평면,
     균열 성장 방향 +Y, 균열전선 = Z축 방향 직선)에 대해 물리적으로 맞는가.**
     - `crackNormal` 이 "균열면 법선" 인가 "균열 성장(확장) 방향" 인가 — Abaqus 2020/2021
       Scripting Reference 로 확인. 단일 튜플 `(1.0,0.0,0.0)` 인자 형식이 유효한가
       (보통 두 점 `((x1,y1,z1),(x2,y2,z2))` 를 요구).
     - `symmetric=True` 반모델에서 K 가 절반만 나오는지 / 보정이 필요한지.

2. **round3 15식 경로와의 정합성**
   - 계획서 §3 표(15식 → FE 단계 매핑)가 `DECISION.md §7.2` 와 일치하는가.
   - 특히 식 10(정규화 거리 역변환)·식 11(반모델 하중 환산) 이 계획서에서 올바르게
     반영됐는가. 계획서: FE 입력 = 반모델 $P_0/2$, $(K/P)_{total} = K_{contour}/P_0$
     ($P_0$ = 총하중). 이 규약이 일관되는가 — Contour Integral 이 반모델에서 주는 K 가
     "총하중 $P_0$ 상태의 K" 인가 "$P_0/2$ 상태의 K" 인가.

3. **강체이동 구속 충분성**
   - BC: 대칭면 일부 $U_1=0$, $X{=}0\,\&\,Y{=}0$ 모서리 $U_2=0$, 그 모서리 폭중앙 1점 $U_3=0$.
   - $Z$(폭) 방향 강체이동·회전이 완전히 구속되는가. 폭 중앙면($Z=W/2$) 대칭을
     쓰는 게(1/4 모델) 나은가 — 균열·하중이 폭 전체 균일하므로 $Z=W/2$ 대칭 성립.

4. **H=50 vs H=100 교차비교의 무차원화**
   - 계획서: "무차원 형상계수 $K/(P\,H^{-3/2})$ 경향 비교". 이 무차원화가
     $H$=50·100 을 같은 축에 올리기에 올바른가. 표준 SENB 는
     $K_I B\sqrt{H}/(P) \propto (S/H)\,f(\alpha)$ 형태 — $B$($=W$)·$S$ 항이 빠진 것은
     문제인가 (여기선 $W$·$S/H$ 가 모든 케이스 동일하므로 상쇄되나?).

5. **2D vs 3D 역할 분담**
   - 논문: 3D 반모델로 "K 가 폭 전체에서 균일" 확인 → 2D(4절점)로 6케이스 예측.
   - 계획서는 3D Contour Integral 을 주로 하고 2D 를 "열림 항목" 으로 둠. 논문 방법
     재현이 목적이면 **6케이스 K 추출은 2D 로 하고 3D 는 1회 검증** 이 맞지 않나.
   - 2D 라면 평면응력 vs 평면변형: 논문 $Y=K^2/E$ ($E$ 그대로) → 평면응력 관례.
     계획서가 이걸 "열림" 으로만 두는 게 적절한가, 아니면 평면응력으로 확정해야 하나.

6. **빠진 것 / 틀린 것 / 과잉**
   - FE 재현에 필요한데 계획서에 없는 절차·식·입력.
   - 계획서에 틀리게 적힌 것.
   - 불필요하게 들어간 것.
