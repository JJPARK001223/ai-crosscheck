2형상 & 경계조건 (Fig 8 · 9)

좌표: $X$ = 길이(0~$L/2$), $Y$ = 깊이(0~$H$), $Z$ = 폭. 균열면 = $X{=}L/2$ 평면, 개구방향 = $X$ → 모드 I 개구응력 = $\sigma_{xx}$ (S11). 균열 성장·거리 $s$ = $+Y$.

  • 대칭면 $X{=}L/2$ : $Y\in[a,H]$ 에 $U_1=0$. $Y\in[0,a]$ (균열면) 자유 — 이것이 균열 (논문: "symmetric BC except for the crack face at the bottom").
  • 지지 (롤러) : $X{=}0$, $Y{=}0$ 에 $U_2=0$.
  • 강체 방지 : 2D 지지점 1점만으로 $t_1$(대칭면이 $t_1$·회전 제거) 외 잔여 모드 없음 → $X{=}0,Y{=}0$ 점에 $U_2=0$ 이면 충분. 3D 폭방향 $t_3$ 를 위해 폭 절반 모델($0..W/2$) + $Z{=}W/2$ 에 ZSYMM (또는 지지 edge 를 $Z{=}W/2$ 에서 partition → vertex 1개 assert → $U_3=0$). v1 의 getByBoundingBox(z=W/2) 1점 방식은 vertex 부재로 실패 → 금지.
  • 하중 : $X{=}L/2$ 쪽 상단($Y{=}H$) 스트립. 반모델이므로 총하중의 절반 $P_0/2$ → 압력 $= (P_0/2)/(\text{strip 길이}\times W)$. 선택면적 × 압력 $= P_0/2$ assert, 해석 후 $\sum RF_2$ 검산.

메시: 균열 선단 요소 ≈ 0.3 mm (논문). 논문 최종 2D ≈ 10,000 요소.

4K 추출 — 2D 6케이스 (본체) + 3D 검증

경로 A — 논문 방식 (곡선맞춤, Fig 10) · 2D

  1. 2D 평면 요소 (CPE4 평면변형 / CPS4 평면응력 — §7 참조), 두께 = $W$ = 100.
  2. 선형탄성, 하중 $P_0/2$. 반력 $\sum RF_2 = P_0/2$ 검산.
  3. 균열 선단에서 균열면 연장선($+Y$) 따라 $\sigma_{xx}$ (S11) 를 path 로 추출. $s$ = mm. (논문 $\sigma_e$ 가 전역 S11 인지 최대 주응력인지는 원문 확인 — §7 열림.)
  4. $\ln\sigma_{xx} = \ln\hat K - \tfrac12\ln s$ 자유 최소자승 → 기울기 $\approx -0.5$ 확인 → 채택 구간에서 기울기 $-\tfrac12$ 고정 재적합.
  5. 팁 극근방 적분점 1~2층 제외. 맞춤창 $[s_{\min}, s_{\max}]$ 스윕 + 메시 3수준 → $\hat K$ 수렴.
  6. $K_{I,fit} = \sqrt{2\pi}\,\hat K$ 로 표준 $K_I$ 환산.

경로 B — Abaqus Contour Integral · 2D + 3D 대표

  • 2D: ContourIntegral(crackNormal=((0.,0.,0.),(1.,0.,0.)), kFactor=ON) — 두 점 형식 (v1 단일 튜플 (1,0,0) 은 공개 Reference 서명 불일치. Abaqus 2020 설치본에서 최종 확인 게이트).
  • $J$ 도 출력 → $J = K_I^2/E'$ 로 kFactor 검산.
  • "앞 N개 contour 제외 평균" 금지 → 위치별 contour plateau(경로독립 구간) 선택.
  • 3D: 대표 1케이스(예: 케이스4) 반폭 모델 → $K(z)$ 를 자유표면·중앙면 위치별로 출력 → 폭방향 균일성·자유표면 영향 정량화 (논문의 "3D → 2D 허용" 주장 재현).
경로 A ↔ B 비교
$K_{I,fit}$ (경로 A, $\sqrt{2\pi}\hat K$) 와 $K_I$ (경로 B, kFactor) 를 비교. 일치 판정 기준은 임의 ±5% 가 아니라 메시·데이터 불확도 예산(수렴표의 변동계수 + 맞춤창 스윕 범위). 논문 Fig 11 정량 비교는 경로 A 기준.
