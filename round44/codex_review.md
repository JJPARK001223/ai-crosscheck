## 2. 틀렸거나 과장되었거나 범위 수정이 필요한 점

### E1. HTML 5: SG 50% 보수의 “거의 0” 구간을 전체 두께로 확대 — 명확한 내용 오류

- **대상 문장:** “50% 수리는 ID 부근을 제외하면 깊이 전체에서 축응력이 거의 0”.
- **원문:** B049 [P46 / p31]은 **50% 깊이 보수의 깊이에 걸쳐** 거의 0이고, 이어서 **보수 깊이부터 압축 구간, OD 근처에서 인장으로 반전**한다고 쓴다. PDF 지면에서도 확인했다.
- **수치 반증:** B049 Table 11 [P106 / p91]에서 x/t=0.68은 −189.60 MPa, 0.92는 299.72 MPa, OD는 200.19 MPa다. 전체 두께가 거의 0일 수 없다.
- **수정:** “ID 부근을 제외한 보수 깊이(약 50%)까지는 거의 0이고, 이후 압축 구간을 거쳐 OD 근처에서 인장으로 반전한다.” `claude.md`에는 이 잘못된 전체 깊이 문장이 없다.

### E2. HTML 8: “입열·토치 속도 — 축대칭이라 무관” — 두 원인을 혼동

- **원문:** B049 Table 4 [P79 / p64]의 “not relevant”는 비드를 한 번에 적층하므로 **토치 속도**에 해당한다. 입열은 별도로 감도해석했다. [P19 / p4]도 입열에 weakly sensitive라고 한다.
- **직접 수치:** B049 [P141~142 / pA-6~7]에서 입열 약 ±10% 변화 시 baseline 최대 차이 약 ±20 MPa, 50% 보수 약 ±50 MPa다.
- **수정:** “토치 속도는 축대칭 적층에서 직접 반영하지 않음. 입열 변동은 조사 범위에서 이차적이라 최종 불확실성에서 제외.” `claude.md`의 “입열은 2차적” 설명은 이 점에서 HTML보다 정확하다.

### E3. HTML 2·5·9 및 `claude.md` §2: 항상 네 해석자의 평균이라는 설명 — 사례별 수를 한정해야 함

- **원문과 맞는 부분:** B049 [P18 / p3]은 전체 참여자 4명과 평균을 설명한다.
- **한계:** B049 [P44 / p29]은 보수 결과를 세 명이 계산했고 일부 사례는 네 명이라고 각주로 구분한다. 최종 불확실성 설명 [P81 / p66]도 **3 또는 4개**라고 명시한다. VC Summer는 한 명뿐이다 [P57 / p42].
- **수정:** HTML 5의 “→4명 평균”은 “→해당 사례의 해석 결과를 취합(보통 3~4개), 필요한 경우 가중”으로 바꾼다. HTML 2·9와 `claude.md`도 “네 명 참여”와 “각 사례의 해석 수”를 구분한다. 단순 평균만이 최종 입력이라는 해석도 p66의 가중 수정과 맞지 않는다.

### E4. HTML 2: 입열을 통일했다는 단정 — 공통 지침과 동일 모델은 다름

## 4. `codex.md`에서 스스로 고쳐야 할 점

이번 지시대로 `codex.md` 원본은 수정하지 않았다. 다음을 자기 정정·보완 기록으로 남긴다.

1. **§3.2 예제 모수 표의 원문 기호:** `μ=172.2258, σ=36.85661`이라고 썼다. 값과 의미는 맞지만 원문 그대로의 기호를 요구한 문제에 맞춰 **`φ=36.85661`**로 고쳐야 한다. B049 [P99 / p84]는 φ를 쓰고 [P86 / p71]도 응력 σ와 구분하기 위해 표준편차를 φ로 쓴다고 명시한다. 내 §3.1은 이 구분을 적었지만 수치표에서 일관성을 놓쳤다.

2. **§3.1 Cholesky 전사의 입력 조건 보완:** 내 문장도 z1,z2를 단순히 표준정규 표본이라고만 했다. B049 [P87 / p72]의 **uncorrelated vector** 조건을 추가해야 한다. 식 자체는 맞으나 조건을 빠뜨리면 위 §3의 반례처럼 분산 복원이 성립하지 않을 수 있다.

3. **§2.2·§4의 재료 근사 설명 보완:** SG의 Alloy 52 제작 문장과 Alloy 182 소개, CF8A 형상 소개와 CF8M 공통 물성, 펌프 재료의 초기 추정이라는 범위를 충분히 드러내지 않았다. B049 [P23~24 / p8~9; P29 / p14; P36~37 / p21~22]을 함께 제시해 원문 내부 진술을 구분해야 한다. 외부 도면 없이 임의로 어느 재질이 최종 진실이라고 정정하지 않는다.

4. **§4.9 “부록의 과거 단계”라는 제목의 확실성 조정:** 최종법을 본문이 요약하고 부록 C에 대안을 싣는다는 사실은 B049 [P81 / p66]로 확인된다. 다만 부록의 모든 문장을 작성 시점별로 확정할 근거는 없다. [P179 / pC-12]는 “current model”이라는 표현도 쓴다. 따라서 제목은 **“부록의 대안·개발 과정과 본문 최종 사양의 구분”**으로 고치고, 모든 차이를 단순한 시간 선후로 확정하지 않는다.

내 입력표 ID 수치·Table 7 전사·Tsuruga 표의 쪽수·원문 99%/2.05σ 불일치 기록에서는 이번 대조로 새 수치 오류를 확인하지 못했다. 이는 이 검토에서 대조한 범위의 결과이며 모든 그림·물성 곡선까지 전수 검증했다는 뜻은 아니다. 근거: B049 [P84 / p69; P102~129 / p87~114].

## 5. 확인 불가와 인계 범위
