방법: codex.md 주장을 round43/txt 원문과 스크립트·grep으로 직접 확인. "Codex가 말했다"는 근거로 쓰지 않음.

## 원문으로 확인되어 맞는 점
- Table 7–34 각 표의 x/t=0 행(축·후프 평균, Param2): 22개 표 전부 스크립트로 추출해 codex.md §3.4 표와 일치(예: SG 15% 축 −18.83/44.79, VC Summer OI 후프 371.15/67.00). 또 Table 7 첫 행 −147.17/18.34 일치.
- North Anna(Table 29–30)와 Ringhals(Table 31–32)의 x/t=0 행이 같은 값(−62.81/50.00, 262.62/67.00) → "같은 수열" 지적 맞음(이유는 원문만으로 확인 불가).
- p.69 "99% confidence interval … adding and subtracting 2.05 × the estimated standard deviation" (txt L2533–2534). 정규분포에서 ±2.05σ 포용률 = 0.9596, ±2.576σ = 0.9900 (계산 확인) → Codex 지적(표기 불일치) 맞음.
- 펌프 노즐 명칭 충돌: 목차·§3.5 제목은 "Pump Outlet Nozzle"(L181, L1789), §2.3.3은 "Pump Inlet" → 맞음.
- A-8 "expected to dominate" (L8513)와 본문 p.65 "modeler uncertainty dominates" (L2360) 상충 → 맞음.
- Table 34 쪽: 목차 113, 실제 PDF 129(인쇄 114) → 맞음. 쪽 변환 PDF = 인쇄 + 15 일치.
- 가중식(p.68) 인쇄가 흐트러져 단일 w식 확정 불가라는 판단은 내 이미지 확인과 일치(내 초안도 "곱 방식 채택" 문장을 기준으로 함).

## Claude가 놓쳤던 점 (Codex가 보완, Claude 수용)
1. "99%/2.05σ" 불일치를 내 초안이 그대로 옮겼음(오류성 전달). → HTML 수정.
2. 축응력=원주균열, 후프응력=축균열 대응과 평형 요구는 축응력만이라는 점을 명시하지 않았음. → 반영.
3. "ID 부근 인장"과 x/t=0 표면 값의 구분(예: SG 15% 축응력은 ID −18.83, x/t 0.04에서 106.60). 본문 §3 서술과 §7 표를 동일시하면 오독. → 반영(Table 9 값은 아래 확인).
4. 수압시험 조건(149°C·21.44/17.13 MPa), 30% 수리는 Fig.20에만 있고 §7 입력표에는 없음.
5. 0.8/0.9/0.95/0.99 상관값 혼용 주의, 정확한 평형이 아니라 "가능한 0에 가깝게"라는 표현.
