## 2. 발표에 반드시 포함할 내용

### 2.1 FE 모델링과 데이터 후처리

1. **실측만으로 데이터베이스를 만들지 않은 이유:** 측정의 불확실성, 제한된 실측 데이터베이스, 추가 측정 비용. 네 숙련 해석자의 예측을 활용한다. 3명은 ABAQUS 6.14, 1명은 ANSYS 17을 사용했다. 참여 조직은 Emc2, DEI, NRC, Battelle다. [P18 / p3; P38 / p23]
2. **축대칭 가정:** 실제 원주 방향 이동 용접 대신 각 패스를 동시에 적층한다. 원래 용접 및 보수의 start/stop 근처에는 적용 한계가 있고, 보수 결과는 start/stop에서 떨어진 보수 중앙에 해당한다고 가정한다. [P18–19 / p3–4]
3. **열/구조 완전 비연성:** 열해석 온도 이력이 구조해석 입력이다. 사용자 FORTRAN 열유속 루틴, 주로 대류 손실, 복사 무시, 직사각형 비드, 용융부 형상을 맞추는 것이 주요 조건이다. 구조 경계조건은 용접에서 떨어진 탄소강 노즐의 적어도 한 노드를 축방향으로 고정한다. [P19 / p4]
4. **경로 의존 제작 순서:** buttering→PWHT→비드별 DMW→필요한 가공/보수→SS closure weld와 시험·운전 사이클. SG/RPV/pump의 실제 모델링 순서는 §2.3을 따른다. 모든 부품에 같은 작업 순서를 복사하면 안 된다. [P19–20 / p4–5; P29–36 / p14–21]
5. **경화법 평균과 해석자 통계는 별개:** 먼저 한 해석자의 isotropic와 nonlinear kinematic 결과를 평균한다(혼합경화 해석 결과에 가까운 근사). 이후 3–4명 결과로 최적 추정과 불확실성을 구성하며, 일부 이상치에는 가중을 적용한다. 실제 혼합경화 구성식을 직접 푼 것으로 표현하지 않는다. [P20 / p5; P40–41 / p25–26; P81–84 / p66–69]
6. **추출 위치:** butter–DMW 경계, DMW 중심, DMW–safe end 경계의 세 경로를 조사했지만 보고서 및 최종 입력의 중심은 **용접 중심선 26점**이다. 전체 용접 단면이나 모든 위치를 대표한다고 단정할 수 없다. [P20 / p5; P41 / p26]

### 2.3 완화 방법은 문헌 기반 규칙

**[사실]** FSWOL/OWOL은 WOR 범주로 묶고, MSIP와 inlay를 포함한다. 본문에서는 3개 완화 계열의 규칙을 설명한다. 지정 노즐에 각 공정을 직접 FE 해석한 결과가 아니라 문헌에서 추정한 규칙을 26점 데이터에 적용했다. Peening은 제외했다. [P60–61 / p45–46]

- **WOR:** 보수로 높은 ID 인장을 낮추거나 압축으로 바꾼다. 이미 axial 압축이면 거의 변화 없거나 약간 증가할 수 있다. Hoop는 ID 근처에서 적어도 200 MPa 감소하는 문헌 경향을 사용했다. [P60 / p45]
- **MSIP:** axial은 ID에서 감소하고 OD에서 증가하는 경향. 문헌의 정량 예는 ID 인장일 때 감소 300–400 MPa, OD 증가 최대 약 150 MPa다. 이것은 모든 입력점에 고정 적용하는 보편 상수가 아니다. [P67 / p52]
- **Inlay:** ID에 용접금속을 추가하므로 ID 근처 axial/hoop WRS가 항복 수준 이상까지 높아질 수 있다. “완화 공법이면 ID 인장응력이 항상 감소한다”는 표현은 틀리다. [P73 / p58]
- 완화 후 입력표는 §7에 실리지 않았고 별도 generic spreadsheet에 있다고 적었다. 완화 불확실성은 원래 SG/RPV/pump 해의 불확실성과 같다고 **가정**했다. [P101 / p86]

### 2.4 불확실성: 최종 포함분과 미포함분

### 2.5 최종 샘플링 논리

1. 위치는 26점에 고정하고 응력값을 정규분포에서 샘플링한다. 독립 샘플링은 비현실적인 톱니 모양을 만들기 때문에 상관을 도입한다. [P85–86 / p70–71]
2. Cholesky 분해로 상관된 정규표본을 만든다. ID의 한 스칼라 표본에 중요도 샘플링을 적용하면서 나머지 두께 방향 응력에 영향을 전달할 수 있다. [P86–87 / p71–72]
3. **Axial WRS → 원주방향 균열**, **hoop WRS → 축방향 균열**이다. 축대칭 가정하 axial은 두께 방향 적분을 가능한 0에 가깝게 해야 한다. Hoop에는 같은 평형 조건을 요구하지 않는다. [P85 / p70; P94–95 / p79–80]
4. 생성한 axial 프로파일 전체를 상수만큼 옮기는 shift 방법은 분포 범위를 벗어나거나 높은 ID 표본을 평균 쪽으로 돌려놓아 극단 조건을 과소대표할 수 있어 대안을 사용했다. [P88–91 / p73–76]
5. 대안은 평균 응력 크기·부호에 따라 상관을 바꾸는 것이다. 평균이 음인 영역은 음의 상관, 0 근처는 작은 상관으로 하여 높은 양의 응력에 대응하는 음의 응력이 생기도록 한다. 결과가 더 굴곡져질 수 있다. **모든 표본의 정확한 평형 보장은 아니다.** [P91–95 / p76–80]
6. 상관 정규화 기준은 ID 평균 대신 **프로파일 최대 양의 평균응력**이다. ID 평균이 0에 가까울 때 불안정해지는 문제를 피한다. ID 평균이 음이면 사용자가 지정하는 중요도 샘플링 분위수의 방향이 반전된다: 원문은 낮은 분위수가 높은 ID 응력을, 높은 분위수가 낮은 ID 응력을 만든다고 설명한다. [P95 / p80]
7. 사용자 입력 분포와 무관하게 각 점 분포를 동일 평균·표준편차의 정규분포로 바꾸므로 입력 workbook에서도 NORMAL을 권한다. [P95 / p80]

## 3. 발표용 식·수치·표의 정확한 원문 근거

### 3.1 수식: 지면 확인분

다음은 원문의 수학 기호·값을 유지한 전사다. 원문에는 이 본문 식들의 별도 식 번호가 없으므로 쪽으로 찾는다.

**프로파일 간 L1 거리** [P82 / p67]:

\[
C_{i,j}=\frac{\sum_{k=1}^{26}|x_{i,k}-x_{j,k}|}{26},\qquad i\ne j
\]

**거리 역수와 가중 평균** [P83 / p68]:

\[
\theta_{i,j}=\frac{1}{C_{i,j}},\qquad
\mu_k=\frac{\sum_{i=1}^{n}w_i x_{i,k}}{\sum_{i=1}^{n}w_i}
\]

원문은 가중치를 합산/곱으로 시험하고 **product procedure를 사용했다**고 명시한다. 다만 같은 쪽 가중치 정의 줄에는 F1/F2 및 w가 이어져 중복·혼합된 인쇄가 있다. **그 줄의 정확한 단일 w 식은 확인 불가**이며 임의로 정정한 식을 “원문 그대로”라고 싣지 않는다. 발표에는 위의 명료한 두 식과 “프로파일 거리의 역수를 이용한 곱 가중”이라는 설명을 사용하고, 실제 구현을 재현하려면 원문이 언급한 workbook의 확인이 필요하다. 동일 프로파일로 C=0이 될 때의 처리도 해당 본문에서는 확인 불가다.

**가중 표준편차 및 두께 방향 평균** [P84 / p69]:

\[
\sigma_k=\sqrt{\frac{\sum_{i=1}^{n}w_i(x_{i,k}-\mu_k)^2}{\sum_{i=1}^{n}w_i}},\qquad
\sigma=\frac{\sum_{k=1}^{26}\sigma_k}{26}
\]

여기서는 분모를 n−1로 바꾸거나 분산을 평균한 뒤 제곱근을 취하는 식으로 바꾸지 않는다.

**정규표본 상관과 응력 복원** [P86 / p71]:

\[
z_3=\rho z_1+\sqrt{1-\rho^2}z_2,
\qquad \sigma_1=\mu_1+\phi_1z_1,
\qquad \sigma_2=\mu_2+\phi_2z_3
\]

이 쪽은 응력을 σ, 표준편차를 φ로 표시한다. 5장의 표준편차 σ와 기호 용도가 다르다. z1,z2는 표준정규 표본이다.

**2×2 Cholesky 설명식** [P87 / p72]:

\[
\begin{bmatrix}1&\rho\\\rho&1\end{bmatrix}
=\begin{bmatrix}1&0\\\rho&\sqrt{1-\rho^2}\end{bmatrix}
\begin{bmatrix}1&\rho\\0&\sqrt{1-\rho^2}\end{bmatrix}=LU,
\qquad Z^*=LZ
\]

**[해석]** 이는 원문의 두 변수 설명식이다. 이 식만으로 최종 26점 부호 의존 상관행렬을 완전히 정의했다고 주장하면 안 된다. 특히 인접상관을 거리의 거듭제곱으로 주는 별도 식을 원문 확인 없이 추가하지 않는다.

## 4. 오해 방지와 원문 한계·오류 기록

1. **보고서 QA 지위:** 서명면은 기술내용이 xLPR Software Quality Assurance Plan에 따라 준비되지 않았다고 명시한다. §2.5는 입력 데이터에 소프트웨어 모듈과 같은 문서화가 요구되지 않지만 계획의 취지에 맞춰 Design Verification을 수행했다고 설명한다. “전체 보고서가 xLPR SQA 인증을 받았다”고 쓰지 않는다. Table 1에는 SG SS pipe ID 29 in 대신 지정값 31 in이어야 하는 오류를 발견해 재메시하고 수정 확인한 구체적 사례가 있다. [P3 / pii; P37–39 / p22–24]
2. **모델 평균=관측 진실 아님:** 가중은 부족한 지식과 해석자 가정 차이에 대한 판단이다. 다수 결과의 군집에 더 신뢰를 주는 가정이지 실측으로 이상치를 판정한 절차가 아니다. [P81–82 / p66–67]
3. **서비스 하중 선형 가산:** 원문은 항복을 넘는 경우 WRS에 운전하중을 선형으로 더하면 K 계산용 하중을 과대평가한다고 지적하고 후속 개선 가능성을 적었다. [P42–43 / p27–28]
4. **재료 입력:** 용접금속에는 annealed 응력–변형률 곡선이 필요하다. as-welded 곡선을 넣으면 모델이 생성하는 응고/수축 경화와 기존 pre-strain을 중복 반영할 수 있다. A508 통계를 A516과 같다고 보는 것, kinematic hardening 무시 등은 부록 A의 물성 불확실성 평가용 가정이며 본문 최종 WRS 전반의 가정으로 확대하면 안 된다. [P36 / p21; P146–147 / pA-11–12]
5. **정확한 평형과 근사적 평형 구별:** 최종 방법은 적분을 가능한 0에 가깝게 한다. §6.4의 평균 프로파일 적분도 약 8 MPa라고 표현한다. 실제 두께 dx 적분의 단위와 정규화 방식까지 이 수치로 확정할 수 없으므로 발표에는 “원문 표기 약 8 MPa”라고 적고, 이를 정확한 축력 0의 검증으로 쓰지 않는다. [P95,99–100 / p80,84–85]
6. **구간 표기 불일치:** [P84 / p69]는 Figure 58을 “99% confidence interval”이라 하면서 “2.05 × estimated standard deviation”을 가감했다고 쓴다. 지면에도 동일하다. **[검산/해석]** 정규분포의 중앙 ±2.05σ는 약 96%이므로 중앙 99%와 일치하지 않는다. 원문 수치 2.05를 몰래 2.576으로 바꾸거나, 원문의 99%를 검증된 값처럼 발표하면 안 된다. 실제 workbook의 계산·Figure 58 구간 생성값은 **확인 불가**다.
7. **가중식 표기:** p68의 가중치 정의 줄은 수식과 인덱스가 중복되어 단일 구현식을 명확히 전사하기 어렵다(§3.1). 원문 자체의 애매함을 기록하고 가중 평균/표준편차와 본문 product 채택 설명만 확정한다.
8. **입구/출구 명칭 충돌:** §2.3.3 및 Figure 9는 RCP inlet, §3.5 제목·첫 문장은 outlet이라고 쓴다. **[해석]** 발표에서는 “B&W cold-leg–RCP DMW”를 사용하고 명칭 불일치를 주석으로 남긴다. PDF만으로 이를 설계정보에 의해 최종 정정하는 것은 **확인 불가**다. [P34–36 / p19–21; P51 / p36]
9. **부록의 과거 단계:** C-12는 baseline 최대 3개·다수 보수 2개 해석을 적지만 본문 p66는 3–4개를 기준으로 최종 방법을 설명한다. 숫자를 하나로 억지 통합하지 않는다. 부록 C의 최대엔트로피·절단정규·6차 표준편차 적합식을 최종 구현이라고 단정하지 않는다. [P81 / p66; P179–180 / pC-12–13]
10. **검증과 외삽:** 기존 mock-up 실측은 방법의 신뢰성 근거지만 대상 노즐 자체를 모두 측정한 것이 아니다. 감도는 RPV outlet만 조사하고 SG/pump에도 적용 가능하다고 가정했다. 축대칭 및 제한된 보수 깊이·짧은 safe end 영향 등을 전 플랜트로 일반화하지 않는다. [P80 / p65; P136 / pA-1]
11. **향후 항목:** 직접 완화 FE 해석, 3D 효과, 물성 불확실성, 추가 보수 깊이, 완화 추정값 검증, safe end 길이 효과를 개선안으로 제시한다. “Version 3에서 구현되었다”는 사실은 이 보고서로 **확인 불가**다. [P130 / p115]
12. **원문 밖 자료의 확인 한계:** 인용된 업체 도면·WRS uncertainty workbook·Subversion 입력 DB·Acceptance STP는 이 조사에서 직접 열지 않았다. 완화 세부 입력표, 최종 26점 상관행렬 구현, 확률계산 코드와 likelihood weight 식의 일치 여부, 자료의 현재 배포 상태는 **확인 불가**다.

## 6. 독립 조사 수행 기록

- 시작 시 `git pull` 성공(Already up to date). 기존 다른 작업의 수정·삭제·미추적 파일은 보존했다.
- 다른 AI 결과 및 자동화/오케스트레이션 스크립트를 열거나 실행하지 않았다. 별도 AI를 호출하지 않았다.
- 원문 PDF와 지정 텍스트를 직접 읽었고 결과 파일 이외의 연구·렌더링 파일은 저장하지 않았다.
- 연구 결과는 이 파일 하나에만 작성했다. Git 인계 완료 여부는 실제 커밋·push 후 원격 브랜치와 대조한 결과로 보고한다.
