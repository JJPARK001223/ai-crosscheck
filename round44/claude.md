## 1. 구성과 역할
- 이 보고서의 역할(p.1, PDF 16): xLPR 2.0에서 용접 잔류응력(WRS)의 두께 방향 프로파일과 불확실성을 만들어 입력으로 제공. WRS → 응력확대계수 K 계산(UWFM) → 균열 성장 구동력(SCC·피로).
- WRS는 균열 안정성에는 영향 없다고 봄(취성 CASS 제외) (p.iv, p.1).
- 장: 1 서론 · 2 WRS 모델 개발(FE 가정, 용접부 선정, 제작 순서, 물성, QA) · 3 결과(SG, RPV, Pump, VC Summer, 완화) · 4 민감도·불확실성 · 5 샘플링·불확실성 정량화 · 6 중요도 샘플링(Cholesky) · 7 입력 표 · 8 Version 3 개선 · 9 요약 · 부록 A(민감도) B(물성) C(불확실성 특성화).

## 2. 핵심 내용
- 직접 측정만으로는 불가(측정 불확실·DB 작음·비용)해서 FE 예측 사용. 4개 기관(Emc2, DEI, NRC, Battelle) 예측의 평균 (p.3, PDF 18; p.23 PDF 38).
- FE 가정(p.3~5, PDF 18~20): 축대칭, 열-구조 비결합, 직사각형 비드, 열경계=대류(복사 무시), ABAQUS 6.14 3명·ANSYS 17 1명. 공정 순서: butter→PWHT→DMW 비드별→스테인리스 폐쇄용접→(기계가공). 마지막 shakedown 300°C·15.5 MPa 3사이클 후 300°C에서 추출. 경화칙: 등방 + 비선형 이동 평균(혼합경화에 근접).
- 추출: 26개 등간격 점(ID→OD), DMW 중심선 값만 사용. 3경로(butter-DMW 경계, 중심선, DMW-safe end 경계) 중 중심선 (p.5, PDF 20).
- 대상 용접부 3종(p.5~): Westinghouse SG 노즐(좁은 개선, 29in ID·2.45in), Westinghouse RPV 고온관 노즐(29in ID, 2.45in, 짧은 safe end <57.2 mm), B&W 냉각재펌프 노즐(28in OD, 2.75in). 각각 baseline·15%·50% 수리 케이스. 별도: VC Summer(현장 균열 사례), 문헌값 기반 North Anna·Ringhals·Tsuruga(검증용).
- 설계검증(2.5): 독립 검증자 5항목 확인. 예: SG 케이스에서 스테인리스관 ID가 29in로 되어 31in 규정과 달라 재메쉬(Table 1, p.23).
- 결과 특징: SG는 4개 해석이 비교적 근접; RPV는 safe end가 짧아 폐쇄용접이 WRS 지배, 후프응력 편차 큼; 펌프는 변동 더 큼. 수리 깊이에 따라 ID 근방 변화, 수리 크기는 모델러가 임의 정의라 불확실성 증가(p.30~31).
- VC Summer: 외부→내부 용접 순서가 가장 가혹(ID 인장 최대). 두 순서 모두 입력표에 포함. 불확실성은 RPV 결과로 추정(Emc2만 해석) (p.40~42).
- 완화(3.7, p.45~): FSWOL/OWOL(WOR), MSIP, Inlay. **문헌 기반 규칙**을 baseline 26점 표에 적용(직접 FE 아님, V3에서 검증 권고). 불확실성 매개변수는 원 케이스와 동일.
- 불확실성(4~5): 열물성·입열·비드 순서·탄성계수·층간온도는 2차적 중요도로 제외; 응력-변형률 곡선 변동은 중요하나 고온 통계자료 부족으로 미포함 → xLPR 2.0은 **모델러 간 변동만** 사용(p.65).
- 5.1 통계량: 각 위치 정규분포 가정, 점별 평균 + 26점 평균 표준편차 하나(상수 σ). 이상치 영향 완화 위해 시뮬레이션 쌍 간 L1 거리로 가중.
  - C_{i,j}=Σ_k|x_{i,k}−x_{j,k}|/26, θ_{i,j}=1/C_{i,j}, 가중치는 합(F1)/곱(F2) 중 **곱** 채택(원문 식 표기 일부 흐트러짐, p.68), μ_k=Σw_i x_{i,k}/Σw_i, σ_k=√(Σw_i(x_{i,k}−μ_k)²/Σw_i), σ=Σσ_k/26. 99% 구간 표시는 평균±2.05σ(p.69).
- 6장 샘플링 제약 6개(p.70): 26점 등간격, 인접점 상관(톱니 방지), 축응력 두께적분≈0(원주균열용 평형), 후프응력은 평형 불필요, 점별 분포 가변, 중요도 샘플링 가능. 5가지 이동 기법은 중요도 샘플링 시 축응력에서 실패(p.70).
- Cholesky: z3=ρ z1+√(1−ρ²) z2, σ1=μ1+φ1 z1, σ2=μ2+φ2 z3 (p.71~72). 정규분포만 가능(정규의 합은 정규). L 행렬 첫 열이 ID 샘플의 영향 → ID 한 스칼라만 중요도 샘플링하면 프로파일 전체에 전파(p.72).
- 평형: (1) 상수 이동 σ*_k=σ_k−Σσ_J/26 → ID 극단값을 평균 쪽으로 되돌려 극단 과소표현, 분포 밖 이탈(p.73~76). (2) 채택: 상관계수를 위치별 평균응력에 비례(음응력에서 음의 상관) → 적분≈0 유지, 이동 불필요; 프로파일이 다소 "wiggly" → 높은 ρ(0.95) 권장 (p.76~77, 비교용은 0.8). 상관 기준은 평균 ID 응력이 아니라 프로파일의 **최대 양응력**(p.80). 이 때문에 평균 ID 응력이 음이면 중요도 샘플링 방향이 뒤집힘(낮은 분위수 → 높은 ID 응력).
- 입력표(7장, p.86~): 26점, x/t 간격 0.04, 분포 NORMAL, Param1=평균, Param2=표준편차, 상관계수 0.9 권고, Sampling loop = Epistemic. 예: SG baseline 축응력 x/t=0 평균 −147.17 MPa, σ=18.34 (Table 7, PDF 102).
- 예제(6.4): 200개 프로파일, ρ=0.9, ID 분포 μ=172.2258, φ=36.85661 (p.84). 평균 적분 약 8 MPa; 적분이 평균보다 작은 비율 약 80%(일반) / 70%(중요도).

## 3. 오해 주의·한계(원문 명시)
- 3D 아닌 축대칭(p.3); 용접 시작/종료점 효과 제외.
- 완화 WRS는 문헌 규칙, 직접 계산 아님(p.45, p.115).
- 재료 물성 변동 미포함(p.65). 서비스 하중을 WRS에 선형 중첩하면 K를 과대평가할 수 있고 효과적 소성 경화계수 보정은 후속 버전 과제(p.27~28).
- 300°C 취합 vs 운전 325°C(주석 p.6).
- 문서는 xLPR SQA 계획에 따라 작성되지 않았다고 명시(PDF 3쪽).
- 부록 A·B·C는 이번 조사에서 개요만 확인(본문 4~6장 중심) → 부록 세부는 확인 불가.
