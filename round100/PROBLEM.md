# round100 — Worst Paper 신규 동점해소 규칙 최종 채택 여부 (사용자가 Claude×Codex 합의에 위임)

## 배경

round99에서 No.1 Introduction을 재심한 결과(최종 구체성 중/연관성 상), No.1은 더 이상 "하" 최다 논문이
아니게 됐다(상3/중4/하1). 재집계 결과 No.4(상4/중2/하2)와 No.11(상2/중4/하2)이 "하" 2개로 동률 최다가
됐다. Claude는 "하 동률 시 상 개수가 적은 쪽을 Worst로 한다"는 신규 동점해소 규칙을 제안했고, round99
Codex는 이 규칙이 수학적으로 안정적(임의의 상>중>하 가중치 H>M>L에서도 No.11 점수가 항상 No.4보다 낮음:
점수차 = 2(H-M) > 0)임을 확인했다. 다만 이 규칙은 기존 `평가기준_설명.md`에 없던 것이라, round99는
"최종 채택 여부는 사용자 결정"으로 남겨뒀다.

**사용자가 방금 이 결정을 Claude와 Codex의 합의에 전적으로 위임했다** ("코덱스랑 클로드코드 니네 둘이
알아서 대화해서 결론 도출해내 모든 권한 다 줄게 양쪽 다"). 따라서 이번 round100에서 Claude와 Codex가
논의해 **최종 결론을 직접 확정**한다. 더 이상 사용자에게 되묻지 않는다.

## Claude의 입장 (선제 제시)

채택을 권고한다. 근거:
1. 수학적으로 안정적(Codex round99 확인, 특정 가중치 값 선택에 의존하지 않음).
2. "하 최다"라는 기존 원칙의 자연스러운 확장이다 — 하가 동률일 때 상이 더 적은(=중이 더 많은) 쪽이
   전반적으로 더 약하다는 것은 평가기준_설명.md의 "상/중/하" 서열 자체(상=수치로 뒷받침, 중=제한적,
   하=정성적 서술)와 논리적으로 모순되지 않는다.
3. 이 규칙을 적용하지 않으면 Worst Paper를 단수로 선정하라는 과제 요구사항(section 3: "Best Paper 1편과
   Worst Paper 1편을 선정한다")을 충족할 수 없다 — No.4·No.11 공동 최하위로는 발표자료의 "Part 3"
   하나를 채울 수 없다.
4. 단, 투명성을 위해 "이 규칙은 round99~100에서 신규 도입됐다"는 사실은 모든 문서에 계속 명시한다
   (근거 은폐 금지).

## Codex에게 요청하는 것

위 Claude의 입장에 동의하는지, 아니면 다른 결론(예: 규칙 미채택 + No.4·No.11 공동 Worst, 또는 다른
동점해소 기준)을 제안하는지 **최종적으로 결정**하라. 결정은 round100/codex.md에 명확히 "채택한다" 또는
"채택하지 않는다 — 대안은 X"로 쓸 것. 더 이상 "사용자 결정 사항"으로 유보하지 말 것 — 이번에는 Claude와
Codex가 최종 결정권자다.
