# Round 30 — 수정 HTML 재검토

대상은 `XLPR_수식_한장씩.html`의 원시 HTML 33개 section 및 data-tex다. HTML은 수정하지 않았다. 유일한 기술 근거: Kyle Schmitt, *xLPR Models Subgroup Report—Crack Growth and Coalescence*, xLPR-MSGR-CGR Version 1.0, EPRI/NRC, 2016, ADAMS ML16341B051. 이하 p.는 **인쇄 쪽수 = PDF 페이지−1**, ‘HTML’은 설명자료 페이지다. 기존 지적은 round29/codex_review.md의 항목별 인용으로 추적했다. 과거 HTML 사본과의 기계적 diff는 없으므로, 지정한 수정 페이지는 현재 문장 전체를 재감사했다.

SUPPORTED는 보고서의 직접 서술·식·표, INFERENCE는 추가 대수 해석·계산, WRONG은 원문과 불일치다. FIXED에는 삭제 또는 작성자 해석으로 구분한 경우도 포함한다. DISAGREE는 지난 내 지적을 철회하는 경우다.

## 4 남은 문제

1. **HTML 27의 인쇄식 여부 표시 — INFERENCE, 해석 표시 없음.** “번호 없는 식, §2.4.1”은 원문에 번호 없는 식이 실제로 있는 것처럼 읽힐 수 있다. “p.61–62 및 p.73 절차를 작성자가 수식화한 것; 원문 인쇄식 아님”이 필요하다. 대수 구조 자체는 보고서와 부합한다.
2. **HTML 24의 계산은 원문 정정이 아니다 — INFERENCE, 구분은 해결됨.** 사용한 중앙값은 p.58–59에 직접 근거가 있다. 표 3-5(p.86)의 반올림 log-μ에서 중앙값을 역산하면 수치가 조금 달라질 수 있으므로 재현성을 위해 C_1=2.76E-10, C_EAC=1.42E-7, C_Kb=0.498을 적으면 좋다. 현재 수치를 오류로 판정하지 않는다. 교점 유도·원문 오기 여부는 지금처럼 독립 계산/미확인으로 유지한다.
3. **작성자 해설인데 직접 사실처럼 남은 부분 — INFERENCE.** HTML 11의 절편·기울기 계산(p.40), HTML 23의 두 α 비교(p.21,57)는 정확한 대수·역할 비교지만 보고서의 직접 문장이 아니다. “식에서 계산하면/역할을 비교하면” 한마디면 출처 층위가 분명해진다. HTML 15의 ‘어떻게 쓰나’도 수식 증가 해석을 반복하며, 같은 페이지 앞 문장의 해석 표시를 이어 받는 것으로 읽힌다.
4. **적용범위·문장 범위의 작은 보완.** HTML 27의 첫 특수 K 규칙은 p.63이 **축방향 표면균열**에 대해 설명한다는 한정이 빠졌다. HTML 19의 ‘원인 미규명’은 p.48의 **90–150°C 역방향 온도 거동**에 붙여야 한다. 이를 모든 온도 거동의 원인 미규명으로 확대할 직접 근거는 없다.
5. **출처 범위 추가.** HTML 27의 합산 독립성은 p.65, 구현·입력·플래그는 p.73,77,86–87이다. HTML 31의 반복 종료는 p.106이다. 머리말의 식 위치 오류는 아니지만, 설명 전체의 근거 범위로는 현재 범위만으로 부족하다.
6. **기술 출처 밖의 주장.** footer의 “식은 PDF 쪽 이미지와 대조했습니다” 및 라운드28·29 이력은 보고서가 입증하는 사실이 아니다. 현재 검토 이력으로 분리했으므로 기술 근거와의 혼동은 해결됐다. 이번 보고서 대조는 과거 작업 이력의 진위를 인증하지 않는다.

**철회해야 할 지난 주장:** 식 3-2의 등호 누락, 그에 따른 식 2-8과의 분기 불일치는 모두 없다. 수정 HTML이 아니라 round29의 내 검토문이 잘못된 항목이다. Git 명령·오케스트레이션 스크립트는 실행하지 않았다.
