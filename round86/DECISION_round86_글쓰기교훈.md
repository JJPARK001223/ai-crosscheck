# round86 — 글쓰기 교훈 레이어 (사용자 결정 기록)

## 배경
round85 HTML 보고서가 등급·근거 설명에서 멈췄다는 사용자 피드백("중간고사 대체 평가인데 정성이 없다")에 따라,
"과학논문작성법" 수업 취지에 맞게 각 논문의 평가에 글쓰기 교훈(왜 이 평가가 좋은/나쁜 글쓰기 사례인지)을 추가했다.

## 절차
1. Claude가 `round86/claude_lessons.md`에 15편 개별 교훈 + 섹션별 공통 교훈 4개를 작성(사용 원칙: CARS, 초록의 정량적 요약, 재현가능성, 정성/정량 서술 — 4개로 한정, 출처 명시).
2. Codex가 `round86/codex_review.md`에서 evaluation_data.md와 대조 검증 → **수정 필요** 판정.
3. Claude가 evaluation_data.md로 재대조해 Codex의 지적을 전부 확인하고 HTML에 수정된 내용만 반영.

## Codex가 발견하고 Claude가 수용한 오류/과잉 일반화
1. "No.2·3·5·8·13·15 전체 상" 집계 오류 → 정정: 4섹션 구체성 모두 상 = No.3·5·9·15(4편), 8개 평가축 모두 상 = No.3·5·15(3편).
2. Results 공통 교훈에서 No.8을 "구체성 중"으로 잘못 포함(실제 상) → No.1·10·11만 중으로 정정.
3. No.14 교훈에서 "가솔린·디젤·수소 가리지 않고 반복"이라는 일반화 → No.13·15(디젤)는 Abstract 구체성이 상이라 모순. "가솔린 No.4·7, 수소 No.14"로 한정.
4. Introduction 공통 교훈에서 No.1·11을 "공백을 명시하지 않았다"고 단정 → No.11은 데이터상 "기존 기법을 체계적으로 분류·비교"한다고 적혀 있어 긍정 근거를 지우는 서술이었음. 부재 단정 삭제.
5. Methodology 공통 교훈의 "상인 논문은 예외 없이 장비·정밀도·재보정까지 명시" → 데이터가 지지하지 않는 보편 규칙. 연구 방식별로 재현 정보가 다르다는 서술로 완화.
6. "초록 압축 과정에서 수치가 빠졌다"는 저술 과정의 인과 단정 → 확인 불가, 관찰로 완화.
7. No.1 "우연이 아니라 나올 수밖에 없다", No.7·14 "저자 습관" 등 필연적 인과 표현 → 전부 삭제·완화.
8. No.9·12를 묶어 "인용 문헌 범주 불일치"로 서술 → 범주 불일치는 No.9만의 사실이며 No.12는 선행문헌 자체의 정성적 서술이 다른 사안. 분리.
9. No.11 "모델 논문은 반드시 물리 실험 검증 필요", No.10 "Results에 계산식 제시는 역할 혼동" → 4개 허용 원칙을 넘는 보편 규칙 신설. 이 논문에 한정한 관찰로 축소.
