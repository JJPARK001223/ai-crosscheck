# round65 Codex 독립 대조 B — 카드 60~118

대상: `input/b046_card.html`, `input/b046.pdf`. 다른 AI의 결과 파일은 읽지 않았다. HTML의 카드 본문·기호표·출처를 PDF 텍스트 및 전체 쪽 이미지와 직접 대조했다. 검토한 이미지: PDF p.44~61, 64, 77, 85~86, 보조 근거 p.12, 35. p.44~61은 150dpi 지정 후 긴 변 1800픽셀(원본 Letter 기준 약 164dpi), 나머지는 150dpi로 렌더링했다.

사실과 제안을 각 항목에서 구분했다. 정의 출처 오류는 해당 기호의 의미가 틀렸다는 판정과 다르다. 같은 출처 오류가 여러 카드에 반복되면 카드별 1건으로 계산했고, 한 카드의 별도 오류는 별도 건으로 계산했다. 식 TeX는 재전사하지 않았으며 이미지 대조 중 보인 식 2-58의 하첨자 변경만 기록했다. 이전 전사의 “103/103 일치” 주장은 이번 검토의 증거로 사용하지 않았다.

Table 2-3~2-7은 PDF p.48, 52~53의 이미지·텍스트와 행·열 머리글 및 데이터 220칸(숫자·부호·지수·NA 포함)을 대조했다. 각 표의 데이터 칸 수는 20, 60, 40, 60, 40이며 모두 일치했다.
