## 2. 수식 검증

### 2.1 확정된 원문 대비 불일치 — 3건

1. **[슬라이드 31 / 식 (2-54), E31.4의 c₃ / 현재 `c₃ = +0.5526 − 0.1937(a/c) − 10.01(a/c)² + 9.382(a/c)^{2.5}` / 원문 `c₃ = −0.5526 − 0.1937(a/c) − 10.01(a/c)² + 9.382(a/c)^{2.5}` / 인쇄 31쪽·PDF 43쪽]**
   - 상수항의 음수 부호 누락. 나머지 세 항의 숫자·부호·지수는 일치한다.

2. **[슬라이드 32 / 식 (2-56), E32.4의 a₃ 마지막 항 / 현재 `+57.98(a/c)^{}` / 원문 `+57.98(a/c)³` / 인쇄 32쪽·PDF 44쪽]**
   - 마지막 항의 지수 3이 비어 있다. 계수 57.98과 앞선 네 항은 일치한다.

3. **[슬라이드 32 / 식 (2-57), E32.5의 좌변 / 현재 `G₁ = b₀ + b₁(a/t)^{0.5} + b₂(a/t) + b₃(a/t)^{1.5}` / 원문 `G₀ = b₀ + b₁(a/t)^{0.5} + b₂(a/t) + b₃(a/t)^{1.5}` / 인쇄 32쪽·PDF 44쪽]**
   - **원문 그대로 표기 대상:** 원문에는 실제로 좌변이 G₀로 인쇄되어 있다. 원문 앞뒤 절과 b 계수 식의 배열을 보면 G₁ 의도일 가능성은 있으나, 이는 추론이다. 이 검토는 원문 PDF만 기준으로 하므로 G₁을 원문과 일치한다고 처리하지 않는다. 원문 인쇄 오류를 바로잡아 쓰려면 별도의 주석과 사용자 판단이 필요하다.
