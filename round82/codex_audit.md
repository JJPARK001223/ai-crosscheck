## 이상 여부 및 집계의 범위

Eqn. 1~63은 전부 존재한다. Eqn. 39(카드 52)의 중첩 slash와 `(tM₂)`, Eqn. 49(카드 66)의 불균형 `{(` ... `}`, Eqn. 52(카드 69)의 불균형 `{(` ... `}`는 지면 그대로다. 이 세 식의 괄호를 올바른 수학식으로 고치도록 권고하지 않는다. Eqn. 4·38의 대문자 P도 지면과 일치한다. Eqn. 1·2의 중첩 아래첨자 `a_{0_j}`는 지면에서 j가 더 낮게 찍힌 모양을 반영하므로 이를 오류로 세지 않았다. 나머지 번호식에서 항 누락·부호·계수 차이는 확인하지 못했다.

Table 1~25의 제목과 수치 데이터는 독립 전사와 일치한다. Table 19의 `1.090`과 Table 21 첫 열 제목 `1pt`는 원문 자체 표기라 교정 대상이 아니다. 병합 셀 반복, 다단 머리글을 별도 행으로 구성한 것, 줄바꿈은 수치 오류로 세지 않았다. 붉은 값은 Table 14의 8칸, Table 17의 3칸, Table 18의 15칸, 합계 26칸이며 위치·값·붉은 표시가 독립 전사와 일치한다. Table 18 맨 오른쪽 열의 붉은 비율도 포함해서 확인했다.

원문 영어 접힘 블록은 서술 카드 49장에 있다. 문단 내용 대조에서는 공백·줄바꿈을 정규화한 뒤 대부분 PDF 텍스트와 일치하며, PDF 53쪽의 bullet 배치 차이 등은 의미 오류로 세지 않았다. 앞뒤 페이지에 나뉜 문장이 이어지는 경우도 확인했다. 수식·표 카드에는 영어 접힘 블록이 없지만 이것을 블록 자체의 불일치로 세지는 않았다. 위 표의 원문블록 지적은 추출 과정에서 손상된 단어·수식 및 표와 서술의 경계에 한정한다.
