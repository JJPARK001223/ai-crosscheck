## 특이사항 / 확인 불가 사항
- **원문 PDF 텍스트 추출 한계**: Sapora(B-3) Eq.(1)(2), Camanho(B-6) Eq.(1)(2)(6)(8)(9)는 2단 조판 때문에
  `pdftotext`로 열이 섞여 추출됨 — 정확한 계수·식 번호는 재구성(개념적 FFM 표준형)했고, 각 HTML 파일에
  "원문 PDF 직접 대조 필요" caveat을 명시함. **추측 금지 원칙에 따라 단정하지 않음.**
- **Irwin 1957(B-1)은 스캔본(텍스트 레이어 없음)** — `pdftoppm`으로 페이지 이미지 렌더 후 직접 읽어
  서론·결론 확인. 핵심식(K, G 관계)은 이미 round7에서 확정된 내용을 재인용(원문 Eqs. 12–14 직접 재확인은
  이번 라운드 범위 밖, 페이지 3–4 이미지 미열람).
- Podgórski(B-8) 파일명의 "ó"가 bash 환경에서 깨져 원본 PDF 열기에 `cp`로 복사 후 처리(기존 비ASCII
  경로 이슈 패턴과 동일, error_log 대상 아님 — 1회성 작업 환경 이슈).
- B-9, B-10 모두 round7 확정에 따라 "선행연구 2"로 호칭하지 않음(배경 문헌으로만 취급) — 각 파일에
  경고 박스로 명시.
