# round47 — B049 서술 카드 원문 문장 직역 대응표

## 문제
`(ML16341B049)Welding residual stresses.pdf`(PDF 16–100, 130–131, 136–187)의 서술 문장을 한 문장씩 한국어로 **직역**한다. 요약·의역·해석·보충 금지. 사용자 지시: "번역에 니 주관이 들어가면 원문으로 돌려라".

## 입력
- `round47/in/bNN.json`: `[{"id","en"}]` (en은 PDF 텍스트 추출본의 한 문장/불릿/제목, 줄바꿈 정리됨, 수식 글자는 `⟦수식⟧`)
- 분담: Codex = b01, b03, b05, b07 / Claude = b02, b04, b06, b08

## 번역 규칙
1. 문장 하나 = 한국어 문장 하나. 빠뜨리거나 합치거나 덧붙이지 않는다. 원문에 없는 설명·괄호 풀이 금지.
2. 수치·단위·부등호·인용번호([5, 6])·Figure/Table 번호는 그대로.
3. 약어(WRS, DMW, PWSCC, RPV, SG, ID, OD 등)는 원문 그대로 둔다. 전문용어는 한국어 통용어 + 필요시 영어 병기가 아니라, 확신이 없으면 영어 원어 그대로.
4. 추출 노이즈(문장 중간에 끼어든 각주·그림 캡션·제목, 쪽 경계 잘림)는 그대로 둔 채 보이는 대로 번역하고, 의미가 불명확하면 번역 끝에 `[원문 추출 불명확]`만 붙인다.
5. `⟦수식⟧`은 그대로 유지. 수식을 풀어 쓰지 않는다.
6. 모호한 표현(possibly, probably, may, less important 등)은 그 정도 그대로. 단정으로 바꾸지 않는다.

## 출력
`round47/out/<작성자>_bNN.json`: `{"id": "한국어 직역", ...}` — 입력의 모든 id가 있어야 함.
