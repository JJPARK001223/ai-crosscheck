## 검증의 한계와 인계 범위

- PDF의 그림 전체에 대한 원시 좌표·숨겨진 입력 덱·외부 워크북 실행을 확인한 것은 아니다. 곡선에서 읽은 값은 도상 근사이며, 읽지 못한 내부 구현이나 원문에 없는 값은 확인 불가다.
- 원문에 기술된 §5~6 최종 방식과 부록 C 대안을 구별했지만, 배포된 특정 xLPR 바이너리의 동작은 실행하지 않았다. 이 보고서는 원문 대조 결과이며 최종 채택 결정은 사용자가 한다.
- Git 인계 대상은 **`round45/codex_review.md` 하나**다. 다른 미커밋 파일과 HTML 수정은 포함하지 않는다. 커밋·push 및 원격 브랜치 확인 결과는 최종 응답에서 별도 보고한다.
