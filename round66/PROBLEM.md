# Round 66 — Tension Bar 피로수명 논문 "5초 설명 HTML" 블라인드 교차검증

## 대상 문서 (이 한 편만 사용, 외부 지식 추가 금지)
`round66/input/paper.pdf`
이정민·정장영·석창성·송정일, 「연속식 하역기 Tension Bar의 피로수명 예측에 관한 연구」,
대한기계학회논문집 A, 43(4), 223–229, 2019. (7쪽)

## 사용자 요청 (기계안전설계특론 수업)
논문을 읽고 "누구나 5초 안에 이해 가능하게" 설명하는 HTML 작성. 저장 위치는 `J:\Desktop\기계안전설계특론\`.

## 이 라운드의 질문
1. 논문의 핵심 주장·수치(소재 물성, S-N 식, 하중 분석, Miner 손상합, 예측 수명, 안전계수, 이상하중 손상)를 논문에서 직접 확인해 목록화.
2. 논문 내부의 불일치·오류·근거 부족(예: 본문/그림/결론 간 수치 차이, 단위·식 오류, 논리 비약)을 찾는다.
3. 일반 독자가 오해하기 쉬운 지점(예: "무한수명"의 의미, 안전계수의 정의)을 짚는다.

## 블라인드 규칙
- Claude는 `claude.md`, Codex는 `codex.md`만 작성한다. 서로의 결과·HTML을 보지 않는다.
- Codex는 `J:\Desktop\기계안전설계특론\`의 HTML과 `round66/claude*.md`를 읽지 않는다.
- 2단계(상호 검증)에서만 상대 결과를 연다.

## 출력 형식 (각 AI 동일)
- 핵심 수치 표: 항목 / 값 / 논문 위치(표·그림·쪽) 
- 불일치·오류·근거 부족 목록: 위치 / 내용 / 심각도
- 오해 위험 지점
- 각 항목 신뢰도(확인됨 / 추정 / 확인 불가)
