## 독립 재계산

### 1. Goodman 환산과 S-N 식

원문 식 (4)에 σfat=0.5σu를 대입하면 다음과 같다.

```text
2σa/σu + σm/σu = 0.9σe/σu + 0.55σe/σu
σe = (2σa + σm)/1.45
Nf = (C/σe)^(1/0.149)
Nj/Nf = Nj × (σe/C)^(1/0.149)
C = 2691 (SM490YA), 3311 (SM570TMC)
```

σu가 소거되므로 표 3·4, 표 6·7의 σe가 소재에 관계없이 같은 것은 이 가정 아래에서 대수적으로 맞는다. σe는 R=0.1 조건의 최대응력이며 응력진폭이나 von Mises 응력으로 바꿔 읽지 않는다. **[확인됨]**

예: 정상 j=1은 (2×2.30+164.5)/1.45=116.62069 MPa → 표의 116.6 MPa. 정상 14행 모두 표의 σa·σm로 계산해 소수 첫째 자리로 반올림하면 표 3·4의 σe와 일치한다. **[확인됨]**

### 4. 수명비와 안전 여유도

동일 σe에서 두 식의 수명비는 `(3311/2691)^(1/0.149)=4.02098`이다. 따라서 SM570TMC 수명은 약 **4.02배**, SM490YA 대비 증가율은 약 **302.1%**다. “400% 이상 우수”를 “400% 증가, 즉 5배 이상”으로 번역하면 식과 맞지 않는다. **[확인됨]**

정상 σa와 σm를 모두 k배 하면 식 (4)의 σe도 k배이며, 손상 D(k)=D(1)×k^(1/0.149), 반복수명 L(k)=L(1)×k^(-1/0.149)이다. 따라서 목표 하역횟수 5,000회에 대한 허용 계수는:

```text
k = (L(1)/5000)^0.149
SM490YA: (6872/5000)^0.149 = 1.04853 ≈ 1.05
SM570TMC: (27630/5000)^0.149 = 1.29009 ≈ 1.29
```

SM490YA는 재현된다. SM570TMC는 본문·그림 1.31이나 결론 1.33으로 재현되지 않는다. 같은 식으로 k=1.31이면 약 4,511.5회, k=1.33이면 약 4,075.3회다. 그림 6의 생성 데이터나 다른 스케일링 방법은 공개되지 않아 원인을 확정할 수 없다. **[확인됨: 명시된 방식의 계산 / 확인 불가: 실제 저자 처리]**

## 일반 독자의 오해 위험과 설명 문구

- **“6,872번”은 배 6,872대에 해당하는 동일 하역 이력 반복수명**이다. 개별 응력 cycle은 한 배 이력에 표 2 기준 230,486회 들어 있다. 6,872년이나 단일 진동 횟수라고 쓰면 안 된다. **[확인됨]**
- **“50년”은 연 100항을 가정한 목표**다. 실제 운항량과 무관하게 50년 안전을 측정한 결과가 아니다. **[확인됨]**
- **“안전계수 1.05”는 목표 5,000회에서 허용되는 응력 배율**이다. 95% 위험, 5% 파손확률, 항복강도/작용응력으로 해석할 수 없다. SM570TMC 수치는 원문 충돌과 독립 계산값을 함께 밝혀야 한다. **[확인됨]**
- **“4배 오래 간다”는 동일 응력·같은 모델 조건에서의 비교**다. 서로 다른 실제 장치의 확정 운용수명이나 파손확률 비교로 넓히지 않는다. **[확인됨: 식의 비율 / 확인 불가: 실제 수명비]**
- **“정상운전 무한수명”에는 피로한도 가정과 평가 범위가 붙는다.** 장치의 모든 부위, 용접, 결함, 외력, 균열진전에 대한 보증이 아니다. 유한 S-N 외삽값과 피로한도 적용 판단을 동시에 제시하되 계산 가정을 구분해야 한다. **[확인됨]**

## 확인의 한계와 인계 범위

공개 표의 합산·역수·Goodman 환산·S-N식 대입은 직접 재계산했다. 원시 측정신호, 상세 시험 데이터, 회귀 과정, 그림 6 생성 자료가 없어 해당 단계는 재현하지 못했다. 본문과 표의 명확한 충돌, 반올림 차이, 모델 타당성의 미확인을 서로 구분했다. 이번 보고서는 독립 단계 결과이며 사용자 최종 결정이나 상대 AI 검증 결과를 포함하지 않는다.
