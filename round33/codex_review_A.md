# Round 33 엄격 원문 한정 감사 A

대상: `XLPR_발표자료_수식정리.html`의 순서상 1–16페이지. 근거는 제공된 보고서 PDF와 그 텍스트 덤프뿐이다. 아래 p.는 모두 보고서 인쇄 페이지이며 PDF 페이지보다 1 작다. 수식 및 표는 PyMuPDF로 렌더링한 원문과 대조했다. 문제가 있는 항목만 기록한다.

## HTML 2페이지

1. **WRONG — 표기한 크기의 종류가 다름**
   - 대상: “공학적으로 의미 있는 크기(예: 크기 1~3 mm 이상)의 균열”
   - 원문: p.19 각주 2는 “1-3 mm or more in depth”라고 하여 **깊이**를 지정한다. 일반적인 크기 기준으로 바꾸지 않는다.
   - 최소 교체: “공학적으로 의미 있는 균열(예: 깊이 1~3 mm 이상)”

2. **INFERENCE/DERIVED/JUDGMENT — 보고서 밖의 자료 구성 설명**
   - 대상: “이 정리 자료는 1~6장을 이 순서로 요약하고, 2~6장에 나오는 식을 한 페이지에 하나씩 다룹니다.”
   - 원문: p.19 §1.4는 보고서의 장별 구성만 설명한다. 이 HTML 자료의 요약 방식이나 페이지 배치는 언급하지 않는다.
   - 최소 교체: **DELETE**

## HTML 3페이지

1. **INFERENCE/DERIVED/JUDGMENT — 하첨자 철자의 확장**
   - 대상 셀: “g = growth(성장)”
   - 원문: p.21은 Q_g를 “thermal activation energy for crack growth”로 정의하지만, g가 growth의 약자라고 별도로 설명하지 않는다. 물리량 정의를 넘어 하첨자의 유래를 확정한 설명이다.
   - 최소 교체: **DELETE** (Q_g의 물리량 정의는 유지)

## HTML 4페이지

1. **잘못된 인쇄 페이지 인용**
   - 대상: “활성화 에너지는 130 kJ/mol로 고정하고 나머지 계수는 선별한 데이터에 다중회귀로 맞추어 β = 1.6을 얻었습니다(식 2-1은 1.16, p.28).”
   - 원문: p.28에 130 kJ/mol, 다중회귀 및 1.6은 있지만 Alloy 600의 β = 1.16은 p.22와 p.82 Table 3-4에 있다.
   - 최소 교체: “활성화 에너지를 130 kJ/mol로 고정한 다중회귀에서 β = 1.6을 얻었습니다(p.28). Alloy 600의 β는 1.16입니다(p.22).”

2. **WRONG — Alloy 82 모델과 개선계수 적용 제한을 혼동**
   - 대상: “Alloy 82에만 쓰는 경우는 PWSCC가 Alloy 82 안에만 있다고 확인될 때뿐입니다.”
   - 원문: p.28 각주 7은 “the improvement factor for Alloy 82 of 2.6 should only be applied”라고 한다. 제한의 대상은 Alloy 82의 **개선계수 2.6**이지 문장처럼 모호한 모델 적용 자체가 아니다.
   - 최소 교체: “Alloy 82의 개선계수 2.6은 모델링하는 PWSCC가 Alloy 82 재료에만 위치한다고 확인된 경우에만 적용해야 합니다(p.28 각주 7).”

## HTML 5페이지

1. **INFERENCE/DERIVED/JUDGMENT — 식에 대입하여 얻은 값**
   - 대상 셀: “수소 보정 계수(전이점에서 1, 전이점에서 충분히 멀어지면 1/P에 가까워짐)”
   - 원문: p.33은 f_H2를 “hydrogen factor”로 정의하고 식 2-4를 제시한다. p.34는 전이점에서 멀어진 높은·낮은 수소 농도에서 CGR 예측이 감소한다고 서술한다. f_H2의 값이 전이점에서 1이고 멀리서 1/P로 접근한다는 문장은 보고서의 직접 서술이 아니라 식의 평가 및 극한 설명이다.
   - 최소 교체: “수소 보정 계수”

## HTML 7페이지

1. **INFERENCE/DERIVED/JUDGMENT — 원문에 없는 주의 지시**
   - 대상: “식 2-6의 온도는 섭씨이므로 단위를 혼동하지 않아야 합니다.”
   - 원문: p.72 식 3-1은 T = T_C + 273.15와 지수 내부 T_C를 명시한다. “단위를 혼동하지 않아야 한다”는 지시는 하지 않는다.
   - 최소 교체: “식 3-1에서 T = T_C + 273.15이고, 전이 수소 농도 계산에는 T_C를 사용합니다(p.72).”

## HTML 9페이지

1. **INFERENCE/DERIVED/JUDGMENT — 하첨자 뜻을 물리량 정의와 다르게 붙임**
   - 대상 셀: “flaw = within-component(부품 내 변동)”
   - 원문: p.38은 식에 부품 내 변동을 나타내는 항이 있다고 설명하고, p.76 Table 3-2는 f_flaw를 “Within-component CGR variation factor”로 정의한다. 이는 계수의 역할이지 flaw라는 하첨자가 within-component의 약자라는 설명은 아니다.
   - 최소 교체: “flaw: 결함” (계수 의미 셀의 부품 내 변동 정의는 유지)

## HTML 10페이지

1. **INFERENCE/DERIVED/JUDGMENT — 입력 순서 추가**
   - 대상: “피로 성장은 ΔK의 함수이므로 모든 피로 식의 첫 입력입니다.”
   - 원문: p.39는 “largely governed by ... ΔK, as well as ... R”라고 한다. ΔK가 모든 피로 식의 ‘첫 입력’이라는 순서를 정하지 않는다.
   - 최소 교체: “사이클당 피로 성장은 응력확대계수 범위 ΔK와 하중비 R에 크게 좌우됩니다(p.39).”

## HTML 12페이지

## HTML 13페이지

1. **잘못된 인쇄 페이지 인용 및 INFERENCE/DERIVED/JUDGMENT**
   - 대상: “원문 p.83은 C_Kth 중앙값을 1로 유지한다고 쓰고 Table 3-5는 log-μ 0.239(약 1.27)로 적었습니다. 원문 안의 서술 차이입니다.”
   - 원문: p.83에는 “the median is held at one”이 있고, **p.86** Table 3-5에는 log-μ 0.239가 있다. Table 3-5에 ‘약 1.27’이라는 값은 없으며, 이를 표의 숫자로부터 환산하고 ‘서술 차이’라고 판정하는 문장은 보고서의 직접 서술이 아니다. 중앙값 1.27 자체는 별도로 p.42에 직접 나온다.
   - 최소 교체: “p.83은 중앙값을 1로 유지한다고 서술합니다. p.86 Table 3-5는 log-μ를 0.239로 제시합니다. p.42는 중앙값 1.27의 분포와 중앙값 1.0을 사용하는 대안을 제시합니다.”

## HTML 14페이지

1. **OVERSTATED — 관측 범위를 Ni계 전체로 일반화**
   - 대상: “공기 중 속도에 ‘환경이 더 빠르게 만드는 항’을 더하는 구조이고, 환경 영향은 공기 중 속도가 작을 때(약 1E-9 m/s 미만) 더 크게 나타납니다.”
   - 원문: p.44의 해당 ‘작은 공기 중 속도에서 환경 증대가 더 큼’은 NUREG/CR-6721의 **Alloy 600 환경 피로 시험**을 설명하는 문단에 있다. 같은 페이지는 Alloy 82/182에서는 높은 피로 속도에 해당하는 하중에서도 환경 증대가 관찰되었고, Alloy 690과 용접금속의 제한된 데이터에서는 환경 증대가 없었다고 구별한다. 재료 제한을 생략한 현재 설명은 Ni계 전체의 관측 특성으로 확대된다.
   - 최소 교체: “식 2-13은 공기 중 사이클당 성장량에 환경항을 더합니다(p.42). Alloy 600 시험에서는 작은 공기 중 피로 속도(예: 1E-9 m/s 미만)에 해당하는 하중 조건에서 환경 증대가 더 크게 관찰되었습니다(p.44).”
