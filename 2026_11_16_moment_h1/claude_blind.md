# m_h1_r5th01a010 수식 독립 검토 (재계산 포함, 새 해석·보간·피팅 없음)

## 1. ML 수식 동일성: 대수적으로 동일
- 두 쪽 모두 ML = 4·Rm²·t·σy·[cos((a/t)·θ/2) − (a/t)·sinθ/2]입니다.
- 워크북 값은 손계산과 일치합니다. 4·160000·80·200 = 1.024e10에 괄호값 0.984426을 곱하면 1.00805e10이고, 엑셀 값은 1.00805e10입니다.
- FE 쪽(Rm300, t60, a6, θ=0.1π)은 4.2527e9입니다. |CM1|=6.379e9에 반단면 계수 2를 곱하면 12.758e9이고, q = 12.758e9/4.2527e9 = 3.0000으로 보고값과 일치합니다.
- 워크북의 θ/π = 0.1000023559는 `B21=C11/(π·C13)`에서 C13이 Ri=360이라서 나온 값입니다(113.1/(π·360)). Rm=400이면 0.09입니다.
  - 즉 θ는 Ri 기준 호길이 113.1(반올림값)에서 유도되었고, FE의 θ=0.1π와는 상대차 약 2.4e-6입니다. ML에는 사실상 영향이 없습니다.
  - 다만 B21 수식이 Rm이 아닌 Ri를 참조한다는 점은 의도 여부를 확인해야 합니다.

## 2. h1 전치계수 변환
- 워크북은 Jp = h1·α·σy·εy·(t−a)(a/t)·q^(n+1)이고, εy=σy/E이므로 α·σy²/E·(t−a)(a/t)·q^(n+1)·h1과 같습니다.
- Kamaya는 Jp = h1·α·σy²·t/E·q^(n+1)입니다.
- 같은 Jp를 주려면 h1_wb = h1_K / [(1−a/t)(a/t)]이어야 합니다. a/t=0.1이면 h1_wb = h1_K/0.09, 즉 약 11.1배입니다.
- 따라서 두 규약의 h1 숫자를 변환 없이 직접 비교하면 안 됩니다.
- Je 항은 h1(n=1)=4.9739와 q²를 같은 전치계수로 쓰고 있어, Jp = Jtotal − Je 분리는 워크북 규약 안에서는 일관됩니다.
- 참고로 FE Job4 평균 J=12401.4를 같은 공식에 대입하면 대략 h1 ≈ 6.3입니다(Je≈48 차감, J 단위가 N/mm라고 가정한 잠정 산술값).
  - 이는 워크북의 n=5 값 5.66, n=3 값 5.55와 같은 규약에서 약 10% 높습니다.
  - n=4.72에 대한 보간은 하지 않았습니다.
- normalized 10.33은 12401.4/1200이고, 1200은 σy·a(=200·6)와 일치합니다. 이 정규화는 h1이 아닙니다.
  - 따라서 이 값을 워크북 h1과 직접 비교하면 안 됩니다.

## 3. 두께 스케일링만으로는 차이를 설명할 수 없음
- Rm/t=5, a/t=0.1, θ/π=0.1, α, n, σy, E가 같다면 비율은 s=60/80=0.75입니다.
  - ML은 s³(=0.4219)로 바뀌고, 이는 10.0805e9 → 4.2527e9으로 확인됩니다.
  - J의 절댓값은 s배가 됩니다.
  - q, h1, J/(σy·εy·길이)는 s에 불변입니다.
- 따라서 두께 스케일링은 무차원 h1이나 정규화 J의 차이를 만들 수 없습니다.
- 기하 상사가 아닌 부분도 있습니다. 워크북은 L/Rm=10(L/t=50)이고 FE는 1500/300=5(L/t=25)입니다.
- FE 쪽에는 요소 품질 문제도 있습니다(왜곡 11869개, 종횡비>100이 15061개). 이는 영향 가능성이 있는 요인이지만, 원인이라는 증거는 아닙니다.

## 4. 소스가 증명하는 것과 증명하지 못하는 것
**증명하는 것**
- ML 식의 형태는 균일 깊이 a를 갖는 유한길이 원주 표면균열의 순단면 붕괴 식입니다.
- 워크북의 α=2, n=5 및 n=3 계산값과 FE의 α=3.39, n=4.72는 서로 다른 재료 조건입니다.

**증명하지 못하는 것**
- 균열 위치(내면/외면)와 FE 균열 형상(균일 깊이/반타원)은 알 수 없습니다. 파일명이나 Ri 사용만으로 단정할 수 없습니다.
- h1이 어떤 균열 형상 전제로 산출되었는지, FE 형상과 같은지도 알 수 없습니다.
- 일부 n=3 JtotalT 셀과 n5 K52는 하드코딩 값이라 ODB와의 연결을 추적할 수 없습니다. 데이터의 독립성과 출처도 확인할 수 없습니다.
- 목표 PNG의 파라미터(α=3.39, n=4.72, Rm/t=5, θ/π=0.1, a/t=0.1)는 현재 FE와 일치합니다. 그러나 PNG의 원래 균열 형상과 σ0 정의(σy와 같은지)는 미확인입니다.
- 워크북은 α=2, n=5·3만 다루므로 PNG를 뒷받침하지 못합니다.
