# DECISION — Round 16: 시멘트 페이스트 FE 연구를 세미나 발표 수준으로 구성하는 흐름 설계

작성: Claude (Claude·Codex 교차검증 종합). round16/claude.md, round16/codex.md 모두
blind로 독립 작성 후 이 문서에서 종합함.

## 0. 결론 먼저

방향성은 완전히 일치했다(연구배경은 짧게·이론은 필요한 시점에 분산 배치·본인 FE
검증이 발표의 주어가 되어야 함·사용자 고유 수치는 문헌값과 분리). 단 Codex가
① 선행연구3 원문 §4의 실제 시편 수치(Claude가 이번에 재확인·검증 완료: W=100mm,
L/H=4, E=20.8GPa, H=50·100mm, 2D 4절점 사각형요소 약 10,000개)까지 직접 대조했고,
② 17장 단위의 훨씬 세밀한 슬라이드 매핑을 제시했고, ③ K/P=0.4793의 **단위 불명확
문제**라는 Claude가 놓친 중요한 결함을 지적했다. 충돌은 없고 Codex 쪽이 전반적으로
더 실행 가능한 수준까지 구체화했으므로, 최종 가이드는 Codex안을 뼈대로 하고 Claude의
표/체크리스트 형식을 보조적으로 결합한다.

## 1. A — 통합 발표 흐름

- 공통: "18장 이론을 전부 먼저 설명 후 FE 결과를 부록처럼 붙이는" 구성은 탈락.
  연구배경은 문제의식만 1장으로 압축하고, 이론은 그것이 실제로 쓰이는 지점(식→FE
  설정→결과) 바로 앞에 분산 배치해야 한다는 원칙은 양쪽이 동일하게 도출.
- **Codex 채택**: 표지·참고문헌 포함 17장 매핑표(round16/codex.md §A-1)를 최종안의
  뼈대로 채택한다. Claude의 12단계 매핑(round16/claude.md §A)은 같은 방향이지만
  해상도가 낮아 Codex안으로 대체.
- **Codex 채택**: "연구배경(문제의식 1장 예고) vs 이론배경(조건1·2 상세 2~3장)"의
  역할 분리 원칙(§A-2)을 그대로 채택. "배경이 짧다"는 벤치마크 관찰을 "이론도 짧아야
  한다"로 일반화하면 안 된다는 Codex의 지적은 Claude가 명시하지 않았던 중요한 구분.
- **Codex 채택**: 선행연구2 미존재, "원 논문 그대로 재현"이라는 표현 금지, Υ≡G_c
  금지 등 기존 교차검증(Round13·15) 원칙을 재확인하고 발표 기호정책 선언을
  슬라이드 레벨까지 끌어올린 것(§A-3)을 채택.

## 2. B — 수식·그림·모델링 배치

- 공통: 선행연구3 §4.3의 2D 곡선맞춤(논문 방법)과 사용자의 3D 상호작용적분(본인
  방법)을 같은 슬라이드에서 섞지 말고 "방법 비교" 슬라이드에서 명확히 분리해야
  한다는 결론은 일치(Round15 DECISION과도 일관).
- **Codex 채택**: 이론정리 3-1.1~3-1.5를 한 덩어리로 보여주지 않고 슬라이드
  6/8/10-11/12/14로 분산 배치하는 구체적 지도(§B-1)를 채택.
- **Codex가 보완(중요, Claude가 놓친 결함)**: `K/P=0.4793`은 차원이 있는 양이므로
  **K의 단위, P가 전체하중인지 반모델 하중인지의 규약, 회귀에 쓴 하중점 수와 R²**
  없이 숫자만 제시하면 발표 근거로 불충분하다. **채택**: 최종 가이드와 추후 실제
  발표자료 모두 이 숫자를 쓸 때 단위·하중규약·R²를 반드시 병기하도록 명시한다.
- **Codex가 보완**: 가장자리-중앙 7.8% 설명에 "자유표면 끝점(F1/F21)의 상호작용적분은
  q방향/표면 normal 설정에 민감할 수 있다"는 추가 주의를 Nakamura&Parks/Abaqus
  문서([S6])와 함께 덧붙인다. 기존 Round15의 "경계층+코너특이장" 설명 자체는 유지하되,
  "물리적 현상으로 확정"이 아니라 "물리적 경향과 일치하며 수치적 민감도 확인이 남은
  관측"으로 톤을 한 단계 더 보수적으로 조정한다. **채택**.
- **Codex가 보완**: 결과 시각화는 Claude가 제안한 "Contour 1~8 겹쳐보기 +
  평균±표준편차" 대신(또는 추가로) **균열전선 위치를 z/W 무차원 좌표로 정규화하고
  K/K_center 비율로 제시**하면 7.8%의 의미가 모델 고유 단위·하중 크기에 덜 의존하게
  된다는 제안(§B-2-6)을 채택 — 사용자 모델 고유값이라는 caveat을 시각적으로도
  뒷받침하는 효과가 있다.
- **Codex가 보완**: 슬라이드 하단 출처 표기를 "문헌수치/사용자FE수치/해석적 판단"
  3종으로 형식을 나눈 것(§B-4)을 채택 — 기존 두 보고서가 이미 구분해온 원칙을
  슬라이드 단위로 공식화한 것이라 충돌 없음.

## 3. C — 수준 비교

- **Codex 채택**: 체크리스트를 "현재 상태 전체"로 뭉뚱그리지 않고 4개 기존 문서
  (18장 뼈대 / 이론정리 / FE결과분석 / 5장·이론흐름 목차군) 각각을 7개 기준으로
  따로 0/0.5/1 채점한 표(§C-2)를 최종 채택. 결과: 기존 문서 중 가장 높은 것도
  4.5/7(5장·이론흐름 목차군)에 그치고, 통합안은 설계상 7/7이지만 "실제 수치·그림을
  채운 뒤에만 성립하는 조건부"라는 단서를 명시한 것도 채택 — Claude의 단일 표보다
  진단력이 높음.
- **Codex가 보완(중요, 실행 가드레일)**: "실행 전 게이트" 목록(§2) — 시편 전체
  치수, 요소타입(C3D20 vs C3D20R), element/node 총수, quarter-point 여부, K/P
  단위·하중규약·R², K값들의 단위·step/frame, Υ 보정용 실험 파괴하중 — 은 **이번
  라운드에서도, 이전 Round13~15에서도 사용자의 실제 .cae/.dat 전체를 재검산하지
  않았으므로 지어내면 안 된다**는 점을 명시적 체크리스트로 만든 것을 전면 채택한다.
  Claude도 "확인 불가 사항"으로 일부(치수, element/node 수) 언급했으나 Codex의
  목록이 더 완전하다.
- **Codex가 보완**: 선행연구3 §4의 실제 시편 수치(W=100mm, L/H=4, E=20.8GPa, H=50·
  100mm, 2D 4절점 사각형요소 약 10,000개)를 제시했다 — **Claude가 이번 DECISION
  작성 중 `선행연구3_원문번역_영한대역_Unified_Failure_Criterion.html` 원문 대조로
  직접 재검증하여 정확함을 확인**(번역문 590~635행, 704행 부근). 단, 이 수치는
  **논문의 시편**이며 사용자 본인 모델의 치수와는 별개이므로 혼동 금지 — 사용자 모델
  고유 치수는 위 "실행 전 게이트"에 따라 .cae에서 별도로 확인해야 함을 재강조.
- 신뢰할 수 있는 추가 출처(Karihaloo, Abdalla & Xiao 2003, *Engineering Fracture
  Mechanics* — Kwon et al. 2024가 인용한 시멘트 페이스트 실험 원자료)를 참고문헌에
  추가하되, **Claude·Codex 모두 이 논문 원문을 직접 읽지 않았으므로 "Kwon et al.
  (2024)가 인용한 자료"라는 전거만 명시하고 그 이상의 내용은 서술하지 않는다.**

## 4. 최종 결정

위 공통결론 + Codex 보완사항 전체(17장 매핑, 이론 분산배치 지도, K/P 단위 문제,
7.8% 설명 톤 조정, 문서별 세분화 채점표, 실행 전 게이트, 검증된 논문 시편 수치)를
반영하여, 새 가이드 문서(`2026_10_02_세미나자료_흐름설계` 폴더, HTML)를 작성한다.
이 문서는 실제 슬라이드가 아니라 **사용자가 슬라이드를 만들 때 따라갈 설계도 +
자기점검표**이며, 범위를 벗어나는 PPT 디자인 자체는 만들지 않는다.
