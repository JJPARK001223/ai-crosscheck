# Round 21 — 이론적배경 문서에 시각화(SVG 개략도) 추가, 물리적 정확성 검증

## 배경
`claude_code\2026_10_06_선행연구1_3_이론적배경\이론적배경_선행연구1_3.html`
(round20에서 작성·검증된 선행연구1·3 유도 자기검증 문서)에 각 유도 단계/사례에 맞는
인라인 SVG 개략도 6종을 추가하려 함. 사용자 요청: "각 과정에 맞는 시각화 자료 가능?
코덱스랑 협업."

## 추가할 6개 그림과 근거 식/섹션
1. **그림 A.1-1** — 조건①(응력) AND 조건②(응력구배) 동시 충족 판정 로직
   (선행연구1 §서론, 식1·2 — Kwon 2021).
2. **그림 A.3-1** — Case 1 도그본 인장시편: 균일응력 σ=σ_l, 응력구배=0 (A.3절).
3. **그림 A.4-1** — Case 2 중앙균열 무한평판: 균열길이 2a, 원거리응력 σ∞, 균열끝
   국소좌표 (r,θ), Irwin 근사 적용 영역 (A.4절, 식4: σ_x=K/√(2πr)).
4. **그림 A.8-1** — Case 3 무한평판 원공: 반경 R, Kirsch 해 σ_θ(r,θ), θ=π/2
   가장자리에서 최대응력 3σ_o (A.8절, 식8~10).
5. **그림 A.10-1** — Case 4 FEA 개념 스케치: 균열전선을 따라 복수 지점에서 K_I 추출
   → 조건①②로 판정하는 절차 (치수는 미기재 — 실제 수치는 확인 불가).
6. **그림 B.3-1** — §4 경화시멘트페이스트 3점굽힘(3PB) 시편 개략도: 지간 S, 하중 P,
   균열깊이 a (기호만, 수치 라벨 없음) + "1점에서 Y 역산 → 나머지 시편 예측" 절차
   (B.3절, 원 실험: Karihaloo et al. 2003).

## 검증 목표 (Codex 블라인드 검증 요청 사항)
아래를 선행연구1(Kwon 2021, JPVT 143(6) 064503)·선행연구3(Kwon 2024, Materials
17(3) 569) 원문 및 표준 LEFM/Kirsch 고전해 기준으로 독립 검증할 것:
- 각 그림의 기하(균열 위치·방향, 원공 vs 균열 구분, 좌표축 방향, θ=π/2 위치)가
  논문의 실제 설정과 일치하는가.
- Case 2(균열)와 Case 3(원공)을 시각적으로 명확히 구분했는가 — 특히 균열은 "선"으로,
  원공은 "구멍"으로 그려야 하며 혼동하면 안 됨.
- Kirsch 해의 응력 분포 개형(가장자리에서 최대, θ=π/2 방향)이 실제 식(8)~(10)과
  맞는가.
- Case4·§4 그림에 추측 치수·수치가 들어가지 않았는가 (들어가면 Rule 3 위반 — 사실만
  전달, 불확실하면 추측 금지).
- 조건①·②의 AND 로직 다이어그램이 논문의 실제 논리(두 조건 모두 충족해야 파괴)를
  왜곡 없이 표현하는가.

## 제약
- 인라인 SVG만 사용(외부 이미지 파일 없음), 다크테마 CSS 변수 재사용.
- 수치 라벨은 기호(S, P, a, R, σ_o 등)만 — 실제 치수 추측 금지.
- 기존 본문 텍스트·수식·구조는 변경하지 않음(시각화 삽입만).
