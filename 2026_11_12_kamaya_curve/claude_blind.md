# 판정: σ 정의는 논문에서 확정 불가, 총 J 예측은 Eq.(11) 해석을 병기하면 가능

## 1. 출처에서 확정되는 것과 확정 안 되는 것

**확정되는 것**
- Eq.(5)는 K(ae) = f1·σ·√(π·ae)입니다.
- Fig. 4의 축 정의는 f1 = K_I/(σ√(πa))입니다.
- 두 곳 모두 σ를 명시적으로 정의하지 않습니다. 본문 추출본에는 정의가 없습니다.
- 따라서 "σ = M/(πRm²t)"와 "σ = σy·M/ML" 중 어느 쪽도 논문 텍스트만으로는 확정할 수 없습니다.
- Eq.(7)과 Eq.(8)로 계산한 ML은 입력값 2,911,159,580과 일치합니다(2σyRm²t × 1.3478). 이 부분은 정상입니다.
- Eq.(11)의 구조는 확정됩니다.
  - ae = a{1 + (0.5n−1.5)·[f1·(…)·(M/ML)]² / (1 + 2(M/ML)²)}
  - Eq.(9)와 Eq.(6)의 대응(α=(n−1)/(6(n+1)))으로 보면 Kumar 식은 ae − a = a·f1²(σ/σy)²·α/(1+(M/ML)²)입니다. 즉 대괄호는 f1·σ/σy에 해당해야 합니다.

**확정 안 되는 것**
- Eq.(9)와 Eq.(11) 대괄호 안의 "2?" 글리프가 깨져 있습니다. (2/π)인지 다른 기호인지 텍스트에서 읽을 수 없습니다.
- 5.1절의 α, β, γ 값 배정도 글리프가 깨져 있어 순서가 모호합니다.
- 원본 PDF 이미지에서 Eq.(9)와 Eq.(11)을 직접 확인해야 합니다.

## 2. σ 정의 판별 (f1을 맞추지 않고, 주어진 f1 = 1.29로 정의만 비교)

입력은 time = 0.01, M = 87,334,800 N·mm, E' = E/(1−ν²) = 219,780, FE J = 0.0224275입니다. 아래 값은 수계산이므로 Excel에서 재확인이 필요합니다.

| σ 후보 | σ (MPa) | Je = (f1σ)²πa/E' | FE 대비 |
|---|---|---|---|
| M/(πRm²t) 공칭 | 5.148 | 0.01891 | **−15.7%** |
| σy·M/ML | 6.000 | 0.02569 | **+14.5%** |
| M·Ro/I (외표면 굽힘응력, 정확한 I) | 5.607 | 0.02243 | **+0.03%** |
| M·Ro/(πRm³t) (박육 근사) | 5.663 | 0.02289 | +2.0% |

- **판정:** FE 모델과 정합하는 정의는 외표면 굽힘응력 σ = M·Ro/I입니다. 정확한 I = π/4(Ro⁴−Ri⁴)를 쓴 값이 최적입니다.
- time = 0.02 점도 Je가 M²에 비례해 일관합니다. 0.0224275×4 = 0.08971이고 FE는 0.0897745입니다.
- **한계:** 이는 FE와의 정합 근거이지 논문이 그렇게 정의했다는 증거가 아닙니다. 논문 정의는 여전히 미확인입니다.
- f1 표의 유효숫자는 3자리라 ±0.4%입니다. FE 메시 오차는 논문 기준 최대 2.4%입니다. 그래서 박육 근사(+2.0%)도 완전히 배제되지는 않습니다.
- 공칭 σ(−15.7%)와 σy·M/ML(+14.5%)은 탄성 구간에서 명확히 배제됩니다.
- Table 1은 θ/π = 0.5, a/t = 0.5, Rm/t = 5에서 f1 = 1.29입니다. 탄성 계수 일관성 측면에서 이 값은 유효합니다.
- h1 = 1.52(n = 5, 같은 격자점)도 표와 일치합니다.

## 3. 총 J 예측 (time = 1, M/ML = 3.0)

- Jp = h1·α·σy²·t/E·(M/ML)^(n+1) = 1.52 × 2 × 200² × 60/200000 × 3⁶ = **26,593.9**
- 탄성항은 ae 해석에 따라 달라집니다. 기준 Je(a)는 σ = 560.7 MPa에서 224.35입니다.

| ae 대괄호 해석 | Je | 총 J | FE 26,002.8 대비 |
|---|---|---|---|
| A: f1·(2/π)·(M/ML) (글리프 문자 그대로 가정) | 296.0 | 26,889.9 | +3.4% |
| B: f1·(M/ML) | 401.1 | 26,995.0 | +3.8% |
| C: f1·σ/σy (Kumar 등가 유도형) | 378.7 | 26,972.6 | +3.7% |

- 이 하중에서는 Jp가 98.9% 이상을 차지합니다.
- ae 해석 불확실성이 총 J에 미치는 영향은 약 0.4%p 이내입니다.
- 따라서 정의가 모호해도 이 하중에서는 총 J 예측을 만들 수 있습니다.
- 다만 M/ML ≤ 1에서는 Je 비중이 커져 ae 해석이 결과를 좌우합니다. 거기서는 PDF 확인 전까지 A, B, C를 병기하세요.

## 4. 외삽 경고

- 논문의 보정 상수(0.5n−1.5, 2, 1)는 M/ML = 1.0, 1.2, 1.5, 1.8에서 시행착오로 맞춘 값입니다.
- M/ML = 3.0은 보정 상한 1.8을 약 1.67배 넘는 **외삽**입니다.
- 논문의 오차 범위(F = −25%~+48%)는 M/ML = 1~1.8에서의 값이라 M/ML = 3에는 적용되지 않습니다.
- 위 +3.4~3.8%는 독립 검증이 아니라 참고용 일치입니다. 특히 Jp가 지배적이어서 h1 계수의 일치를 본 것에 가깝습니다.
- time = 0.01(M/ML = 0.03)도 보정 범위 밖이지만 순수 탄성 영역이라 Eq.(5) 점검에만 쓰세요.
- 범위 내 검증을 위해 M/ML = 1~1.8에 해당하는 time(약 0.33~0.6)의 FE 결과를 추가로 확보하세요.

## 5. Excel 열 구성

입력 셀: Rm, t, a, sy, E, nu, alpha, n, f1, h1, ML

| 열 | 수식 | 비고 |
|---|---|---|
| time | 입력 | |
| M | `=2*4366740000*time` | |
| Mr | `=M/ML` | |
| Ro, Ri | `=Rm+t/2`, `=Rm-t/2` | |
| I | `=PI()/4*(Ro^4-Ri^4)` | |
| σ_bend | `=M*Ro/I` | ★ FE 정합. 미확정 가정 |
| Ep | `=E/(1-nu^2)` | |
| Je_a | `=(f1*σ)^2*PI()*a/Ep` | ae 적용 전 |
| ae 계수 A | `=1+(0.5*n-1.5)*(f1*2/PI()*Mr)^2/(1+2*Mr^2)` | 글리프 가정 |
| ae 계수 B | `=1+(0.5*n-1.5)*(f1*Mr)^2/(1+2*Mr^2)` | |
| ae 계수 C | `=1+(0.5*n-1.5)*(f1*σ/sy)^2/(1+2*Mr^2)` | |
| Je_A / B / C | `=Je_a*ae계수` | ae는 √ 안에만 들어가므로 Je에 선형 비례 |
| Jp | `=h1*alpha*sy^2*t/E*Mr^(n+1)` | |
| J_tot_A / B / C | `=Je+Jp` | |
| 오차 % | `=(J_tot/J_FE-1)*100` | |
| 구간 플래그 | `=IF(AND(Mr>=1,Mr<=1.8),"보정범위","외삽")` | |

- **출처 불확실(σ 정의, Eq.9·11 글리프)과 FE 정합 근거는 열을 분리해 표기하세요.**
- σ 후보 4종의 Je 비교 열을 별도 시트에 두면 정의 판별 근거가 추적됩니다.
- f1과 h1은 표값을 그대로 쓰고 FE에 맞춰 조정하지 마세요.
