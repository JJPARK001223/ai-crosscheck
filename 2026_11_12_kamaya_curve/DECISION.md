# 최종 권고 (Eq.(11) 분모 1+2q 확정본)

아래 수치는 Excel이나 코드로 실행하지 않고 직접 계산한 값입니다. 워크북에 반영하면 수식 결과와 대조해 주세요.

## 사용한 식
- ae = a·[1 + (0.5n−1.5)·f1²·q²/(1+2q)]. 블라인드 Claude 보고서의 분모 1+2q², 2/π 변형, 총 J=26,995는 폐기합니다.
- Je = f1²σ²π·ae/E′, E′ = E/(1−ν²) = 219,780.
- Jp = h1·α·σy²·t/E·q^(n+1).
- σ(조건부 주 기준) = M·Ro/[π/4(Ro⁴−Ri⁴)]. 이 기준은 f1을 FE에 맞춘 것이 아니라, 초기 탄성 구간과의 일치(약 +0.2%)를 근거로 고른 것입니다.

## 계산 결과 (마지막 점, time=1, q≈3.0)

| 항목 | 값 |
|---|---|
| σ | 560.7 MPa |
| Je (ae 보정 전) | 224.3 |
| ae/a | 3.140 (보정항 2.140 = 14.977/7) |
| **Je (보정 후)** | **≈704.3** |
| **Jp** | **26,593.9** |
| **J_total** | **≈27,298.2** |
| **J/(σy·a)** | **≈4.550** |
| FE 26,002.8 대비 | **+1,295 (≈+5.0%)** |

- 첫 점 (time=0.01, q=0.03): 예측 J ≈ 0.02247이고, FE 0.0224275 대비 약 +0.17%입니다.
- 이 점에서 ae 보정은 약 0.14%, Jp는 약 1e-8 수준이라 사실상 탄성 Je만 남습니다.
- 대안 σ는 민감도 열로만 남깁니다. 공칭 M/(πRm²t)는 초기 점에서 약 −15.7%, σy·q는 약 +14.5% 차이가 납니다.

## 한계
1. σ 정의는 논문에서 확인되지 않았습니다. 따라서 이 곡선은 검증된 예측이 아니라 조건부 예측이며, 위 차이는 조건부 예측 불일치로만 보고해야 합니다.
2. q>1.8 구간은 논문의 오차 평가 범위(1~1.8)를 벗어난 외삽입니다. q=3에서는 ae가 a의 3.14배로 실제 두께를 넘을 수 있으므로, ae는 경험적 보정값이지 물리적 균열 길이가 아닙니다.
3. Jp가 총 J의 97% 이상을 차지합니다. 그래서 마지막 점의 +5%는 Eq.(11)보다 h1, 하중 스케일(2×Mref), FE와의 정의 차이에 더 민감합니다.
4. 2×Mref 전단면 하중 환산은 기존 작업 가정이며, 단면 합력으로 확인하는 일이 남아 있습니다.
5. h1과 f1은 FE에 맞추지 않았고 논문 값(1.52, 1.29)을 그대로 썼습니다.

**결론:** Eq.(11)(분모 1+2q)과 외표면 σ를 쓴 조건부 곡선을 주 결과로 하고, 공칭 및 기준응력 곡선은 민감도로 병기하세요. "검증됨"이라는 표현은 쓰지 말고, 최종 선택은 사용자가 결정해야 합니다.
