## 이미 확정된 사실 (round 1·3·5·7·8, DECISION_round8)
- 계보: 선1(JPVT 2021, 143, 064503) → 선2(JPVT 2022, 144, 051506) → Polymers(2022, 14, 2481) → 선3(Materials 2024, 17, 569). 인용 [34][35][36].
- 선1 식(1)~(7)·선3 식(1)~(4) 유도 수학적 정확 (양측 blind 재유도 일치, JS 수치검산 4e-16).
- 응력구배조건 절댓값은 물리상 필수 (원문 인쇄 누락). 초안의 ≥ 부등식 표기는 정확.
- Y = G_c/(2π) 평면응력 / G_c/[2π(1-ν²)] 평면변형 — Polymers §3 p.5 식(13)이 직접 지지.
  "Y ≡ G_c" 수치 등식은 부정확 (Y 입력 ~6.28배, 예측 하중 ~2.51배 오차). 단 동일 정의로 시험 1개 역산·재사용 시 공통 상수 상쇄 → 예측 불변.
- 시멘트 §4 = 노치 보 3점굽힘 **균열** (홀 아님). W=100·L/H=4·E=20.8GPa 원문 §4.1. 6케이스 = H∈{50,100}×a/H∈{0.1,0.3,0.5}. 보정점 = H=100·a/H=0.1. 이상치 = H=100·a/H=0.3.
- 곡선맞춤 시 √ℓ₀ 역변환·반모델 P/2 규약 복원 필수 (round3). Fig 10 횡축이 s/ℓ₀면 절편에 √ℓ₀ 복원, ℓ₀=H가 50·100으로 달라 누락 시 √2 체계오차.
- 선2 원문 홀 반경 지수 R^{-1/3} 인쇄, 두 조건 재유도 시 R^{-1/2} (선1 Case 3 √(14Ew_f/27R)와 일치) — 원문 정규화 불일치.
- Fig 11 세로축 = 파괴하중 P(kN), 공칭강도 아님.
- [37] = Schmeier·Träger·**Kwon**·Sachau 2023 (AM 시편, 통합기준 적용 분기).
- 노치 정의: ρ→0 **그리고** 개구각→0 이라야 균열 (Williams 1952). 선2 실제 슬릿 끝 직경 ~1.1mm.
