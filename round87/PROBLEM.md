# round87 — 중간평가.pptx 최종 내용 검증 (오류 탐색)

## 배경
`J:\Desktop\과학논문작성법 과제\중간평가.pptx`는 사용자의 실제 중간고사 대체 과제 파일(세미나 양식)이다.
No.1(사용자 본인 작성)·No.2 Abstract행(사용자 본인 작성)을 제외한 나머지(No.2의 Intro/Methodology/Results 3줄 +
No.3~No.15 전체 4섹션×2기준)는 Claude가 `round85/input/evaluation_data.md`(이미 확정된 15편 평가 데이터, Claude-Codex
교차검증 완료본)를 근거로 삼아 수작업 XML로 채워 넣었다.

**이번 라운드의 목적은 그 "채워 넣는 과정"에서 오류가 생기지 않았는지 검사하는 것이다.** 평가 자체(등급이 맞는지)는 이미
round85에서 검증이 끝났으므로 다시 평가하지 않는다. 오직 "evaluation_data.md의 내용이 pptx에 정확히, 빠짐없이,
올바른 논문 번호/섹션에 옮겨졌는가"만 검사한다.

## 입력 자료 (고정, 수정 금지)
- `round87/input/evaluation_data.md` — round85에서 확정된 유일한 정답 데이터.
- `round87/input/pptx_text.md` — `중간평가.pptx`를 `python-pptx` 기반 스크립트로 추출한 20개 슬라이드의 전체 텍스트(표 포함).
  슬라이드 5=No.1, 6=No.2, 7=No.3, 8=No.4, 9=No.5, 10=No.6, 11=No.7, 12=No.8, 13=No.9, 14=No.10, 15=No.11, 16=No.12,
  17=No.13, 18=No.14, 19=No.15, 20=마무리.

## 검사 항목 (반드시 전부 확인)
1. **등급 일치**: 15편×4섹션×2기준=120개 등급(상/중/하) 전부가 evaluation_data.md와 pptx_text.md에서 정확히 같은가.
2. **근거 문장 일치**: 각 셀의 설명 문장이 evaluation_data.md의 근거를 왜곡·축약·오기 없이 반영했는가(완전히 똑같은 문장이
   아니어도 되지만, 숫자·고유명사·인과관계가 달라지면 오류로 표시).
3. **논문-슬라이드 매칭**: 각 슬라이드의 제목(논문 제목)이 목차(슬라이드 2~4)의 순서 및 evaluation_data.md의 No.번호와
   정확히 일치하는가. 슬라이드 순서가 뒤바뀌거나 다른 논문 제목이 잘못 들어간 곳이 있는지 특히 주의.
4. **누락·중복**: 15편 중 빠진 논문이나 중복된 논문이 있는지, 각 논문의 4섹션이 전부 채워졌는지(빈 칸 없는지).
5. **오타/깨진 문자**: 특수문자(λ, κ, μ, °, ², ↑, ↓, ±, ·)가 깨지거나 인코딩 오류로 보이는 곳이 있는지.

## 절차
1. Claude가 `round87/claude.md`에 독립적으로 1~5 항목을 전부 점검한 결과(오류 목록 또는 "오류 없음")를 작성한다(Codex 결과를
   보기 전에 작성 완료).
2. Codex가 `round87/codex.md`에 Claude 결과를 보지 않고 동일한 점검을 독립적으로 수행한다.
3. 서로의 결과를 대조해 Claude가 `round87/claude_review.md`에 codex.md를 검증, Codex가 `round87/codex_review.md`에
   claude.md를 검증한다. 두 AI가 찾은 오류 목록이 다르면 어느 쪽이 맞는지 input 자료로 직접 재확인한다.
4. Claude가 최종적으로 수정이 필요한 항목 목록을 `DECISION_round87_pptx검증.md`에 정리하고, 실제 pptx 파일 수정이
   필요하면 수정 후 보고한다.

## 범위
- evaluation_data.md 자체의 등급·근거를 재평가하지 않는다(round85에서 이미 확정).
- pptx의 디자인/서식(폰트, 색상, 표 스타일)은 검사 대상이 아니다. 오직 텍스트 내용의 정확성만 본다.
