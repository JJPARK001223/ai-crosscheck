# round87 — Claude가 codex.md를 검증

evaluation_data.md 원문을 직접 재대조해 codex.md의 5건(E1~E5)과 120셀 대조표를 전부 확인했다.

## E1~E5 재검증 결과

| ID | Codex 판정 | Claude 재확인 | 수용 여부 |
|---|---|---|---|
| E1 | `Abstact`(오타, 15회) → `Abstract`로 수정 | **부분 수용.** 이 "오타"는 사실 사용자가 **본인이 직접 작성한 슬라이드5(No.1)·슬라이드6 Abstract행**에서부터 있던 표기다. Claude는 슬라이드5·슬라이드6 Abstract행을 전혀 건드리지 않았고(사용자 본인 작업 보존), 나머지 13개 슬라이드(No.2 나머지 행~No.15)를 채울 때 "사용자의 기존 표기와의 일관성"을 위해 의도적으로 `Abstact`를 그대로 사용했다(이전 턴에서 이미 이렇게 결정하고 사용자에게 알린 바 있음). 즉 Claude가 만들어낸 오타가 아니라 **사용자 본인 표기를 따른 디자인 결정**이다. 전부 `Abstract`로 고치려면 슬라이드5·6(사용자 작성분)까지 건드려야 하므로, 이건 Claude가 임의로 결정할 사안이 아니라 **사용자에게 물어야 할 사안**으로 분류한다. |
| E2 | `3중` → `3종`(No.1, 슬라이드5) | **범위 밖.** 슬라이드5는 사용자 본인이 작성한 No.1 내용이며 Claude가 작성/수정한 적이 없다. evaluation_data.md 원문은 `3가지`였고 사용자가 본인 슬라이드에 `3중`이라고 직접 썼다. Claude의 작업 오류가 아니다. |
| E3 | `COV ~33%·~32%` → `COV 33% ~ 32%`(No.2 Abstract, 슬라이드6) | **범위 밖.** 슬라이드6의 Abstract행도 사용자 본인이 이미 작성해둔 부분이라 Claude는 그대로 보존했을 뿐이다(이전 턴에서 "Abstract 행은 사용자 원문 그대로, 나머지 3행만 새로 채움"이라고 명시한 대로). Claude의 작업 오류가 아니다. |
| E4 | No.3(슬라이드7) Introduction 연관성: "수소/메탄올/가솔린 혼합을 상세히" 범위가 빠지며 공백의 의미가 넓어짐 | **수용(실제 오류).** evaluation_data.md 원문 재확인: "선행연구가 다양한 람다값·부하조건에서 수소/메탄올/가솔린 혼합을 상세히 다루지 않았다는 공백". Claude가 이 셀을 채울 때 압축하면서 의미가 달라졌다. **실제 pptx 수정이 필요한 유일한 의미상 오류.** |
| E5 | No.8(슬라이드12) Abstract 구체성: `CO2.24ppm` → `CO 2.24ppm` | **수용(실제 오류, 오타).** evaluation_data.md 원문 "CO 2.24ppm"(공백 있음) 확인. Claude가 셀을 채울 때 공백을 빠뜨렸다. CO2(이산화탄소)로 오독될 수 있어 수정 필요. |

## 120셀 대조표(섹션 2) 검토

Codex의 60행×2열 "정상/압축" 분류를 evaluation_data.md와 무작위로 10곳 이상 재대조했고, 분류가 전부 타당했다. 압축으로
분류된 항목들은 Claude의 claude.md가 이미 짚은 9건(Design-Expert®, Behçet&Yakın, 1400~3000rpm, EGT 세부수치, CZA촉매
사양, 팜바이오디젤, Kohler KDH, DEGR, Rassweiler-Withrow)과 겹치거나 그보다 더 촘촘하게 추가로 찾아낸 것들이다(예:
No.4 Results의 "ER 0.5~1.5 구간" 생략, No.6 Introduction의 저자명 생략, No.7 전반의 TiAl·Inconel·BP10/BP90 생략 등).
**등급 자체를 바꾸는 압축은 없다는 결론에 동의한다.**

## 특수문자 대조(섹션 4) 검토

↓ 개수 차이(7→9)와 · 개수 차이(185→125)에 대한 Codex의 설명("압축으로 인한 구분자 수 감소", "'감소'를 ↓로 표기 전환")을
evaluation_data.md·pptx_text.md에서 직접 확인했고 타당하다. 글자 깨짐(U+FFFD)은 없다는 결론도 동일하게 확인했다.

## 최종 판정

- **실제로 pptx를 수정해야 하는 것은 E4, E5 2건뿐**이다(둘 다 Claude가 이번에 채운 슬라이드의 오류).
- E1(Abstact 표기), E2, E3은 Claude의 작업 범위(No.2 나머지 3행 + No.3~15) 밖의, 사용자 본인이 이미 써둔 내용에 관한
  것이라 Claude가 임의로 고치지 않는다 — 사용자에게 확인 후 처리한다.
- round85의 120개 등급 자체는 CONFIRMED(두 AI 모두 전수 일치 확인), 사실 왜곡 없음.
