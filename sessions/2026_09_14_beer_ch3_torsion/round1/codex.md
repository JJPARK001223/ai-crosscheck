## 2. 단위와 공통 공식

스크립트의 기본 단위계는 힘 N, 길이 mm, 응력 및 G는 MPa = N/mm², 토크 N·mm, 회전각 rad이다.

- `J = π(b⁴-a⁴)/2`: mm⁴. 중실축이면 a=0.
- `τ(r)=Tr/J`: N/mm². `φ=TL/(GJ)`: 무차원(rad).
- `T_allow=τ_allow J/b`: N·mm. 중실축에서는 `π τ_allow b³/2`.
- N·mm → N·m는 1,000으로, N·mm → kN·m는 1,000,000으로 나눈다.
- `P=Tω`에서 T가 N·m이면 P는 W. `ω=2πf` 또는 `2π rpm/60`.
- 탄소성 평형은 `T=∫τr dA=2π∫τ(r)r²dr`. 적분항의 단위는 MPa·mm³=N·mm이다. 소성역에 탄성식 `τ=Tr/J`를 그대로 적용하면 안 된다.

이 기본식과 기어의 접선 변위·접촉력 관계는 David Roylance, MIT, *Shear and Torsion* (2000), 식 (8), (10)~(14), Example 5와 대조했다. [공식 강의자료](https://web.mit.edu/course/3/3.11/www/modules/torsion.pdf). 이하 수치는 해당 식으로 독립 재계산한 값이다.

## 3. 집중 검토

### 3.36: 코드의 고정단 호환식은 가정한 문제에는 맞지만 원문 문제에는 적용 불가

대상: b2, 32~51행. 원문: 제공 PDF 6~7쪽, 그림 P3.36.

코드는 A와 E가 모두 고정되고 B, C, D에 같은 방향으로 400, 900, 500 N·m가 가해진다고 가정한다. 그 가정 아래

```text
T_AB = T_A
T_BC = T_A + 400000
T_CD = T_A + 1300000
T_DE = T_A + 1800000
Σ T_i L_i / (G J_i) = 0
```

은 올바른 부정정축 호환식이다. 같은 재료이므로 G를 약분하는 것도 맞다. 독립 대입 시 `T_A=-650357.934518 N·mm`, 호환식 잔차 `-2.78×10⁻¹⁷ rad`로 코드와 일치한다.

**그러나 원문 A, E는 베어링 지지이며 고정벽이 아니다. C의 900 N·m는 B의 400 및 D의 500 N·m와 반대 방향이다.** 외부 토크는 `400-900+500=0`으로 평형을 이룬다. 양끝 비틀림각을 같게 만드는 조건은 주어지지 않았다. 베어링의 비틀림 반력을 임의로 추가하면 다른 문제를 풀게 된다.

구간 비틀림에 사용하는 부호를 `T_BC=+400 N·m`, `T_CD=-500 N·m`로 선택하면

```text
T_AB = T_DE = 0
φ_C - φ_B = (400000)(800)/(27000 J_30) = +8.539332679°
φ_D - φ_B = (400000)(800)/(27000 J_30)
            - (500000)(1000)/(27000 J_36) = +2.104770897°
J_30 = π(15⁴)/2, J_36 = π(18⁴)/2
```

축방향·회전방향의 양의 기준을 반대로 택하면 두 각의 부호도 함께 반전된다. 상대각의 크기는 각각 **8.53933°, 2.10477°**이다. 코드의 `-5.34472°, +3.01560°`는 원문 해가 아니다.

### 3.56: 간극을 포함한 호환조건과 강성 분배가 맞음

대상: b2, 174~197행. 원문: PDF 13쪽, 그림 P3.55/P3.56. `G=77000 MPa`, `L_AB=600 mm`, `L_CD=900 mm`, 반지름 15 및 18 mm, `T=570000 N·mm`, 간극 `δ=1.5°`.

간극 접촉 전에는 CD만 저항한다. 접촉 토크

```text
T_contact = δ G J_CD/L_CD = 369.340335898 N·m < 570 N·m
```

이므로 접촉 후 두 축이 함께 저항한다. 양의 회전각 θ_B, θ_C와 반력 토크의 크기를 사용하면

```text
k_AB=GJ_AB/L_AB, k_CD=GJ_CD/L_CD
T_AB + T_CD = T
θ_C - θ_B = δ
T_AB=k_AB θ_B, T_CD=k_CD θ_C
```

이다. 이를 직접 연립해 얻은 결과가 코드의 단계별 강성 분배와 일치한다.

| 항목 | 독립 계산 |
|---|---:|
| T_AB | 84.225849606 N·m |
| T_CD | 485.774150394 N·m |
| θ_B | 0.472872050° |
| θ_C | 1.972872050° |
| τ_AB,max | 15.887360357 MPa |
| τ_CD,max | 53.026994006 MPa |

평형 잔차는 `1.16×10⁻¹⁰ N·mm`, 간극 호환식 잔차는 0 rad였다.

작은 코드 결함: 접촉하지 않는 입력으로 바꾸면 `else`에서 `T1`을 정의하지 않은 채 출력하므로 `NameError`가 난다. 현재 570 N·m 입력의 결과에는 영향이 없다.

### 3.58: 기어 호환식은 맞고, CD 길이 입력이 틀림

대상: b2, 199~215행. 원문: PDF 14쪽, 그림 P3.57/P3.58.

기어의 전역 회전 부호를 동일하게 정하면 `R_B θ_B + R_C θ_C=0`. 크기로 쓰면 `R_B |θ_B|=R_C |θ_C|`이다. 따라서

```text
T_CD/T_AB = (L_AB/L_CD)(G_CD J_CD / (G_AB J_AB))(R_B/R_C)
T_applied_at_B = T_AB + (R_B/R_C) T_CD
```

이다. 같은 강재이므로 G가 약분되고, 코드의 `k` 및 외부 토크 합산식의 형태는 맞다. 기어 접촉력으로 보면 `F=T_CD/R_C`이므로 B가 받는 기어 반력 토크는 `F R_B`이다.

**원문은 AB=300 mm, CD=500 mm이다. 코드의 `LCD=200`은 잘못된 값이다. 500 mm는 두 축 길이의 합을 나타내는 치수가 아니다.**

| 항목 | 코드: CD=200 mm | 원문: CD=500 mm |
|---|---:|---:|
| k=T_CD/T_AB | 1.1865234375 | 0.474609375 |
| T_AB | 753.982237 N·m | 1884.955592 N·m |
| T_CD | 894.617595 N·m | 894.617595 N·m |
| B에 가하는 최대 T | 2.990526226 kN·m | **4.121499581 kN·m** |
| τ_AB,max | 17.777778 MPa | 44.444444 MPa |
| τ_CD,max | 50 MPa | 50 MPa |

수정한 입력으로 기어 접선변위 호환식 잔차는 0 mm였다. 두 계산 모두 CD의 허용응력이 지배한다.

### 3.106: 중공축 탄소성 적분은 정확함

대상: b4, 78~90행. 원문: PDF 21쪽, 그림 P3.106/P3.107. 안반지름 `a=15 mm`, 바깥반지름 `b=35 mm`, 탄소성 경계 `ρ`, `τ_Y=180 MPa`.

탄성·완전소성 재료의 단조 비틀림에서

```text
τ(r)=τ_Y r/ρ,  a≤r≤ρ
τ(r)=τ_Y,      ρ≤r≤b
```

이므로

```text
T = 2π [ ∫_a^ρ (τ_Y/ρ) r³ dr + ∫_ρ^b τ_Y r² dr ]
  = (πτ_Y/2)(ρ⁴-a⁴)/ρ + (2πτ_Y/3)(b³-ρ³)
φ = τ_Y L/(Gρ)
```

이다. 코드의 `T_hollow_plastic`과 정확히 같다. **탄성 영역 적분에서 구멍의 a⁴를 빼야 하는데 코드가 이를 포함했다.** 적용 범위는 `a≤ρ≤b`이다.

| 상태 | 토크 | 비틀림각 |
|---|---:|---:|
| 항복 시작, ρ=b=35 mm | 11.713652608 kN·m | 3.435202177° |
| 소성 깊이 10 mm, ρ=25 mm | 14.118317385 kN·m | 4.809283047° |
| 전 단면 항복, ρ=a=15 mm | 14.891149178 kN·m | 8.015471745° |

탄성·소성 영역을 나누어 각각 20,000개 구간의 Simpson 적분으로 재검산했다. 위 세 상태에서 해석식 대비 상대오차는 최대 `1.6×10⁻¹⁶`이었다. `ρ=b`에서는 `T=τ_Y J/b`, `ρ=a`에서는 `T=(2πτ_Y/3)(b³-a³)`로 환원된다. 고체축의 4/3 소성형상계수를 중공축에 그대로 적용하지 않았다.

응력분포와 적분의 출발점은 Cambridge Engineering 제공 *Presetting a Torsion Bar*, 식 (i)~(v)와도 대조했다. 저자·발행연도는 해당 PDF에 표시되지 않아 미확인이다. [기관 제공 자료](https://www-mdp.eng.cam.ac.uk/web/library/enginfo/textbooks_dvd_only/DAN/springs/appendix.pdf). 중공 구간의 적분과 수치는 본 검토에서 직접 유도·계산했다.

### 3.118: 완전소성 토크와 탄성 제하가 맞고, 최대 잔류응력은 안쪽 표면

대상: b4, 149~157행. 원문: PDF 23쪽, 그림 P3.118. `a=12.5 mm`, `b=30 mm`, `τ_Y=145 MPa`.

```text
T_p = 2π∫_a^b τ_Y r²dr = (2πτ_Y/3)(b³-a³)
    = 7.606417588 kN·m
J = π(b⁴-a⁴)/2
τ_res(r) = τ_Y - T_p r/J
```

이 제하식은 처음의 완전소성 응력에 반대 방향의 탄성 응력 변화를 중첩한 것이다. 코드와 일치한다.

- 안쪽 표면 `r=12.5 mm`: `+67.949298062 MPa`.
- 바깥 표면 `r=30 mm`: `-39.921684650 MPa`.
- 분포가 r에 대해 단조 감소하므로 최대 절댓값은 **안쪽 표면의 67.949298062 MPa**.
- 두 끝점의 잔류응력 절댓값이 모두 145 MPa 미만이고, 제하 경로에서도 역항복에 도달하지 않는다. 탄성 제하 가정이 일관된다.
- `2π∫τ_res r²dr`를 직접 적분한 잔류 토크는 `3.26×10⁻¹⁰ N·mm`로 수치오차 수준의 0이다.

코드는 두 끝점 값만 출력하므로 최종 서술에서 최대 위치와 절댓값을 명시해야 한다. 참고로 이 중공축의 `T_p/T_Y=1.275321963`이며, 중실축의 4/3과 다르다.

### 3.114: “지름 30 mm라면 7.8배”라는 산술은 맞지만, 원문에 대한 불일치 판정은 틀림

대상: b4, 139~142행. 원문: PDF 22쪽, 그림 P3.114를 고해상도로 확인했다.

**그림의 30 mm 치수는 중심에서 원주까지의 반지름 표시이다. 본문에도 지름 30 mm라는 조건은 없다. 코드의 `c=15.0`은 반지름을 다시 절반으로 줄인 값이다.**

| 해석 | T_Y | T_p | 8.475 kN·m / T_p |
|---|---:|---:|---:|
| 가정상 지름 30 mm, c=15 mm | 0.816421391 kN·m | 1.088561854 kN·m | **7.785501545** |
| 원문 반지름 30 mm, c=30 mm | 6.531371127 kN·m | 8.708494836 kN·m | **0.973187693** |

완전소성 토크는 `T_p=2πτ_Y c³/3`. 반지름을 두 배로 바꾸면 T_p가 8배가 된다. 따라서 다음 두 판단을 구분해야 한다.

1. **가정상 φ30 mm인 탄성·완전소성 중실축**에 8.475 kN·m를 정적으로 유지할 수 없다는 판단은 맞다. 적용 토크가 T_p의 약 7.79배이다. 이것은 변형경화가 없는 해당 재료모델에 대한 판단이다.
2. **실제 P3.114에는 그 지름 가정이 맞지 않는다.** 올바른 반지름에서는 `T_Y<T<T_p`이므로 탄소성 해가 존재한다. 원문 토크를 오타로 처리할 근거가 없다.

올바른 입력으로 검산하면

```text
ρ = c (4 - 3T/T_Y)^(1/3) = 14.253427537 mm
τ_res(ρ) = τ_Y - Tρ/J = +59.058929747 MPa
τ_res(c) = τ_Y - Tc/J = -45.827872993 MPa
```

탄성 중심부에서는 잔류응력이 0에서 `τ_res(ρ)`까지 선형 증가하고, 바깥 소성역에서는 외표면까지 선형 감소한다. 따라서 **최대 잔류 전단응력의 절댓값은 59.058929747 MPa이며 위치는 r=14.253427537 mm**이다. 단순히 외표면 값만 택하면 안 된다.

### 3.148: 개방단면 가정 기각, 연결된 단일 셀 폐단면

대상: b5, 128~134행. 원문: PDF 29쪽, 그림 P3.148.

고해상도 도면에서 내·외 원호의 두 끝은 각각 짧은 벽으로 연결되어 있다. 벽의 중심선을 따라가면 바깥 원호 → 한쪽 연결벽 → 안쪽 원호 → 다른 연결벽으로 돌아오는 **닫힌 경로**가 된다. 중앙의 빈 공간이 바깥과 통한다는 것과, 튜브 벽의 경로가 열린다는 것은 서로 다른 조건이다. 그림은 자유단 두 개를 갖는 단일 나선형 판재가 아니다.

따라서 코드가 쓴

```text
J_open ≈ (1/3) [2π(c1+c2)] t³
τ_max = 3T / [2π(c1+c2)t²]
T_outer/T = c1/(c1+c2)
```

는 다른 개방단면에 대한 식이다. 단위는 맞지만 P3.148의 단면 위상과 맞지 않는다.

문제에서 지정한 작은 틈새 치수를 무시하고, 금속판 중심선 반지름 `c1=150 mm`, `c2=100 mm`, `t=3 mm`를 그대로 쓰면 단일 셀의 면적과 전단흐름은

```text
A_m = π(c1²-c2²) = 39269.908169872 mm²
q = T/(2A_m) = 38.197186342 N/mm
τ = q/t = 12.732395447 MPa
```

이다. 일정 두께이므로 박육 이론상 각 벽의 전단응력 크기는 같다. 미소 연결부의 국부 응력집중은 이 근사에 포함하지 않는다.

바깥 원호에서 `dT=q ds·c1`, 안쪽 원호의 흐름은 반대 방향이므로

```text
T_outer = +2πq c1² = +5.400 kN·m
T_inner = -2πq c2² = -2.400 kN·m
T_outer + T_inner = +3.000 kN·m
```

이다. 바깥 원호의 기여가 전체 토크보다 큰 것은 안쪽 원호가 반대 부호의 토크를 전달하기 때문이다. 코드의 `τ=636.619772 MPa`, `T_outer=1.8 kN·m`, `T_inner=1.2 kN·m`는 채택할 수 없다. 코드 응력은 이 폐단면 계산의 **50배**다.

폐단면의 `q=T/(2A_m)`와 개방단면의 `J≈Σbt³/3` 구분은 Eric R. Johnson, *Aerospace Structures*, Virginia Tech Publishing (2022), Ch.3, 식 (3.123), (3.161), (3.165)에서 확인했다. [교과서 본문](https://eng.libretexts.org/Under_Construction/Aerospace_Structures_(Johnson)/03%3A_Elements_of_a_thin-walled_bar_theory), [출판기관·서지정보](https://publishing.vt.edu/books/m/10.21061/AerospaceStructures). P3.148의 면적 및 부호별 토크 적분은 본 검토의 직접 계산이다.
