(Codex가 turn 예산 소진으로 이 파일을 직접 작성/커밋하지 못해, 세션 로그에 남은 Codex의 실제 실행결과·발언을 Claude가 그대로 옮겨 기록한다.)

## 실행 내용
- claude_calc_b1.py ~ b4.py 를 Python 3.12(codex 런타임 내장)로 직접 실행 → 전부 정상 실행, 수치 출력 확인.
- 0914_문제.pdf를 pdftoppm으로 재추출(고배율)해 원문 도면과 Claude의 판독을 대조.

## 발견한 오류 (Codex 발언 원문)
> "원문 대조에서 중요한 오류가 확인됐습니다. 3.114의 `30 mm`는 반지름 표시여서, 지름 30 mm로 계산한
> "완전소성 토크의 7.8배" 판단을 원문에 적용할 수 없습니다. 3.58도 코드의 CD 길이 200 mm와 달리
> 도면에는 500 mm로 표시되어 있습니다. b1~b4는 Python 3.12로 모두 정상 실행됐습니다."

## Claude의 반영 (양쪽 모두 채택, 아래 두 파일 정정 후 재게시)
1. **3.114**: c=30mm(반지름, ⌀60mm)로 정정. T_p=8708.5N·m로 T=8475N·m를 수용(T/T_p=97.3%).
   ρ_Y=14.25mm, 최대 잔류응력 ≈ **59.1 MPa**(탄소성 경계에서, 외표면 −45.8MPa보다 절댓값 큼).
   → `3.92~3.120.html` 정정·재게시(Version 2).
2. **3.58**: L_CD=500mm(1차 판독 200mm에서 정정) → k=0.4746, T_applied=**4121.5 N·m**(CD 지배, τ_CD=50MPa 한계).
   → `3.32~3.60.html` 정정·재게시(Version 2).
