# Codex의 Claude 독립 검토 검증

claude.md와 codex.md가 c5a097c까지 Git 인계된 후 대조. 원본 이미지 재확인.

1. Claude p3 식(4) 지적 수용. 확대 detail-03.png에서 분자가 sigma_x+sigma_y로 확실히 보임. Codex blind의 식4 맞다는 판단 철회. 올바른 식 -(sigma_x-sigma_y)/2 sin2theta+tau_xy cos2theta. sigma_x=sigma_y=s, tau=0 넣으면 모든 theta에서 전단0이어야 하는데 필기식은 -s sin2theta여서 반례로 검증됨. tau_xy=tau_yz처럼 보이는 보조식도 tau_yx로 정리 필요.
2. Claude p5의110kN 판독은 기각. 손글씨70의7이 굽어있고 p6 동일70 및 모든 대입280000 일관. 원본 B하중 화살표는40kN 한 개. 110kN 가능성 제시는 근거 없음. 70 유지. d1 필기22.59는22.5676의근사, d2 최소15.9577이므로15.96이상.
3. Claude p11 각도 해석 기각. detail-11.png의 theta는 아래쪽 수직선과 하중 사이의 각. 손글씨에도 수평240sin theta라고 명시. 따라서 수직240cos, 수평240sin 맞음. sigma0=-4.267MPa,sigma90=-2.133MPa. 원본 N_DE=-(320cos+160sin)는 인장양 축력으로 맞고 FBD화살표/모멘트부호 일치 보완 및 최종응력추가만 필요.
4. Claude p12 불확실성 해소. 원형 부재 반경r1.4, 중심O에서B 오른쪽1.4, 중심O에서C 아래1.4이므로 C기준B=(1.4,1.4), A높이1.4+1.4sin30=2.1. 0.56은B-D 수평차이지C-B가 아님. P=33.0667kN 확정, BD2mm만2m로수정.
5. Claude p1,p2 개념모두정확은 수정 필요. 응력은힘자체아닌면적당내력, 내력은복원성질아님, 선형Hooke는비례범위, 전체외력합0과절단체평형구분. 상세 codex.md 참조.
6. Claude가 놓친 p13 A에서모멘트취한다고Ay0이되는것아님: Ay=-18.133kN. 28.53kN=28530N 수정합의. Dy중간분수도수정.
7. Claude가 놓친 p15 대입은105e6/25e3로 역수임. 올바른 A_AE=25e3/105e6=2.38095e-4m². 좌변F_AE도A_AE로수정. 최종238mm²는맞음.
8. p14 Codex자체보충대로 절단법으로E모멘트식은성립; 오류단정철회. Claude의 절단위치BC,CF,CG설명은 해당E모멘트유도와 맞지않음. AB,AE,DE를절단한오른쪽전체구조에서E모멘트취하면0.9N_AB-15*1.2=0. B에서BF0,AB=BC20,C에서CG25 확정.
9. p10 BD101.6 CE-21.7MPa합의. 8*36=288; Pa지수10^8→10^7. 압축이면언제나총단면이라는일반화는피한다.
