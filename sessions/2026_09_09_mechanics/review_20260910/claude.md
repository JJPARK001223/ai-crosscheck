# 1. "N"의 의미 — 문서 안에서 두 가지로 쓰임

| 용법 | 나타나는 곳 | 의미 |
|---|---|---|
| **① 힘의 단위 뉴턴(Newton)** | `[N/m²]`, `70×10³ N`, `1 N/mm² = 1 MPa`, `1 kN = 1000 N` (p.1, p.6, p.8 등) | SI 힘 단위. 항상 숫자 뒤에 붙음. |
| **② 단면 내력(축방향 수직내력, internal normal/axial force)** | p.5의 정의 "P(외부하중), **N(단면내력)**", "축방향의 내력", 그리고 `σ = N/A`, `N_AB`, `N_BC`, `N_CG`, `N_AE` (p.5·6·8·14·15) | 어떤 단면을 잘랐을 때 그 단면을 가로질러 전달되는 **수직응력의 합력**. 자유물체 평형에서 그 단면 너머에 걸린 외력의 합과 같음. 인장(+)·압축(−). |

즉 `σ = N/A`에서 N은 "그 단면에 작용하는 축방향 내력"이고, 단위로서의 N(뉴턴)과는 다른 대상입니다. 문서에서 아래첨자(N_AB 등)가 붙거나 `σ=N/A` 안에 있으면 ②, 숫자 뒤에 있으면 ①로 읽으면 됩니다. p.5에서 저자가 "N (단면내력)"이라고 직접 정의해 두었습니다.

# 2. 페이지별 검토

## 개념 정리 (p.1 ~ p.4)

**p.1 (응력)**
- σ = P/A = F/A `[N/m²]`, 지압응력 σ_b = P/A = P/(t·d), 전단응력 τ_ave = F/A, 후크 법칙 σ = Eε, 응력–변형률 선도(탄성한계·항복점·극한응력·파단점, 기울기=E) — **개념·식 모두 정확**.
- 사소함: 선도에서 비례한도/탄성한계/항복점을 세밀히 구분하지 않고 뭉뚱그림(교육용 단순화, 오류 아님).

**p.2 (소성·피로·내력)**
- 소성(plasticity), 네킹(necking), 피로(fatigue: 항복점 미만 반복하중에서도 파괴) — **정확**.
- 외력·내력·반력 도식, ΣF_s = F_I (외력 합 = 내력) — 표현이 다소 느슨하지만 평형 개념으로 맞음.

**p.3 (평면응력·경사면 응력)** — ⚠️ **오류 1개**
- 평면응력 정의: 문구가 다소 엉켰으나("z축·y축에 평행" → 정확히는 "모든 응력성분이 x–y 평면 내에 있고 σ_z=τ_xz=τ_yz=0") 의도는 맞음.
- 식(1),(2): 경사 쐐기 요소의 평형식 — 표준 형태.
- 식(3): σ_x,θ = (σx+σy)/2 + (σx−σy)/2·cos2θ + τxy·sin2θ — **정확**.
- **식(4) 오류**: 노트는
  τ_xy,θ = −**(σx+σy)/2**·sin2θ + τxy·cos2θ 로 적었는데,
  올바른 식은 τ_x'y',θ = −**(σx−σy)/2**·sin2θ + τxy·cos2θ.
  분자가 (σx+σy)가 아니라 **(σx−σy)**여야 함. (p.4의 식(5)에는 (σx−σy)로 제대로 썼으므로, 식(4)만의 전사 실수로 보임.)

**p.4**
- 식(5): σ_y,θ = (σx+σy)/2 − (σx−σy)/2·cos2θ − τxy·sin2θ — **정확**.
- 응력 불변량 σ_x,θ + σ_y,θ = σx + σy — **정확**.

## 문제 풀이 (p.5 ~ p.16)

### p.5 — 문제 1.1: 봉 AB·BC의 최소 허용지름 d₁, d₂ ⚠️ **표기 불일치**
조건: AB(길이 300, 지름 d₁), σ_all=175 MPa; BC(길이 250, 지름 d₂), σ_all=150 MPa. B에서 40 kN, C에서 30 kN.

- N_BC = 30 kN, N_AB = 40+30 = **70 kN** 이어야 함.
- ⚠️ 노트 여백에 "N_AB = 40+30 = **110 kN**"으로 적고, 본문에도 "N = 110×10³ N"이라 씀 → **산술·표기 오류** (40+30=70). 게다가 실제 공식에는 70 kN을 대입함(분자 280,000 = 4×70,000).
- 재계산 (N_AB=70 kN):
  d₁ ≥ √(4·70 000 / (π·175)) = √(280 000/549.78) = √509.3 = **22.57 mm** ✓ (노트 값 일치. 단 중간에 "√500.55"로 잘못 적음 → 509.3이 맞고 결과는 22.57로 정상)
- 재계산 (N_BC=30 kN):
  d₂ ≥ √(4·30 000/(π·150)) = √(120 000/471.24) = √254.65 = **15.96 mm** ✓ (노트 15.95)
- **결론**: 최종답 d₁≈22.57 mm, d₂≈15.96 mm 는 N_AB=70 kN 기준으로 **정확**. 다만 여백의 "110 kN"은 오류.
- **불확실성**: 만약 원본 그림의 B점 하중이 "40 kN 양쪽(=80 kN)"으로 작용하는 칼라 하중이면 N_AB = 80+30 = 110 kN이 맞고, 그 경우 p.5의 d₁과 p.6의 σ_AB가 모두 과소평가됨. 그림 원본 확인 필요. (p.6에서 저자가 N_AB=70으로 명시하므로 70이 의도된 값으로 판단.)

### p.6 — 문제 1.2: d₁=50, d₂=30 → σ_AB, σ_BC (N_AB=70, N_BC=30)
- A_AB = π·50²/4 = **1963.5 mm²** (노트 1962.5, π≈3.14 사용)
- A_BC = π·30²/4 = **706.86 mm²** (노트 706.5)
- σ_AB = 70 000/1963.5 = **35.65 MPa** ✓
- σ_BC = 30 000/706.86 = **42.44 MPa** ✓
- 단위 관계(1 N/mm² = 1 MPa) 정확.
- 사소함: π=3.14로 계산해 약 0.05% 오차. 무시 가능.

### p.7 — 문제 1.3: σ_AB(인장) = 2·|σ_BC|(압축) 되는 P
- N_AB = P (인장), N_BC = P − 240 (0<P<240에서 압축, |N_BC| = 240−P) ✓
- A₂/A₁ = (75/50)² = 2.25 ✓
- P/A₁ = 2(240−P)/A₂ → P(A₂+2A₁) = 480 A₁ → P = 480/(A₂/A₁ + 2) = 480/(2.25+2) = 480/4.25 = **112.94 kN** ✓
- 비율만 쓰므로 π 오차 없음. **정확**.

### p.8 — 문제 1.4: P = 160 kN → σ_AB, σ_BC
- N_AB = 160 kN(인장), N_BC = 160 − 240 = −80 kN(압축) ✓
- σ_AB = 160 000/1962.5 = **81.5 MPa** ✓ (정확 π로 81.49)
- σ_BC = −80 000/4415.6 = **−18.12 MPa** ✓ (정확 π로 −18.11)
- **정확**.

### p.9 — 문제 1.5: 스페이서 바깥지름 d_o (볼트 d=16, σ_b=200, σ_s=130)
- 볼트·스페이서에 같은 힘 F. 가장 경제적 = 둘 다 허용응력.
- σ_s = F_max/A_s = σ_b·d_b²/(d_o² − d_i²), d_i = d_b = 16
- d_o = √(d_i² + (σ_b/σ_s)·d_b²) = √(256 + (200/130)·256) = √(256 + 393.85) = √649.85 = **25.49 mm** ✓
- 개념(볼트 축력 = 스페이서 축력, 스페이서는 내경=볼트경인 환형 단면) 타당. **정확**.

### p.10 — 문제 1.7: 링크 BD, CE의 최대 평균 수직응력
- 평형: A(0)에서 20 kN↑, B(0.25), C(0.65).
  ΣM_C: F_BD = −20·(0.65)/0.40 = **−32.5 kN** (링크 BD 인장, 32.5 kN)
  ΣM_B: F_CE = 20·(0.25)/0.40 = **12.5 kN** (링크 CE 압축)
  연직합 검산: −32.5 + 12.5 + 20 = 0 ✓
- 단면적: 인장재 BD는 핀구멍 제외 순단면 t(w−d) = 8·(36−16) = 160, ×2링크 = **320 mm²**
  압축재 CE는 총단면 t·w = 8·36 = **288 mm²**(노트에 "266"으로 오기), ×2링크 = **576 mm²** (576은 정확 = 2×288)
- σ_BD = 32 500/320 = **101.6 MPa** ✓
- σ_CE = −12 500/576 = **−21.7 MPa** ✓
- 인장은 순단면, 압축은 총단면을 쓰는 구분이 정확. **결과 정확** (8×36 오기만 사소).

### p.11 — 문제 1.8: 링크 DE(폭25×두께3), θ=0 및 θ=90° ⚠️ **모멘트 팔 뒤바뀜 + 미완성**
저자 표기 기하: E는 C에서 오른쪽 0.3 m, F는 C에서 오른쪽 0.4 m·아래 0.2 m, θ는 수평 기준.

- 노트의 식:
  ΣM_C: 0.3·F_DE + **0.4·(240 cosθ) + 0.2·(240 sinθ)** = 0
- **오류**: 수평력 성분(240 cosθ)의 모멘트 팔은 **연직거리 0.2 m**, 연직력 성분(240 sinθ)의 팔은 **수평거리 0.4 m**여야 함. 노트는 팔을 서로 바꿔 씀.
  검산(θ=0): 힘이 순수 수평 240 N, C에서 0.2 m 아래 → 모멘트는 240·0.2 = 48 N·m. 그런데 노트 식은 240·0.4 = 96 N·m를 줌 → 틀림.
- **올바른 식**: F_DE = −(0.2·240 cosθ + 0.4·240 sinθ)/0.3 = **−(160 cosθ + 320 sinθ) N**
  A_DE = 25·3 = 75 mm² = 75×10⁻⁶ m²
  - θ=0: F_DE = −160 N → σ_DE = −160/75×10⁻⁶ = **−2.13 MPa (압축)**
  - θ=90°: F_DE = −320 N → σ_DE = −320/75×10⁻⁶ = **−4.27 MPa (압축)**
- 노트대로면 (a)와 (b) 답이 서로 뒤바뀜.
- **또한 이 페이지는 미완성**: F_DE 식만 유도하고 실제 응력값 계산이 없음.
- **불확실성**: 기하(0.4/0.2 배치, θ 기준)를 저자 필기 문구로만 추론했음. 원본 그림 P1.8에서 F의 좌표가 "오른쪽 0.2·아래 0.4"라면 노트가 맞을 수 있음. 문구대로면 오류.

### p.12 — 문제 1.9: 링크 BD(중앙부 800 mm², σ=50 MPa) → 하중 P ⚠️ **기하 가정 불확실**
- F_BD = σ·A = 50 N/mm²·800 mm² = 40 000 N = **40 kN** ✓
- BD 길이 = √(0.56² + 1.92²) = √4.0 = **2.0 m** (노트에 "2 mm"로 오기)
- 방향코사인 (0.28, 0.96): 0.28²+0.96² = 1 ✓ (수평 0.56, 연직 1.92와 일관)
- ΣM_C: 저자는 F_BD의 **수평성분(0.28)과 연직성분(0.96) 모두에 모멘트 팔 1.4 m**를 곱해
  2.1·P = 1.4·(0.96+0.28)·40 = 1.736·40 = 69.44 → **P = 33.07 kN** (노트 "33.1 kN")
- **문제점**: 연직성분(0.96·F_BD)의 모멘트 팔은 C→B의 **수평거리 x_B**여야 함. 저자는 x_B = 1.4 m로 가정(= 하부 스트럿 CB가 45°, B가 C에서 수평·연직 모두 1.4 m). 그림의 바닥 치수 0.56 m와는 상충되어 보임.
  - x_B = 1.4 m가 실제 그림 좌표와 맞으면 P ≈ 33.1 kN 정답.
  - x_B ≠ 1.4 m이면 P 값이 달라짐. (효과적으로 저자의 1.736은 "C에서 직선 BD까지의 수직거리"인데, 이는 B의 실제 좌표에 의존.)
- **불확실성 큼** — 원본 그림 P1.11의 B 좌표(특히 C에서의 수평거리) 확인 필요.

## D. 불확실성 (원본 그림 없이는 확정 불가)

1. **p.5 vs p.6 — N_AB = 70 kN인가 110 kN인가.**
   두 페이지가 서로 다르게 다룸(여백은 110, 공식은 70). 그림 P1.1의 B점 하중이 단일 40 kN이면 N_AB=70(현재 최종답 유효), 칼라에 40 kN이 양쪽(80 kN)으로 작용하면 N_AB=110이고 p.5의 d₁(→약 28.3 mm)과 p.6의 σ_AB(→약 56 MPa)가 모두 틀림. **p.7~8의 유사 문제는 120 kN을 양쪽(240 kN)으로 처리하므로, 그림에 칼라 하중 관례가 있을 가능성 있음.** 원본 확인 권장.

2. **p.12 P1.9 — 점 B의 C 기준 수평거리.**
   저자는 x_B = 1.4 m로 가정(연직·수평 팔을 모두 1.4로 사용). 그림 바닥 치수 0.56 m와 상충되어 보임. x_B가 1.4 m가 아니면 P ≈ 33.1 kN이 바뀜. 기하 확인 필요.

3. **p.11 P1.8 — F와 E의 정확한 좌표 및 θ 기준.**
   위 오류 #3은 저자 필기 문구("오른쪽 0.4 m, 아래 0.2 m", θ는 수평 기준)를 근거로 판정. 원본 그림에서 좌표가 반대면 저자 식이 맞을 수 있음.

4. **p.14 트러스 내력 경로** (F_BC = 20 kN 가정, 다른 대각재의 전단 분담 여부) — 원본 그림 없이 완전검증 불가하나, σ_CG = 98.2 MPa는 표준 교재답과 일치.
