# DECISION — 손글씨 역학 풀이 17쪽 검토 (2026-09-10)

Claude·Codex 독립검토 후 상호검증. 원본 PNG 17쪽 + 확대본(detail-03, detail-11) 직접 대조.

## 1. "N"의 의미
- **힘의 단위 뉴턴**: `[N/m²]`, `70×10³ N`, `1 N/mm²=1 MPa`.
- **단면 축력(축방향 수직내력, normal/axial force)**: `σ = N/A`의 N, 그리고 N_AB·N_BC·N_CG·N_AE. 봉 축을 x로 잡으면 N = ∫_A σ_xx dA. 어떤 단면을 자를 때 그 단면을 가로질러 전달되는 수직응력의 합력이며, 절단체 평형으로 외력과 연결된다(구간마다 하중이 다르면 외력과 반드시 같지는 않음). 인장 +, 압축 −. p.5에서 저자가 "N(단면내력)"으로 직접 정의. "수직"은 *단면에 수직*이라는 뜻이지 화면 세로가 아니다.

## 2. 공통 결론 (양측 합의)
- 응력변환식 (3)(5) 및 σ_x'+σ_y'=σ_x+σ_y는 표준식과 일치. θ는 x축→경사면 법선 x'까지의 각. **단, 식(4)는 오류**(§4).
- 최종 수치답은 **대부분 정확**: p6·p7·p8·p9·p10·p12·p13·p14·p15·p16 (§5).
- p5: N_AB = 70 kN, N_BC = 30 kN (B 하중 화살표 1개, 모든 대입 280,000 = 4×70,000).
- p10: 인장링크는 순단면(320 mm²), 압축링크는 몸통 총단면(576 mm²) — 교재 이상화에 부합. "8×36=266"→288 오기, 지수 10⁸→10⁷ 오기(최종 −21.7 MPa는 정상).
- p11은 미완성(F_DE 식만 있고 최종 응력값 없음).

## 3. 충돌 및 판단 근거

**(a) p11 θ 기준 — Claude 지적 철회.**
Claude blind는 "θ가 수평 기준이면 모멘트 팔이 뒤바뀜"이라 했으나, detail-11 확인 결과 **θ는 하중과 아래쪽 수직선 사이의 각**이고 저자도 "수평 240 sinθ"로 명기. 따라서 연직성분 240 cosθ(팔 0.4 m), 수평성분 240 sinθ(팔 0.2 m)로 **저자 식이 옳다**:
F_DE = −(0.4·240 cosθ + 0.2·240 sinθ)/0.3 = −(320 cosθ + 160 sinθ) N.
→ 보완만 필요: **θ=0 → σ_DE = −320/75 = −4.27 MPa, θ=90° → −160/75 = −2.13 MPa (둘 다 압축)**.

**(b) p12 기하 — Claude 불확실성 해소.**
Codex가 확대 원본 확인: 원형부재 반경 r=1.4, 중심 O 기준 B는 오른쪽 1.4, C는 아래 1.4 → **C기준 B=(1.4, 1.4)**. 0.56 m는 B–D 수평차이지 C–B가 아님. 저자의 모멘트 팔 1.4 사용이 옳고 **P = 33.07 kN 확정**(A 높이 1.4+1.4 sin30°=2.1도 일치). "BD=2 mm"만 2 m로 정정.

**(c) p5 "110" 판독 — Claude 판독 기각.**
확대 시 "70"(굽은 7). p6도 동일 70, 모든 대입 일관, B 하중은 단일 40 kN. 하중 재해석 근거 없음 → d₁·d₂ 답 유효.

**(d) p1·p2 개념 — Codex 지적 수용.**
Claude가 "정확"이라 한 것을 정정: 응력은 "내부에 생기는 힘 자체"가 아니라 **단위면적당 내력의 강도**. p2에서 내력을 "원래 상태로 돌아가는 복원력"으로 한정한 것도 부정확(소성 중에도 내력 존재). 절단체 평형은 ΣF_ext + F_cut = 0 이며 모멘트 평형도 필요.

**(e) p14 유도 — Codex 자체 정정 수용.**
AB·AE·DE를 절단해 오른쪽을 취하면 AE·DE 작용선이 E를 지나 소거되므로 붉은 식 `0.9·N_AB − 15·1.2 = 0`(→ N_AB=20)은 **옳다**. B절점 BF=0 → N_BC=20, C절점 → N_CG=20/0.8=25 kN. (전체구조 A 수평반력 40 kN과 축력 AB 20 kN은 서로 다른 값 — 혼동 주의.)

## 4. 반드시 고칠 핵심 오류

| 위치 | 오류 | 수정 |
|---|---|---|
| **p3 식(4)** | τ_x'y',θ = −**(σx+σy)/2**·sin2θ + τxy cos2θ | 분자는 **(σx−σy)**: τ_x'y',θ = −(σx−σy)/2·sin2θ + τxy cos2θ. 검증: σx=σy, τxy=0 대입 시 모든 θ에서 전단 0이어야 하나 필기식은 −σx·sin2θ ≠ 0. (p4 식(5)는 (σx−σy)로 옳게 씀.) |
| **p11** | 최종 응력 미계산 | σ_DE = −4.27 MPa(θ=0), −2.13 MPa(θ=90°) 추가. 식·방법은 옳음. |
| **p13 개념** | "A가 힌지 → 반력 A_x=A_y=0" | ΣM_A=0은 **모멘트만** 0. 실제 A_y = 12 − 28.53 − 1.6 = **−18.13 kN**. (F_BE는 ΣM_A로 구했으므로 최종답 285 mm²엔 영향 없음.) |
| **p15 대입** | A_AE = N/σ 를 (105×10⁶)/(25×10³)로 분수 뒤집어 씀, 좌변도 F_AE로 오기 | A_AE = (25×10³ N)/(105×10⁶ Pa) = 2.381×10⁻⁴ m² = **238 mm²** (최종값은 옳게 적음). |
| **p13 단위** | "28.53 kN = 2853 N" | **28,530 N**. |

**기타 사소**(결과 영향 없음): p6·p8 π≈3.14 사용(≈0.05% 오차); p10 "8×36=266"→288, 10⁸→10⁷; p12 "2 mm"→"2 m"; p14 평형식 라벨(ΣF_E/ΣF_x) 부정확.
