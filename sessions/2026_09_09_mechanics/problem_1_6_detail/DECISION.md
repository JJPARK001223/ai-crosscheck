## 1. 공통 결론 (Claude = Codex, 독립 일치)

두 독립 유도가 식·수치·부호·물리 해석까지 전부 일치. **충돌 없음.**
`problem_set_01/DECISION.md` 의 확정 답과도 일치.

| 항목 | 값 |
|---|---|
| 비중량 | γ = ρg = 8470 × 9.81 = **83 090.7 N/m³** (dW = ρg·A·dy 에서 유도, 단위 N/m³) |
| 면적비 | k = (d_BC/d_AB)² = (10/15)² = **4/9** |
| BC 내부 응력 | σ_BC(x) = γ(L − x) — 단면적 소거, B 바로 아래에서 최대 = γb |
| AB 내부 응력 | σ_AB(x) = γ(a − x) + γkb — A에서 최대 = γ(a + kb) |
| B 응력비 | σ(BC쪽)/σ(AB쪽) = 1/k = 9/4 (내력 연속 γA_BC·b, 면적만 점프) |
| 전체 최대 | max{ γb, γ(a + kb) } (b = L − a) |
| 최적 길이 | **a\* = (1−k)L/(2−k) = 5L/14 = 250/7 ≈ 35.714 m**, b\* = 450/7 ≈ 64.286 m |
| 최소 최대응력 | **σ\* = γL/(2−k) = γ·450/7 = (83 090.7 × 450)/7 = 37 390 815/7 = 5 341 545 Pa = 5.341545 MPa → 5.34 MPa** |
| 발생 위치 | A 바로 아래 + B 바로 아래(BC쪽), 두 곳에서 같은 값 |
| 균일봉 대비 | 균일봉 상단 = γL = 8.309 MPa. 비 = 1/(2−k) = 9/14. 감소율 = 5/14 = **35.7% (≈ 36%)** |

## 2. 검증에서 정정된 사항 (최종 답 불변, 표현·정밀도만)

Codex 지적 전건 수용:

1. **B 극한 표기** — claude.md "σ_BC,max at B⁻" 는 "아래로 x 증가" 좌표와 불일치.
   → "B 바로 아래 (x = a, BC 쪽)" 로 표기.
2. **minimax 논거** — "증가·감소 함수의 max는 아래로 볼록" 일반화는 부정확.
   이 문제는 **두 일차함수** → max 가 V자형. 교점 좌·우에서 F′ = −γ / F′ = +γ(1−k) 로
   부호가 바뀌므로 교점이 유일 전역 최소. 허용구간 내 교점 존재는 0 < k < 1 에서 보장.
3. **g = 9.807 보조 수치 삭제** — claude.md 의 γ = 83 063, σ = 5.339 는 오산(정확값
   8470×9.807 = 83 065.29, σ = 5.3399 MPa). PROBLEM 이 g = 9.81 을 지정하므로 이 보조
   계산 자체를 HTML 에서 제거.
4. **k = 1 (지름 계단 없음)** — 이때 F(a) = γL 이 모든 a 에서 성립 → 최적해 비유일,
   a = 0 은 그중 하나. "개선 불가" 결론은 유효. "a = 0 만 최적" 이라는 인상 주지 않기.
5. **재료 안전성 표현 제거** — 합금 등급·항복강도 미제공.
   "탄성, 타당" / "B 위는 여유" / "두 위험점이 동시에 한계" → 각각
   "이 풀이만으로 항복·안전 판정 불가" / "B의 AB 쪽 평균응력은 최댓값보다 작다(kσ\* = 2.374 MPa)" /
   "두 후보가 같은 최댓값을 가진다" 로.
6. **"100 m 비현실적" 삭제** — 근거 없는 평가.
7. **수치 대입** — 64.286 과 64 + 0.2857 혼용·반올림 곱을 등호로 잇지 말고
   **450/7 을 끝까지 유지** → (83 090.7 × 450)/7 = 5 341 545 Pa 정확값 후 마지막에 반올림.
8. **균일봉 비교 전제 명시** — 같은 재료·같은 총길이·자중 조건. "같은 총질량" 최적화 아님.
9. **γ 주의** — 단위 길이당 하중은 γA [N/m]. γ 자체를 선하중으로 쓰지 말 것.
10. **출처** — Beer et al., *Mechanics of Materials*, 8th ed. (McGraw-Hill, 2020), Ch.1.
    γ = ρg 는 표준 정의(specific weight / weight density). "g = 9.81 = Beer 관례" 주장 대신
    "문제에서 g = 9.81 지정".
