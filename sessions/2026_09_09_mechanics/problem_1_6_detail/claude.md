## 0. 문제 정리

- 두 황동봉이 A(천장)에 매달림. 위 봉 AB(지름 d_A = 15 mm, 길이 a), 아래 봉 BC(지름 d_B = 10 mm, 길이 b).
- a + b = L = 100 m. 외부 하중 없음, **자중만**.
- ρ = 8470 kg/m³, g = 9.81 m/s².
- 구할 것: (a) 전체에서 최대 수직응력이 최소가 되는 a, (b) 그때의 최대 수직응력.

---

## 1. 비중량 γ = ρg — 어디서 나오는가

자중은 **체적력(body force)**: 봉의 모든 미소 요소가 중력을 받는다.

봉에서 길이 dy, 단면적 A 인 얇은 조각:
- 부피 dV = A dy
- 질량 dm = ρ dV = ρ A dy   (ρ = 밀도, kg/m³)
- 무게(중력) dW = dm·g = ρ g A dy   (g = 중력가속도, m/s²)

여기서 **비중량(specific weight, 단위중량) γ ≡ ρ g** 로 정의한다. 단위는

  γ = ρ g → [kg/m³]·[m/s²] = [kg·m/s²]/[m³] = [N/m³]

즉 γ = **단위 부피당 무게**. 그러면 dW = γ A dy 로 간단해진다.

수치:
  γ = 8470 × 9.81
    8470 × 9    = 76 230
    8470 × 0.81 = 6 860.7
    합          = 83 090.7 N/m³

---

## 2. 자중이 만드는 축내력 — 절단면 자유물체도

봉 전체는 A(위)에서 지지되고 C(아래)는 자유단. 중력은 모두 아래로 → 어느 수평 단면에서든
**윗부분이 아랫부분 전체 무게를 들고 있어야** 한다 → 전 구간 **인장**.

임의 단면의 내력 N = 그 단면 **아래에 매달린 전체 무게**.

좌표: A를 원점, 아래로 x 증가. 봉 AB는 0 ≤ x ≤ a, 봉 BC는 a ≤ x ≤ L.

### 2-1. 봉 BC 내부 (a ≤ x ≤ L)

단면 아래 = BC 중 길이 (L − x) 조각. 그 무게 = γ A_B (L − x).
절단면 평형(아래 조각): N_BC(x) − γ A_B (L − x) = 0
  → **N_BC(x) = γ A_B (L − x)**
  → σ_BC(x) = N_BC/A_B = **γ (L − x)**   ← 단면적이 소거됨!

- x = L (C, 자유단): σ = 0
- x = a (B 바로 아래, BC 최상단): **σ_BC,max = γ (L − a) = γ b**
- σ 는 위치에 대해 선형(삼각형 분포), **A_B 와 무관**.
  이유: 무게도 A_B 에 비례, 응력은 나누므로 상쇄.

### 2-2. 봉 AB 내부 (0 ≤ x ≤ a)

단면 아래 = AB 중 (a − x) 조각 + BC 전체.
  무게 = γ A_A (a − x) + γ A_B b
절단면 평형: N_AB(x) = γ A_A (a − x) + γ A_B b
  → σ_AB(x) = N_AB/A_A = γ (a − x) + γ (A_B/A_A) b

여기서 **면적비**

  k ≡ A_B / A_A = (π d_B²/4)/(π d_A²/4) = (d_B/d_A)² = (10/15)² = (2/3)² = **4/9**

  → σ_AB(x) = γ (a − x) + γ k b

- x = a (B 바로 위, AB 최하단): σ = γ k b
- x = 0 (A, 지지점): **σ_A ≡ σ_AB,max = γ (a + k b)**
- 역시 위치에 대해 선형, 기울기 −γ.

### 2-3. 접합부 B의 응력 불연속

내력 N 은 B에서 연속: N(B) = BC 전체 무게 = γ A_B b (양쪽 동일).
그러나 면적이 A_B → A_A 로 **커지므로**:
- B 아래(BC): σ = γ A_B b / A_B = γ b
- B 위(AB):   σ = γ A_B b / A_A = γ b · k = γ k b   (k < 1 → 더 작음)

응력이 B를 위로 지나며 γb → γkb 로 **떨어진다**(굵은 봉이 같은 힘을 더 넓은 면적으로 받음).
그 뒤 A로 갈수록 자기 무게가 더해져 다시 선형 증가.

### 2-4. 전체 최대 응력

각 봉에서 σ(x) 는 위로 갈수록 커지므로(기울기 −γ, x는 아래로 증가) 각 봉의 최댓값은 최상단:
- 봉 BC 최댓값: σ_BC,max = γ b  (at B⁻)
- 봉 AB 최댓값: σ_A = γ (a + k b)  (at A)

∴ 전체 최대 = **max{ γ b , γ (a + k b) }**

---

## 3. (a) 최댓값의 최소화

b = L − a 대입:
- g₁(a) ≡ σ_BC,max = γ (L − a)              — a 증가 시 **감소**
- g₂(a) ≡ σ_A = γ [a + k(L − a)] = γ [kL + (1 − k)a]  — a 증가 시 **증가** (1 − k = 5/9 > 0)

극단:
- a → 0: g₁ = γL, g₂ = γkL → max = γL
- a → L: g₁ = 0, g₂ = γL → max = γL

한쪽은 증가, 한쪽은 감소하는 두 함수의 **상측 포락선(max)**은 아래로 볼록하고,
**두 함수가 만나는 지점에서 최솟값**을 가진다(그 지점을 벗어나면 둘 중 커진 쪽이 포락선을 끌어올림).

교점 조건 g₁ = g₂:
  γ (L − a) = γ [kL + (1 − k)a]
  L − a = kL + (1 − k)a
  L − kL = a + (1 − k)a
  (1 − k)L = (2 − k)a
  → **a = (1 − k)/(2 − k) · L**

수치 (k = 4/9, L = 100 m):
  1 − k = 1 − 4/9 = 5/9
  2 − k = 2 − 4/9 = 14/9
  a = (5/9)/(14/9) · 100 = (5/14) · 100 = 500/14 = **250/7 = 35.714 m**
  b = L − a = 100 − 250/7 = 450/7 = **64.286 m**

---

## 4. (b) 그때의 최대 수직응력

최적점에서 두 후보가 같으므로 어느 쪽으로 계산해도 동일. 간단한 쪽:

  σ_max = γ b = γ · 450/7

닫힌형: σ_max = γ(L − a) = γ[L − (1−k)L/(2−k)] = γL · (2−k−1+k)/(2−k) = **γL/(2 − k)**
  = γ · 100/(14/9) = γ · 900/14 = γ · 450/7 = γ · 64.286 m   (일치)

수치:
  σ_max = 83 090.7 × 64.286
    83 090.7 × 64      = 5 317 805
    83 090.7 × 0.2857  = 23 739
    합                 ≈ 5.3415 × 10⁶ N/m²
  = **5.3415 × 10⁶ Pa = 5.3415 MPa → 5.34 MPa**

단위: [N/m³]·[m] = [N/m²] = [Pa]. 1 MPa = 10⁶ Pa.

교차검산 (AB 쪽):
  σ_A = γ(a + k b) = γ(250/7 + (4/9)(450/7)) = γ(250/7 + 200/7) = γ(450/7) = 5.3415 MPa ✓

---

## 5. 검산·해석

1. **차원** — γ[N/m³]×길이[m] = Pa ✓. a = (무차원)·L → m ✓.
2. **두 후보 일치** — 최적점에서 σ_BC,max = σ_A = 5.3415 MPa (설계상 두 위험점이 동시에 한계) ✓.
3. **B 위(굵은 봉)** — σ = γ k b = (4/9)(5.3415) = 2.374 MPa < 5.34 → B 위는 여유 있음 ✓.
4. **극한 대비** — 단일 균일봉(전부 한 지름)이면 상단 응력 = γL = 83 090.7 × 100 = 8.309 MPa.
   최적 설계는 이를 σ_max/γL = 1/(2−k) = 9/14 = 0.643 배, 즉 **8.31 → 5.34 MPa (36% 감소)**.
   지름 계단(k < 1)이 없으면(k = 1) a = 0, σ_max = γL 로 개선 불가 → **계단이 개선을 가능케 함**.
5. **크기 감각** — 황동 항복 ~ 수백 MPa. 5.34 MPa 는 훨씬 아래 → 탄성, 타당 ✓.
   (100 m 길이는 비현실적이지만 교재의 개념 문제.)
6. **g = 9.81 vs 9.807** — γ = 83 063, σ_max = 5.339 MPa. 유효숫자 3자리에서 5.34 MPa 동일.

---

## 답

- **(a)** a = 250/7 ≈ **35.7 m** (b = 450/7 ≈ 64.3 m)
- **(b)** σ_max = γ·450/7 ≈ **5.34 MPa** (인장), A점과 B점(BC쪽)에서 동시에 발생
