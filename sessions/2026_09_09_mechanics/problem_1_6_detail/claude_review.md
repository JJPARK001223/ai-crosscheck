## Codex 가 추가로 지적한 것 (수용)

1. **"36% 감소" 는 정수 반올림** — 정확히는 5/14 = 35.714%. HTML 에 "약 36% (정확히 5/14 ≈ 35.7%)" 로 표기.
2. **균일봉 비교의 전제** — 같은 재료·같은 총길이의 균일봉과 비교이며, "같은 질량" 최적화가 아님. 캡션에 명시.
3. **γ 를 단위 길이당 하중으로 쓰면 안 됨** — 단위 길이당 하중은 γA [N/m]. 좋은 주의사항, HTML 에 반영.
4. Codex 는 N_B ≈ 419.52 N, N_A ≈ 943.93 N 등 절대 내력값도 제시(검산용). 참고로 수록 가능.
