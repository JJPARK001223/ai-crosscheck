# 연습문제 1.6 — Codex blind 독립 상세 유도

## 1. 입력, 좌표 및 해석 범위

입력 출처: 같은 폴더의 `PROBLEM.md`(프로젝트 제공 문제, 2026-09-09; 원 교재 저자·판본·연도는 제공되지 않음). 아래 결과는 그 입력과 정적 평형으로 직접 유도하고 .NET System.Double 배정밀도 연산으로 검산했다. 외부 자료나 Claude의 풀이를 사용하지 않았다.

A에서 지지되는 수직 봉의 위쪽 AB는 지름 15 mm, 길이 a이고, 아래쪽 BC는 지름 10 mm, 길이 b이다. C는 자유단이다.

- 총길이: L = a + b = 100 m.
- 두 봉의 밀도: ρ = 8470 kg/m³.
- 중력가속도: g = 9.81 m/s².
- 좌표 x는 A에서 아래쪽으로 측정한다. A: x=0, B: x=a, C: x=L.
- 인장 축내력 N 및 인장 수직응력 σ를 양으로 정한다.

여기서 응력은 일차원 봉 이론의 단면 평균 축응력 σ=N/A이다. 접합부의 상세 형상이 주어지지 않았으므로 삼차원 국부 응력집중을 계산하는 문제는 아니다. 길이와 단면적은 주어진 형상을 기준으로 사용한다.

## 2. 비중량 γ는 어떻게 나오는가?

봉에서 두께 dy, 단면적 A인 미소요소를 취한다. 체적, 질량, 중량을 차례로 쓰면

    dV = A dy
    dm = ρ dV = ρ A dy
    dW = g dm = ρ g A dy.

따라서 단위 체적당 중량인 비중량(specific weight)을

    γ ≡ dW/dV = ρg

로 정의하면 dW = γ A dy가 된다. 밀도 ρ는 단위 체적당 질량, 비중량 γ는 단위 체적당 중량(중력에 의한 힘)이다.

단위는

    [γ] = (kg/m³)(m/s²)
        = (kg·m/s²)/m³
        = N/m³.

수치의 곱셈을 풀어 쓰면

    γ = (8470 kg/m³)(9.81 m/s²)
      = 8470 × (9 + 0.8 + 0.01) N/m³
      = (76230 + 6776 + 84.7) N/m³
      = 83090.7 N/m³.

단위 길이당 중량은 γA [N/m]이고, 길이 dy를 곱해야 실제 힘 dW [N]가 된다. γ 자체를 단위 길이당 하중으로 쓰면 안 된다.

## 3. 원형 단면적과 면적비 k

원형 단면에서 A=πd²/4이므로

    d_AB = 15 mm = 0.015 m
    A_AB = π(0.015 m)²/4
         = π(0.000225 m²)/4
         = 0.00017671458676442585 m².

    d_BC = 10 mm = 0.010 m
    A_BC = π(0.010 m)²/4
         = π(0.000100 m²)/4
         = 0.000078539816339744827 m².

아래 봉의 면적을 위 봉의 면적으로 나눈 비를 k라 두면

    k ≡ A_BC/A_AB
      = [πd_BC²/4]/[πd_AB²/4]
      = (d_BC/d_AB)²
      = (10 mm / 15 mm)²
      = (2/3)² = 4/9.

k는 무차원이다. 지름비 2/3이 아니라 면적비 4/9을 사용해야 한다.

## 4. 절단면 자유물체도에서 축내력 유도

어떤 위치에서 봉을 자른 뒤 절단면 아래의 부분만 떼어 낸다. 아래 부분의 중량은 아래로 작용하며, 나머지 위쪽 봉이 절단면에 가하는 인장력 N(x)는 위로 작용한다. 정적 평형에 의해 절단면 축내력은 그 아래 매달린 전체 중량과 같다.

### 4.1 BC 내부: a < x < L

절단면 아래에는 길이 L−x인 BC만 남는다.

```text
절단면 x       ↑ N_BC(x)
               │
               │ BC의 남은 길이 L−x
               ↓ 분포 자중 dW = γ A_BC dy
자유단 C       (추가 끝단 하중 없음)
```

아래 방향을 힘의 양의 방향으로 쓰면

    ΣF_y = 0: −N_BC(x) + ∫[x,L] γ A_BC dy = 0
    N_BC(x) = γ A_BC (L−x).

응력은 이 힘을 해당 절단면의 면적으로 나눈 값이다.

    σ_BC(x) = N_BC(x)/A_BC
            = γ A_BC (L−x)/A_BC
            = γ(L−x).

같은 A_BC가 중량과 하중을 지탱하는 면적에 동시에 들어가므로 소거된다. 이는 같은 밀도·일정 단면인 자기 아래 봉의 자중을 지탱하기 때문이다. 다른 면적의 봉까지 매달린 경우에는 그 면적비가 남는다.

    dσ_BC/dx = −γ < 0.

따라서 BC에서는 아래로 갈수록 응력이 선형으로 감소한다. 자유단에서 σ_BC(L)=0이며, 최대는 B 바로 아래에서

    σ_BC,max = σ(a⁺) = γ(L−a) = γb.

### 4.2 AB 내부: 0 < x < a

절단면 아래에는 길이 a−x의 AB와 길이 b의 BC 전체가 남는다.

```text
절단면 x       ↑ N_AB(x)
               │ AB의 남은 길이 a−x, 면적 A_AB
               ↓ 중량 γ A_AB(a−x)
접합부 B       │
               │ BC 전체 길이 b, 면적 A_BC
               ↓ 중량 γ A_BC b
자유단 C
```

B에서 두 부분이 서로 주고받는 힘은 이 자유물체 전체의 내부력이므로 전체 평형식에 별도 외력으로 더하지 않는다.

    ΣF_y = 0:
    −N_AB(x) + ∫[x,a] γ A_AB dy + ∫[a,L] γ A_BC dy = 0.

따라서

    N_AB(x) = γ A_AB(a−x) + γ A_BC b
    σ_AB(x) = N_AB(x)/A_AB
            = γ(a−x) + γ(A_BC/A_AB)b
            = γ(a−x) + γkb.

첫 항은 절단면 아래 AB 자체의 중량으로 인한 응력, 둘째 항은 BC 전체 중량으로 인한 응력이다.

    dσ_AB/dx = −γ < 0.

따라서 AB의 최대응력은 A 바로 아래에서

    σ_AB,max = σ(0⁺) = γ(a+kb).

지지 반력도 전체 중량과 같아서 R_A=N_AB(0)=γ(A_AB a+A_BC b)이다.

## 5. 접합부 B에서 내력은 연속인데 응력은 왜 불연속인가?

B에 별도의 집중 외력이나 집중 질량이 없으므로, B를 감싼 무한히 짧은 요소의 평형에서 양쪽 축내력은 같다.

    N(a⁻) = γ A_BC b = N(a⁺).

그러나 절단면적은 위쪽 A_AB에서 아래쪽 A_BC로 작아진다.

    σ(a⁻) = N_B/A_AB = γkb
    σ(a⁺) = N_B/A_BC = γb.

b>0이면

    σ(a⁺)/σ(a⁻) = A_AB/A_BC = 1/k = 9/4,
    σ(a⁺)−σ(a⁻) = γ(1−k)b > 0.

즉, 같은 힘을 작은 면적으로 지탱하는 BC 쪽의 평균응력이 더 크다. 응력의 점프가 내력의 점프나 평형 위반을 뜻하지 않는다. 이 값들은 일차원 모델에서 B 양측 단면의 극한값이다.

## 6. 전체 최대응력을 최소화하는 길이

각 구간에서 응력이 아래로 갈수록 감소하므로 검토할 최대 후보는 BC 상단과 AB 상단 두 곳뿐이다.

    σ_max(a) = max{γb, γ(a+kb)}
             = γ max{L−a, a+k(L−a)}
             = γ max{L−a, kL+(1−k)a}.

γ>0은 상수이므로 다음 두 유효 길이의 최댓값을 최소화하면 된다.

    f(a) = L−a                  (기울기 −1: 감소)
    h(a) = kL+(1−k)a             (기울기 1−k=5/9: 증가).

두 응력을 같게 놓는 것은 단순한 가정이 아니라 다음 단조성으로 증명된다.

    f(a)−h(a) = (1−k)L−(2−k)a.

교점 a*보다 왼쪽에서는 f>h이므로 최대값이 f이고, a를 늘리면 최대값이 감소한다. 교점 오른쪽에서는 h>f이므로 최대값이 h이고, a를 늘리면 최대값이 증가한다. 따라서 교점에서 유일한 최소값을 갖는다. 0<k<1이므로 교점은 0<a*<L에 있어 실제 두 봉의 길이가 모두 양수이다.

교점 방정식을 한 단계씩 정리하면

    L−a = a+k(L−a)
    L−a = a+kL−ka
    L−kL = 2a−ka
    (1−k)L = (2−k)a
    a* = (1−k)L/(2−k).

k=4/9를 대입하면

    1−k = 1−4/9 = 5/9
    2−k = 2−4/9 = 14/9
    a* = [(5/9)/(14/9)]L
       = (5/14)L
       = (5/14)(100 m)
       = 500/14 m = 250/7 m
       ≈ 35.714285714285715 m.

이에 따라

    b* = L−a* = 100 m−250/7 m
       = (700−250)/7 m
       = 450/7 m ≈ 64.285714285714286 m.

## 7. 최소 최대응력의 수치 대입

교점에서

    b* = L−[(1−k)/(2−k)]L
       = [(2−k−1+k)/(2−k)]L
       = L/(2−k).

따라서 최소화된 전체 최대응력은

    σ_max,min = γL/(2−k)
              = (83090.7 N/m³)(100 m)/(14/9)
              = (8309070 N/m²)(9/14)
              = (74781630/14) N/m²
              = 5341545 N/m².

동일한 값을 b*로 직접 계산하면

    σ_max,min = γ(450/7 m)
              = (83090.7 N/m³)(450/7 m)
              = [(83090.7 × 450)/7] N/m²
              = (37390815/7) N/m²
              = 5341545 Pa
              = (5341545/1000000) MPa
              = 5.341545 MPa
              ≈ 5.3415 MPa
              ≈ 5.34 MPa.

마지막 값은 소수 둘째 자리(유효숫자 3자리)로 반올림했다. 최적 설계에서는 A 바로 아래와 B 바로 아래 두 곳에서 이 최대응력이 동시에 나타난다.

## 8. 배정밀도 직접 계산 및 검산

### 8.1 실행 방법과 중간 산술값

PowerShell의 .NET System.Double(IEEE 754 binary64)로 직접 계산했다. 재현 코드는 다음과 같다. 중간값을 반올림해서 다음 연산에 넣지 않았다.

```powershell
[double]$rho = 8470
[double]$g = 9.81
[double]$L = 100
$gamma = $rho * $g
$A1 = [math]::PI * [math]::Pow(0.015, 2) / 4
$A2 = [math]::PI * [math]::Pow(0.010, 2) / 4
$k = [math]::Pow(10.0 / 15.0, 2)
$a = (1 - $k) * $L / (2 - $k)
$b = $L - $a
$sBC = $gamma * $b
$sAB = $gamma * ($a + $k * $b)
$sMPa = $sBC / 1e6
$uniform = $gamma * $L
$reduction = (1 - $b / $L) * 100
```

| (10/15)² | 0.44444444444444442 | 무차원 |

| 2−k | 1.5555555555555556 | 무차원 |

십진 소수와 분수 중 상당수는 이진 부동소수점으로 정확하게 표현할 수 없어 위 표의 마지막 자릿수에는 반올림 오차가 있다. 주어진 입력값의 대수적 계산 결과 5341545 Pa와 실행값의 차이는 약 9.31×10⁻¹⁰ Pa이며, 최종 5.34 MPa에는 영향을 주지 않는다.

### 8.2 차원 검산

    dW: (N/m³)(m²)(m) = N
    N(x): γAℓ → (N/m³)(m²)(m) = N
    σ(x): γℓ → (N/m³)(m) = N/m² = Pa
    a*: [(무차원)/(무차원)]L → m.

모든 식의 차원이 일치한다.

### 8.3 두 최대 후보 및 접합부 검산

분수 형태로 두 후보의 유효 길이를 비교하면

    a*+kb* = 250/7 m + (4/9)(450/7 m)
            = 250/7 m + 200/7 m
            = 450/7 m = b*.

따라서 두 후보는 정확히 같은 5341545 Pa이다. B 위쪽에서는

    σ(a⁻) = γkb* = (4/9)(5341545 Pa)
           = 2374020 Pa = 2.37402 MPa,

B 아래쪽에서는 5.341545 MPa이다. 직접 계산한 내력은

    N_B = γA_BC b* ≈ 419.52396327048217 N
    N_A = γ(A_AB a*+A_BC b*) ≈ 943.92891735858507 N.

N_B를 각각 A_AB와 A_BC로 나누면 위의 서로 다른 B 양측 응력이 나온다. N_A/A_AB는 5.341545 MPa이다. C에서는 N=σ=0이므로 자유단 경계조건도 만족한다.

### 8.4 균일봉 대비 감소율

같은 밀도와 길이를 가진 일정 단면의 수직 균일봉은 상단에서 자기 전체 중량을 지탱한다.

    σ_uniform,max = γAL/A = γL
                  = (83090.7 N/m³)(100 m)
                  = 8309070 Pa
                  = 8.30907 MPa ≈ 8.309 MPa.

반올림 전 값을 사용한 비율은

    σ_max,min/σ_uniform,max
      = [γL/(2−k)]/(γL)
      = 1/(2−k) = 9/14
      ≈ 0.6428571428571429.

따라서 감소율은

    (1−9/14) × 100%
      = (5/14) × 100%
      = 35.7142857142857…%
      ≈ 36%.

“36% 감소”는 정수 백분율로 반올림한 표현이며 정확히 36%는 아니다. 이 비교는 같은 재료·총길이의 균일봉과의 자중 최대응력 비교이며, 동일 질량 조건을 추가한 최적화는 아니다.

## 9. 독립 계산의 답

- AB의 최적 길이: **a = 250/7 m ≈ 35.714 m**.
- BC의 길이: **b = 450/7 m ≈ 64.286 m**.
- 최소화된 전체 최대 평균 축응력: **5.341545 MPa ≈ 5.3415 MPa → 5.34 MPa (인장)**.
- 최대응력 위치: **A 바로 아래 및 B 바로 아래**.
- 균일봉의 8.30907 MPa 대비 **약 35.714%, 정수 반올림으로 약 36% 감소**.
