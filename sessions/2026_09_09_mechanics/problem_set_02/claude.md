# Claude blind 상세 유도 — 비어 8판 1장 1.7 ~ 1.14

부호 규약: 인장(+), 압축(−). 평균 수직응력 σ = N/A (N = 축방향 내력, A = 단면적).
모멘트 CCW(+). 도면 치수는 mm → m 환산.

## 1.7 — 네 개의 수직 링크

### FBD (수평 강체봉 ABC)
- A(왼쪽 끝): 20 kN ↑
- B: 링크 BD 힘 (연직)
- C: 링크 CE 힘 (연직)
- A→B = 0.25, B→C = 0.4 (도면 비율; 5 : 8)

a = A→B, b = B→C. 좌표 A(0), B(a), C(a+b).

### 평형
ΣM_C = 0: −20(a+b) − b·F_BD = 0
  → F_BD(봉에 작용) = −20(a+b)/b
  a : b = 25 : 40 → (a+b)/b = 65/40 = 13/8
  → F_BD = −20 · 13/8 = **−32.5 kN** (봉에 아래로) → 링크 BD **인장 32.5 kN**

ΣM_B = 0: −20a + b·F_CE = 0 → F_CE = 20a/b = 20 · 25/40 = **+12.5 kN** (봉에 위로) → 링크 CE **압축 12.5 kN**

검산 ΣF_y: +20 − 32.5 + 12.5 = 0 ✓

### 응력
링크 단면: 8 × 36 mm, 핀 지름 16 mm. 각 위치에 평행 링크 2개.

(a) 링크 BD (인장): 핀 구멍이 단면을 깎음 → **순단면적**
  A_net(1개) = 8·(36 − 16) = 160 mm²,  2개 → 320 mm² = 320×10⁻⁶ m²
  σ_BD = 32.5×10³ / 320×10⁻⁶ = 1.015625×10⁸ = **+101.6 MPa (인장)**

(b) 링크 CE (압축): 핀이 구멍을 메워 지압 → **총단면적**
  A_gross(1개) = 8·36 = 288 mm²,  2개 → 576 mm² = 576×10⁻⁶ m²
  σ_CE = −12.5×10³ / 576×10⁻⁶ = −2.170×10⁷ = **−21.7 MPa (압축)**

기준값 일치 ✓

## 1.8 — 링크 DE (θ = 0, 90°)

### 기하 (부재 CEF, C에서 핀)
C를 원점. E는 C에서 오른쪽 0.3 m (링크 DE 연직, D가 위 고정).
하중 240 N은 C에서 (0.4, −0.2) 위치, 연직에서 각 θ.
성분: 수평 240 sinθ, 연직(아래) 240 cosθ.

### 평형
ΣM_C = 0 :  0.3·F_DE + 0.4·(240 cosθ) + 0.2·(240 sinθ) = 0
  → F_DE = −(0.4·240 cosθ + 0.2·240 sinθ)/0.3 = −(96 cosθ + 48 sinθ)/0.3
  → **F_DE = −(320 cosθ + 160 sinθ) N**  (부호 − → 압축)

### 응력
A_DE = 25 mm · 3 mm = 75 mm² = 75×10⁻⁶ m²

(a) θ = 0: F_DE = −320 N → σ_DE = −320/75×10⁻⁶ = −4.267×10⁶ = **−4.27 MPa**
(b) θ = 90°: F_DE = −160 N → σ_DE = −160/75×10⁻⁶ = −2.133×10⁶ = **−2.13 MPa**

기준값 일치 ✓
(주: 도면 부호 규약에 따라 F_DE 식의 sinθ·cosθ 부호가 달라질 수 있으나 θ=0,90°의 크기·압축 성격은 동일. Codex 확인 요망.)

## 1.9 — 곡선 브래킷, 링크 BD

### 내력 (목표 응력에서 역산)
F_BD = σ · A = (50×10⁶)(800×10⁻⁶) = **40×10³ N = 40 kN (링크 인장)**

### 기하
링크 BD: 수평 0.56, 연직 1.92 → 길이 √(0.56² + 1.92²) = √(0.3136 + 3.6864) = √4.0 = **2.00 m**
성분비: 수평 0.56/2.00 = 0.28, 연직 1.92/2.00 = 0.96
B는 핀 C에서 수평 1.4 m·연직 1.4 m (두 성분의 모멘트 팔 모두 1.4 m).
P는 A에서 30°, C에 대한 모멘트 팔 = 0.7 + 1.4 = 2.1 m.

### 평형 (자유물체 브래킷 AC, C에서 핀)
ΣM_C = 0 :
  (0.28·F_BD)(1.4) + (0.96·F_BD)(1.4) − P(2.1) = 0
  (0.28)(40000)(1.4) + (0.96)(40000)(1.4) = 2.1 P
  15680 + 53760 = 69440 = 2.1 P
  → P = 33 067 N ≈ **33.1 kN**

기준값 일치 ✓

## 1.10 — 세 개의 힘, 봉 BE (참고 풀이집 없음 — 신규 풀이)

### 도면 해석
- 수평 봉 ABCD, A는 벽 핀지지.
- B에서 연직 봉 BE가 위 고정점 E로. BE는 2력 부재 (연직력).
- 세 하중 각 P = 4 kN ↓, C를 중심으로 0.100 m 간격 → C−0.1, C, C+0.1.
- A→B = 0.150, B→C = 0.300, C→D = 0.250 (m). A 기준: B = 0.150, C = 0.450, D = 0.700.
- 하중 위치(A 기준): 0.350, 0.450, 0.550 m.

### 평형 (자유물체 봉 ABCD)
ΣM_A = 0 :  F_BE·(0.150) − 4·(0.350) − 4·(0.450) − 4·(0.550) = 0
  F_BE·0.150 = 4·(0.350 + 0.450 + 0.550) = 4·1.350 = 5.400 kN·m
  → F_BE = 36 kN (인장, +100 MPa 부호와 일치)

### 단면적
σ = F/A → A_BE = F_BE / σ = 36×10³ / 100×10⁶ = 3.60×10⁻⁴ m² = **360 mm²**

(검증 요망: 세 하중이 정확히 C 중심 대칭인지. 답이 정수(360)로 떨어지는 것은 해석이 옳을 가능성 시사.)

## 1.11 — 강체봉 EFG + 트러스, 부재 CG

### 기하
벽 핀 A(0, 0.9), D(0, 0). 하단 강체봉 E(1.2, 0), F(2.4, 0), G(3.6, 0). 상단 B(1.2, 0.9), C(2.4, 0.9).
대각재 AE: A(0,0.9)→E(1.2,0), 길이 √(1.2²+0.9²) = 1.5. 연직성분비 0.9/1.5 = 0.6.
대각재 CG: C(2.4,0.9)→G(3.6,0), 길이 1.5, 연직성분비 0.6.
하중 15 kN ↓ at F.

### 1단계 — 단면법 (F를 포함하는 우측 절단)
AB(상현), AE(대각), DE(하현 수평)을 절단. 우측(B,C,E,F,G + 강체봉 + 15 kN)을 자유물체.
연직 평형: 절단면에서 연직성분을 갖는 부재는 AE뿐.
  ΣF_y = 0 : 0.6·F_AE − 15 = 0 → **F_AE = 25 kN (인장)**

### 2단계 — 강체봉 EFG, F에 대한 모멘트
F에서 15 kN 하중은 모멘트 0. 수평 하현력(DE)의 작용선은 y=0 → F에 대한 팔 0.
남는 것: E에서 AE의 연직성분 (0.6·F_AE = 15 kN ↑), G에서 CG의 연직성분 (0.6·F_CG ↑).
  EF = FG = 1.2 m.
  ΣM_F = 0 : (0.6·F_AE)(1.2) − (0.6·F_CG)(1.2) = 0 → **F_CG = F_AE = 25 kN (인장)**

### 응력
A_CG = (π/4)(0.018)² = (π/4)(3.24×10⁻⁴) = 2.5447×10⁻⁴ m²
σ_CG = 25×10³ / 2.5447×10⁻⁴ = 9.824×10⁷ = **+98.3 MPa (인장)**

기준값 일치 ✓
(주: 트러스 대각재 배치를 정확히 확정하려면 도면 필요. 단, 단면법+ΣM_F 논리로 F_CG = F_AE = 25 kN는 견고. Codex 검증 요망.)

## 1.12 — 같은 구조, 부재 AE 단면적

1단계에서 F_AE = 25 kN (1.11과 동일).
목표 σ = 105 MPa.
  A_AE = F_AE / σ = 25×10³ / 105×10⁶ = 2.381×10⁻⁴ m² = **238 mm²** (≈ 238.1 mm²)

기준값 일치 ✓

## 1.13 — 비행기 견인봉, 봉 CD

### 1단계 — 전체 견인봉 자유물체
자중 W = m·g = 200 · 9.81 = **1962 N** (무게중심 G, 힌지 A에서 1150 mm)
지면 반력 R (바퀴, A에서 850 mm).
  ΣM_A = 0 : 850·R − 1150·(1962) = 0
  → R = 1150·1962 / 850 = 2 256 300 / 850 = **2654.5 N**

### 2단계 — 팔·휠 장치 DEF 자유물체 (E에서 핀)
CD(유압 로드)의 각도: tan α = 100/675 → α = arctan(0.14815) = **8.43°**
  ΣM_E = 0 : (F_CD cos α)(550) − R·(500) = 0
  → F_CD = R·500 / (550 cos α) = 2654.5·500 / (550·0.98921)
         = 1 327 250 / 544.06 = **2439.4 N** (압축 — 로드가 장치를 밀어 지지)

### 응력
A_CD = (π/4)(0.025)² = π·(0.0125)² = 4.9087×10⁻⁴ m²
σ_CD = −2439.4 / 4.9087×10⁻⁴ = −4.969×10⁶ = **−4.97 MPa (압축)**

기준값 일치 ✓

## 1.14 — 1500 N·m 우력, 피스톤 로드 BC

### 1단계 — 피스톤+로드+크랭크 전체 자유물체
실린더 벽 수평반력 H (피스톤에 작용), A에서 연직거리 200 + 80 = 280 mm.
크랭크핀 A에 우력 M = 1500 N·m.
  ΣM_A = 0 : (0.280)·H − 1500 = 0 → **H = 5357.1 N**

### 2단계 — 피스톤만 자유물체
연결봉 BC는 2력 부재 → 힘 F_BC는 BC 방향.
BC 기하: 연직 200 mm, 수평 60 mm → 길이 ℓ = √(200² + 60²) = √(40000 + 3600) = √43600 = **208.81 mm**
힘 삼각형 (P ↓, H →, F_BC 사선):
  P / H = 200 / 60 → P = 5357.1 · 200/60 = **17 857 N ≈ 17.86 kN**  … (a)
  F_BC / H = 208.81 / 60 → F_BC = 5357.1 · 3.4802 = **18 644 N** (압축)

### 응력
A_BC = 450 mm² = 450×10⁻⁶ m²
σ_BC = −18 644 / 450×10⁻⁶ = −4.143×10⁷ = **−41.4 MPa (압축)**  … (b)

기준값 일치 ✓
