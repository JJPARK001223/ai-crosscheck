## 수정·확정 3건 (Codex 지적 → Claude 도면 확인 → 양측 승인)

### 1.9 — 링크 BD는 **압축**, P는 수평 우향
- 도면 확대: P 화살표 수평 오른쪽. `30°`는 원호 중심 O–A 반지름과 수평선의 각(P 경사각 아님).
- 핀 C는 O에서 연직 아래 1.4 m → C 기준 B = (1.4, 1.4) m, A는 C보다 2.10 m 위.
  이 기하에서 참고 풀이집의 `P(0.7+1.4)`·`F_BD 두 성분 모두 팔 1.4`가 정확히 재현.
- ΣM_C: −2.10 P − 1.736 N_BD = 0. P 우향(+) → N_BD < 0 (압축).
- |N_BD| = |σ|·A = 50 MPa × 800 mm² = 40 kN → **P = 1.736×40/2.10 = 33.07 kN ≈ 33.1 kN** (참고값 일치).
- Claude blind는 P를 30° 경사로 오독해 인장으로 판정 → 정정. 크기 P는 동일.

### 1.10 — D = 롤러, C = 내부 힌지 → **A_BE = 285 mm²**
- 도면 확대: A 벽핀, E 천장핀(봉 BE), **C 봉 중간 핀(내부 힌지)**, **D 바닥 롤러**(작은 원들).
- 한 개 강체봉으로 보면 반력 4 > 식 3 → 1차 부정정. C 내부 힌지로 정정.
- 세 하중 x = 0.350 / 0.450 / 0.550 m (가운데가 C 바로 위, 간격 0.100 m).
- CD 구간 ΣM_C: D_y(0.250) − 4(0.100) = 0 → D_y = 1.60 kN.
- 전체 ΣM_A: F_BE(0.150) + 1.60(0.700) − 4(1.350) = 0 → F_BE = 4.280/0.150 = **28.53 kN (인장)**.
- A_BE = 28 533 / 100 = **285 mm²** (285.3).
- Claude blind(36 kN, 360 mm²)는 롤러·힌지 누락 오류 → 정정. 참고 풀이집에 없는 문제.

### 1.11 — σ_CG = **98.2 MPa** (일부 답지 98.3은 면적 반올림)
- N_CG = N_AE = 25 kN (양측 단면법 일치).
- A_CG = (π/4)(18)² = 81π = 254.469 mm².
- σ_CG = 25 000 / 254.469 = 98.244 MPa → 3자리 **98.2 MPa**.
- 답지의 98.3은 A ≈ 254.4로 자른 값. 81π의 정상 반올림은 254.5. 원자료 오차 과정은 미확인(각주로만).
