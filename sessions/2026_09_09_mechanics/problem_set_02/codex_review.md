# Codex 교차검증 — Claude 풀이 및 수정 검토

검증일: 2026-09-09. 대상: 같은 폴더의 `claude.md`, `claude_review.md`, `codex.md`, `PROBLEM.md`.

## 판정 및 범위

요청된 세 수정(1.9 BD 압축, 1.10 면적 285 mm², 1.11 응력 98.2 MPa)에 동의한다. 나머지 다섯 문제의 최종 수치에도 실질적 이견이 없다. 다만 **최종 수치의 합의와 상세 유도의 정확성은 구별해야 한다.** 기존 Claude 본문의 방향·부호·설명에는 아래 수정이 필요하다.

이번 검증은 문서 대조 및 JavaScript `Number`(IEEE 754 binary64, 배정밀도)로 수행한 독립 재계산이다. 원 PDF를 이번에 다시 열지는 않았다. 도면 관련 판단은 원문을 직접 확인한 기존 `codex.md`의 좌표·부재 배치 기록과 대조했다. 특히 1.10은 사용자가 지정한 D 롤러·C 내부 힌지 및 세 하중 위치를 전제로 계산한다.

자료 출처: Beer 등, 『고체역학』 8판, 1장 pp.22–23, 그림 P1.7–P1.14, 사용자 제공 `J:/Desktop/문제풀이/연습문제2.pdf`(발췌본 발행연도 미확인). 비교 답은 `PROBLEM.md`에 전재된 값이며, 그 문서는 Dean Updike, McGraw-Hill, 2009 풀이집으로 출처를 소개한다. 해당 풀이집 원본 및 오차 발생 과정은 이번에 직접 확인하지 않았다. 아래 수치는 주어진 기하에 대한 평형식의 직접 실행 결과이다.

## 1.10 — 배정밀도 재검산: 승인

단위는 힘 kN, 거리 m. 위쪽 힘과 반시계 모멘트를 양수로 둔다. BE의 인장 축력 N_BE는 B에 위쪽으로 작용한다.

```text
x_B = 0.150, x_C = 0.450, x_D = 0.700
하중 위치 = 0.350, 0.450, 0.550; 각각 4 kN 아래쪽
CD의 C점 모멘트: 0.250 D_y - 4(0.100) = 0
D_y = 1.600000000000000 kN

전체 A점 모멘트:
0.150 N_BE + 0.700 D_y - 4(0.350+0.450+0.550) = 0
N_BE = (5.400 - 1.120)/0.150
     = 28.533333333333335 kN (인장)
A_BE = N_BE × 1000 / 100
     = 285.33333333333337 mm²
A_y = 12 - N_BE - D_y = -18.133333333333336 kN
```

따라서 **F_BE = 28.53 kN, A_BE = 285 mm²(유효숫자 3자리)**는 옳다. 축력을 3자리로 표시하면 +28.5 kN이다. 전체 모멘트 잔차 0 kN·m, CD 모멘트 잔차 0 kN·m, 전체 연직력 잔차 −1.78×10⁻¹⁵ kN으로 배정밀도 오차 범위에서 평형을 만족했다.

분리 자유물체로도 검산된다. 중앙 4 kN을 CD 쪽에 포함하면 C가 CD에 가하는 힘은 +6.40 kN, ABC에 가하는 힘은 −6.40 kN이다. 따라서 `0.150 N_BE - 4(0.350) - 6.40(0.450) = 0`으로 같은 결과다. 중앙 하중은 C에 대한 모멘트가 0이지만 힘 평형에서 누락해서는 안 된다. 어느 쪽에 배정했는지 표시하고 이중 계상하지 않는다.

`claude.md`의 36 kN·360 mm²는 D 반력을 누락한 결과이므로 HTML에 남기면 안 된다. C가 모멘트를 전달하지 않는다는 조건은 **CD를 분리한 자유물체**에 적용한다. 전체 구조에 대해 C점 모멘트를 쓰는 것만으로 독립 평형식이 추가되는 것은 아니다. 또한 “1장 문제이므로 내부 힌지여야 한다”는 논리는 도면 판독의 증거가 아니다. 지지 기호를 근거로 모델을 명시한다.

## 1.9 — 부호와 크기: 승인

인장 양수인 축력 N_BD를 사용한다. C 기준 B=(1.4,1.4) m, B→D 단위벡터=(0.28,−0.96). P는 수평 오른쪽이며 작용선 높이는 2.10 m이다.

```text
ΣM_C = -2.10 P - 1.736 N_BD = 0
N_BD = -50 N/mm² × 800 mm² = -40000 N = -40 kN
P = 1.736 × 40 / 2.10 = 33.06666666666666 kN
```

따라서 **|F_BD|=40 kN, P=33.07 kN(3자리 33.1 kN), BD 압축**이 맞다. 실제 B점 힘은 (−11.2,+38.4) kN이고 반시계 모멘트 +69.44 kN·m로 P의 시계 모멘트를 상쇄한다. 부호 있는 응력은 −50 MPa이다. 30°는 원호 반지름의 각도이며 P의 경사각이 아니다.

## 1.11 — 정확 면적과 반올림: 승인, 원인 표현 수정

```text
A_CG = 81π = 254.46900494077323 mm²
σ_CG = 25000/(81π) = 98.24379203203416 MPa
```

따라서 **+98.24 MPa(소수 둘째 자리), +98.2 MPa(유효숫자 3자리), 인장**이다. 98.3은 이 정확값의 정상적인 3자리 반올림이 아니다.

254.4 mm²를 사용하면 98.27044025157232 MPa로 98.3이 재현된다. 그러나 `claude_review.md`의 “기준 98.3은 중간 반올림 흔적”이라는 원인 단정은 근거보다 강하다. **“기준에 기재된 면적 254.4 mm²를 사용하면 98.3이 재현되나, 원자료의 오차 발생 과정은 미확인”**으로 바꾼다. 81π의 소수 첫째 자리 반올림은 254.5이다.

## HTML 상세풀이에 추가로 반드시 반영할 사항

1. **1.8의 도면 설명과 부호를 수정한다.** 기존 Codex 도면 기록에서 D는 E 아래이고, F의 힘은 `F_x=−240 sinθ, F_y=−240 cosθ`이다. `claude.md`의 “D가 위 고정”과 양의 수평 성분 설명은 이와 충돌한다. 인장 양수 N_DE이면 E점 힘은 아래쪽이다. C 기준 E=(300,50), F=(400,−200) mm를 사용해 `−300N_DE−96000cosθ−48000sinθ=0`을 제시하면 `N_DE=−320cosθ−160sinθ`가 일관되게 나온다. “규약에 따라 식이 달라도 압축은 동일”이라는 문구로 방향 오류를 덮지 않는다.
2. **1.11의 강체봉 F점 모멘트 유도를 보완한다.** CF 및 BF의 F점 힘은 존재할 수 있으나 모멘트팔이 0이라 제외되는 것이다. 반시계 양수이면 `−1.2(0.6N_AE)+1.2(0.6N_CG)=0`이다. Claude 본문의 식은 전역 선언과 반대 부호지만 식 전체를 −1배 한 것이므로 결과는 같다. EFG를 일반 트러스 절점들로 취급하지 않으며 절단 부재·남긴 자유물체를 표시한다.
3. **1.14의 실제 H 방향을 왼쪽으로 수정한다.** C의 BC 압축력은 오른쪽 위, P는 아래쪽, 가이드 반력 H는 왼쪽이다. `claude.md`의 “H →”는 잘못이다. A는 고정 크랭크축, B는 크랭크핀, C는 연직 이동 피스톤이다. `0.280H−1500=0`에서 H는 왼쪽 반력의 양의 크기로 정의해야 식과 그림이 맞는다.
4. **1.7의 면적 설명을 제한한다.** BD는 링크 한 개의 힘 16.25 kN/순단면 160 mm² 또는 두 개 합력 32.5 kN/320 mm²로 일관되게 쓴다. CE는 균일부 총단면 기준의 평균 압축응력으로 설명한다. “핀이 구멍을 메우므로 총단면”이라는 문구를 압축 링크 전반의 보편적 법칙으로 쓰지 않는다. 국부 지압·응력집중과 해당 평균응력을 구별한다.
5. **1.13은 두 휠을 묶은 자유물체와 합반력 R을 표시한다.** 단일 봉 CD의 힘을 다시 2로 나누지 않는다. 부분 팔·휠 자중을 별도로 무시하는 이상화를 밝힌다.
6. **축력 부호와 공간 방향을 구별한다.** N은 인장(+)/압축(−), 반력 성분은 오른쪽·위쪽(+), 모멘트는 반시계(+)로 정의한다. 크기는 |N| 또는 별도 양의 기호로 표시한다. “수직응력”은 단면에 수직인 정상응력이며 지면 기준 연직 응력이라는 의미가 아니다.
7. **단위와 유효숫자를 통일한다.** `1 MPa=1 N/mm²`, `1 kN=1000 N`, `1 mm²=10⁻⁶ m²`. 분수에는 괄호를 써서 `−320/(75×10⁻⁶)`처럼 표시한다. 101.6 및 17.86은 4자리이므로 모든 답을 3자리라고 선언한 표에 그대로 넣지 않는다. 285 mm²·238 mm²는 등식으로 구한 면적의 반올림값이며, 허용응력 이하를 보장하는 정수 단면의 올림 설계값이라는 뜻은 아니다.
8. **기존 문서 오류를 최종 HTML로 복사하지 않는다.** PROBLEM.md에도 1.9 하중 방향, 1.10 지지조건 누락, 1.14 점 이름·이동 방향 오류가 있다. 풀이집 98.3과의 차이는 각주에 남기고 본문 답은 98.2로 한다. `claude_review.md`의 “합의 6문항” 표에는 실제 5문항만 있으며, Markdown 표 안의 `|F_BD|`는 열 구분자로 해석되지 않도록 수식 또는 이스케이프 처리한다.
