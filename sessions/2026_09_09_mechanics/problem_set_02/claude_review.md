## 불일치 → 도면 재확인 결과 (Codex 채택)

### 1.9 — 링크 BD는 **압축**, P는 수평 우향
- 도면 확대: **P 화살표는 수평 오른쪽**. `30°`는 P의 경사각이 아니라
  원호 중심 O에서 A로 가는 반지름과 수평선의 각. 하단 좌측 핀 C는 O에서 연직 아래 1.4 m.
- 따라서 C 기준: B = (1.4, 1.4) m, A는 C보다 2.10 m 위 (= 0.7 + 1.4).
  → 참고 풀이집의 `P(0.7+1.4)` 와 `F_BD 두 성분 모두 팔 1.4` 가 이 기하에서 정확히 재현됨.
- ΣM_C: −2.10 P − 1.736 N_BD = 0 → P 우향(+) 이면 **N_BD < 0 (압축)**.
  물리적으로도: P가 A를 오른쪽으로 밀어 브래킷이 C 중심 시계방향 회전 → B가 D 쪽으로 이동 → 링크 BD 압축.
- |N_BD| = |σ|·A = 50 MPa × 800 mm² = 40 kN.
  P = 1.736 × 40 / 2.10 = **33.07 kN ≈ 33.1 kN** (기준값 일치).
- 내 blind는 P를 30° 경사로 잘못 봐 인장으로 판정. **크기 P = 33.1 kN 은 동일**, 부호(압축)는 Codex가 맞음.
  문제의 "수직응력 50 MPa"는 크기로 해석(도면상 P가 우향이므로 BD는 압축).

### 1.10 — D는 **롤러 지지**, C는 **내부 힌지** → A_BE = 285 mm²
- 도면 확대: **A = 벽 핀, E 위 = 천장 핀(봉 BE), C = 봉 중간의 핀(내부 힌지), D = 바닥 롤러(작은 원들이 해칭면 위)**.
- 정역학 확인: 만약 A~D가 한 개의 강체봉이면 반력 4개(핀 A 2 + 봉 BE 1 + 롤러 D 1) > 평형식 3개
  → **1차 부정정**. 1장 문제로 부적절. **C의 내부 힌지가 있어야 정정**(ΣM_C = 0 추가).
- 하중 위치: 세 P는 0.100 m 간격, 가운데 P가 C 바로 위 → x = 0.350, 0.450, 0.550 m (A 기준).
- CD 구간 ΣM_C: D_y(0.250) − 4(0.100) = 0 → D_y = 1.60 kN.
- 전체 ΣM_A: F_BE(0.150) + D_y(0.700) − 4(0.350+0.450+0.550) = 0
  → F_BE(0.150) = 5.400 − 1.120 = 4.280 → **F_BE = 28.53 kN (인장)**.
- A_BE = 28 533 / (100 MPa) = **285 mm²** (285.3).
- 내 blind(360 mm²)는 롤러 D·힌지 C를 놓친 오류. **Codex 채택.**

### 1.11 — σ_CG = 98.2 MPa (기준 98.3은 중간 반올림 흔적)
- N_CG = 25 kN (양쪽 합의). A_CG = (π/4)(18)² = 81π = 254.469 mm².
- σ_CG = 25 000 / 254.469 = 98.244 MPa → **유효숫자 3자리 98.2 MPa**.
- 참고 풀이집 98.3은 A ≈ 254.4 로 자른 값(25 000/254.4 = 98.27). 정상 반올림은 254.5.
- **정확값 98.2 MPa 채택**, 일부 답지 표기 98.3 은 각주.
