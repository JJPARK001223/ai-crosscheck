# Codex blind 독립 풀이 — 재료역학 연습문제 1.1~1.6

## 입력·출처·공통 규약

입력은 같은 폴더의 `PROBLEM.md`만 사용하였다. Claude 풀이, 다른 round 폴더, 원본 PDF는 열람하지 않았다. 따라서 아래 결과는 PROBLEM.md에 명시된 형상·하중의 독립 풀이이며, 스캔 원문의 전사 정확성을 별도로 검증한 결과는 아니다.

출처: Beer 등, 『고체역학』(Mechanics of Materials), 한국어판 8판, 제1장 연습문제 1.1~1.6. 적용 근거는 제1장의 **평형을 이용한 내력 결정 및 평균 수직응력(축하중)** 내용이다. 제공된 파일에 출판연도·정확한 절 번호가 없어 해당 정보는 미확인으로 남긴다. 아래의 자유물체 평형, 수식 전개 및 최적화는 직접 수행하였다.

축내력 N과 평균 수직응력 σ는 **인장(+), 압축(−)** 으로 정한다. 외력의 좌표 방향과 내력의 인장·압축 부호를 구별한다. 공통식은 σ=N/A(문제의 σ=P/A와 동일)이며, 원형 중실 단면은 A=πd²/4이다. 1 MPa=1 N/mm². 1.1~1.5는 자중을 무시하고, 1.6은 ρ=8470 kg/m³, g=9.81 m/s²를 사용한다. 여기서 응력은 단면 평균값이며, 용접부·지름 변화부의 국부 응력집중을 계산하는 문제가 아니다.

## 1.1 — 두 봉의 최소 지름

### 자유물체도와 내력

전체 봉: A의 반력 ↑R_A, B의 하중 ↓40 kN, C의 하중 ↓30 kN.

- 전체 평형: R_A−40−30=0 → R_A=70 kN(위쪽).
- AB 절단면 아래 부분: 절단면에서 ↑N_AB, B에서 ↓40, C에서 ↓30 kN → N_AB=+70 kN.
- BC 절단면 아래 부분: 절단면에서 ↑N_BC, C에서 ↓30 kN → N_BC=+30 kN.

두 봉 모두 인장이다.

### 공식 → 기호식 → 수치대입

σ=N/A=4N/(πd²)≤σ_allow 이므로

d_min=√[4N/(πσ_allow)].

- d₁,min=√[4×70000/(π×175)] mm = **22.567583… mm**.
- d₂,min=√[4×30000/(π×150)] mm = **15.957691… mm**.

### 검산

계산된 최소 단면적은 A_AB=70000/175=400 mm², A_BC=30000/150=200 mm²이다. 역대입하면 각각 +175 MPa, +150 MPa로 허용응력과 일치한다. 지름을 더 줄이면 면적이 작아져 허용응력을 초과한다. 0.01 mm 단위로 선정한다면 최소값보다 작아지지 않도록 각각 **22.57 mm, 15.96 mm**를 택한다.

## 1.2 — 주어진 지름에서의 응력

### 자유물체도와 내력

1.1과 같은 전체 평형 및 절단면 아래 부분의 자유물체도를 사용한다. R_A=70 kN(위쪽), N_AB=+70 kN, N_BC=+30 kN이다.

### 공식 → 기호식 → 수치대입

σ_AB=N_AB/(πd₁²/4), σ_BC=N_BC/(πd₂²/4).

- A_AB=π(50 mm)²/4=1963.495408 mm².
- A_BC=π(30 mm)²/4=706.858347 mm².
- σ_AB=70000/1963.495408 = **+35.6507 MPa(인장)**.
- σ_BC=30000/706.858347 = **+42.4413 MPa(인장)**.

### 검산

반올림 전 수치로 σ_AB A_AB=70000 N, σ_BC A_BC=30000 N을 얻는다.
두 내력의 차이 70−30=40 kN은 B점 집중하중과 일치한다. BC는 내력이 더 작지만 단면적도 작으므로 응력이 AB보다 크다.

## 1.3 — 인장응력이 압축응력 크기의 두 배인 P

### 자유물체도와 내력

외력의 +x를 오른쪽으로 둔다. 전체 봉에는 A에서 ←P, B에서 →240 kN, C에서 반력 R_C가 작용한다.

- 전체 평형: −P+240+R_C=0 → R_C=P−240 kN.
- AB 절단면의 왼쪽 부분: −P+N_AB=0 → N_AB=P.
- BC 절단면의 왼쪽 부분: −P+240+N_BC=0 → N_BC=P−240 kN.

왼쪽 절단체의 오른쪽 절단면에서 양의 N은 오른쪽으로 작용하는 인장력이다. AB 인장·BC 압축 조건을 만족하려면 0<P<240 kN이어야 한다.

### 공식 → 기호식 → 수치대입

A₁=π(50)²/4, A₂=π(75)²/4이므로 A₂/A₁=(75/50)²=9/4.

σ_AB=P/A₁, σ_BC=(P−240)/A₂.

요구 조건은 σ_AB=2|σ_BC|이므로

P/A₁=2(240−P)/A₂,

P(A₂+2A₁)=480A₁,

P=480/(A₂/A₁+2)=480/(2.25+2) = **112.941176… kN**.

### 검산

N_AB=+112.941176 kN, N_BC=−127.058824 kN이고, R_C=−127.058824 kN(왼쪽)이다.

σ_AB=+57.520469 MPa, σ_BC=−28.760234 MPa.
따라서 σ_AB/|σ_BC|=2이며, 0<P<240 kN도 만족한다. 전체 외력 합 −112.941176+240−127.058824=0 kN이다.

## 1.4 — P=160 kN에서의 응력

### 자유물체도와 내력

외력은 A에서 ←160 kN, B에서 →240 kN이다. 전체 평형에서 R_C=−80 kN(왼쪽).

- AB 왼쪽 절단체: −160+N_AB=0 → N_AB=+160 kN.
- BC 왼쪽 절단체: −160+240+N_BC=0 → N_BC=−80 kN.

### 공식 → 기호식 → 수치대입

σ_AB=4P/(πd₁²), σ_BC=4(P−240 kN)/(πd₂²).

- σ_AB=160000/[π(50)²/4] = **+81.4873 MPa(인장)**.
- σ_BC=−80000/[π(75)²/4] = **−18.1083 MPa(압축)**.

### 검산

응력에 각 단면적을 곱하면 +160 kN, −80 kN으로 복원된다. N_AB−N_BC=160−(−80)=240 kN으로 B점 하중과 일치하며, 전체 외력도 −160+240−80=0 kN이다.

## 1.5 — 황동 스페이서의 바깥지름

### 자유물체도와 내력

볼트는 양 끝에서 바깥쪽으로 당겨져 N_b=+F, 스페이서는 양 끝에서 안쪽으로 눌려 N_s=−F이다. 각 강판의 축방향 평형에 따라 볼트 인장력과 스페이서 압축력의 크기가 같다.

입력에서 정의한 경제적 설계는 볼트의 최대 허용 축력을 지지할 수 있는 최소 스페이서 면적이다.

### 공식 → 기호식 → 수치대입

A_b=πd_b²/4, A_s=π(d_o²−d_i²)/4,

σ_b=F/A_b, σ_s=−F/A_s.

볼트 한계에서 F_max=σ_b,allow A_b. 최소 스페이서는 A_s=F_max/σ_s,allow 이므로

d_o=√[d_i²+(σ_b,allow/σ_s,allow)d_b²].

d_i=d_b=16 mm를 대입하면

F_max=200×π(16)²/4=40212.385966 N=40.212386 kN,

A_s,min=40212.385966/130=309.326046 mm²,

d_o=16√(1+200/130) = **25.492080… mm**.

### 검산

이 지름의 고리 단면적에 대해 σ_s=−40212.385966/309.326046=−130 MPa이고, 볼트 응력은 +200 MPa이다. 두 부재가 동시에 허용응력에 도달한다. 0.01 mm 단위 설계 지름이라면 내림하지 않고 **25.50 mm**를 택한다(25.49 mm는 이론적 최소값보다 작음).

## 1.6 — 자중에 의한 최대 응력의 최소화

### 자유물체도와 내력

L=a+b=100 m, A₁=π(0.015 m)²/4, A₂=π(0.010 m)²/4로 두면 r=A₂/A₁=4/9이다. 단위체적당 중량은

γ=ρg=8470×9.81=83090.7 N/m³.

봉의 임의 절단면 아래 부분을 떼어내면 절단면의 위쪽 인장력이 아래 부분의 자중과 평형을 이룬다. 모든 내력은 인장이다.

- BC에서 B로부터 아래로 y(0≤y≤b): N_BC(y)=γA₂(b−y).
- AB에서 A로부터 아래로 x(0≤x≤a): N_AB(x)=γ[A₁(a−x)+A₂b].
- 지지반력: R_A=γ(A₁a+A₂b)(위쪽).

### 공식 → 기호식

σ=N/A를 적용하면

σ_BC(y)=γ(b−y),

σ_AB(x)=γ[(a−x)+rb].

각 구간에서 아래로 갈수록 응력이 선형으로 감소한다. 최대 후보는 **AB의 A 바로 아래** 및 **BC의 B 바로 아래**이다.

σ_A=γ(a+rb), σ_B,BC=γb.

따라서 b=L−a를 대입한 목적함수는

σ_max(a)=γ max[rL+(1−r)a, L−a].

첫 번째 항은 a에 따라 증가하고 두 번째 항은 감소한다. 교점보다 작은 a에서는 두 번째 항이 지배하면서 감소하고, 교점보다 큰 a에서는 첫 번째 항이 지배하면서 증가하므로 교점이 전역 최소점이다.

rL+(1−r)a=L−a,

(2−r)a=(1−r)L,

a=(1−r)L/(2−r), b=L/(2−r),

σ_max,min=γL/(2−r).

### 수치대입과 결과

(a) a=[(1−4/9)/(2−4/9)]×100 = **35.714286 m**.

이에 대응하는 b=64.285714 m.

(b) σ_max,min=(8470×9.81)×100/(2−4/9)

=5341545 Pa = **+5.341545 MPa(인장)**.

### 검산

- 길이: a+b=100 m.
- A 바로 아래: γ[a+(4/9)b]=5341545 Pa.
- B 바로 아래의 가는 봉: γb=5341545 Pa. 두 최대 후보가 일치한다.
- B 바로 위의 굵은 봉: γrb=2374020 Pa=+2.374020 MPa. B에서 내력은 연속이지만 면적이 달라 응력은 불연속이다.
- C에서는 N=0, σ=0이고, 각 구간 내부의 응력은 해당 구간 상단보다 작다.
- a→0 또는 a→100 m의 극한에서 최대 응력은 γL=8.309070 MPa로, 최적값보다 크다.
- γ의 단위 N/m³에 길이 m를 곱하면 N/m²=Pa로 일관된다.
