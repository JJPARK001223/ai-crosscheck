# Claude 독립 풀이 — 연습문제 1.1 ~ 1.6 (blind)

작성일 2026-09-09. `PROBLEM.md`만 보고 독립적으로 풀었다. `codex.md`는 보지 않았다.
교재: 비어 고체역학 8판 1장. 공식: 평균 수직응력 σ = P/A, 원형 단면 A = πd²/4.
부호: 인장 (+), 압축 (−). 자중은 1.6에만 고려.

상수: π/4 = 0.78539816.

---

## 1.1 — d₁, d₂ 최소 허용치

**내력(자유물체도).** 봉은 A에서 매달리고 B에 40 kN(↓), C에 30 kN(↓).
- 단면을 BC 사이에 자른다 → 아래쪽에는 C의 30 kN만 있다. **F_BC = +30 kN (인장).**
- 단면을 AB 사이에 자른다 → 아래쪽에 40 kN + 30 kN. **F_AB = +70 kN (인장).**

**d₁ (봉 AB, 허용 175 MPa).**
πd₁²/4 ≥ F_AB / σ_allow = 70 000 N / 175 (N/mm²) = 400 mm²
d₁² ≥ 400 / 0.78539816 = 509.296 mm² → d₁ ≥ 22.567 mm
**d₁,min = 22.6 mm**

**d₂ (봉 BC, 허용 150 MPa).**
πd₂²/4 ≥ 30 000 / 150 = 200 mm²
d₂² ≥ 200 / 0.78539816 = 254.648 mm² → d₂ ≥ 15.958 mm
**d₂,min = 16.0 mm**

검산: d₁ = 22.567 → A = 400.0 mm² → σ = 70000/400 = 175.0 MPa ✓
d₂ = 15.958 → A = 200.0 mm² → σ = 30000/200 = 150.0 MPa ✓

---

## 1.2 — d₁ = 50 mm, d₂ = 30 mm 일 때 중앙 단면 평균 수직응력

내력은 1.1과 동일: F_AB = +70 kN, F_BC = +30 kN.
- A_AB = 0.78539816 × 50² = 1963.495 mm²
- A_BC = 0.78539816 × 30² = 706.858 mm²

**(a) σ_AB = 70 000 / 1963.495 = 35.65 MPa → +35.7 MPa (인장)**
**(b) σ_BC = 30 000 / 706.858 = 42.44 MPa → +42.4 MPa (인장)**

---

## 1.3 — 힘 P (σ_AB,인장 = 2 · σ_BC,압축)

- A_AB = 0.78539816 × 50² = 1963.495 mm²
- A_BC = 0.78539816 × 75² = 4417.865 mm²

**내력.** +x = 오른쪽. A에서 P는 왼쪽(−x). B의 칼라에 240 kN(+x).
- AB 단면: 왼쪽에 P(왼쪽으로). 봉을 잡아당김 → **F_AB = P (인장).**
- BC 단면: 왼쪽 조각의 외력 합 = (−P) + (240) = 240 − P.
  절단면 평형: F_BC + (240 − P) = 0 → **F_BC = P − 240.**
  P < 240 이면 F_BC < 0 → 압축, 크기 240 − P.

**조건.** σ_AB = 2 σ_BC (크기):
P / A_AB = 2 (240 − P) / A_BC
P / 1963.495 = 2 (240 − P) / 4417.865
4417.865 P = 3926.990 (240 − P)
4417.865 P = 942 477.6 − 3926.990 P
8344.855 P = 942 477.6
**P = 112.94 kN ≈ 113 kN**

검산: F_BC = 240 − 112.94 = 127.06 kN(압축).
σ_AB = 112 940 / 1963.495 = 57.52 MPa (인장)
σ_BC = 127 060 / 4417.865 = 28.76 MPa (압축)
57.52 = 2 × 28.76 ✓

## 1.4 — P = 160 kN 일 때 중앙 단면 평균 수직응력

F_AB = P = +160 kN (인장)
F_BC = P − 240 = −80 kN (압축 80 kN)

- A_AB = 1963.495 mm², A_BC = 4417.865 mm²

**(a) σ_AB = 160 000 / 1963.495 = 81.49 MPa → +81.5 MPa (인장)**
**(b) σ_BC = 80 000 / 4417.865 = 18.11 MPa → −18.1 MPa (압축)**

## 1.5 — 스페이서 바깥지름 d_o

볼트와 스페이서는 같은 축력 P를 전달(볼트 인장 = 스페이서 압축).

**볼트가 낼 수 있는 최대 축력** (허용 200 MPa, 지름 16 mm):
A_bolt = 0.78539816 × 16² = 201.062 mm²
P_max = 200 × 201.062 = 40 212 N ≈ 40.21 kN

**"가장 경제적이고 안전한" 스페이서**: 이 P_max에서 스페이서 응력이 정확히 허용치
130 MPa가 되도록 바깥지름을 최소화.
A_spacer,req = P_max / 130 = 40 212 / 130 = 309.33 mm²
스페이서는 볼트를 감싸는 중공 원통, 안지름 = 16 mm:
π/4 (d_o² − 16²) = 309.33
d_o² − 256 = 309.33 / 0.78539816 = 393.85
d_o² = 649.85 → d_o = 25.49 mm
**d_o ≈ 25.5 mm**

검산: A_spacer = 0.78539816 (25.49² − 256) = 0.78539816 × 393.9 = 309.4 mm²
σ_spacer = 40 212 / 309.4 = 130.0 MPa ✓ (볼트 = 200 MPa, 스페이서 = 130 MPa 동시 만족)

## 1.6 — 자중 하 최대응력 최소화

L = a + b = 100 m. d_AB = 15 mm, d_BC = 10 mm. ρ = 8470 kg/m³, g = 9.81 m/s².
비중량 γ = ρg = 8470 × 9.81 = 83 090.7 N/m³.
- A_AB = π/4 (0.015)² = 1.76715×10⁻⁴ m²
- A_BC = π/4 (0.010)² = 7.85398×10⁻⁵ m²
- 면적비 k = A_BC / A_AB = (10/15)² = 4/9 = 0.44444

**응력 분포 (자중, 각 단면은 그 아래 전체 무게를 지탱 → 인장).**
- 봉 BC 내부: 단면 위 무게 = γ A_BC ·(그 아래 BC 길이). B 바로 아래에서 최대:
  σ_BC,max = γ A_BC b / A_BC = **γ b** (면적 무관).
- 봉 AB 내부: 단면 아래 무게 = (BC 전체) + (그 아래 AB). 최상단 A에서 최대:
  N_A = γ A_BC b + γ A_AB a → σ_A = γ (a + k b) = **σ_AB,max**.
- 접합부 B에서 응력은 불연속: BC쪽 γb → AB쪽 γ k b (< γb) 로 낮아졌다가 A로 갈수록
  선형 증가. 따라서 전체 최대는 { σ_BC,max = γb , σ_AB,max = γ(a + kb) } 중 큰 값.

**최소화.** b = L − a 대입:
- f₁(a) = γ(L − a) : a 증가 시 감소
- f₂(a) = γ(a + k(L − a)) = γ[a(1−k) + kL] : a 증가 시 증가 (k < 1)
두 곡선이 만나는 곳에서 max가 최소:
L − a = a + k(L − a)
(L − a)(1 − k) = a → (L − a)(5/9) = a → 5(L − a) = 9a → 5L = 14a
**a = 5L/14 = 500/14 = 35.71 m** (b = 64.29 m)

**(b)** σ_max = γ b = 83 090.7 × 64.286 = 5.342×10⁶ Pa ≈ **5.34 MPa**
교차검산: σ_AB,max = γ(a + k b) = 83 090.7 (35.714 + 0.44444×64.286)
       = 83 090.7 × (35.714 + 28.571) = 83 090.7 × 64.286 = 5.34 MPa ✓

(g = 9.807 사용 시 γ = 83 063, σ_max = 5.339 MPa — 유효숫자 3자리에서 동일.)
