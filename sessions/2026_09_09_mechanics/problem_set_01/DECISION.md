## 3. 검증 과정에서 정정된 사항 (최종 답 불변, 표기/검산 엄밀화)

1. **1.1 중간 표기** — "d₁ ≥ 22.567 mm"는 이론 최소값(22.5676)을 유효숫자에서 절단한 값이라
   그대로 채택하면 σ = 175.01 MPa로 근소 초과. 올바른 최소조건은 d₁ ≥ 22.568 mm(올림).
   최종 답 22.6 mm는 영향 없음.
2. **1.3 / 1.4 검산 부호** — 압축 내력·응력을 크기(양수)로 적은 부분은 |·| 또는 음수 표기로
   통일. 물리 판단(압축)은 옳음.
3. **1.5 검산** — claude.md가 "25.49 mm에서 볼트 200 · 스페이서 130 MPa 동시 만족"이라 했으나
   25.49 mm는 이론 최소값 25.4921 mm보다 작아 |σ_s| ≈ 130.04 MPa로 130을 근소 초과.
   **두 부재가 정확히 동시에 허용응력에 도달하는 것은 이론값 25.4921 mm에서**이며,
   최종 선정 25.50 mm에서는 스페이서가 σ_s ≈ 129.87 MPa로 안전. → 검산을 이론값 기준으로 수정.
4. **1.6** — claude.md "단면 위 무게" → "단면 아래 무게" 오타 정정. g = 9.807 부가계산의
   수치(γ, σ)는 오류였고 불필요하므로 삭제. 3자리 유효숫자 결과 5.34 MPa는 불변.
5. **반올림 방향** — 최소 치수를 구하는 1.1·1.5는 이론값 이하로 내리면 조건 위반이므로
   항상 올림. 0.01 mm 단위: 1.1 → 22.57 / 15.96 mm, 1.5 → 25.50 mm.

## 4. 최종 풀이 근거 요약

- **1.1** 매달린 봉의 내력 = 그 단면 아래 하중 합. N_AB = 70, N_BC = 30 kN(인장).
  d_min = √[4N/(πσ_allow)] → 22.6 / 16.0 mm.
- **1.2** 같은 내력, 주어진 지름 대입. σ = 4N/(πd²) → +35.7 / +42.4 MPa.
- **1.3** N_AB = P(인장), N_BC = P − 240(압축, 크기 240 − P).
  σ_AB = 2|σ_BC| ⟹ P = 480/(A₂/A₁ + 2), A₂/A₁ = (75/50)² = 9/4 ⟹ P = 1920/17 ≈ 113 kN.
- **1.4** P = 160 → N_AB = +160, N_BC = −80 kN → σ_AB = +81.5, σ_BC = −18.1 MPa.
- **1.5** F_max = σ_bolt,allow · (πd_b²/4) = 40.21 kN.
  d_o = √[d_i² + (σ_bolt,allow/σ_spacer,allow)·d_b²] = √[16² + (200/130)·16²] = 25.49 mm → 선정 25.5 mm.
- **1.6** γ = ρg. σ_AB,max = γ(a + kb) (at A), σ_BC,max = γb (at B), k = (d_BC/d_AB)² = 4/9.
  b = L − a 대입 후 두 식이 만나는 a가 최적: a = (1−k)L/(2−k) = 5L/14 = 35.7 m,
  σ_max,min = γL/(2−k) = γ·9L/14 = 5.34 MPa.
