# Beer Ch.8 "주어진 하중 하에서의 보의 설계 / 조합하중 하의 주응력" 짝수 38문제 교차검증 최종 결정

Claude(round1/claude.md, HTML 4개 원본) ↔ Codex(round1/codex.md, blind 재계산) 대조 결과.
**Ch7과 달리 이번 챕터는 3차원 조합하중(굽힘+비틀림+전단) 문제가 많아 기하 판독(작용점 좌표, 편심, 회전축)에서 두 AI가 서로 다른 그림 해석을 한 경우가 많다. Ch7처럼 "자기 자신의 다른 풀이와 대조"할 재확인 수단이 없어, 아래 불일치 항목들은 정정 확정이 아니라 원본 재확인을 권고하는 수준이다.**

## 7. 특별 지적 — 8.76 단면 형상 해석 차이 (Ch7과 달리 정정 보류, 원본 재확인 권장)
Claude(8.62~8.76.html)는 60×60mm **정사각형** 단면으로, Codex는 40×60mm **직사각형** 단면으로 풀었다. 세션 시작 시 직접 확인한 원본 이미지(0920_문제.pdf p.15)에도 "40mm"와 "60mm" 두 치수가 표기되어 있어 **직사각형(Codex 해석)이 더 유력**해 보이나, 확정을 위해 원본 재확인을 권장한다.

## 8. 결론 및 권고
- 38문제 중 11문제는 완전 일치, 2문제는 부호만 다르고 계산은 검증됨(3번 항목만 정정 확정).
- **14문제(4·5번 표)는 두 AI의 입력 판독 자체가 크게 갈려, Ch7처럼 자기교차검증할 방법이 없다.** 특히 8.72(토크 유무 결론이 정반대)와 8.18/8.34/8.36/8.44/8.46/8.58/8.70(3배 이상 차이)은 우선순위를 높여 원본 재확인을 권장한다.
- 6문제는 완전성 차이(오류 아님, 데이터 부족으로 한쪽만 완결).
- 다수 문제가 원본 스캔 자체의 판독 난제(페이지 곡률, 여백 잘림, 3D 좌표 판독)를 갖고 있어, Ch6·Ch7보다 원본 재확인이 더 많이 필요한 챕터로 파악됨.
