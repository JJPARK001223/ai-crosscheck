# Claude blind 유도 — 배치 1 (1.15 ~ 1.19)

공통: 평균 전단응력 τ = V/A (V = 전단면에 평행한 내력, A = 전단면적).
평균 지압응력 σ_b = P/A_b (A_b = 하중을 전달하는 접촉 투영면적).
1 MPa = 1 N/mm², 1 kPa = 10⁻³ N/mm².

---

## 1.15 — 목재 시편 전단 파손

- 파손면은 목재의 수평면 하나. 그 면에 축하중 P가 전단력으로 그대로 작용(P′와 P가 어긋난 계단형이라
  두 힘 사이 수평면이 전단면).
- 전단면적 A = (길이)(폭) = (90 mm)(15 mm) = 1350 mm² = 1350×10⁻⁶ m².
- τ = P/A = 8000 N / 1350×10⁻⁶ m² = 5.9259×10⁶ Pa.

**τ = 5.93 MPa** (참고 답 일치).

---

## 1.16 — 장부촉이음 파손 하중

- 빗살 이음: 두 판이 서로 맞물린 핑거. 목재 결을 따라 전단이 일어나는 면(핑거의 하중 평행면)이 여러 개.
- 매뉴얼 해석: 파손 시 전단면 **6개**, 각 면 = (핑거 폭 16 mm)(판 두께 12 mm) = 192 mm².
- 면당 파손력 F = τ_ult · A = (8 N/mm²)(192 mm²) = 1536 N.
- 6개 면이 하중을 병렬로 분담 → P = 6 F = 6 × 1536 = 9216 N.

**P = 9.22 kN** (참고 답 일치).

- 그림 해석 주: 25/50/50/25 는 핑거 배열 위치, 16 mm 는 핑거 폭. 전단면이 정확히 6개인지는
  핑거 개수(맞물림 형상)에 의존 — 매뉴얼이 6으로 확정.

---

## 1.17 — 알루미늄 판 구멍의 강재봉, 최대 P

두 파손 모드 각각의 한계 하중을 구하고 작은 쪽 채택.

**(1) 강재봉이 뽑히는 전단** (봉이 판·머리 사이에서 원통 전단):
- 전단면 = 지름 d₁ = 12 mm, 길이 t₁ = 10 mm 인 원통 측면.
- A₁ = π d₁ t₁ = π (12)(10) = 376.99 mm².
- P₁ = τ_steel · A₁ = (180 N/mm²)(376.99 mm²) = 67,858 N = 67.86 kN.

**(2) 알루미늄 판이 봉 머리 둘레에서 뚫리는 전단**:
- 전단면 = 지름 d₂ = 40 mm(머리 지름), 길이 t₂ = 8 mm(판 두께) 인 원통 측면.
- A₂ = π d₂ t₂ = π (40)(8) = 1005.31 mm².
- P₂ = τ_alum · A₂ = (70 N/mm²)(1005.31 mm²) = 70,372 N = 70.37 kN.

**P_max = min(67.86, 70.37) = 67.9 kN** (강재봉 전단이 지배). 참고 답 일치.

- 그림 해석 주: 10 mm(강재봉 물림 길이)와 8 mm(판 두께)의 역할 교환 여부가 관건.
  매뉴얼이 A₁ = π(12)(10), A₂ = π(40)(8) 로 확정 → 채택.

---

## 1.18 — 접착 핑거이음 최소 허용 길이 d (매뉴얼 없음)

- 접착 전단면 = 맞물린 핑거끼리 맞닿는 수평면(하중 P에 평행). 각 면적 = d × (판 두께 22 mm).
- 폭 160 mm, 핑거 피치 20 mm → 160/20 = 8 구획. 좌·우 판이 4개씩 번갈아.
  맞물린 계면(전단면) 개수 n = 8 − 1 = **7개**.
- 파손 조건: τ_avg = P / (n · d · t) = 820 kPa = 0.820 N/mm².
  0.820 = 7600 / (7 · d · 22)
  d = 7600 / (7 · 22 · 0.820) = 7600 / 126.28 = 60.18 mm.

**d ≈ 60.2 mm** (전단면 7개 가정).

- 민감도: n=6 → d = 70.2 mm, n=8 → d = 52.7 mm.
- 대안 해석(전단면이 d×160 이고 2개뿐이라면): d = 7600/(2·160·0.820) = 28.96 mm — 그림상 핑거 이음이라
  가능성 낮음. 7개 계면 채택하되 Codex·그림 재확인 필요.

---

## 1.19 — 환상 와셔 최소 바깥지름

**(1) 강철봉 축응력 한계로 최대 P**:
- A_rod = (π/4)(22)² = (π/4)(484) = 380.13 mm².
- P_max = σ_rod · A_rod = (35 N/mm²)(380.13 mm²) = 13,305 N.

**(2) 와셔–목재 지압 조건으로 필요 면적**:
- 지압 면적(환상) A_b = P / σ_b = 13,305 / 5 = 2661.0 mm².
- A_b = (π/4)(d² − d_i²), d_i = 25 mm.
  2661.0 = (π/4)(d² − 625)
  d² − 625 = 4 × 2661.0 / π = 3388.0
  d² = 4013.0 → d = 63.35 mm.

**d ≈ 63.3 mm** (참고 답 일치).

- 주: 봉 지름 22 mm ≠ 와셔 내경 25 mm. 지압 면적의 안쪽 경계는 와셔 내경 25 mm 사용(봉이 아니라 와셔가
  목재에 닿음). 봉 지름 22 는 (1)의 봉 단면적 계산에만 사용.
