## 1.20 — 지압판 최소 길이 L
목재 보를 지지하는 기둥 축하중 P = 75 kN. 목재에 가해지는 지압응력이 **3.0 MPa** 초과 안 되게 하는
지압판 최소 허용길이 L. 그림 P1.20: 지압판 폭(그림) **140 mm**, 길이 L, 아래에서 P.
- σ_b = P/(L·w) ≤ 3.0 → L ≥ 75000/(3.0·140) = **178.6 mm**. (매뉴얼 대응 1.19 동일 방법; 매뉴얼은 P=75, 3.0, 140 → 178.6 mm.)

## 1.21 — 판 측면 길이 a
콘크리트 기초 위 짧은 기둥 W200×59 (단면적 **A = 7650 mm²**). 기둥 평균 수직응력 ≤ **200 MPa**,
콘크리트 위 지압응력 ≤ **20 MPa**. 가장 경제적·안전한 정사각 판 측면 길이 a. 그림 P1.21: 정사각 a×a, 중앙 P.
- 기둥이 견디는 P = σ_col·A = 200·7650 = 1,530,000 N = 1530 kN.
- a² = P/σ_b = 1530000/20 = 76500 mm² → a = √76500 = **276.6 mm ≈ 277 mm**.
- (매뉴얼 1.22는 A=7560 → P=1512 kN, a=275 mm. 0910은 7650.)

## 1.22 — 콘크리트 지지대 크기
불균일 토양 위 콘크리트 지지대가 짧은 목재 기둥을 지지. 축하중 P = **40 kN**. 목재 기둥 단면 **100 × 120 mm**.
(a) 콘크리트 지지대에 작용하는 최대 지압응력, (b) 토양 평균 지압응력이 **145 kPa**일 때 지지대 크기(정사각 b).
- (a) σ_b(concrete) = P/(100·120) = 40000/12000 = **3.33 MPa**.
- (b) b² = P/145kPa = 40000/(145×10⁻³) = 275,862 mm² → b = **525 mm**. (매뉴얼 1.21 동일.)

## 1.23 — 포크리프트 링크, 핀 B

부재 BD 두께 **16 mm**. (a) B의 **12 mm** 핀에서 평균 **전단응력**, (b) 부재 BD의 B에서 지압응력.
그림 P1.23: 벽에 A(위)·D(아래) 핀, 가위형 X(중심 C), 우측 끝에 6 kN 아래. 수직간격 300 mm(A~C), 300 mm(C~D),
하중은 D보다 380 mm 아래. 수평 400 + 400 + 500 mm.
- 한쪽 포크(부재 BD 등) 자유물체 ΣM: 매뉴얼 1.26 방식 → E = 5 kN, B_x = 5 kN, B_y = 6 kN.
  B = √(5²+6²) = **7.81 kN**.
- (a) τ_pin = B/(π/4·12²) = 7810/113.10 = **69.0 MPa**. (핀 단전단 가정 — 매뉴얼도 단전단.)

## 1.24 — 벨크랭크, 핀 B 설계 (θ=40°, P=9 kN)  ★그림 해석 검증 필요

**수평 링크 BC**(길이 750 mm)로 오른쪽 브래킷 C의 핀에 연결.
(a) 핀에서 평균 전단응력 ≤ 120 MPa 인 B 핀의 최소 허용 직경,
(b) 이에 상응하는 B에서 부재 AB의 평균 지압응력,
(c) 이에 상응하는 B에서 지지 브래킷의 평균 지압응력.

- (a) 핀이 브래킷에서 **복전단(double shear)** 가정: τ = (B/2)/(πd²/4) = 120 → d = √(2B/(π·120)) = √(2·87240/376.99) = **21.5 mm**.
- (b) σ_b(AB) = B/(d·t_AB), t_AB = 16 mm → 87240/(21.5·16) = **253.6 MPa**.
- (c) 브래킷 지압: 브래킷 판 두께가 그림에 안 보임 → **미상. Codex가 그림에서 브래킷 두께 확인 필요.**

## 1.26 — 링크 AB, 핀 지름과 지압
폭 b = **50 mm**, 두께 t = **6 mm**인 링크 AB가 수평 보 끝단을 지지. 링크 평균 수직응력 **−140 MPa**(압축),
두 핀 각각 평균 전단응력 **80 MPa**. (a) 핀 지름 d, (b) 링크에서 평균 지압응력.
- 링크 압축력 P = |σ|·A = 140·(50·6) = 140·300 = 42,000 N.
- (a) 핀 (단전단): A_p = P/τ = 42000/80 = 525 mm² → d = √(4·525/π) = **25.9 mm**.
- (b) σ_b(link) = P/(d·t) = 42000/(25.85·6) = 42000/155.1 = **271 MPa**. (매뉴얼 1.28 동일: d=25.9, σ_b=271.)

## 1.27 — "연습문제 1.7에서" 파생
연습문제 1.7: 수평 강체봉 ABC, A에 20 kN ↑. B는 링크쌍 BD(각 8×36 mm, 2개), C는 링크쌍 CE(2개)로

→ 1.7 결과: F_BD = **+32.5 kN**(인장), F_CE = −12.5 kN. (봉 ABC 자유물체 ΣM: F_BD = 20·(0.25+0.4)/0.4 = 32.5.)
1.27: (a) B의 핀에서 평균 지압응력(767판은 전단응력), (b) 부재 BD에서 B에서 평균 지압응력,
(c) 부재 ABC에서 B에서 평균 지압응력. 부재 ABC는 **10 × 50 mm** 일정 사각단면.

**Claude 해석**:
- B에서 핀에 걸리는 힘 = F_BD = 32.5 kN. 핀은 봉 ABC(중앙) + 링크 BD 2개(양쪽) 연결 → **복전단**.

## 1.28 — 목재 부재 CD 끝의 강철봉 AB
12 mm 지름 강철봉 AB가 목재 부재 CD 끝 C 부근 원형 구멍에 끼워짐. 하중: A에 2.25 kN, B에 2.25 kN,
상단에 4.5 kN (그림 P1.28: 18 mm, 75 mm, 점선 전단면, b, C, D).
(a) 목재의 최대 평균 수직응력, (b) 점선 표면 평균 전단응력 620 kPa 되는 거리 b, (c) 목재 평균 지압응력.
- (a) A_net = (75 − 12)(18) = 63·18 = 1134 mm². σ = P/A_net = 4500/1134 = **3.97 MPa**.
- (b) 두 점선면(복전단), 각 면적 b·18: τ = P/(2·b·18) = 620×10⁻³ → b = 4500/(2·18·0.620) = 4500/22.32 = **201.6 mm**.
- (c) σ_b = P/(d·t) = 4500/(12·18) = 4500/216 = **20.8 MPa**.
- (매뉴얼 1.25 동일: 3.97 MPa / 202 mm / 20.8 MPa.)

## 1.29 — 경사 접착 이음, 응력 (P = 6 kN)
두 목재 부재 접착제 단순 맞대기 접합, 하중 P = **6 kN**. 접착면 발생 수직·전단응력.
그림 P1.29&P1.30: 사각 단면 **75 × 125 mm**, 접착면 각도 **60°**(축과), θ = 90°−60° = 30°.
- A₀ = 0.075·0.125 = 9.375×10⁻³ m².
- σ = (P/A₀) cos²θ = (6000/9.375e-3)·cos²30° = 640000·0.75 = 480,000 Pa = **0.480 MPa**.
- τ = (P/A₀) sinθ cosθ = 640000·0.4330 = 277,000 Pa = **0.277 MPa**.
- (매뉴얼 1.29는 P≈6.227 kN 사용 → 0.498/0.288 MPa. 0910은 6 kN.)

## 1.30 — 경사 접착 이음, 최대 P (σ_all = 500 kPa)
같은 이음(75×125, 60°). 접착면 최대 허용 **인장응력 500 kPa**. (a) 안전 최대 P, (b) 그때 전단응력.
- (a) σ = (P/A₀)cos²30° = 500e3 → P = 500e3·9.375e-3/0.75 = **6.25 kN**.
- (b) τ = (P/A₀)sinθcosθ = (6250/9.375e-3)·0.4330 = 666667·0.4330 = 288,700 Pa = **0.289 MPa**.
- (매뉴얼 1.30은 525 kPa → 6.62 kN / 0.303 MPa. 0910은 500 kPa.)

## 1.33 — 나선 용접 강관, 최대 축하중 P
바깥지름 **300 mm**, 판 두께 **6 mm**. 나선 용접, 나선 경사각 = 관축에 직각인 면과 **25°**.
용접선의 수직·접선 방향 응력이 각각 σ = **50 MPa**, τ = **30 MPa**. 최대 축하중 P.
- r_o = 150, r_i = 144 mm. A₀ = π(150² − 144²) = π·1764 = 5541.8 mm² = 5.5418×10⁻³ m².
- θ = 25° (용접면 법선과 관축 사이 각).
- σ 기준: P = A₀·σ/cos²25° = 5.5418e-3·50e6/0.82139 = 277,090/0.82139 = **337,350 N ≈ 337 kN**.
- τ 기준: P = A₀·τ/(sin25°cos25°) = 5.5418e-3·30e6/0.38302 = 166,254/0.38302 = **434,060 N ≈ 434 kN**.
- P_max = min = **337 kN** (σ 지배).
- (매뉴얼 1.35는 400 mm/10 mm/20°/60·36 → 833 kN. 0910 값 다름.)

## 1.34 — 나선 용접 강관, 용접선 응력 (P = 250 kN)
같은 관(300 OD, 6 wall, 25°). 축하중 P = **250 kN**. 용접선의 수직·전단응력.
- σ = −(P/A₀)cos²25° = −(250000/5.5418e-3)·0.82139 = −45,112,000·0.82139 = **−37.05 MPa ≈ −37.1 MPa**.
- τ = (P/A₀)sinθcosθ = 45,112,000·0.38302 = 17,278,000 Pa = **17.3 MPa**.
- (매뉴얼 1.36은 300 kN, 400/10/20° → −21.6/7.87 MPa. 0910 값 다름.)
