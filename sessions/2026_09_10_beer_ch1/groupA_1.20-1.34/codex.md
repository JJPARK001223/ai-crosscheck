## 공통 부호, 자유물체 및 면적 정의

힘은 N, 길이는 mm를 기본 단위로 쓰면 응력은 N/mm² = MPa이다. 1 kPa = 0.001 MPa. 축 수직응력은 인장 양(+), 압축 음(-)으로 두며, 지압응력과 전단응력의 답은 별도 표시가 없으면 크기이다. 자중·마찰·핀 굽힘·국부 응력집중은 주어지지 않았으므로 이 장의 평균응력 모형에서 제외한다.

1. 축방향 절단면의 내부 합력은 자유물체 평형으로 구한 축력 N이며, 평균 축응력은 σ = N/A이다. 구멍을 통과하는 인장 단면에는 순단면적을 쓴다.
2. 핀 단전단: 전단면 한 개, A_s = πd²/4, τ = V/A_s. 대칭 두 귀 브래킷의 복전단: 각 면의 힘 V/2, 총 전단면적 2πd²/4, τ = V/(2πd²/4).
3. 핀-판 지압: 원통 접촉면의 **투영면적** A_b = dt. 핀 원형 단면적이나 원통 표면적 πdt가 아니다. 동일한 두 판이 총하중 V를 반씩 받으면 판당 응력은 (V/2)/(dt) = V/(2dt)이다.
4. 경사 접착면: α를 **면의 법선과 부재 축 사이 각**으로 정의한다. 축에 수직인 단면적 A₀와 실제 접착면적 A_α는 A_α cosα = A₀를 만족한다. 인장력 P에 대하여 절단 자유물체의 평형은 N_α = P cosα, V_α = P sinα이고,

   σ_α = N_α/A_α = (P/A₀)cos²α,

   |τ_α| = V_α/A_α = (P/A₀)sinα cosα.

계산 중에는 반올림하지 않고 최종 답을 3유효숫자로 표시한다. 설계 경계값의 반올림 표시는 실제 치수의 올림 선정과 구별한다. 예를 들어 b_min = 525.2257… mm의 3유효숫자 표시는 525 mm이지만, 정수 mm로 실제 제작한다면 526 mm 이상을 선택해야 한다.

## 1.20 지압판의 최소 길이

**도면·입력:** PDF 2쪽 P1.20. P = 75 kN, 접촉 폭 w = 140 mm, 목재 허용 지압응력 3.0 MPa.

**자유물체:** 지압판에 기둥이 위로 가하는 P와 목재가 아래로 가하는 접촉압력의 합력이 평형을 이룬다. 따라서 접촉면이 전달하는 합력은 75,000 N이다.

L_min = 25,000/140 = 178.5714 mm.

**답: L_min = 179 mm.** `PROBLEM.md`의 178.6 mm와 같은 계산이며, 최종 3유효숫자로 정리했다.

## 1.21 정사각 지압판의 한 변

**도면·입력:** PDF 2쪽 P1.21. 원문에서 A_col = **7650 mm²**를 확인했다. 기둥 허용 압축응력 크기 200 MPa, 콘크리트 허용 지압응력 20 MPa.

**자유물체:** 기둥의 위쪽 하중 P와 판의 반력이 평형이고, 판을 통해 콘크리트에도 같은 P가 전달된다. 기둥의 허용 하중을 온전히 활용하면서 판 면적을 최소화하는 조건을 쓴다.

P_col,all = 200(7650) = 1,530,000 N = 1530 kN,

σ_b = P_col,all/a² ≤ 20,

a²_min = 1,530,000/20 = 76,500 mm²,

a_min = √76,500 = 276.5863 mm.

**답: a = 277 mm.** 제안값에 동의한다. P가 임의로 더 작으면 필요한 판도 작아지지만, 여기서는 기둥의 허용 하중에 맞춘 경제적 설계이다.

## 1.23 포크리프트의 B 핀과 BD 지압

**도면 확인:** PDF 3쪽 P1.23. B는 포크 상단의 핀 연결이고 E는 포크의 수직 안내면을 따라 움직이는 롤러 접촉이다. 따라서 E 반력은 수평이며, E_y = 0이다. B-E의 수직 거리는 300 + 300 = 600 mm, 하중 작용선은 B/E보다 오른쪽 500 mm이다. 하중은 **한 시스템에 이미 6 kN**이므로 두 시스템이라는 이유로 다시 2로 나누지 않는다. BD는 한 개의 16 mm 판이며 B의 연결은 단전단이다.

도면의 E 높이에서 포크 하중 높이까지 치수는 **350 mm**이다. `PROBLEM.md`의 380 mm는 도면과 다르다. 이 수직 치수는 수직하중의 모멘트 팔에는 들어가지 않아 아래 답에는 영향을 주지 않는다.

**자유물체:** 오른쪽 포크 전체만 분리한다. x 오른쪽, y 위쪽. 외력은 B_x, B_y, E_x 및 6000 N 아래쪽 하중이다. B를 원점으로 E = (0, -600) mm, 하중점의 x = 500 mm로 둔다.

ΣM_B = 0: 600E_x - 500(6000) = 0 → E_x = +5000 N,

ΣF_x = 0: B_x + E_x = 0 → B_x = -5000 N,

ΣF_y = 0: B_y - 6000 = 0 → B_y = +6000 N,

B = √(5000² + 6000²) = 7810.24968 N.

BD가 받는 핀 힘은 위 포크의 B 반력과 반대 방향이고 크기는 같다. X 링크 전체를 두힘부재로 가정하거나, 중간 핀 C의 힘을 무시하여 BD축 방향으로만 B를 놓아서는 안 된다.

(a) d = 12 mm 핀의 단전단:

A_s = π(12)²/4 = 113.09734 mm²,

τ_B = 7810.24968/113.09734 = 69.05777 MPa.

(b) BD의 핀 구멍 지압 투영면적:

A_b,BD = dt = 12(16) = 192 mm²,

σ_b,BD = 7810.24968/192 = 40.67838 MPa.

**답: (a) τ_B = 69.1 MPa, (b) σ_b,BD = 40.7 MPa.** 제안의 힘과 면적 정의에는 동의한다. 제안의 69.0 MPa는 최종 반올림을 **69.1 MPa**로 고친다.

**문구 주의:** 스캔의 (a) 오른쪽에 판독되는 문구는 '평균 지압…'이다. 오른쪽 끝이 잘려 있어 원문의 완전한 문장을 복구하지는 못했다. 이번 사용자 요청과 `PROBLEM.md`의 명시적인 (a) 전단 요구에 맞춰 위 전단값을 제공했다. 문자 그대로 핀의 지압을 묻는다면 BD와 접촉하는 핀 부분의 평균 지압은 작용·반작용에 의해 (b)와 같은 40.7 MPa이고, 포크 측 접촉부는 그 판 두께가 있어야 별도로 계산할 수 있다.

## 1.24 AB-케이블 AC 시스템의 B 핀 설계

### 도면 판독: 제안의 벨크랭크 모형을 수정

근거는 PDF 3쪽 **P1.24 및 P1.25**의 확대 도면이다.

- B에 핀으로 지지된 부재는 AB이고, A에서 C로 이어지는 가는 부재는 **케이블 AC**이다. B-C는 두 지지점 사이의 수평 거리이며, B에서 50 mm의 짧은 크랭크 팔이 수평 링크를 미는 구조가 아니다.
- **θ는 AB와 B에서 왼쪽으로 연장한 수평선 사이 각**이다. 연직선 기준이 아니다.
- 두 750 mm는 **AB의 핀 중심 간 길이 750 mm**, **수평 지지점 간 거리 BC = 750 mm**이다. 케이블 AC 길이가 750 mm인 것도 아니다.
- **50 mm는 AB 판의 면내 폭**이다. 회전중심과 케이블 작용선 사이 모멘트 팔이 아니다. 이 문제의 B 구멍 지압에는 폭 50 mm 대신 판 두께가 쓰인다.
- AB 판 두께는 **16 mm**이고, B의 브래킷은 AB 양쪽에 귀판 한 개씩이 있는 **복전단** 연결이다.
- 도면의 **12 mm** 치수는 B 브래킷의 **각 귀판 두께**를 표시한다. 핀 지름이 아니다. 두 귀판의 지압 투영면적 합은 2(12)d이다.

### 자유물체와 일반 평형식

B = (0, 0), C = (L, 0), A = (-L cosθ, L sinθ), L = 750 mm로 둔다. 케이블의 A→C 방향벡터는

AC = L(1 + cosθ, -sinθ),

|AC| = 2L cos(θ/2),

u_AC = (cos(θ/2), -sin(θ/2)).

즉 케이블은 A에서 오른쪽 아래로 수평선과 θ/2의 각을 이룬다. AB의 자유물체에는 A의 P 아래쪽, A의 케이블 장력 T u_AC, B의 핀 반력 (B_x, B_y)가 작용한다.

ΣM_B = 0:

PL cosθ - TL sin(θ/2) = 0,

T = P cosθ/sin(θ/2).

여기서 케이블의 B에 대한 모멘트 팔은 **L sin(θ/2)**이다. 50 mm가 아니다.

ΣF_x = 0 → B_x = -T cos(θ/2),

ΣF_y = 0 → B_y = P + T sin(θ/2) = P(1 + cosθ).

이를 정리하면

(B_x, B_y) = P cot(θ/2)(-cosθ, sinθ),

**B = P cot(θ/2).**

반력이 AB축 방향으로 나오는 것은 추가 평형 확인이다. AB는 A에서 케이블력과 하중의 합력을 받고 B에서 그 반력을 받으므로 압축된다.

### θ = 40°, P = 9 kN 계산

|AC| = 1500 cos20° = 1409.5389 mm,

T = 9000 cos40°/sin20° = 20,157.8770 N,

B_x = -18,942.2083 N, B_y = +15,894.4000 N,

B = 9000 cot20° = 24,727.2968 N.

모멘트 검산: PL cos40° = TL sin20° = 5.17079999 × 10⁶ N·mm. 핀 각 전단면과 브래킷 각 귀판은 B/2 = 12,363.6484 N을 전달한다.

(a) 핀 허용 평균 전단응력 120 MPa:

τ_B = B/(2πd²/4) ≤ 120,

d_min = √[2B/(π·120)] = 11.45348784 mm.

(b) AB의 B 구멍 지압:

A_b,AB = 16d_min = 183.2558054 mm²,

σ_b,AB = B/(16d_min) = 134.93322 MPa.

(c) B 브래킷의 두 귀판 지압:

A_b,bracket,total = 2(12)d_min = 274.8837082 mm²,

σ_b,bracket = B/[2(12)d_min] = 89.95548 MPa.

**답: (a) d_min = 11.5 mm, (b) σ_b,AB = 135 MPa, (c) σ_b,bracket = 90.0 MPa.** (b), (c)는 반올림 전 이론적 최소 지름에 대응한다. 실제로 d = 11.5000 mm를 채택하여 다시 계산한 값과 미세하게 다른 것은 정상이다.

**제안과 충돌:** 86.8 kN의 수평 링크력, B = 87.2 kN, d = 21.5 mm 및 AB 지압 253.6 MPa는 도면과 다른 하중 전달 모형에서 나온 값이므로 채택하지 않는다. 복전단이라는 판단만 일치한다. 브래킷 두께는 미상이 아니라 도면상 각 12 mm로 확인된다.

## 1.25 θ = 60°에서 최대 하중

**원문 확인:** PDF 3쪽 1.25 첫 줄 오른쪽의 핀 지름 숫자는 **10**으로 판독된다. 뒤의 단위 부분은 페이지 오른쪽에서 잘렸지만 다음 줄의 '직경 핀' 문구와 함께 B의 지름 10 mm 핀 조건으로 읽힌다. 그림의 12 mm는 위에서 확인한 브래킷 판 두께이다. 본문은 핀 전단 120 MPa, B 브래킷 **그리고 부재 AB**의 평균 지압 90 MPa를 제한한다. 브래킷의 허용 지압 90 MPa도 뒤의 공통 서술에서 확인된다.

**자유물체:** 1.24와 동일한 AB, P, 케이블 T, 핀 반력이다. θ = 60°에서는

B = P cot30° = √3 P = 1.73205081P,

T = P cos60°/sin30° = P,

B_x = -(√3/2)P, B_y = (3/2)P.

각 파손 모드가 허용하는 B를 먼저 구한다. d = 10 mm, t_AB = 16 mm, 각 t_bracket = 12 mm이다.

| 제한 모드 | 사용 면적 | 허용 핀력 B (N) | 대응 P 한계 (kN, 반올림 전) |
|---|---:|---:|---:|
| 핀 복전단, τ ≤ 120 MPa | 2π(10)²/4 = 157.07963 mm² | 18,849.5559 | 10.8827962 |
| AB 지압, σ_b ≤ 90 MPa | 10(16) = 160 mm² | 14,400 | 8.31384388 |
| 브래킷 지압, σ_b ≤ 90 MPa | 2(10)(12) = 240 mm² | 21,600 | 12.4707658 |

P_max = min(10.8827962, 8.31384388, 12.4707658) = 8.31384388 kN.

이 하중에서 B = 14,400 N, T = 8313.84388 N이며, 각 조건을 다시 대입하면

τ_pin = 14,400/157.07963 = 91.67325 MPa < 120 MPa,

σ_b,AB = 14,400/160 = 90.0 MPa,

σ_b,bracket = 14,400/240 = 60.0 MPa < 90 MPa.

**답: P_max = 8.31 kN, AB의 지압이 지배한다.** 제안의 1.33 kN은 수정한다. 지배 모드의 이름은 같지만, 기하에 따른 B/P와 핀 지름 입력이 다르다.

판독의 영향을 분리하기 위한 참고 계산: 만약 다른 원본에서 핀 지름이 실제로 12 mm로 확인된다면 동일한 올바른 기하로 P_max = 90(12)(16)/√3 = 9.98 kN이다. 이것은 0910 스캔에서 판독한 10 mm 조건의 답을 대체하지 않으며, 어느 경우에도 제안의 1.33 kN이 되지 않는다.

## 1.26 압축 링크의 핀 지름과 지압

링크 몸통의 총단면적 A₀ = bt = 50(6) = 300 mm²,

N = σA₀ = -140(300) = -42,000 N.

(a) 단전단 면적과 지름:

(b) 링크 구멍의 지압면적 A_b = dt = 25.85441473(6) = 155.1264884 mm²,

**답: (a) d = 25.9 mm, (b) σ_b = 271 MPa.** 제안값에 동의한다.

## 1.27 P1.7의 B 연결부

**입력 근거:** PDF 3쪽 1.27 본문은 (a) 'B의 핀에서의 평균 지압응력', (b) BD의 B 지압, (c) ABC의 B 지압을 명시한다. ABC 단면 10 × 50 mm도 확인된다. 원도면 P1.7은 이번에 열지 않았으므로 다음 입력은 `PROBLEM.md`에 의존한다: A에서 위쪽 20 kN, AB = 0.25 m, BC = 0.40 m, BD 링크 두 장의 두께 각 8 mm, 링크 폭 36 mm, 핀 d = 16 mm, ABC를 가운데에 두고 양쪽에 BD 링크가 한 장씩 있는 배치.

**강체봉 ABC의 자유물체:** x 오른쪽, y 위쪽. B_y와 C_y를 봉에 작용하는 수직 힘의 대수값으로 둔다.

ΣM_B = 0: -20(0.25) + C_y(0.40) = 0 → C_y = +12.5 kN,

ΣF_y = 0: 20 + B_y + 12.5 = 0 → B_y = -32.5 kN.

따라서 BD 링크쌍은 합계 32.5 kN의 인장력을 전달하며, 동일한 각 링크에는 16.25 kN이 걸린다. CE 링크쌍은 합계 12.5 kN 압축이다. **32.5 kN은 BD 링크 한 장의 힘이 아니다.**

### (a)를 전단응력으로 읽는 경우

B 핀은 중앙 ABC와 바깥 두 BD 링크 사이에 전단면이 두 개 있다.

A_pin = π(16)²/4 = 201.06193 mm²,

τ_B = 32,500/(2A_pin) = 80.82087 MPa.

**(a-전단) 답: 80.8 MPa.**

### (b) BD 링크의 지압

각 링크의 지압 투영면적은 d t_BD = 16(8) = 128 mm²이다.

σ_b,BD = 16,250/128 = 32,500/[2(16)(8)] = 126.953125 MPa.

**(b) 답: 127 MPa.** 링크 폭 36 mm는 구멍을 통과하는 축 인장 순단면적에는 관계되지만, 여기서 묻는 핀 지압면적에는 쓰지 않는다.

### (c) 중앙 부재 ABC의 지압

ABC는 총 핀력 32,500 N을 받는다. 핀 축방향의 판 두께는 10 mm이다.

A_b,ABC = 16(10) = 160 mm²,

σ_b,ABC = 32,500/160 = 203.125 MPa.

**(c) 답: 203 MPa.** 단면의 다른 변 50 mm는 여기서 dt의 t가 아니다.

### 원문의 (a)를 문자 그대로 지압응력으로 읽는 경우

핀과 연결 판은 동일 접촉면에서 크기가 같은 접촉력을 서로 주고받는다. 따라서 핀의 **BD 접촉 구간** 평균 지압은 각 127 MPa, 핀의 **ABC 접촉 구간** 평균 지압은 203 MPa이다. 전체 핀에 단 하나의 평균 지압값을 부여하는 것은 접촉 구간의 구분을 빠뜨린다. '어느 접촉 구간의 평균값이 가장 큰가'를 묻는다면 **203 MPa**이다. 이는 실제 접촉압력 분포의 국부 최대값이라는 뜻은 아니다.

**제안 대조:** 80.8 / 127 / 203 MPa의 계산은 모두 일치한다. 다만 '지압'을 '전단'의 오타라고 확정하지 않는다. 스캔에는 지압으로 인쇄되어 있고, 다른 판본의 문구는 이번 blind 범위에서 직접 확인하지 못했다. 위 두 해석을 구분하여 보존한다.

## 1.28 목재 끝의 강철봉

**도면·입력:** PDF 3쪽 P1.28. 목재 폭 w = 75 mm, 두께 t = 18 mm, 봉 지름 d = 12 mm. 봉의 양 끝에는 각각 2.25 kN이 작용하여 합계 4.50 kN이 목재에 전달된다. 반대쪽 목재의 축하중 4.50 kN과 평형이다.

(a) **구멍을 지나는 목재 인장 단면의 자유물체:** 내부 축력 N = 4500 N. 봉이 통과하여 빠진 폭 d를 제외한 두 인장 인대의 순단면적 합을 사용한다.

A_net = (w - d)t = (75 - 12)(18) = 1134 mm²,

σ_max,avg = 4500/1134 = 3.968254 MPa.

비교용 몸통 평균응력은 4500/[75(18)] = 3.33333 MPa이므로 구멍 단면의 평균 인장응력이 더 크다. '최대 평균'은 이렇게 단면별 평균을 비교한 값이며 구멍 가장자리 응력집중 계수는 주어지지 않았다.

(b) **봉에서 끝 C 방향으로 뜯겨 나갈 목재 블록의 자유물체:** 봉 접촉력의 합계 4500 N을 그림의 두 점선 전단면이 합계로 저항한다. 각 점선면의 길이는 도면의 b, 두께는 18 mm이다.

A_s,total = 2bt = 2b(18),

τ_avg = 4500/[2b(18)] = 620 kPa = 0.620 MPa,

b = 4500/[2(18)(0.620)] = 201.612903 mm.

이는 목재의 두 전단면이며, 강철봉 자체의 핀 복전단응력을 계산한 것이 아니다.

(c) **목재-봉 접촉부:** 전체 4500 N에 대해 지압 투영면적 A_b = dt = 12(18) = 216 mm²이다.

σ_b = 4500/216 = 20.833333 MPa.

**답: (a) 3.97 MPa(인장), (b) b = 202 mm, (c) 20.8 MPa.** 제안값에 동의한다.

## 1.33 나선 용접 강관의 최대 축하중

**도면·입력:** PDF 4쪽 P1.33/P1.34 및 1.33 본문. 바깥지름 300 mm, 벽 두께 6 mm, 용접 나선은 축에 직각인 방향과 25°, 용접부 허용 수직응력 크기 50 MPa 및 전단응력 크기 30 MPa. 그림의 축하중은 아래쪽으로 가하는 **압축**이다.

### 단면과 용접 각도

r_o = 150 mm, r_i = 150 - 6 = 144 mm,

A₀ = π(r_o² - r_i²) = π(22,500 - 20,736)

= 1764π = 5541.769441 mm².

동일하게 πd_mean t = π(294)(6)로 계산된다. πd_outer t = π(300)(6)는 이 문제의 정확한 환형 단면적이 아니다.

**자유물체:** 관을 축에 수직으로 잘라 분리하면 내부 압축 합력의 크기가 P이다. 따라서 축방향 평균응력은 σ_z = -P/A₀이다.

나선 용접은 관 전체를 하나의 평면으로 비스듬히 자른 접착 이음과는 형상이 다르다. 관벽을 국소적으로 펼쳐 축방향 z와 원주방향 s를 잡는다. 용접선의 접선은 원주방향과 β = 25°, 관벽 안에서 용접선을 가로지르는 법선은 축방향과 β = 25°이다. 축압축만 있는 응력장에서 이 국소 방향으로 응력 성분을 분해하면

σ_n = -(P/A₀)cos²25°,

|τ_nt| = (P/A₀)sin25°cos25°.

이는 국소 절단면의 축수직 투영면적 관계 dA₀ = dA_w cos25°와 합력 분해로도 얻어진다. 25°를 65°로 바꾸지 않는다.

cos²25° = 0.8213938048,

sin25°cos25° = 0.3830222216.

### 두 허용조건을 각각 적용

수직응력 제한:

P_σ = 50A₀/cos²25° = 337,339.3741 N = 337.3393741 kN.

전단응력 제한:

P_τ = 30A₀/(sin25°cos25°) = 434,055.9734 N = 434.0559734 kN.

P_max = min(P_σ, P_τ) = 337.3393741 kN.

검산: 이때 축응력은 -60.87214 MPa, 용접부 수직응력은 -50.0000 MPa, 전단응력 크기는 23.31538 MPa < 30 MPa이다.

**답: P_max = 337 kN(압축), 용접부 수직응력 제한이 지배한다.** 제안값에 동의한다. 주어진 응력 한계만 적용한 답이며, 문제에 좌굴 계산에 필요한 관 길이·지지조건은 없다.

**추가 산술 충돌:** `PROBLEM.md`의 1.30에는 '매뉴얼은 525 kPa → 6.62 kN / 0.303 MPa'라고 되어 있다. 그러나 같은 75 × 125 mm 단면 및 α = 30°에서 525 kPa만 대입하면

P = 0.525(9375)/0.75 = 6562.5 N = **6.56 kN**,

τ = 0.525 tan30° = **0.303 MPa**.

따라서 **6.62 kN은 그 입력 조합과 산술적으로 일치하지 않는다.** 실제 매뉴얼에 다른 치수가 있는지, 제공된 대응 설명의 오기인지는 이번 자료 범위에서 알 수 없다. 이 불일치를 0910 답 6.25 kN과 혼합하지 않는다.

## 검산 및 남는 자료 한계

- 중간 계산을 JavaScript의 배정밀도 수치 연산으로 별도 재계산했다. 1.23의 포크 평형, 1.24의 두 모멘트 일치, 1.25의 세 허용응력 조건, 경사 접착면의 힘 분해/면적 투영, 1.33의 비지배 전단 한계를 확인했다.
- 핵심 충돌은 1.24/1.25의 도면 해석이다. 실제 핀력 식은 B = P cot(θ/2)이며, `15P sinθ`의 수평 링크력 모형은 이 도면에 적용되지 않는다.
- 1.23(a)의 잘린 문구 및 1.27(a)의 인쇄된 '지압'은 전단 풀이와 구분하여 기록했다. 다른 판본을 보지 않았으므로 번역 오타의 원인이나 교정 이력을 단정하지 않는다.
- 1.27 결과는 `PROBLEM.md`가 준 P1.7의 링크 배치·치수를 전제로 한다. 매뉴얼 대응 번호·입력의 출처 수준은 위 표에 명시했으며, 확인되지 않은 서지 연도와 미제공 대응 번호는 알 수 없다고 남겼다.
