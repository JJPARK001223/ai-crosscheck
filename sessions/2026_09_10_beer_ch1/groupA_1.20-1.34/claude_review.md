## 1.24 / 1.25 — 그림 재해석 (Codex 수정 수용, 잔여 불확실 표시)

**Codex 판독 (신규 렌더링 기반)**:
- B에 핀 지지되는 부재 = **AB**. A→C 가는 부재 = **케이블(2력 부재) AC**.
- **θ = AB와 수평선 사이 각** (연직 아님).
- 두 "750 mm" = AB 핀중심 길이 750, 수평 지지점 간 BC = 750. 케이블 길이는 750 아님.
- **"50 mm" = AB 판의 면내 폭** (모멘트 팔 아님).
- **"12 mm" = B 브래킷 각 귀판 두께** (핀 지름 아님). AB 두께 = 16 mm. 핀 B = 복전단.
- ΣM_B: P·L cosθ = T·L sin(θ/2) → T = P cosθ/sin(θ/2). **|B 핀력| = P·cot(θ/2)** (AB축 방향).

**1.24 (θ=40°, P=9 kN)**: B = 9·cot20° = **24.73 kN**.
- (a) 핀 복전단, τ≤120: d_min = √(2B/(π·120)) = √(2·24727/376.99) = **11.5 mm**.
- (b) σ_b(AB) = B/(16·d) = 24727/(16·11.453) = **135 MPa**.
- (c) σ_b(브래킷 2귀판) = B/(2·12·d) = 24727/(2·12·11.453) = **90.0 MPa**.

**1.25 (θ=60°, 핀 d=10 mm — 본문에서 Codex가 판독)**: B = P·cot30° = √3·P.
- 핀 복전단 τ≤120: B ≤ 2·(π/4·10²)·120 = 18,850 → P ≤ 10.88 kN.
- AB 지압 σ_b≤90: B ≤ 90·(10·16) = 14,400 → P ≤ **8.31 kN** (지배).
- 브래킷 지압 σ_b≤90: B ≤ 90·(2·10·12) = 21,600 → P ≤ 12.47 kN.

**Claude 판단**: Codex의 신규 렌더링 기반 해석이 내 blind(벨크랭크 15 P sinθ)보다 신뢰도 높음.
Codex 식 B = P cot(θ/2)는 자체 일관(모멘트·힘 평형 검산됨). **수용**.
- **다만 잔여 불확실**: ① θ가 수평 기준이 맞는지(그림상 θ 여는 선이 완전 수평은 아님 — 수직 기준이면 sinθ↔cosθ, B = P cot((90°−θ)/2)),
  ② "50 mm"가 실제로 미사용(무관 치수)인지 — Beer가 무관한 치수를 표기하는 건 이례적. Codex가 codex_review 에서 재확정 요망.
- HTML에는 Codex 모형 + "그림 해석에 의존, 대안 존재" 명시.
