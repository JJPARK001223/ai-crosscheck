## 세부 근거

### 1.37/1.38 — 브래킷 AD + 링크 BC (0910 전용)
- 그림 P1.37&P1.38 (0910): 상단 수평선에 A(좌)·B(우), 600 mm. A에서 경사 부재 AD 아래로.
  AD 위 점 C (A에서 480 mm)에 짧은 링크 BC 가 B와 연결, **BC ⊥ AD (그림에 90° 표기)**. 끝 D에 P 아래로.
- BC⊥AD 조건: cos β = 480/600 = 0.8 (β = AD의 수평 아래 각 = 36.87°). C = (384, −288).
- D는 B 바로 아래(그림) → D = (600, −450), AD 길이 750.
- 부재 AD ΣM_A: F_BC·480 = P·600 → **F_BC = 1.25 P** (인장).
- 1.37: F_BC = 20 kN, 링크 단면 25×6 = 150 mm², σ_u = 480 → FS = 480·150/20000 = **3.60**.
- 1.38: F_BC = 25 kN, σ_u = 450, FS = 3 → σ_all = 150, A = 166.7, w = **27.8 mm**.

### 1.39/1.40 — 트러스 (0910 전용)
- 그림 P1.39,P1.40: 벽에 A(위)·C(아래). B는 우측, A보다 0.4 m 아래. C는 A보다 1.4 m 아래.
  A→B 수평 0.75 m. 하중 28 kN ↓ at B.
- A=(0,0), B=(0.75,−0.4), C=(0,−1.4). AB 길이 0.85 (8-15-17), 대각재("AC"=CB) 길이 1.25 (3-4-5).
- 절점 B 평형 → **F_AB = +17 kN (인장), |F_AC| = 25 kN (압축)**.
- 재료 극한: 20 mm 사각봉 실험 120 kN → σ_ult = 120000/400 = **300 MPa**.
- 1.39: (a) AB 15 mm 사각 → A = 225. FS = 300·225/17000 = **3.97**. (b) AC 같은 FS → A = 3.97·25000/300 = 330.9 → 변 **18.2 mm**.
- 1.40: FS = 3.2 → σ_all = 93.75. AB: A = 17000/93.75 = 181.3 → 변 **13.5 mm**. AC: A = 266.7 → 변 **16.3 mm**.
- 주: 문제는 "부재 AB 및 AC"라 부르지만 도면상 대각재는 C–B 연결. "AC"로 표기하되 = 하중점 B 와 벽 하부 C 사이 부재.

### 1.49 — 콘크리트 슬라브 강철판 앵카 (767 교재로 복구)
- 767 교재 1.49 (전체 문장): 판 두께 8 mm, 구멍 지름 20 mm, 강 극한강도 250 MPa,
  **판–콘크리트 극한 접합응력 2 MPa**, P = 10 kN, FS 3.60.
- (a) 강판 순단면 파손: A_net = (a − 20)·8. FS = σ_u·A_net/P → A_net = FS·P/σ_u = 3.6·10000/250 = 144 mm².
  (a − 20)·8 = 144 → **a = 38.0 mm**.
- (b) 접합 파손: 박힌 판의 두 큰 면(각 a × b)이 콘크리트에 접합. 총 접합면적 = 2ab.
  (아래 가장자리 수직응력 무시.) FS = τ_u·(2ab)/P → 2ab = FS·P/τ_u = 3.6·10000/2 = 18000 mm².
  b = 18000/(2·38) = **236.8 mm ≈ 237 mm**.
