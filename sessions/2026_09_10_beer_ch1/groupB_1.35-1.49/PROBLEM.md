## 1.35 — 화강암 블록, 최대 응력 (P = 1060 kN)
그림과 같이 화강암 블록에 \(1060\ \text{kN}\)의 하중 P가 작용. (a) 수직응력, (b) 전단응력의 최대값, 그리고
이들 최대값이 발생하는 면의 방향을 명시.
그림 P1.35 & P1.36: 정사각 단면 **\(140 \times 140\ \text{mm}\)** 기둥.
- \(A_0 = 140^2 = 19\,600\ \text{mm}^2\).
- (a) \(\sigma_{\max} = P/A_0 = 1\,060\,000/19\,600 = 54.08\ \text{MPa}\) (압축), 면의 방향 \(\theta = 0°\)(축에 수직).
- (b) \(\tau_{\max} = P/(2A_0) = 27.04\ \text{MPa}\), \(\theta = 45°\).
- **제안: σ_max ≈ 54.1 MPa, τ_max ≈ 27.0 MPa.**

## 1.36 — 화강암 블록, 하중 역산 (τ = 18 MPa)
중심하중 P가 블록에 작용. 블록에 발생한 (최대) 전단응력이 \(18\ \text{MPa}\)라면,
(a) 하중 P의 크기, (b) 최대 전단응력 발생 면의 방향, (c) 그 면에 발생하는 수직응력, (d) 블록의 최대 수직응력.
- \(A_0 = 19\,600\ \text{mm}^2\), \(\tau_{\max} = 18\ \text{MPa}\).
- (a) \(P = 2A_0\tau_{\max} = 2(19\,600)(18) = 705\,600\ \text{N} = 706\ \text{kN}\).
- (b) \(\theta = 45°\). (c) \(\sigma_{45°} = -P/(2A_0) = -18\ \text{MPa}\). (d) \(\sigma_{\max} = -P/A_0 = -36.0\ \text{MPa}\).
- **제안: P ≈ 706 kN, θ=45°, σ_45 = −18 MPa, σ_max = −36.0 MPa.**

## 1.37 — 브래킷 링크 BC, 안전계수 (P = 16 kN)
링크 BC 두께 \(6\ \text{mm}\), 폭 \(w = 25\ \text{mm}\), 극한 인장강도 \(480\ \text{MPa}\).
\(P = 16\ \text{kN}\)의 하중을 지탱하도록 설계 시 안전계수는?
그림 P1.37 & P1.38: 상단 수평(벽) 위에 A(좌), B(우), \(600\ \text{mm}\) 간격. A에서 경사 부재 AD가 아래로.
그 부재 위의 점 C(A에서 \(480\ \text{mm}\))에 짧은 링크 BC가 B와 연결, BC ⊥ AD (90°). 끝 D에 하중 P 아래로. D는 B 바로 아래.
**Claude 기하**: AD 경사각 \(\cos\beta = 480/600 = 0.8\) (BC⊥AD 조건에서). D_x = 600 → 부재 AD 길이 750.
- 부재 AD ΣM_A: \(F_{BC}(480) - P(600) = 0\) → \(F_{BC} = 1.25 P\) (인장).
- 1.37: \(F_{BC} = 20\ \text{kN}\). \(A_{BC} = 25 \times 6 = 150\ \text{mm}^2\).
  \(P_{\text{ult}}(\text{link}) = 480 \times 150 = 72\,000\ \text{N}\). **FS = 72000/20000 = 3.6**.
- **제안: FS ≈ 3.60.** (기하: BC⊥AD, D 아래 B — Codex 그림 확인.)

## 1.38 — 브래킷 링크 BC, 폭 결정 (FS = 3, P = 20 kN)
같은 링크 BC 두께 \(6\ \text{mm}\), 극한 인장강도 \(450\ \text{MPa}\). 안전계수 3으로 \(P = 20\ \text{kN}\) 지탱 설계 시 폭 w?
- \(F_{BC} = 1.25 \times 20 = 25\ \text{kN}\). \(\sigma_{\text{allow}} = 450/3 = 150\ \text{MPa}\).
- \(A = F_{BC}/\sigma_{\text{allow}} = 25\,000/150 = 166.7\ \text{mm}^2\). \(w = A/6 = 27.8\ \text{mm}\).
- **제안: w ≈ 27.8 mm.**

## 1.39 — 트러스 AB·AC, AB 안전계수 + AC 치수
트러스 부재 AB 및 AC(=BC), 동일 합금 사각단면. 동일 합금 \(20\ \text{mm}\) 사각봉을 파단까지 실험 → 극한하중 \(120\ \text{kN}\).
봉 AB가 \(15\ \text{mm}\) 사각단면일 때, (a) 봉 AB의 안전계수, (b) 봉 AC가 봉 AB와 같은 안전계수를 갖는다면 봉 AC의 단면 치수.
그림 P1.39, P1.40: 벽에 A(위)·C(아래). \(A\!\to\!B\) 수평 \(0.75\ \text{m}\), B는 A보다 \(0.4\ \text{m}\) 아래, C는 A보다 \(1.4\ \text{m}\) 아래.
하중 \(28\ \text{kN}\) 아래로 B에.
**Claude 기하**: A=(0,0), B=(0.75, −0.4), C=(0, −1.4). AB 길이 0.85 (15-8-17), CB 길이 1.25 (3-4-5).
- 절점 B 평형 → \(F_{AB} = +17\ \text{kN}\) (인장), \(F_{BC} = -25\ \text{kN}\) (압축, |F|=25).
- 재료 극한: \(\sigma_{\text{ult}} = 120\,000/(20 \times 20) = 300\ \text{MPa}\).
- (a) AB: \(A = 15^2 = 225\ \text{mm}^2\). \(P_{\text{ult}} = 300 \times 225 = 67\,500\ \text{N}\). **FS = 67500/17000 = 3.97**.
- (b) AC(=BC): \(|F| = 25\ \text{kN}\). \(A_{AC} = \text{FS} \times |F|/\sigma_{\text{ult}} = 3.97 \times 25\,000/300 = 330.9\ \text{mm}^2\).
  변 = \(\sqrt{330.9} = 18.2\ \text{mm}\).
- **제안: (a) FS ≈ 3.97, (b) AC 변 ≈ 18.2 mm.**

## 1.40 — 트러스 AB·AC, 각 봉 FS = 3.2
같은 트러스. 각 봉에 대하여 \(3.2\)의 안전계수. (a) 봉 AB, (b) 봉 AC의 단면 필요 치수.
- \(\sigma_{\text{allow}} = 300/3.2 = 93.75\ \text{MPa}\).
- (a) AB: \(A = 17\,000/93.75 = 181.3\ \text{mm}^2\). 변 = \(\sqrt{181.3} = 13.5\ \text{mm}\).
- (b) AC: \(A = 25\,000/93.75 = 266.7\ \text{mm}^2\). 변 = \(\sqrt{266.7} = 16.3\ \text{mm}\).
- **제안: AB 변 ≈ 13.5 mm, AC 변 ≈ 16.3 mm.**

## 1.41 — 링크 AB 단면적 (FS, σ_ult = 450 MPa)
링크 AB는 극한 수직응력 \(450\ \text{MPa}\)인 강. 안전계수가 [잘림 — 매뉴얼은 3.50]일 때 링크 AB의 단면적.
단, 링크는 A와 B의 핀 주위에서 적절하게 강화(순단면 감소 무시).
그림 P1.41: 수평 보, 좌측 위에 링크 AB (\(35°\)), 보 위에 등분포하중 \(8\ \text{kN/m}\) (구간 \(B\!\to\!D\)?), C에 집중하중 \(20\ \text{kN}\) 아래.
점 B, C, D, E, 간격 \(0.4 + 0.4 + 0.4\ \text{m}\). D에 핀(받침).
**Claude(매뉴얼 1.42 방식)**: \(w = (1.2)(8) = 9.6\ \text{kN}\) (등분포 합력, B~E 1.2 m 구간).
ΣM_D: \(-0.8(F_{AB}\sin 35°) + 0.2(9.6) + 0.4(20) = 0\) → \(F_{AB} = 21.62\ \text{kN}\).
- \(A_{AB} = \text{FS} \times F_{AB}/\sigma_{\text{ult}} = 3.50 \times 21\,620/450 = 168.1\ \text{mm}^2\).
- **제안: A_AB ≈ 168 mm² (FS = 3.50 가정 — Codex가 0910 스캔에서 FS 확인).**

## 1.42 — 강철 루프 ABCD, 최대 하중 Q (FS = 3)
\(24\ \text{mm}\) 직경 알루미늄 봉 AC 주위를 길이 \(1.2\ \text{m}\), \(10\ \text{mm}\) 직경 강철 루프 ABCD가 감고 있다.
\(12\ \text{mm}\) 직경 케이블 BE 및 DF가 하중 Q 작용에 사용. 강철(루프·케이블) 극한강도 \(480\ \text{MPa}\),
알루미늄(봉 AC) 극한강도 \(260\ \text{MPa}\), 안전계수 \(3.0\). 최대 하중 Q.
그림 P1.42: 마름모 ABCD (B 위, D 아래, A 좌, C 우). 수평 대각 \(A\!\to\!C\) = 봉 AC. 수직으로 케이블 BE(위, Q) 및 DF(아래, Q').
\(240 + 240\ \text{mm}\) (E~B~? 수평), \(180 + 180\ \text{mm}\) (수직). 즉 마름모 반대각 \(2 \times 240\) 수평, \(2 \times 180\) 수직.
**Claude(매뉴얼 1.37 방식)**: 절점 B: \(2 \cdot \tfrac{3}{5} F_{AB} = Q\) → \(Q = \tfrac{6}{5}F_{AB}\).
절점 A: \(2 \cdot \tfrac{4}{5} F_{AB} = F_{AC}\) → \(F_{AC} = \tfrac{4}{5}\cdot\tfrac{5}{6}Q \cdot 2 = ...\); 정리하면 \(Q = \tfrac{3}{4}F_{AC}\).
루프 대각변: 수평 240, 수직 180 → 길이 300 (3-4-5). \(\sin = 180/300 = 0.6\), \(\cos = 0.8\).
- 케이블 BE: \(Q_u = \sigma_u A = 480 \times \tfrac{\pi}{4}(12)^2 = 480 \times 113.10 = 54\,290\ \text{N}\).
- 강철 루프: \(Q_u = \tfrac{6}{5}F_{AB,u} = \tfrac{6}{5}\sigma_u\tfrac{\pi}{4}(10)^2 = \tfrac{6}{5}(480)(78.54) = 45\,240\ \text{N}\).
- 알루미늄 봉 AC: \(Q_u = \tfrac{3}{4}F_{AC,u} = \tfrac{3}{4}(260)\tfrac{\pi}{4}(24)^2 = \tfrac{3}{4}(260)(452.39) = 88\,220\ \text{N}\).
- \(Q_u = \min = 45\,240\ \text{N}\). \(Q = Q_u/3 = 15\,080\ \text{N}\).
- **제안: Q ≈ 15.08 kN (강철 루프 지배).** (매뉴얼 1.37 동일.)

## 1.43 — 이중 겹판 이음, 길이 L (FS = 2.75)
하중 \(16\ \text{kN}\) 지탱하는 두 목재 부재가 접촉면 전체를 접착제로 붙인 이중 겹판(plywood splice plate)으로 결합.
접착부 극한 전단응력 \(2.5\ \text{MPa}\), 부재 간극 \(6\ \text{mm}\). 안전계수 \(2.75\)라면 양쪽 겹판 길이 L.
그림 P1.43 & P1.44: 겹판 두 장, 각 폭 \(125\ \text{mm}\), 길이 L, 부재 사이 간극 \(6\ \text{mm}\).
**Claude(매뉴얼 1.43)**: 겹판 접착면 **4개**, 각각 하중의 절반 \(8\ \text{kN}\) 전달. \(P_u = \text{FS} \times 8 = 22\ \text{kN}\).
\(\ell = P_u/(\tau_u w) = 22\,000/(2.5 \times 125) = 70.4\ \text{mm}\). \(L = 2\ell + \text{간극} = 2(70.4) + 6 = 146.8\ \text{mm}\).
- **제안: L ≈ 147 mm** (매뉴얼 146.8 mm).

## 1.44 — 이중 겹판 이음, 안전계수 (L = 180 mm)
연습문제 1.43에서 겹판 길이 \(L = 180\ \text{mm}\)일 때 안전계수.
**Claude(매뉴얼 1.44)**: \(\ell = (L - \text{간극})/2 = (180 - 6)/2 = 87\ \text{mm}\). \(A = \ell w = 87 \times 125 = 10\,875\ \text{mm}^2\).
\(P_u = \tau_u A = 2.5 \times 10\,875 = 27\,187.5\ \text{N}\). \(\text{FS} = P_u/8000 = 3.40\).
- **제안: FS ≈ 3.40** (매뉴얼 동일).

## 1.45 — 천장 매단 목재의 핀, 허용하중 P (FS = 3.2)
천장에 고정된 짧은 목재 부재를 관통하는 강재 핀에 하중 P (양쪽 \(\tfrac{1}{2}P\)). 목재 극한: 인장 \(60\ \text{MPa}\),
전단 \(7.5\ \text{MPa}\); 강 극한 전단 \(145\ \text{MPa}\). \(b = 40\), \(c = 55\), \(d = 12\ \text{mm}\), FS \(3.2\). 허용하중 P.
그림 P1.45: 목재 부재 폭 \(w = 40\ \text{mm}\), 핀 위 목재 높이 \(b\)(인장), 핀 아래 \(c\)(전단), 핀 지름 \(d\). \(\tfrac12 P\) 씩 양옆.
**Claude(매뉴얼 1.47/1.48)**:
- 핀 복전단: \(P_u = 2 \cdot \tfrac{\pi}{4}(12)^2 \cdot 145 = 32\,800\ \text{N}\).
- 목재 인장(순단면): \(P_u = w(b-d)\sigma_u = 40(40-12)(60) = 67\,200\ \text{N}\).
- 목재 복전단: \(P_u = 2wc\tau_u = 2(40)(55)(7.5) = 33\,000\ \text{N}\).
- \(P_u = \min = 32\,800\ \text{N}\) (핀). \(P = P_u/3.2 = 10\,250\ \text{N}\).
- **제안: P ≈ 10.25 kN (핀 전단 지배).**

## 1.46 — 위 문제, d=16, P=20 → FS, b, c
연습문제 1.45에서 핀 지름 \(d = 16\ \text{mm}\), \(P = 20\ \text{kN}\)일 때, (a) 핀의 안전계수, (b) 목재 부재의 안전계수가
(a)의 핀 안전계수와 같을 때 필요한 b, c.
**Claude**:
- (a) 핀: \(P_u = 2\tfrac{\pi}{4}(16)^2(145) = 58\,310\ \text{N}\). \(\text{FS} = 58\,310/20\,000 = 2.92\).
- (b) 목재 인장: \(b = d + \dfrac{\text{FS}\cdot P}{w\sigma_u} = 16 + \dfrac{2.92(20\,000)}{40(60)} = 16 + 24.3 = 40.3\ \text{mm}\).
      목재 전단: \(c = \dfrac{\text{FS}\cdot P}{2w\tau_u} = \dfrac{2.92(20\,000)}{2(40)(7.5)} = 97.2\ \text{mm}\).
- **제안: (a) FS ≈ 2.92, (b) b ≈ 40.3 mm, c ≈ 97.2 mm.**

## 1.47 — 강판 3볼트, 볼트 지름 (FS = 3.35)
강판이 목재 보에 세 개의 강재 볼트로 고정. 판이 \(110\ \text{kN}\) 하중 지지, 강 극한 전단응력 \(360\ \text{MPa}\), 안전계수 \(3.35\).

**Claude(매뉴얼 1.46)**: 볼트당 하중 \(110/3 = 36.667\ \text{kN}\). \(P_u = \text{FS} \times 36.667 = 122.83\ \text{kN}\).
\(d = \sqrt{4 P_u/(\pi \tau_u)} = \sqrt{4(122\,830)/(\pi \cdot 360)} = 20.8\ \text{mm}\).
- **제안: d ≈ 20.8 mm.**

## 1.49 — 콘크리트 슬라브 강철판 앵카 (FS = 3.60, P = 10 kN)  ★잘림 — Codex가 767 교재로 보완

(a) 판의 폭 [a], (b) 콘크리트에 장착되는 판재의 최소 깊이 b. (슬라브와 판재 아래 가장자리 사이 수직응력 무시.)
