## 1.59 — 뼈 안지름
A = P/σ = 1200 N / 3.80 MPa = 315.79 mm²
A = (π/4)(D_o² - D_i²) → D_i² = D_o² - 4A/π = 625 - 4(315.79)/π = 625 - 402.06 = 222.94
**D_i = 14.93 mm**

## 1.60 — 링크 AB, BC 응력
힘의 삼각형 (조인트 B, 합력 40kN 수평, AB와 40kN 사이각 45°, BC와 40kN 사이각 60°, 두 링크 사이각 95°):
F_AB/sin45° = F_BC/sin60° = 40/sin95°
F_AB = 40×sin45°/sin95° = 40×0.70711/0.99619 = 28.39 kN (인장)
F_BC = 40×sin60°/sin95° = 40×0.86603/0.99619 = 34.77 kN (압축)

(a) 링크AB 순단면적(핀구멍 20mm 차감, 인장): A_net=(45-20)(12)=300mm² → σ_AB=28390/300= **94.6 MPa**
(b) 링크BC 전체단면적(압축, 구멍 무관): A=(45)(12)=540mm² → σ_BC=-34770/540= **-64.4 MPa**

→ 767 매뉴얼(94.7/-64.4)과 일치 (반올림 차이).

## 1.61 — 핀 C 전단·지압
F_BC=34.77kN, 핀 지름 20mm, A_pin=(π/4)(20²)=314.16mm²
(a) 핀C 복전단: τ=34770/(2×314.16)= **55.34 MPa**
(b) BC의 C에서 지압(단일면, t=12mm): σb=34770/(12×20)= **144.9 MPa**
(c) BC의 B에서 지압(두 겹이라 지압면 2배): σb=34770/(2×12×20)= **72.4 MPa**

→ 767 매뉴얼(55.3/144.9/72.4)과 일치.

## 1.62 — 크레인 링크 CD
좌표(D=원점): D=(0,0), C=(0,15), A=(15,0) [A는 그림에서 D보다 오른쪽 15m, 같은 높이 — 600dpi 재렌더링 픽셀측정], B=(40,50) [C 기준 수평40m·수직35m 위 = D 기준 수평40m·수직50m].
W = 80,000×9.81 = 784,800 N = 784.8 kN (B에 연직하향)

**조인트 B** (부재 AB, CB만 만남):
B→A = (-25,-50)/55.902, B→C = (-40,-35)/53.151
평형: -0.4472 F_AB - 0.7526 F_CB = 0 (x)
     -0.8944 F_AB - 0.6586 F_CB - 784.8 = 0 (y)
→ F_AB = -1.6829 F_CB, 대입: 0.8468 F_CB = 784.8 → F_CB = 926.8 kN (인장)
F_AB = -1559.8 kN (압축)

**조인트 C** (부재 CB(기지), CA, DC):
C→B=(40,35)/53.151=(0.7526,0.6586), C→A=(15,-15)/21.213=(0.7071,-0.7071), C→D=(0,-1)
힘: F_CB가 C를 B쪽으로 당김(인장) = 926.8×(0.7526,0.6586)=(697.5,610.4)
평형: 697.5 + 0.7071 F_CA = 0 → F_CA = -986.3 kN (압축)
610.4 - F_DC - 0.7071×(-986.3) = 0 → F_DC = 610.4+697.5 = **1307.9 kN (인장)**

전역 평형 검산: 조인트A에서 R_Ay=+2092.6kN(상향), R_Dy=-F_DC=-1307.9kN → 합 784.7kN ≈ W ✓

σ_CD = 1,307,900 N / (50×150 mm²) = 1,307,900/7500 = **174.4 MPa (인장)**

## 1.63 — 합판 스플라이스 L
τ = P/(2×w×L), w=75mm, τ_allow=700kPa=0.7MPa, P=15kN
L = 15000/(2×75×0.7) = 15000/105 = **142.9 mm**

## 1.64 — 스카프이음 FS
A₀=100×60=6000mm², P/A₀=6000/6000=1.0MPa
- α=20°: σ=cos²20°=0.8830MPa, τ=sin20°cos20°=0.3214MPa → FS_σ=1.26/0.8830=1.427, FS_τ=1.50/0.3214=4.667 → **FS=1.43(인장지배)**
- α=35°: σ=cos²35°=0.6710, τ=sin35°cos35°=0.4699 → FS_σ=1.878, FS_τ=3.192 → **FS=1.88(인장지배)**
- α=45°: σ=τ=0.5 → FS_σ=2.52, FS_τ=3.0 → **FS=2.52(인장지배)**
세 경우 모두 FS_σ<FS_τ → **P 증가시 항상 인장파괴 먼저 발생**

## 1.65 — 케이블 BD 안전계수
C=원점, A=(-1.2,0.6), B=(-0.4,0.6) [단위 m]
P=16kN, 방향(연직에서 40°, 아래-오른쪽): P=(P sin40°, -P cos40°)
F(케이블 BD 장력, B를 D쪽 위-오른쪽으로): F=(F cos30°, F sin30°)

ΣM_C=0 (반시계 +): x_A P_y - y_A P_x + x_B F_y - y_B F_x = 0
(-1.2)(-16cos40°) - (0.6)(16sin40°) + (-0.4)(F sin30°) - (0.6)(F cos30°) = 0
1.2×16×0.76604 - 0.6×16×0.64279 = F(0.4×0.5+0.6×0.86603)
14.7239 - 6.1708 = F×0.71962
8.5531 = 0.71962 F → F = **11.89 kN**

FS = 100/11.89 = **8.41**

(1.63 소수점 재계산에 맞춰 위 값 소폭 조정 — 최종 F≈11.9kN, FS≈8.4)

## 1.66 — 링크 CF 안전계수
아래 부재 E-F-G (E=0, F=400mm, C-F 아래, G=650mm, D와 같은 위치):
ΣM_E=0: F_CF(400) - 24(650) = 0 → F_CF = 39 kN (인장)
ΣFy=0: F_BE = 24-39 = -15 kN (압축 15kN)
→ F_CF=39kN이 지배 (문제도 CF만 질문)

링크 CF (2장, 총단면 2×10×40=800mm²): σ=39000/800=**48.75MPa**, FS_link=400/48.75=**8.21**
핀 C,F (복전단, d=20mm, A=314.16mm²): τ=39000/(2×314.16)=**62.07MPa**, FS_pin=150/62.07=**2.42**

**전체 FS = min(8.21, 2.42) = 2.42 (핀 지배)**

## 1.67 — 페달 핀 C
로드AB(2력부재,수평): 페달(B-C-D, C힌지) 모멘트평형(C기준):
F_AB×125 = P×300 → F_AB=750×300/125=1800N
C반력: Cx=1800N, Cy=750N → |C|=√(1800²+750²)=√(3,240,000+562,500)=√3,802,500=**1950 N**

(a) 복전단 τ=40MPa: 1950=2×(π/4)d²×40 → d²=1950/(2×π/4×40×10⁶)... 단위정리: d²=1950/(2×0.7854×40×10⁶)=1950/(62.83×10⁶)=31.03×10⁻⁶m²=31.03mm² → d=**5.57mm**
(b) 페달지압(t=5mm): σb=1950/(5.57×5)=1950/27.86=**70.0MPa**
(c) 브라켓지압(t=9mm, 각 975N): σb=975/(5.57×9)=975/50.14=**19.4MPa**

## 1.68 — 강화봉 L
전단: P=τ_all·πdL, 인장: P=σ_all(π/4)d² → **L_min = σ_all·d/(4τ_all)**
→ 767 매뉴얼과 정확히 일치.

## 1.69 — θ 범위 FS≥3.0
A₀=0.0015m², P=10kN, Pu=30kN(FS=3)
인장: cos²θ=σ_U A₀/Pu=17e6×0.0015/30000=0.85 → θ=arccos(√0.85)=arccos(0.9220)=**22.8°** (θ≥22.8°)
전단: sin2θ=2A₀τ_U/Pu=2×0.0015×9e6/30000=0.9 → 2θ=64.16° → θ=**32.1°** (θ≤32.1°)
**→ 22.8°≤θ≤32.1°** (767 매뉴얼과 일치)

## 1.70 — θ 최적 FS 최대
