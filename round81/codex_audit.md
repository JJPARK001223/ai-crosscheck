# B044 HTML 카드 79장 대조 감사

감사 대상은 `round81/input/b044_cards.html`의 meta에 표시된 카드 1~79이다. `round81/PROBLEM.md`, `round81/codex_A.md`, `round81/codex_B.md`를 읽고 `round81/input/b044.pdf`의 지면 이미지와 대조했다. HTML은 수정하지 않았다. 다른 AI의 연구 결과 파일은 읽지 않았다. 아래 PDF쪽은 파일의 1부터 센 쪽이며, 본문 인쇄쪽은 PDF쪽 − 11이다.

**확인된 사실:** 번호식 Eq. 1~18의 계수·항·분모·아래첨자·부호는 일치한다. Table 1~23의 값과 제목에서도 전사 불일치를 발견하지 않았다. 아래 ‘식’ 2건은 잘못된 수치가 아니라 **data-tex 전사 범위의 누락**이다. 해당 내용은 카드의 일반 문장에는 남아 있다. 반복 인쇄된 동일 식을 하나로 묶은 것과 `frac`/`dfrac`, 곱셈 기호·공백의 차이는 오류로 세지 않았다.
